    Chapter 06: CARLA 시뮬레이터 설치와 첫 주행¶

    🎯 이 장에서 배우는 것¶

    • CARLA 시뮬레이터의 역할과 자율주행 개발에서의 중요성을 설명할 수 있다
    • CARLA를 자신의 컴퓨터에 설치하고 정상 작동을 확인할 수 있다
    • Python API로 가상 세계에 차량을 생성하고 기본 조작(전진, 회전, 정지)을 할 수 있다
    • 카메라 센서를 차량에 부착하고 주행 중 이미지를 캡처하여 저장할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기: 게임 속 자동차를 키보드가 아니라 코드로 조종할 수 있다면 어떨까요?

    실제 자율주행차를 개발하려면 수만 킬로미터의 도로 테스트가 필요합니다. 하지만 진짜 차량으로 테스트하면 비용이 어마어마하고, 무엇보다 위험합니다. 벽에 부딪혀도, 신호를 무시해도, 아무도 다치지 않는 곳이 있다면요?

    CARLA 시뮬레이터가 바로 그런 공간입니다. 전 세계 자율주행 연구자들이 사용하는 오픈소스 시뮬레이터로, 현실과 매우 유사한 가상 도시에서 자유롭게 실험할 수 있습니다.

    이번 장에서 우리는 이 시뮬레이터를 직접 설치하고, Python 코드로 차량을 생성해 첫 주행을 경험합니다. 앞으로 배울 자율주행 알고리즘을 모두 이 시뮬레이터 위에서 실험하게 되니, 이번 장은 전체 과정의 출발점입니다.

    📚 핵심 개념¶

    개념 1: CARLA 시뮬레이터란?¶

    🎮 비유로 시작

    오픈월드 자동차 게임(예: GTA)을 떠올려보세요. 넓은 도시를 자유롭게 돌아다니고, 날씨가 바뀌고, 다른 차량과 보행자가 돌아다닙니다. CARLA는 이런 게임과 비슷하지만, 목적이 다릅니다. 놀기 위한 것이 아니라, 자율주행 AI를 훈련하고 테스트하기 위한 것입니다.

    📖 정확한 정의

    CARLA(Car Learning to Act)는 자율주행 연구용 오픈소스 시뮬레이터입니다. Unreal Engine 기반으로 사실적인 3D 도시 환경을 제공하며, Python API를 통해 시뮬레이터 안의 모든 요소를 프로그래밍으로 제어할 수 있습니다.

    🔍 예시로 확인

    CARLA에서 할 수 있는 것들을 살펴보겠습니다.

    • 차량 생성: 원하는 위치에 원하는 차종의 차량을 등장시킴
    • 센서 부착: 카메라, LiDAR, GPS 등 다양한 센서를 차량에 장착
    • 날씨 변경: 맑음, 비, 안개, 야간 등 환경 조건 자유롭게 설정
    • 교통 시뮬레이션: NPC(Non-Player Character) 차량과 보행자를 자동으로 움직이게 함
    graph LR A[CARLA 서버<br/>3D 가상 세계] <-->|TCP 통신| B[Python 클라이언트<br/>우리가 작성하는 코드] B --> C[차량 생성] B --> D[센서 부착] B --> E[주행 제어] B --> F[데이터 수집]

    알아보기: CARLA는 서버-클라이언트 구조입니다. CARLA 서버는 3D 세계를 실행하는 프로그램이고, 우리가 Python으로 작성하는 코드가 클라이언트입니다. 둘은 네트워크(TCP)로 통신합니다. 이 구조 덕분에 서버와 클라이언트를 서로 다른 컴퓨터에서 실행할 수도 있습니다.

    개념 2: 월드(World)와 액터(Actor)¶

    🎮 비유로 시작

    영화 촬영장을 상상해보세요. 월드(World)는 촬영장 전체(도시 세트, 조명, 날씨)이고, 액터(Actor)는 그 안에 등장하는 모든 것(배우, 자동차, 카메라)입니다. 감독(우리 코드)이 "이 배우를 저 위치에 세워라"고 명령하듯, 우리도 코드로 액터를 배치합니다.

    📖 정확한 정의

    • 월드(World): 시뮬레이터가 실행하는 가상 환경 전체. 지도(Map), 날씨, 시간 등 포함
    • 액터(Actor): 월드 안에 존재하는 모든 객체. 차량(Vehicle), 보행자(Walker), 센서(Sensor), 신호등 등
    • 블루프린트(Blueprint): 액터를 생성하기 위한 설계도. 어떤 차종인지, 어떤 색상인지 등의 정보를 담고 있음

    🔍 예시로 확인

    graph TD W[🌍 World 월드] --> M[🗺️ Map 지도<br/>Town01~Town10] W --> WE[🌤️ Weather 날씨] W --> A1[🚗 Actor: 차량] W --> A2[🚶 Actor: 보행자] W --> A3[📷 Actor: 센서] W --> A4[🚦 Actor: 신호등] A1 --> BP1[Blueprint:<br/>vehicle.tesla.model3] A3 --> BP2[Blueprint:<br/>sensor.camera.rgb]

    CARLA에서 차량을 만드는 흐름을 정리하면 이렇습니다.

    1. 블루프린트 라이브러리에서 원하는 차량 설계도를 선택
    2. 월드에서 스폰 포인트(생성 위치)를 정함
    3. 월드에 "이 설계도로 이 위치에 액터를 만들어줘"라고 요청

    개념 3: 차량 제어 — VehicleControl¶

    🎮 비유로 시작

    실제 자동차를 운전할 때 우리는 세 가지를 조작합니다. 액셀(가속 페달), 핸들(조향), 브레이크. CARLA에서도 정확히 같은 방식으로 차량을 제어합니다. 다만 발과 손 대신 코드의 숫자값으로 조작합니다.

    📖 정확한 정의

    carla.VehicleControl은 차량에 전달하는 조작 명령 객체입니다.

    • throttle (스로틀): 가속. 0.0(안 밟음) ~ 1.0(끝까지 밟음)
    • steer (조향): 핸들 방향. -1.0(왼쪽 끝) ~ 0.0(직진) ~ 1.0(오른쪽 끝)
    • brake (브레이크): 감속. 0.0(안 밟음) ~ 1.0(끝까지 밟음)
    • reverse (후진): True면 후진, False면 전진

    🔍 예시로 확인

    import carla

# 직진 가속 (스로틀 50%)
control = carla.VehicleControl(throttle=0.5, steer=0.0, brake=0.0)

# 우회전하며 천천히 전진
control = carla.VehicleControl(throttle=0.3, steer=0.5, brake=0.0)

# 급정거
control = carla.VehicleControl(throttle=0.0, steer=0.0, brake=1.0)

    생각해보기: steer 값이 0.3이면 약간 오른쪽, -0.7이면 많이 왼쪽입니다. 실제 운전처럼 가속과 조향을 동시에 줄 수도 있습니다. 급커브에서는 어떤 값 조합이 좋을까요?

    개념 4: 센서(Sensor)와 콜백(Callback)¶

    🎮 비유로 시작

    자동차에 블랙박스 카메라를 달면, 카메라가 알아서 영상을 계속 녹화합니다. 우리가 매 순간 "지금 찍어!"라고 말할 필요가 없죠. CARLA의 센서도 마찬가지입니다. 한 번 부착하면, 새로운 데이터가 생길 때마다 우리가 미리 정해둔 함수를 자동으로 호출합니다. 이 자동 호출되는 함수를 콜백(Callback)이라 합니다.

    📖 정확한 정의

    • 센서(Sensor): 차량에 부착하여 환경 데이터를 수집하는 특수 액터. RGB 카메라, 깊이 카메라, LiDAR, GNSS(GPS) 등
    • 콜백(Callback): 센서가 새로운 데이터를 생성할 때마다 자동으로 실행되는 함수. sensor.listen(콜백함수) 형태로 등록

    🔍 예시로 확인

    sequenceDiagram participant C as Python 코드 participant S as 카메라 센서 participant W as CARLA 월드 C->>S: listen(save_image) 콜백 등록 W->>S: 시뮬레이션 틱 (프레임 갱신) S->>C: save_image(image) 자동 호출 W->>S: 다음 틱 S->>C: save_image(image) 자동 호출 Note over C: 매 프레임마다 자동으로<br/>이미지 저장 함수 실행
    # 콜백 함수 정의 — 센서가 이미지를 보내올 때마다 자동 실행
def save_image(image):
    image.save_to_disk('output/%06d.png' % image.frame)

# 센서에 콜백 등록
camera_sensor.listen(save_image)

    알아보기: 콜백은 프로그래밍에서 매우 자주 쓰이는 패턴입니다. "이런 일이 발생하면, 이 함수를 실행해줘"라고 미리 약속하는 것입니다. 웹 프로그래밍의 이벤트 핸들러, 게임의 충돌 감지 함수 등도 모두 콜백입니다.

    🔨 따라하기¶

    사전 준비: 시스템 요구사항 확인¶

    CARLA를 설치하기 전에, 자신의 컴퓨터가 요구사항을 충족하는지 확인하세요.

    최소 사양 - 운영체제: Windows 10/11 또는 Ubuntu 18.04/20.04 - GPU: NVIDIA GPU (GTX 1060 이상, VRAM 4GB 이상) - RAM: 8GB 이상 - 저장공간: 20GB 이상 여유 - Python: 3.7 이상 (Chapter 4에서 설치 완료)

    권장 사양 - GPU: RTX 2070 이상 (VRAM 8GB 이상) - RAM: 16GB 이상

    ⚠️ NVIDIA GPU가 없는 경우: 인텔 내장 그래픽이나 AMD GPU로는 CARLA 실행이 매우 어렵습니다. 이 경우 클라우드 GPU 서비스(Google Cloud, AWS)를 고려하거나, 품질 설정을 최저로 낮춰야 합니다.

    Step 1: CARLA 시뮬레이터 다운로드 및 설치¶

    CARLA는 별도 설치 프로그램 없이, 압축 파일을 다운로드하고 풀면 끝입니다.

    1-1. CARLA 공식 GitHub에서 다운로드

    CARLA의 릴리즈 페이지(https://github.com/carla-simulator/carla/releases)에 접속합니다.

    이 교재에서는 CARLA 0.9.15 버전을 기준으로 설명합니다. 릴리즈 목록에서 CARLA_0.9.15를 찾습니다.

    Windows 사용자: CARLA_0.9.15_Windows.zip 다운로드 Linux 사용자: CARLA_0.9.15_Linux.tar.gz 다운로드

    파일 크기가 약 15~20GB이므로 안정적인 인터넷 환경에서 다운로드하세요.

    1-2. 압축 해제

    Windows의 경우, 다운로드한 zip 파일을 간단한 경로에 압축 해제합니다.

    권장 경로: C:\CARLA_0.9.15\

    ⚠️ 경로에 한글이나 공백이 포함되면 오류가 발생할 수 있습니다. C:\Users\김학생\CARLA처럼 한글이 들어간 경로는 피하세요!

    1-3. 폴더 구조 확인

    압축을 풀면 다음과 같은 구조가 보입니다.

    CARLA_0.9.15/
├── CarlaUE4.exe          ← CARLA 서버 실행 파일 (Windows)

├── HDMaps/
└── ...

    Step 2: CARLA Python 패키지 설치¶

    CARLA 서버와 통신하려면 Python에서 carla 패키지를 사용할 수 있어야 합니다.

    2-1. pip로 설치 (가장 간단한 방법)

    터미널(또는 명령 프롬프트)을 열고 다음 명령어를 실행합니다.

    pip install carla==0.9.15

    2-2. 설치 확인

    Python을 실행하여 정상적으로 import되는지 확인합니다.

    import carla
print(carla.__file__)  # carla 모듈 경로가 출력되면 성공

    Step 3: CARLA 서버 실행 및 연결 테스트¶

    3-1. CARLA 서버 실행

    Windows의 경우, CarlaUE4.exe를 더블 클릭하거나 명령 프롬프트에서 실행합니다.

    cd C:\CARLA_0.9.15
CarlaUE4.exe

    GPU 성능이 낮은 경우 다음 옵션을 추가하세요.

    CarlaUE4.exe -quality-level=Low -ResX=800 -ResY=600
    • -quality-level=Low: 그래픽 품질 낮춤
    • -ResX=800 -ResY=600: 화면 해상도 축소

    Linux의 경우는 다음과 같습니다.

    cd ~/CARLA_0.9.15
./CarlaUE4.sh

    Step 4: 가상 세계에 차량 생성하기¶

    이제 본격적으로 차량을 만들어봅시다!

    # spawn_vehicle.py
import carla
import time

# 1. 서버 연결
client = carla.Client('localhost', 2000)
client.set_timeout(10.0)
world = client.get_world()

# 2. 블루프린트(설계도) 선택
blueprint_library = world.get_blueprint_library()

# Tesla Model 3 블루프린트 가져오기
vehicle_bp = blueprint_library.find('vehicle.tesla.model3')
print(f"선택한 차량: {vehicle_bp.id}")

# 3. 스폰 포인트(생성 위치) 선택
spawn_points = world.get_map().get_spawn_points()
print(f"사용 가능한 스폰 포인트: {len(spawn_points)}개")

# 첫 번째 스폰 포인트 사용
spawn_point = spawn_points[0]

# 4. 차량 생성!
vehicle = world.spawn_actor(vehicle_bp, spawn_point)
print(f"✅ 차량 생성 완료! ID: {vehicle.id}")

# 5. 10초 후 차량 제거 (정리)
time.sleep(10)
vehicle.destroy()
print("🗑️ 차량 제거 완료")

    이 코드를 실행하면 CARLA 서버 화면에 Tesla Model 3가 나타납니다!

    생각해보기: spawn_points는 지도에서 차량이 안전하게 생성될 수 있는 미리 정의된 위치 목록입니다. 교차로 한가운데나 건물 안에 차량이 생기면 안 되겠죠? CARLA가 미리 도로 위의 안전한 위치들을 정해놓은 것입니다.

    Step 5: 코드로 차량 주행하기¶

    이제 차량을 움직여봅시다! VehicleControl을 사용합니다.

    # first_drive.py
import carla
import time

# 서버 연결 및 차량 생성
client = carla.Client('localhost', 2000)
client.set_timeout(10.0)
world = client.get_world()

blueprint_library = world.get_blueprint_library()
vehicle_bp = blueprint_library.find('vehicle.tesla.model3')
spawn_point = world.get_map().get_spawn_points()[0]
vehicle = world.spawn_actor(vehicle_bp, spawn_point)

print("🚗 차량 생성 완료! 3초 후 출발합니다...")
time.sleep(3)

# === 주행 시작 ===

# 1단계: 직진 (3초)
print("▶️ 직진!")
vehicle.apply_control(carla.VehicleControl(throttle=0.5, steer=0.0))
time.sleep(3)

# 2단계: 우회전하며 전진 (2초)
print("➡️ 우회전!")
vehicle.apply_control(carla.VehicleControl(throttle=0.4, steer=0.3))
time.sleep(2)

# 3단계: 직진 (2초)
print("▶️ 다시 직진!")
vehicle.apply_control(carla.VehicleControl(throttle=0.5, steer=0.0))
time.sleep(2)

# 4단계: 정지!
print("⏹️ 정지!")
vehicle.apply_control(carla.VehicleControl(throttle=0.0, brake=1.0))
time.sleep(2)

# 차량 위치 확인
location = vehicle.get_location()
print(f"📍 최종 위치: x={location.x:.1f}, y={location.y:.1f}, z={location.z:.1f}")

# 정리
vehicle.destroy()
print("✅ 주행 완료!")

    Step 6: 카메라 센서 부착 및 이미지 캡처¶

    자율주행차의 눈 역할을 하는 카메라를 부착해봅시다.

    # camera_capture.py
import carla
import time
import os

# 이미지 저장 폴더 생성
os.makedirs('output', exist_ok=True)

# 서버 연결 및 차량 생성
client = carla.Client('localhost', 2000)
client.set_timeout(10.0)
world = client.get_world()

blueprint_library = world.get_blueprint_library()
vehicle_bp = blueprint_library.find('vehicle.tesla.model3')
spawn_point = world.get_map().get_spawn_points()[0]
vehicle = world.spawn_actor(vehicle_bp, spawn_point)
print("🚗 차량 생성 완료!")

# === 카메라 센서 설정 ===

# 카메라 블루프린트 가져오기
camera_bp = blueprint_library.find('sensor.camera.rgb')

# 카메라 해상도 설정
camera_bp.set_attribute('image_size_x', '800')
camera_bp.set_attribute('image_size_y', '600')
camera_bp.set_attribute('fov', '90')  # 시야각 90도

# 카메라 부착 위치 (차량 지붕 위)
camera_transform = carla.Transform(
    carla.Location(x=1.5, z=2.4)  # 차량 앞쪽(x=1.5), 위쪽(z=2.4)
)

# 카메라를 차량에 부착!
camera = world.spawn_actor(camera_bp, camera_transform, attach_to=vehicle)
print("📷 카메라 부착 완료!")

# === 콜백 함수 정의 ===
frame_count = 0

def save_image(image):
    global frame_count
    frame_count += 1
    # 10프레임마다 한 번씩 저장 (너무 많은 파일 방지)
    if frame_count % 10 == 0:
        filename = f'output/frame_{frame_count:04d}.png'
        image.save_to_disk(filename)
        print(f"  📸 저장: {filename}")

# 콜백 등록 — 이 순간부터 자동으로 이미지 캡처 시작!
camera.listen(save_image)

# === 주행하면서 촬영 ===
print("\n🎬 촬영 시작! 주행합니다...")
time.sleep(1)

# 직진 (5초)
vehicle.apply_control(carla.VehicleControl(throttle=0.5, steer=0.0))
time.sleep(5)

# 좌회전 (3초)
vehicle.apply_control(carla.VehicleControl(throttle=0.4, steer=-0.3))
time.sleep(3)

# 정지
vehicle.apply_control(carla.VehicleControl(throttle=0.0, brake=1.0))
time.sleep(2)

# === 정리 ===
camera.stop()       # 센서 중지
camera.destroy()    # 센서 제거
vehicle.destroy()   # 차량 제거

print(f"\n✅ 완료! output 폴더에서 캡처된 이미지를 확인하세요.")
print(f"   총 저장된 프레임: {frame_count // 10}장")
