    📖 Chapter 13: 모델 학습과 하이퍼파라미터 튜닝¶

    Part 4: 딥러닝으로 자율주행 모델 만들기

    🎯 이 장에서 배우는 것¶

    • 학습률, 배치 크기, 에포크 수가 모델 학습에 미치는 영향을 설명할 수 있다
    • 학습 곡선을 보고 과적합과 과소적합을 진단할 수 있다
    • 드롭아웃, 조기종료 등 정규화 기법을 적용하여 모델 성능을 개선할 수 있다
    • 학습된 모델을 파일로 저장하고 다시 불러올 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    시험 공부를 떠올려 보세요. 너무 적게 공부하면 실력이 안 늘고, 교과서만 달달 외우면 새로운 문제를 못 풉니다. 그렇다면 AI는 어떨까요? AI도 얼마나, 어떻게 학습하느냐에 따라 성능이 크게 달라집니다.

    지난 장에서 우리는 자율주행 모델의 구조(CNN)를 설계했습니다. 하지만 좋은 모델 구조를 만들었다고 끝이 아닙니다. 같은 모델이라도 학습 설정을 어떻게 하느냐에 따라 성능이 천차만별입니다.

    이번 장에서 배울 하이퍼파라미터 튜닝은 마치 요리의 "불 조절"과 같습니다. 아무리 좋은 재료(데이터)와 레시피(모델 구조)가 있어도, 불이 너무 세면 타버리고 너무 약하면 설익습니다. 딥러닝에서 이 "불 조절"에 해당하는 것이 바로 학습률, 배치 크기, 에포크 수 같은 하이퍼파라미터입니다.

    📚 핵심 개념¶

    개념 1: 하이퍼파라미터 — 학습의 조종간 🎛️¶

    비유로 시작

    자전거 타기를 배운다고 상상해 보세요. - 한 번에 얼마나 고칠까? → 핸들을 살짝 돌릴지, 확 꺾을지 = 학습률(Learning Rate) - 몇 번 연습할까? → 운동장을 몇 바퀴 돌지 = 에포크(Epoch) - 한 번에 몇 개를 볼까? → 사진 1장씩 볼지, 32장씩 묶어 볼지 = 배치 크기(Batch Size)

    정확한 정의

    • 학습률(Learning Rate): 모델이 한 번의 업데이트에서 가중치를 얼마나 크게 변경할지 결정하는 값입니다. 보통 0.001 정도에서 시작합니다.
    • 에포크(Epoch): 전체 학습 데이터를 처음부터 끝까지 한 번 보는 것을 1에포크라 합니다.
    • 배치 크기(Batch Size): 가중치를 한 번 업데이트하기 전에 모델이 한꺼번에 보는 데이터 개수입니다.

    예시로 확인 — 학습률이 결과를 바꾼다

    graph LR A["학습률 너무 큼<br/>(lr=1.0)"] -->|"발산! 💥"| B["손실이 커짐<br/>학습 실패"] C["학습률 적절<br/>(lr=0.001)"] -->|"안정적 하강 ✅"| D["최적점 도달<br/>학습 성공"] E["학습률 너무 작음<br/>(lr=0.000001)"] -->|"너무 느림 🐌"| F["시간만 낭비<br/>덜 학습됨"]

    알아보기 📌

    하이퍼파라미터는 사람이 직접 정해주는 값입니다. 모델이 학습하면서 스스로 찾는 가중치(파라미터)와 구별됩니다. "하이퍼"는 "상위의"라는 뜻으로, 학습 과정 자체를 제어하는 상위 설정이라는 의미입니다.

    개념 2: 과적합과 과소적합 — AI의 벼락치기 vs 덜 공부하기 📊¶

    비유로 시작

    • 과소적합(Underfitting): 시험 전날 교과서를 대충 훑어보기만 한 상태. 기본 개념도 이해 못 해서 쉬운 문제도 틀립니다.
    • 과적합(Overfitting): 기출문제 답을 통째로 외운 상태. 똑같은 문제는 맞추지만, 조금만 변형되면 틀립니다.

    정확한 정의

    • 과소적합: 모델이 학습 데이터의 패턴조차 제대로 학습하지 못한 상태. 학습 데이터와 검증 데이터 모두에서 성능이 낮습니다.
    • 과적합: 모델이 학습 데이터에 지나치게 맞춰져서, 학습 데이터에서는 성능이 좋지만 새로운 데이터(검증 데이터)에서는 성능이 떨어지는 상태.

    예시로 확인 — 학습 곡선 읽기

    학습 곡선(Learning Curve)은 에포크가 진행됨에 따라 손실(loss)이 어떻게 변하는지 보여주는 그래프입니다.

    graph TD subgraph 정상 학습 A1["에포크 증가 →"] --> A2["학습 손실 ↓"] A1 --> A3["검증 손실 ↓"] A2 --> A4["두 곡선이 함께 내려감 ✅"] A3 --> A4 end subgraph 과적합 발생 B1["에포크 증가 →"] --> B2["학습 손실 ↓ 계속 내려감"] B1 --> B3["검증 손실 ↗ 다시 올라감!"] B2 --> B4["두 곡선이 벌어짐 ⚠️"] B3 --> B4 end

    핵심 판단법: 학습 손실은 계속 내려가는데, 검증 손실이 어느 순간부터 올라가기 시작하면 → 과적합 신호입니다!

    개념 3: 정규화 기법 — 과적합을 막는 안전장치 🛡️¶

    비유로 시작

    과적합을 막는 것은 마치 "시험 공부할 때 여러 참고서를 보는 것"과 같습니다. 한 권만 달달 외우면 그 책에만 맞춰지지만, 여러 자료를 보면 진짜 개념을 이해하게 됩니다.

    정확한 정의와 주요 기법 3가지

    🔸 드롭아웃(Dropout)

    학습 중에 신경망의 뉴런 일부를 무작위로 꺼버리는 기법입니다. 예를 들어 Dropout(0.5)는 학습할 때마다 뉴런의 50%를 랜덤으로 비활성화합니다. 이렇게 하면 특정 뉴런에만 의존하지 않고, 여러 뉴런이 고르게 학습됩니다.

    🔸 조기종료(Early Stopping)

    검증 손실이 더 이상 줄어들지 않으면 학습을 일찍 멈추는 기법입니다. "더 공부해도 실력이 안 느는데 괜히 지치기만 한다"면 멈추는 것이 현명하듯이요.

    🔸 데이터 증강(Data Augmentation)

    기존 이미지를 회전, 좌우반전, 밝기 조절 등으로 변형하여 학습 데이터를 늘리는 기법입니다. 같은 도로 사진이라도 다양한 각도에서 보면 일반화 능력이 좋아집니다.

    graph LR A["과적합 문제 😰"] --> B["드롭아웃<br/>뉴런 일부 끄기"] A --> C["조기종료<br/>적절할 때 멈추기"] A --> D["데이터 증강<br/>다양한 데이터 만들기"] B --> E["일반화 성능 향상 🎉"] C --> E D --> E

    개념 4: 모델 저장과 불러오기 — 학습 결과 보관하기 💾¶

    비유로 시작

    열심히 공부한 내용을 노트에 정리해두지 않으면, 나중에 다시 처음부터 공부해야 합니다. AI도 마찬가지로, 학습이 끝난 모델을 파일로 저장해두지 않으면 매번 몇 시간씩 다시 학습해야 합니다.

    정확한 정의

    • 모델 저장: 학습된 가중치와 모델 구조를 파일(.h5 또는 .keras)로 저장하는 것
    • 모델 불러오기: 저장된 파일에서 모델을 복원하여 바로 예측에 사용하는 것
    • 체크포인트(Checkpoint): 학습 중간중간 가장 좋은 상태를 자동 저장하는 기능

    예시로 확인

    # 저장 - 한 줄이면 됩니다!
model.save('my_driving_model.h5')

# 불러오기 - 역시 한 줄!
from tensorflow.keras.models import load_model
loaded_model = load_model('my_driving_model.h5')

    알아보기 📌

    .h5는 HDF5라는 파일 형식입니다. 모델의 구조 + 가중치 + 옵티마이저 상태를 모두 담고 있어서, 불러온 즉시 예측이나 추가 학습이 가능합니다. 최신 Keras에서는 .keras 확장자도 사용합니다.

    🔨 따라하기¶

    이번 실습에서는 12장에서 만든 CNN 모델을 가지고, 하이퍼파라미터를 바꿔가며 실험하고, 정규화 기법을 적용하여 최적의 모델을 만들어 저장합니다.

    Step 1: 실험 환경 준비 및 데이터 로드¶

    먼저 필요한 라이브러리를 불러오고, 실험용 데이터를 준비합니다. 이번에는 자율주행 시뮬레이션을 위해 CIFAR-10 데이터셋의 자동차 이미지를 활용합니다.

    import numpy as np
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense, Dropout
from tensorflow.keras.callbacks import EarlyStopping, ModelCheckpoint
from tensorflow.keras.preprocessing.image import ImageDataGenerator
import matplotlib.pyplot as plt

# 재현성을 위한 시드 고정
tf.random.set_seed(42)
np.random.seed(42)

# CIFAR-10 데이터 로드
(X_train_full, y_train_full), (X_test, y_test) = tf.keras.datasets.cifar10.load_data()

# 정규화: 0~255 → 0~1
X_train_full = X_train_full.astype('float32') / 255.0
X_test = X_test.astype('float32') / 255.0

# 학습/검증 분리 (80% 학습, 20% 검증)
split = 40000
X_train, X_val = X_train_full[:split], X_train_full[split:]
y_train, y_val = y_train_full[:split], y_train_full[split:]

print(f"학습 데이터: {X_train.shape}")
print(f"검증 데이터: {X_val.shape}")
print(f"테스트 데이터: {X_test.shape}")

    실행 결과: 

    학습 데이터: (40000, 32, 32, 3)
검증 데이터: (10000, 32, 32, 3)
테스트 데이터: (10000, 32, 32, 3)

    Step 2: 학습률 실험 — 불 조절의 핵심¶

    같은 모델 구조에서 학습률만 바꿔가며 어떤 차이가 나는지 실험해 봅시다.

    def create_model(learning_rate):
    """같은 구조의 모델을 만들되, 학습률만 다르게 설정"""
    model = Sequential([
        Conv2D(32, (3, 3), activation='relu', input_shape=(32, 32, 3)),
        MaxPooling2D((2, 2)),
        Conv2D(64, (3, 3), activation='relu'),
        MaxPooling2D((2, 2)),
        Flatten(),
        Dense(64, activation='relu'),
        Dense(10, activation='softmax')
    ])

    optimizer = tf.keras.optimizers.Adam(learning_rate=learning_rate)
    model.compile(optimizer=optimizer,
                  loss='sparse_categorical_crossentropy',
                  metrics=['accuracy'])
    return model

# 세 가지 학습률로 실험
learning_rates = [0.01, 0.001, 0.0001]
histories = {}

for lr in learning_rates:
    print(f"\n{'='*40}")
    print(f"학습률 = {lr} 로 학습 시작!")
    print(f"{'='*40}")

    model = create_model(lr)
    history = model.fit(X_train, y_train,
                       epochs=15,
                       batch_size=64,
                       validation_data=(X_val, y_val),
                       verbose=0)  # 출력 생략

    # 최종 결과 출력
    final_val_acc = history.history['val_accuracy'][-1]
    print(f"  → 최종 검증 정확도: {final_val_acc:.4f}")

    histories[lr] = history
