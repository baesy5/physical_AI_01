    Chapter 16: 학습 실행과 결과 분석 – 로봇이 정말 배울까?¶

    Part 4 | [2권] 시뮬레이션으로 강화학습 실습하기

    🎯 이 장에서 배우는 것¶

    • 수백~수천 에피소드의 Q-learning 학습을 실행하고 에피소드별 보상 변화를 그래프로 시각화할 수 있다
    • 학습된 Q-테이블을 분석하여 로봇이 어떤 정책(Policy)을 학습했는지 해석할 수 있다
    • 학습 전 무작위 행동과 학습 후 행동을 비교하여 강화학습의 효과를 직접 입증할 수 있다
    • 학습 곡선(Learning Curve)을 읽고 학습이 잘 되었는지 판단할 수 있다

    💡 왜 이걸 배우나요?¶

    지난 장까지 우리는 Q-learning 에이전트를 설계하고 코드로 구현했습니다. 레시피를 완성한 것이죠. 하지만 요리는 실제로 만들어 먹어봐야 맛있는지 알 수 있습니다. 🍳

    이 장에서는 드디어 그 레시피로 요리를 합니다. 로봇을 수백 번, 수천 번 시뮬레이션 환경에서 반복 학습시키고, 정말로 똑똑해지는지 데이터로 확인합니다.

    "로봇이 정말 배울까?"라는 질문에 대한 답을, 그래프와 숫자로 직접 눈에 보이게 만드는 시간입니다. 강화학습을 공부하면서 가장 짜릿한 순간이 바로 이 순간이에요!

    📚 핵심 개념¶

    개념 1: 학습 곡선 (Learning Curve)¶

    🎯 비유로 시작

    수영을 처음 배우는 아이를 떠올려보세요. 첫날은 물에 들어가기만 해도 허우적거립니다. 일주일 뒤에는 발차기를 하고, 한 달 뒤에는 25미터를 완주합니다. 매주 기록을 측정해서 그래프로 그리면, 처음에는 느리다가 점점 빨라지는 곡선이 나타날 겁니다. 이것이 바로 학습 곡선입니다.

    📖 정확한 정의

    학습 곡선이란, 학습이 진행됨에 따라 성과(보상)가 어떻게 변하는지를 시각화한 그래프입니다. X축은 에피소드 번호(학습 횟수), Y축은 해당 에피소드에서 얻은 누적 보상입니다.

    ✨ 예시로 확인

    • 학습 초반: 로봇이 무작위로 행동 → 보상이 낮고 들쭉날쭉
    • 학습 중반: 좋은 행동을 서서히 발견 → 보상이 점차 상승
    • 학습 후반: 최적 행동을 거의 파악 → 보상이 높은 수준에서 안정
    graph LR A["에피소드 1~100<br/>🎲 무작위 탐험<br/>보상: 낮음"] --> B["에피소드 100~500<br/>📈 패턴 발견<br/>보상: 상승 중"] B --> C["에피소드 500~1000<br/>🎯 정책 완성<br/>보상: 높고 안정"]

    개념 2: Q-테이블 해석과 정책 추출¶

    🎯 비유로 시작

    시험공부를 다 끝낸 학생의 노트를 펼쳐본다고 상상해보세요. 각 문제 유형 옆에 "이건 공식 A를 써!", "이건 방법 B가 확실해!"라고 메모가 적혀 있습니다. Q-테이블도 마찬가지입니다. 로봇이 학습하면서 채워넣은 치트시트이고, 각 상태에서 어떤 행동이 가장 좋은지 적혀 있습니다.

    📖 정확한 정의

    학습 완료된 Q-테이블에서 각 상태마다 Q-값이 가장 높은 행동을 선택하는 것이 바로 학습된 정책(Policy)입니다. 수식으로 표현하면:

    정책(상태) = argmax Q(상태, 행동)  ← Q-값이 가장 큰 행동을 선택

    ✨ 예시로 확인

    • 상태 "장애물이 앞에 있음" → Q-값: 전진(-5.2), 좌회전(3.8), 우회전(2.1) → 정책: 좌회전!
    • 상태 "목표가 오른쪽" → Q-값: 전진(1.0), 좌회전(-1.3), 우회전(4.5) → 정책: 우회전!

    개념 3: 이동 평균을 활용한 추세 파악¶

    🎯 비유로 시작

    주식 차트를 본 적이 있나요? 매일의 주가는 위아래로 요동치지만, 이동 평균선을 그으면 전체적인 추세가 보입니다. 학습 곡선도 에피소드마다 보상이 들쭉날쭉한데, 이동 평균을 적용하면 "전반적으로 올라가고 있구나"를 깔끔하게 확인할 수 있습니다.

    📖 정확한 정의

    이동 평균(Moving Average)은 최근 N개 에피소드의 보상 평균값입니다. 예를 들어 50-에피소드 이동 평균이라면, 현재 에피소드를 포함한 최근 50개 보상의 평균을 구해서 하나의 점으로 찍습니다.

    ✨ 예시로 확인

    원래 보상이 [2, 5, 1, 8, 3]이라면, 3-에피소드 이동 평균은: - 3번째: (2+5+1)/3 = 2.67 - 4번째: (5+1+8)/3 = 4.67 - 5번째: (1+8+3)/3 = 4.0

    들쭉날쭉한 원본보다 부드러운 곡선이 만들어집니다.

    개념 4: 학습 전 vs 학습 후 비교 (Before & After)¶

    🎯 비유로 시작

    다이어트 광고에서 항상 "Before / After" 사진을 보여주죠? 그래야 효과가 확실히 느껴지니까요. 강화학습도 동일합니다. 학습 전 무작위 행동과 학습 후 행동을 나란히 비교해야 "로봇이 정말 배웠구나!"를 확신할 수 있습니다.

    📖 정확한 정의

    학습 전(Before)은 Q-테이블이 모두 0인 상태에서 무작위로 행동하는 것이고, 학습 후(After)는 충분히 학습된 Q-테이블을 기반으로 greedy하게(Q-값이 가장 높은 행동만 선택) 행동하는 것입니다.

    ✨ 예시로 확인

    • 학습 전: 로봇이 벽에 부딪히고, 빙빙 돌고, 목표에 도달 못함 → 보상: -50
    • 학습 후: 로봇이 장애물을 피하고, 최단 경로로 목표 도달 → 보상: +40

    🔨 따라하기¶

    이전 장(Chapter 15)에서 만든 SimpleRobotEnv 환경과 QLearningAgent 클래스를 이어서 사용합니다. 코드를 이어 붙여서 실행하세요!

    Step 1: 환경과 에이전트 준비 (복습)¶

    이전 장의 핵심 코드를 가져옵니다. 이미 완성했다면 건너뛰어도 됩니다.

    import numpy as np
import random

class SimpleRobotEnv:
    """간단한 1D 로봇 환경: 0~4 위치, 목표는 4번 위치"""
    def __init__(self):
        self.goal = 4
        self.state = 0

    def reset(self):
        self.state = 0
        return self.state

    def step(self, action):
        # action: 0=왼쪽, 1=오른쪽
        if action == 1:
            self.state = min(self.state + 1, 4)
        else:
            self.state = max(self.state - 1, 0)

        # 보상 설계
        if self.state == self.goal:
            return self.state, 10, True   # 목표 도달! +10
        else:
            return self.state, -1, False  # 한 걸음마다 -1

class QLearningAgent:
    def __init__(self, n_states, n_actions, lr=0.1, gamma=0.99, epsilon=1.0, epsilon_decay=0.995, epsilon_min=0.01):
        self.q_table = np.zeros((n_states, n_actions))
        self.lr = lr
        self.gamma = gamma
        self.epsilon = epsilon
        self.epsilon_decay = epsilon_decay
        self.epsilon_min = epsilon_min

    def choose_action(self, state):
        if random.random() < self.epsilon:
            return random.randint(0, 1)  # 탐험
        return int(np.argmax(self.q_table[state]))  # 활용

    def learn(self, state, action, reward, next_state, done):
        target = reward if done else reward + self.gamma * np.max(self.q_table[next_state])
        self.q_table[state, action] += self.lr * (target - self.q_table[state, action])

    def decay_epsilon(self):
        self.epsilon = max(self.epsilon_min, self.epsilon * self.epsilon_decay)

    Step 2: 학습 전 무작위 행동 기록하기 (Before)¶

    학습 전 성능을 먼저 기록해둡니다. 나중에 비교할 "Before" 데이터입니다.

    def run_episodes(env, agent, n_episodes, learn=True, max_steps=50):
    """에피소드를 반복 실행하고 보상 기록을 반환"""
    rewards_history = []
    for ep in range(n_episodes):
        state = env.reset()
        total_reward = 0
        for step in range(max_steps):
            action = agent.choose_action(state)
            next_state, reward, done = env.step(action)
            if learn:
                agent.learn(state, action, reward, next_state, done)
            total_reward += reward
            state = next_state
            if done:
                break
        if learn:
            agent.decay_epsilon()
        rewards_history.append(total_reward)
    return rewards_history

# 학습 전 성능 측정 (무작위 행동)
env = SimpleRobotEnv()
random_agent = QLearningAgent(n_states=5, n_actions=2, epsilon=1.0)
random_agent.epsilon_min = 1.0  # 항상 무작위로 행동하도록 고정!

before_rewards = run_episodes(env, random_agent, n_episodes=100, learn=False)
print(f"📊 학습 전 평균 보상: {np.mean(before_rewards):.2f}")

    실행하면 평균 보상이 음수로 나올 겁니다. 무작위로 움직이니 목표에 도달하기 어렵죠!

    Step 3: 1000 에피소드 학습 실행하기 🚀¶

    이제 진짜 학습을 시작합니다!

    # 학습용 에이전트 생성
env = SimpleRobotEnv()
agent = QLearningAgent(
    n_states=5,
    n_actions=2,
    lr=0.1,
    gamma=0.99,
    epsilon=1.0,
    epsilon_decay=0.995,
    epsilon_min=0.01
)

# 1000 에피소드 학습 실행
training_rewards = run_episodes(env, agent, n_episodes=1000, learn=True)

print(f"✅ 학습 완료!")
print(f"📊 처음 100 에피소드 평균 보상: {np.mean(training_rewards[:100]):.2f}")
print(f"📊 마지막 100 에피소드 평균 보상: {np.mean(training_rewards[-100:]):.2f}")
print(f"📊 최종 epsilon: {agent.epsilon:.4f}")

    처음 100 에피소드의 평균 보상과 마지막 100 에피소드의 평균 보상을 비교해보세요. 확연한 차이가 보일 겁니다! 🎉

    Step 4: 학습 곡선 시각화하기 📈¶

    숫자만으로는 부족합니다. 그래프로 봐야 학습 과정이 한눈에 들어옵니다.

    import matplotlib.pyplot as plt

# 이동 평균 계산 함수
def moving_average(data, window=50):
    return [np.mean(data[max(0, i-window+1):i+1]) for i in range(len(data))]

# 그래프 그리기
plt.figure(figsize=(10, 5))

# 원본 보상 (연한 색)
plt.plot(training_rewards, alpha=0.3, color='blue', label='에피소드 보상')

# 이동 평균 (진한 색)
ma = moving_average(training_rewards, window=50)
plt.plot(ma, color='red', linewidth=2, label='50-에피소드 이동 평균')

plt.xlabel('에피소드')
plt.ylabel('누적 보상')
plt.title('🤖 Q-Learning 학습 곡선')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('learning_curve.png', dpi=100)
plt.show()

print("📈 학습 곡선이 그려졌습니다!")

    그래프를 읽는 법: - 🔵 연한 파란 점들: 각 에피소드의 실제 보상 (들쭉날쭉) - 🔴 빨간 선: 이동 평균 (전체 추세) - 빨간 선이 왼쪽에서 오른쪽으로 올라가는 모양이면 → 학습 성공! 🎉

    📝 전체 코드¶

    아래 코드를 하나의 파일(chapter16_train.py)에 저장하고 실행하세요.

    import numpy as np
import random
import matplotlib.pyplot as plt

# ──────────────────────────────────────
# 1. 환경 정의
# ──────────────────────────────────────
class SimpleRobotEnv:
    def __init__(self):
        self.goal = 4
        self.state = 0

    def reset(self):
        self.state = 0
        return self.state

    def step(self, action):
        if action == 1:
            self.state = min(self.state + 1, 4)
        else:
            self.state = max(self.state - 1, 0)
        if self.state == self.goal:
            return self.state, 10, True
        else:
            return self.state, -1, False

# ──────────────────────────────────────
# 2. Q-Learning 에이전트
# ──────────────────────────────────────
class QLearningAgent:
    def __init__(self, n_states, n_actions, lr=0.1, gamma=0.99,
                 epsilon=1.0, epsilon_decay=0.995, epsilon_min=0.01):
        self.q_table = np.zeros((n_states, n_actions))
        self.lr = lr
        self.gamma = gamma
        self.epsilon = epsilon
        self.epsilon_decay = epsilon_decay
        self.epsilon_min = epsilon_min

    def choose_action(self, state):
        if random.random() < self.epsilon:
            return random.randint(0, 1)
        return int(np.argmax(self.q_table[state]))

    def learn(self, state, action, reward, next_state, done):
        target = reward if done else reward + self.gamma * np.max(self.q_table[next_state])
        self.q_table[state, action] += self.lr * (target - self.q_table[state, action])

    def decay_epsilon(self):
        self.epsilon = max(self.epsilon_min, self.epsilon * self.epsilon_decay)

# ──────────────────────────────────────
# 3. 학습 실행 함수
# ──────────────────────────────────────
def run_episodes(env, agent, n_episodes, learn=True, max_steps=50):
    rewards_history = []
    for ep in range(n_episodes):
        state = env.reset()
        total_reward = 0
        for step in range(max_steps):
            action = agent.choose_action(state)
            next_state, reward, done = env.step(action)
            if learn:
                agent.learn(state, action, reward, next_state, done)
            total_reward += reward
            state = next_state
            if done:
                break
        if learn:
            agent.decay_epsilon()
        rewards_history.append(total_reward)
    return rewards_history

def moving_average(data, window=50):
    return [np.mean(data[max(0, i-window+1):i+1]) for i in range(len(data))]

# ──────────────────────────────────────
# 4. 학습 전 성능 (Before)
# ──────────────────────────────────────
env = SimpleRobotEnv()
random_agent = QLearningAgent(n_states=5, n_actions=2, epsilon=1.0)
random_agent.epsilon_min = 1.0
before_rewards = run_episodes(env, random_agent, n_episodes=100, learn=False)
print(f"📊 학습 전 평균 보상: {np.mean(before_rewards):.2f}")

# ──────────────────────────────────────
# 5. 학습 실행 (1000 에피소드)
# ──────────────────────────────────────
env = SimpleRobotEnv()
agent = QLearningAgent(n_states=5, n_actions=2)
training_rewards = run_episodes(env, agent, n_episodes=1000, learn=True)
print(f"✅ 학습 완료!")
print(f"📊 처음 100 에피소드 평균: {np.mean(training_rewards[:100]):.2f}")
print(f"📊 마지막 100 에피소드 평균: {np.mean(training_rewards[-100:]):.2f}")

# ──────────────────────────────────────
# 6. 학습 곡선 시각화
# ──────────────────────────────────────
plt.figure(figsize=(10, 5))
plt.plot(training_rewards, alpha=0.3, color='blue', label='에피소드 보상')
plt.plot(moving_average(training_rewards, 50), color='red', linewidth=2, label='50-에피소드 이동 평균')
plt.xlabel('에피소드')
plt.ylabel('누적 보상')
plt.title('Q-Learning 학습 곡선')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('learning_curve.png', dpi=100)
plt.show()

# ──────────────────────────────────────
# 7. Q-테이블 분석
# ──────────────────────────────────────

print("\n🧠 학습된 Q-테이블:")

# ──────────────────────────────────────
