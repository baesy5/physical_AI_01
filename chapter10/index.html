    Chapter 10: 딥러닝 기초 — 신경망의 원리¶

    Part 4: 딥러닝으로 자율주행 모델 만들기

    🎯 이 장에서 배우는 것¶

    • 인공 신경망의 기본 구조(입력층-은닉층-출력층)를 그림으로 그리고 설명할 수 있다
    • 뉴런(퍼셉트론)이 입력을 받아 출력을 만드는 과정을 수식 없이 비유로 설명할 수 있다
    • TensorFlow/Keras로 간단한 신경망 모델을 만들고 학습시킬 수 있다
    • 손실 함수, 옵티마이저, 에포크의 의미를 자신의 말로 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔: 사람의 뇌가 학습하는 과정과 AI의 학습 과정은 어떻게 비슷할까?

    여러분이 자전거를 처음 배울 때를 떠올려 보세요. 처음에는 넘어지고, 넘어질 때마다 몸이 "아, 이쪽으로 기울면 안 되는구나"를 기억합니다. 수십 번 반복하면 어느새 의식하지 않아도 균형을 잡을 수 있죠. 딥러닝도 정확히 이 과정을 따릅니다. 데이터를 보고, 예측하고, 틀리면 조금 수정하고, 이것을 수천 번 반복합니다.

    우리는 이제 자율주행 자동차의 두뇌를 만들려고 합니다. 자율주행차는 카메라 영상을 보고 "직진할지, 좌회전할지, 브레이크를 밟을지" 판단해야 합니다. 이 판단을 가능하게 하는 핵심 기술이 바로 인공 신경망(Neural Network) 입니다.

    이번 장에서는 신경망이 무엇이고 어떻게 학습하는지를 이해한 뒤, 직접 코드로 만들어 봅니다. 이 기초가 탄탄해야 다음 장에서 실제 자율주행 모델을 설계할 수 있습니다.

    📚 핵심 개념¶

    개념 1: 뉴런 — 신경망의 가장 작은 단위¶

    🧠 비유로 시작

    여러분의 뇌 속에는 약 860억 개의 뉴런(신경세포) 이 있습니다. 하나의 뉴런이 하는 일은 의외로 단순합니다.

    1. 다른 뉴런들로부터 신호(전기 자극)를 받는다
    2. 받은 신호를 합산한다
    3. 합산한 값이 일정 기준(임계값)을 넘으면 다음 뉴런에게 신호를 보낸다

    이것을 투표에 비유해 봅시다. 반 친구 5명이 "오늘 점심 짜장면 먹을까?"에 대해 의견을 줍니다. 그런데 모든 친구의 말이 동등하지는 않죠 — 미식가 친구의 의견은 좀 더 무겁게(가중치가 크게) 반영됩니다. 모든 의견을 가중 합산한 결과가 "찬성 쪽"이면 "짜장면 먹자!"라고 결정합니다.

    📖 정확한 정의

    인공 뉴런(퍼셉트론)은 이 생물학적 뉴런을 수학으로 모방한 것입니다.

    • 입력(Input): 데이터가 들어오는 통로 (친구들의 의견)
    • 가중치(Weight): 각 입력이 얼마나 중요한지를 나타내는 숫자 (친구별 신뢰도)
    • 편향(Bias): 기본적인 성향값 (원래 짜장면을 좋아하는 정도)
    • 활성화 함수(Activation Function): 합산 결과를 최종 출력으로 변환하는 함수 (찬성/반대 결정 기준)
    flowchart LR x1["입력 1 (x₁)"] -->|"가중치 w₁"| SUM["합산 + 편향(b)"] x2["입력 2 (x₂)"] -->|"가중치 w₂"| SUM x3["입력 3 (x₃)"] -->|"가중치 w₃"| SUM SUM --> ACT["활성화 함수"] ACT --> OUT["출력 (y)"]

    ✏️ 예시로 확인

    자율주행 상황을 생각해 봅시다. "브레이크를 밟아야 할까?"를 판단하는 뉴런 하나가 있다면:

    • 입력 1: 앞차와의 거리 → 가까울수록 큰 값
    • 입력 2: 현재 속도 → 빠를수록 큰 값
    • 입력 3: 신호등 상태 → 빨간불이면 큰 값

    각 입력에 가중치를 곱하고 더한 값이 임계값을 넘으면 → "브레이크!" 라는 출력을 냅니다.

    알아보기 📌: 퍼셉트론(Perceptron)은 1957년 프랭크 로젠블랫이 만든 최초의 인공 뉴런 모델입니다. 하나의 퍼셉트론만으로는 단순한 문제(직선으로 나눌 수 있는 문제)만 풀 수 있습니다. 그래서 여러 개를 층으로 쌓는 방법이 등장했습니다.

    개념 2: 신경망의 구조 — 층(Layer)을 쌓는다¶

    🏗️ 비유로 시작

    공장의 조립 라인을 떠올려 보세요.

    • 1단계(원자재 투입): 철판, 나사, 유리 등이 들어옵니다
    • 2단계(가공): 각 부품이 잘리고, 구부러지고, 조합됩니다
    • 3단계(완성품 출하): 완성된 자동차가 나옵니다

    신경망도 이와 같습니다. 데이터가 여러 층(Layer) 을 차례로 통과하며 점점 의미 있는 정보로 변환됩니다.

    📖 정확한 정의

    flowchart LR subgraph 입력층["🟦 입력층 (Input Layer)"] I1["뉴런 1"] I2["뉴런 2"] I3["뉴런 3"] end subgraph 은닉층1["🟧 은닉층 (Hidden Layer)"] H1["뉴런 A"] H2["뉴런 B"] H3["뉴런 C"] H4["뉴런 D"] end subgraph 출력층["🟩 출력층 (Output Layer)"] O1["출력"] end I1 --> H1 & H2 & H3 & H4 I2 --> H1 & H2 & H3 & H4 I3 --> H1 & H2 & H3 & H4 H1 --> O1 H2 --> O1 H3 --> O1 H4 --> O1
    • 입력층(Input Layer): 데이터를 받아들이는 층. 특징(feature)의 수만큼 뉴런이 있습니다
    • 은닉층(Hidden Layer): 입력 데이터에서 패턴을 찾아내는 층. 여러 개를 쌓을 수 있고, "딥(Deep)"러닝이라고 부르는 이유가 바로 이 은닉층이 깊게(여러 개) 쌓이기 때문입니다
    • 출력층(Output Layer): 최종 결과를 내보내는 층. 예측하려는 값의 형태에 맞춰 설계합니다

    ✏️ 예시로 확인

    속도와 도로 경사도로 제동 거리를 예측하는 신경망이라면:

    • 입력층: 뉴런 2개 (속도, 경사도)
    • 은닉층: 뉴런 4개 (내부에서 패턴을 학습)
    • 출력층: 뉴런 1개 (예측 제동 거리)

    생각해보기 🤔: 은닉층의 뉴런 수를 늘리면 어떤 일이 일어날까요? 무조건 많으면 좋을까요? (이 질문의 답은 실습에서 직접 확인해 봅니다!)

    개념 3: 신경망은 어떻게 학습하나? — 손실 함수와 옵티마이저¶

    🎯 비유로 시작

    다트 게임을 생각해 봅시다.

    1. 다트를 던진다 → 예측(Prediction)
    2. 과녁 중심에서 얼마나 벗어났는지 측정한다 → 손실(Loss)
    3. "조금 왼쪽으로 던져야겠다"라고 판단한다 → 옵티마이저(Optimizer)
    4. 다시 던진다, 또 측정하고, 또 수정한다 → 반복(Epoch)

    이 과정을 수천 번 반복하면, 다트가 점점 과녁 중심에 가까워집니다.

    📖 정확한 정의

    • 손실 함수(Loss Function): 모델의 예측값과 실제 정답 사이의 오차를 숫자로 계산하는 함수. 이 숫자가 작을수록 모델이 잘 예측하고 있다는 뜻입니다
    • 회귀 문제(숫자 예측): MSE(Mean Squared Error, 평균 제곱 오차) 를 주로 사용

    • 분류 문제(카테고리 예측): Cross-Entropy(교차 엔트로피) 를 주로 사용

    • 옵티마이저(Optimizer): 손실을 줄이기 위해 가중치를 어떤 방향으로, 얼마만큼 수정할지 결정하는 알고리즘

    • 가장 많이 쓰이는 것: Adam (적응적 학습률 최적화)

    • 기본 원리: 경사 하강법(Gradient Descent) — 산에서 가장 가파른 내리막길을 따라 내려가면 골짜기(최소 손실)에 도달하는 원리

    • 에포크(Epoch): 전체 학습 데이터를 한 번 다 보는 것 = 1에포크. 보통 수십~수백 에포크 반복합니다

    flowchart TD A["1️⃣ 데이터를 모델에 넣는다"] --> B["2️⃣ 모델이 예측값을 출력한다"] B --> C["3️⃣ 손실 함수로 오차를 계산한다"] C --> D["4️⃣ 옵티마이저가 가중치를 수정한다"] D --> E{"모든 에포크 완료?"} E -->|"아니오"| A E -->|"예"| F["5️⃣ 학습 완료! 🎉"]

    ✏️ 예시로 확인

    • 실제 제동 거리: 25m
    • 모델 예측: 30m
    • 오차: 5m → 손실 함수가 이 오차를 숫자(예: 25)로 계산
    • 옵티마이저: "가중치를 이렇게 바꾸면 다음번엔 27m로 예측할 수 있겠다"
    • 100에포크 후: 모델 예측 25.1m → 거의 정확!

    개념 4: Keras — 신경망을 쉽게 만드는 도구¶

    🧰 비유로 시작

    레고 블록을 생각하세요. 레고로 집을 만들 때, 벽돌 하나하나의 화학 성분을 알 필요는 없습니다. 그냥 블록을 순서대로 쌓으면 됩니다. Keras가 바로 이 레고 같은 도구입니다.

    Keras는 TensorFlow(텐서플로) 위에서 동작하는 고수준 API(쉬운 인터페이스)로, 복잡한 수학을 몰라도 층을 쌓듯이 신경망을 만들 수 있게 해줍니다.

    📖 정확한 정의

    Keras의 핵심 작업 흐름은 딱 4단계입니다.

    flowchart LR A["1. 모델 정의\n(층 쌓기)"] --> B["2. 컴파일\n(손실함수+옵티마이저 설정)"] B --> C["3. 학습\n(fit)"] C --> D["4. 평가/예측\n(evaluate/predict)"]
    • Sequential 모델: 층을 순서대로 쌓는 가장 기본적인 모델 형태
    • Dense 층: 모든 뉴런이 이전 층의 모든 뉴런과 연결된 층 (가장 기본적인 층, "완전 연결층"이라고도 부릅니다)
    • 활성화 함수 'relu': 음수는 0으로, 양수는 그대로 통과시키는 함수. 은닉층에서 가장 널리 사용됩니다

    ✏️ 예시 코드 미리보기

    from tensorflow import keras
from tensorflow.keras import layers

# 1. 모델 정의 — 레고 블록 쌓기
model = keras.Sequential([
    layers.Dense(4, activation='relu', input_shape=(2,)),  # 은닉층: 뉴런 4개
    layers.Dense(1)                                         # 출력층: 뉴런 1개
])

# 2. 컴파일 — 학습 규칙 설정
model.compile(optimizer='adam', loss='mse')

# 3. 학습 — 데이터로 훈련
# model.fit(X, y, epochs=100)

# 4. 예측
# model.predict(새로운_데이터)

    알아보기 📌: Dense(4, activation='relu', input_shape=(2,)) 이 한 줄이 의미하는 것 - 4: 이 층의 뉴런 수 - activation='relu': 활성화 함수 - input_shape=(2,): 입력 데이터의 특징(feature)이 2개라는 뜻

    🔨 따라하기: 속도로 제동 거리 예측하기¶

    자동차의 속도(km/h) 를 입력하면 제동 거리(m) 를 예측하는 신경망을 만들어 봅시다. 자율주행에서 "이 속도면 얼마 전에 브레이크를 밟아야 하는가?"를 판단하는 기초가 됩니다.

    Step 1: 환경 준비와 데이터 만들기¶

    # 필요한 라이브러리 설치 확인
# !pip install tensorflow numpy matplotlib

import numpy as np
import matplotlib.pyplot as plt
from tensorflow import keras
from tensorflow.keras import layers

# 재현 가능한 결과를 위한 시드 설정
np.random.seed(42)
import tensorflow as tf
tf.random.set_seed(42)

print("✅ 라이브러리 로드 완료!")
print(f"TensorFlow 버전: {tf.__version__}")

    이제 학습 데이터를 만듭니다. 실제 물리 법칙에 따르면, 제동 거리는 속도의 제곱에 비례합니다. 여기에 약간의 노이즈(현실 세계의 불확실성)를 추가합니다.

    # 학습 데이터 생성
# 속도: 10km/h ~ 120km/h (50개 데이터)
speed = np.linspace(10, 120, 50)

# 제동 거리 (물리 공식 기반 + 랜덤 노이즈)
# 실제 제동거리 ≈ 속도² / (2 × 감속도 × 3.6²)를 단순화
braking_distance = 0.005 * speed**2 + 0.1 * speed + np.random.normal(0, 2, 50)

# 데이터 시각화
plt.figure(figsize=(8, 5))
plt.scatter(speed, braking_distance, color='royalblue', alpha=0.7, label='실제 데이터')
plt.xlabel('속도 (km/h)', fontsize=12)
plt.ylabel('제동 거리 (m)', fontsize=12)
plt.title('🚗 속도 vs 제동 거리', fontsize=14)
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

print(f"데이터 수: {len(speed)}개")
print(f"속도 범위: {speed.min():.0f} ~ {speed.max():.0f} km/h")
print(f"제동 거리 범위: {braking_distance.min():.1f} ~ {braking_distance.max():.1f} m")

    알아보기 📌: 왜 직접 데이터를 만들까요? 실제 프로젝트에서는 센서 데이터를 사용하지만, 학습 목적으로는 우리가 "정답을 아는" 데이터를 만들어야 모델이 제대로 학습했는지 확인할 수 있기 때문입니다.

    Step 2: 데이터 전처리 — 정규화¶

    신경망은 입력값의 크기(스케일) 에 민감합니다. 속도가 10~120 범위이고 다른 특징이 0~1 범위라면, 신경망은 큰 숫자에 편향될 수 있습니다. 그래서 모든 데이터를 비슷한 범위로 맞추는 정규화(Normalization) 가 필요합니다.

    # 정규화: 0~1 범위로 변환
speed_min, speed_max = speed.min(), speed.max()
dist_min, dist_max = braking_distance.min(), braking_distance.max()

speed_normalized = (speed - speed_min) / (speed_max - speed_min)
dist_normalized = (braking_distance - dist_min) / (dist_max - dist_min)

print(f"정규화 전 속도 범위: {speed.min():.0f} ~ {speed.max():.0f}")
print(f"정규화 후 속도 범위: {speed_normalized.min():.2f} ~ {speed_normalized.max():.2f}")
print()
print(f"정규화 전 제동거리 범위: {braking_distance.min():.1f} ~ {braking_distance.max():.1f}")
print(f"정규화 후 제동거리 범위: {dist_normalized.min():.2f} ~ {dist_normalized.max():.2f}")

    생각해보기 🤔: 정규화를 하지 않으면 어떤 일이 일어날까요? 학습이 아예 안 되지는 않지만, 훨씬 느리게 수렴하거나 불안정해질 수 있습니다.

    Step 3: 신경망 모델 만들기¶

    이제 핵심입니다! Keras로 신경망을 만들어 봅시다.

    # 신경망 모델 정의
model = keras.Sequential([
    # 은닉층 1: 뉴런 8개, 활성화 함수 relu
    layers.Dense(8, activation='relu', input_shape=(1,)),
    # 은닉층 2: 뉴런 4개, 활성화 함수 relu
    layers.Dense(4, activation='relu'),
    # 출력층: 뉴런 1개 (제동 거리 하나를 예측)
    layers.Dense(1)
])

# 모델 구조 확인
model.summary()

    실행하면 아래와 비슷한 결과가 나옵니다.

    Model: "sequential"

    Param(파라미터) 수는 어떻게 계산될까?

    • 첫 번째 층: 입력 1개 × 뉴런 8개 + 편향 8개 = 16개
    • 두 번째 층: 입력 8개 × 뉴런 4개 + 편향 4개 = 36개
    • 출력층: 입력 4개 × 뉴런 1개 + 편향 1개 = 5개
    • 총 57개의 가중치와 편향이 학습을 통해 조정됩니다

    Step 4: 모델 컴파일과 학습¶

    # 모델 컴파일
model.compile(
    optimizer='adam',      # 옵티마이저: Adam
    loss='mse'             # 손실 함수: 평균 제곱 오차 (Mean Squared Error)
)

# 모델 학습
history = model.fit(
    speed_normalized,       # 입력: 정규화된 속도
    dist_normalized,        # 정답: 정규화된 제동 거리
    epochs=200,             # 전체 데이터를 200번 반복 학습
    verbose=0               # 학습 과정 출력 생략 (0=미출력, 1=전체, 2=요약)
)

print("✅ 학습 완료!")
print(f"최종 손실(loss): {history.history['loss'][-1]:.6f}")

    학습이 잘 됐는지 확인하기 위해 손실 그래프를 그려봅시다.

    # 학습 과정 시각화
plt.figure(figsize=(8, 5))
plt.plot(history.history['loss'], color='tomato', linewidth=2)
plt.xlabel('에포크 (Epoch)', fontsize=12)
plt.ylabel('손실 (Loss)', fontsize=12)
plt.title('📉 학습 과정 — 손실이 줄어드는 모습', fontsize=14)
plt.grid(True, alpha=0.3)
plt.show()

    그래프가 오른쪽으로 갈수록 아래로 내려가면 학습이 잘 되고 있다는 뜻입니다! 처음에는 손실이 크다가 점점 작아지는 것이 정상입니다.

    정리하기 📋: 이 그래프가 보여주는 것은 "다트를 던질수록 과녁 중심에 가까워지는 과정"입니다. 에포크가 늘어날수록 모델의 예측이 정답에 가까워집니다.

    Step 5: 예측 결과 확인하기¶

    학습된 모델로 예측해 보고, 실제 데이터와 비교합니다.

    # 예측
pred_normalized = model.predict(speed_normalized, verbose=0)

# 정규화 복원 (원래 스케일로 되돌리기)
pred_original = pred_normalized * (dist_max - dist_min) + dist_min

# 결과 시각화
plt.figure(figsize=(8, 5))
plt.scatter(speed, braking_distance, color='royalblue', alpha=0.7, label='실제 데이터')
plt.plot(speed, pred_original, color='tomato', linewidth=2, label='신경망 예측')
plt.xlabel('속도 (km/h)', fontsize=12)
plt.ylabel('제동 거리 (m)', fontsize=12)
plt.title('🎯 신경망 예측 vs 실제 데이터', fontsize=14)
plt.legend(fontsize=11)
plt.grid(True, alpha=0.3)
plt.show()

    빨간 선(예측)이 파란 점(실제 데이터) 사이를 잘 통과하면 성공입니다! 🎉

    Step 6: 새로운 데이터로 예측하기¶

    학습에 사용하지 않은 새로운 속도로 제동 거리를 예측해 봅시다.

    # 새로운 속도로 예측
new_speeds = np.array([30, 60, 80, 100])

# 정규화 적용 (학습 때와 같은 기준 사용!)
new_speeds_norm = (new_speeds - speed_min) / (speed_max - speed_min)

# 예측
predictions_norm = model.predict(new_speeds_norm, verbose=0)
predictions = predictions_norm * (dist_max - dist_min) + dist_min

# 결과 출력
print("=" * 40)
print("🚗 속도별 예측 제동 거리")
print("=" * 40)
for s, p in zip(new_speeds, predictions.flatten()):
    print(f"  속도 {s:3d} km/h → 제동 거리 약 {p:.1f} m")
print("=" * 40)
