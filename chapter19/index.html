    챕터 19: 센서 연결과 실시간 데이터 수집¶

    Part 6: RC카로 현실 세계에 도전하기

    🎯 이 장에서 배우는 것¶

    • 웹캠 또는 파이카메라를 라즈베리파이에 연결하여 실시간 영상을 캡처할 수 있다
    • 초음파 센서(HC-SR04)의 원리를 이해하고 장애물까지의 거리를 측정할 수 있다
    • 카메라 영상과 센서 데이터를 동시에 읽어 하나의 프로그램에서 처리할 수 있다
    • RC카를 수동 주행하며 학습용 데이터(이미지-조향값 쌍)를 체계적으로 수집할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기: CARLA 시뮬레이터에서는 카메라 센서를 코드 한 줄(world.spawn_actor(camera_bp, ...))로 붙였습니다. 그런데 현실의 RC카에 카메라를 달려면 무엇이 필요할까요?

    시뮬레이션과 현실 사이에는 Sim-to-Real Gap(시뮬레이션-현실 격차)이 존재합니다. 가상 세계에서는 완벽한 센서 데이터가 즉시 나왔지만, 현실에서는 다릅니다.

    • 카메라를 물리적으로 연결하고 드라이버를 설정해야 합니다
    • 조명, 그림자, 반사광 때문에 이미지 품질이 달라집니다
    • 초음파 센서는 전선 하나 잘못 꽂으면 작동하지 않습니다
    • 데이터를 저장하려면 타이밍 동기화를 직접 관리해야 합니다

    이 장에서 직접 센서를 연결하고 데이터를 수집하면, 다음 장에서 이 데이터를 이용해 자율주행 AI 모델을 학습시킬 수 있습니다. 좋은 데이터 없이는 좋은 AI도 없습니다. 데이터 수집은 자율주행의 기초 공사입니다.

    📚 핵심 개념¶

    개념 1: 카메라 연결과 영상 캡처¶

    🎨 비유로 시작하기

    카메라를 RC카에 다는 것은, 사람의 눈을 로봇에 이식하는 것과 같습니다. 눈(카메라 하드웨어)을 달았다고 끝이 아닙니다. 눈에서 들어온 빛을 뇌(라즈베리파이)가 해석할 수 있도록 시신경(드라이버와 소프트웨어)을 연결해야 합니다.

    📖 정확한 정의

    라즈베리파이에서 사용할 수 있는 카메라는 크게 두 종류입니다.

    • 파이카메라(Pi Camera): 라즈베리파이 전용 CSI 포트에 연결하는 카메라 모듈. 지연이 적고 라즈베리파이에 최적화되어 있습니다.
    • USB 웹캠: 일반 USB 포트에 꽂는 카메라. 범용성이 높고 구하기 쉽습니다.

    어떤 카메라를 사용하든, Python에서는 OpenCV 라이브러리로 동일하게 다룰 수 있습니다.

    flowchart LR A["📷 카메라\n(하드웨어)"] -->|"CSI / USB"| B["🍓 라즈베리파이"] B -->|"드라이버"| C["🐍 OpenCV\n(소프트웨어)"] C --> D["🖼️ 프레임 이미지\n(numpy 배열)"]

    💻 예시로 확인

    USB 웹캠을 연결한 뒤, 터미널에서 인식 여부를 확인합니다.

    # 연결된 비디오 장치 확인
ls /dev/video*

    /dev/video0 같은 결과가 나오면 카메라가 정상 인식된 것입니다.

    OpenCV로 한 장의 이미지를 캡처하는 최소 코드는 다음과 같습니다.

    import cv2

cap = cv2.VideoCapture(0)  # 0번 카메라 열기
ret, frame = cap.read()     # 한 프레임 읽기

if ret:
    cv2.imwrite("test_capture.jpg", frame)
    print(f"캡처 성공! 이미지 크기: {frame.shape}")
else:
    print("카메라를 열 수 없습니다.")

cap.release()

    알아보기: frame.shape의 결과가 (480, 640, 3)이라면, 세로 480픽셀, 가로 640픽셀, 색상 채널 3개(BGR)를 의미합니다.

    개념 2: 초음파 센서(HC-SR04)로 거리 측정¶

    🎨 비유로 시작하기

    박쥐가 어둠 속에서 벽을 피해 날 수 있는 이유를 아시나요? 박쥐는 초음파를 발사하고, 벽에 부딪혀 돌아오는 시간을 측정해서 거리를 계산합니다. HC-SR04 센서는 이 박쥐의 능력을 전자회로로 구현한 것입니다.

    📖 정확한 정의

    HC-SR04는 초음파를 이용한 거리 측정 센서입니다.

    • Trig 핀: 초음파 펄스를 발사하는 신호를 보내는 핀
    • Echo 핀: 반사되어 돌아온 신호를 감지하는 핀
    • 측정 범위: 약 2cm ~ 400cm
    • 측정 원리: 거리 = (왕복 시간 × 음속) / 2
    sequenceDiagram participant Pi as 라즈베리파이 participant Trig as Trig 핀 participant Sound as 초음파 participant Wall as 장애물 participant Echo as Echo 핀 Pi->>Trig: 10μs HIGH 신호 Trig->>Sound: 초음파 8회 발사 Sound->>Wall: 음파 전파 Wall->>Sound: 반사 Sound->>Echo: 돌아온 신호 감지 Echo->>Pi: HIGH 지속 시간 측정 Note over Pi: 거리 = 시간 × 34300 / 2

    💻 예시로 확인

    음속은 약 343m/s (= 34,300cm/s)입니다. Echo 핀이 HIGH 상태로 유지된 시간이 0.001초(1ms)라면:

    거리 = 0.001초 × 34,300cm/s ÷ 2 = 17.15cm

    알아보기: 왜 2로 나눌까요? 초음파는 센서 → 장애물 → 센서로 왕복하기 때문입니다. 실제 거리는 왕복 거리의 절반입니다.

    개념 3: 센서 데이터 동기화¶

    🎨 비유로 시작하기

    영화를 촬영할 때 "슬레이트"(딱 소리 나는 클랩보드)를 치는 이유를 아시나요? 영상과 소리의 타이밍을 맞추기 위해서입니다. RC카도 마찬가지입니다. 카메라 이미지와 조향 명령이 같은 순간의 데이터여야 AI가 올바르게 학습할 수 있습니다.

    📖 정확한 정의

    데이터 동기화란 여러 센서에서 수집한 데이터가 같은 시점의 상태를 나타내도록 타임스탬프(시간 기록)를 맞추는 것입니다.

    flowchart TD A["⏱️ 현재 시간\ntimestamp"] --> B["📷 카메라 프레임 캡처"] A --> C["🎮 조향 입력 기록"] A --> D["📏 초음파 거리 측정"] B --> E["💾 저장\nimg_000001.jpg"] C --> F["💾 저장\ndriving_log.csv"] D --> F

    핵심은 하나의 루프 안에서 모든 데이터를 순차적으로 빠르게 읽어서, 시간 차이를 최소화하는 것입니다.

    💻 예시로 확인

    import time

timestamp = time.time()  # 현재 시간 (소수점 이하 초 단위)
# 결과 예: 1700000000.123456

# 이 timestamp를 이미지 파일명과 CSV에 함께 기록하면
# 나중에 어떤 이미지가 어떤 조향값과 짝인지 정확히 알 수 있습니다.

    개념 4: 학습 데이터 수집 전략¶

    🎨 비유로 시작하기

    요리를 배우려는 학생에게 "볶음밥 만드는 영상"만 100번 보여주면 어떻게 될까요? 볶음밥은 잘 만들겠지만, 파스타를 만들라고 하면 당황할 것입니다. AI도 마찬가지입니다. 다양한 상황의 데이터를 충분히 모아야 다양한 환경에서 잘 동작합니다.

    📖 정확한 정의

    학습 데이터 수집이란, AI 모델을 훈련시키기 위해 입력(카메라 이미지)과 정답(그때의 조향값)을 쌍으로 기록하는 과정입니다. 이를 지도학습(Supervised Learning)을 위한 레이블링이라고 합니다.

    좋은 데이터셋의 조건:

    • 충분한 양: 최소 수천 장 이상 (5,000~10,000장 권장)
    • 다양한 상황: 직진, 좌회전, 우회전, 다양한 조명
    • 균형: 좌회전 데이터만 많으면 AI가 계속 좌회전합니다
    • 깨끗한 레이블: 이미지와 조향값이 정확히 대응
    pie title 이상적인 데이터 분포 "직진" : 40 "좌회전 (약)" : 15 "좌회전 (강)" : 10 "우회전 (약)" : 15 "우회전 (강)" : 10 "복구 주행" : 10

    알아보기: 복구 주행(Recovery Driving) 데이터란 무엇일까요? 일부러 차선 가장자리로 치우친 뒤, 다시 중앙으로 돌아오는 동작을 기록한 것입니다. 이 데이터가 있어야 AI가 경로를 이탈했을 때 스스로 복구할 수 있습니다.

    🔨 따라하기¶

    Step 1: 카메라 연결 및 실시간 영상 확인¶

    먼저 카메라가 제대로 동작하는지 확인합니다.

    USB 웹캠 사용자: 1. 라즈베리파이의 USB 포트에 웹캠을 꽂습니다 2. 터미널에서 ls /dev/video*로 인식을 확인합니다

    파이카메라 사용자: 1. 라즈베리파이 전원을 끈 상태에서 CSI 포트에 리본 케이블을 연결합니다 2. sudo raspi-config → Interface Options → Camera → Enable 순으로 활성화합니다 3. 재부팅합니다

    다음 코드로 실시간 영상을 확인합니다.

    # camera_test.py
import cv2

cap = cv2.VideoCapture(0)

# 해상도 설정 (RC카용으로 낮은 해상도 사용)
cap.set(cv2.CAP_PROP_FRAME_WIDTH, 320)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 240)

if not cap.isOpened():
    print("❌ 카메라를 열 수 없습니다!")
    exit()

print("카메라 열림! 'q'를 누르면 종료합니다.")

while True:
    ret, frame = cap.read()
    if not ret:
        break

    cv2.imshow("RC Car Camera", frame)

    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
print("✅ 카메라 테스트 완료!")

    생각해보기: 해상도를 320×240으로 낮추는 이유는 무엇일까요? 라즈베리파이의 처리 능력은 제한적이기 때문에, 고해상도 영상은 처리 속도가 느려집니다. 자율주행에는 도로의 대략적인 형태만 파악하면 되므로 낮은 해상도로도 충분합니다.

    Step 2: 초음파 센서 회로 연결¶

    HC-SR04 센서를 라즈베리파이에 연결합니다.

    필요한 부품: - HC-SR04 초음파 센서 1개 - 브레드보드 1개 - 저항 1kΩ 1개, 2kΩ 1개 (또는 비슷한 값) - 점퍼 와이어 4개

    연결 방법:

    flowchart LR subgraph HC_SR04["HC-SR04 센서"] VCC["VCC"] TRIG["Trig"] ECHO["Echo"] GND_S["GND"] end subgraph RPI["라즈베리파이 GPIO"] PIN2["5V (Pin 2)"] PIN16["GPIO 23 (Pin 16)"] PIN18["GPIO 24 (Pin 18)"] PIN6["GND (Pin 6)"] end PIN2 -->|"빨간 선"| VCC PIN16 -->|"노란 선"| TRIG ECHO -->|"1kΩ 저항"| PIN18 ECHO -->|"2kΩ 저항"| PIN6 GND_S -->|"검정 선"| PIN6

    ⚠️ 중요: Echo 핀은 5V 신호를 출력하지만, 라즈베리파이 GPIO는 3.3V만 받을 수 있습니다. 반드시 분압 저항 회로를 사용하세요! 저항 없이 직접 연결하면 라즈베리파이가 손상될 수 있습니다. 1kΩ과 2kΩ 저항을 직렬로 연결하면 5V가 약 3.3V로 낮아집니다.

    Step 3: 초음파 센서 거리 측정 코드¶

    # ultrasonic_test.py
import RPi.GPIO as GPIO
import time

# GPIO 설정
GPIO.setmode(GPIO.BCM)
TRIG = 23
ECHO = 24

GPIO.setup(TRIG, GPIO.OUT)
GPIO.setup(ECHO, GPIO.IN)

def measure_distance():
    """초음파 센서로 거리를 측정하여 cm 단위로 반환"""
    # Trig 핀 초기화
    GPIO.output(TRIG, False)
    time.sleep(0.01)

    # 10μs 동안 HIGH 신호 보내기
    GPIO.output(TRIG, True)
    time.sleep(0.00001)  # 10마이크로초
    GPIO.output(TRIG, False)

    # Echo 핀이 HIGH가 되는 시점 기록
    timeout = time.time() + 0.04  # 40ms 타임아웃
    while GPIO.input(ECHO) == 0:
        pulse_start = time.time()
        if pulse_start > timeout:
            return -1  # 타임아웃

    # Echo 핀이 LOW로 돌아오는 시점 기록
    timeout = time.time() + 0.04
    while GPIO.input(ECHO) == 1:
        pulse_end = time.time()
        if pulse_end > timeout:
            return -1  # 타임아웃

    # 거리 계산
    pulse_duration = pulse_end - pulse_start
    distance = pulse_duration * 34300 / 2  # cm 단위

    return round(distance, 1)

    # manual_drive.py
import sys
import tty
import termios

def get_key():
    """키보드에서 한 글자를 읽어 반환 (터미널 설정 변경)"""
    fd = sys.stdin.fileno()
    old_settings = termios.tcgetattr(fd)
    try:
        tty.setraw(sys.stdin.fileno())
        ch = sys.stdin.read(1)
    finally:
        termios.tcsetattr(fd, termios.TCSADRAIN, old_settings)
    return ch

def key_to_action(key):
    """키 입력을 조향값과 속도값으로 변환"""
    # 조향: -1.0(좌) ~ 0.0(직진) ~ 1.0(우)
    # 속도: 0.0(정지) ~ 1.0(최대)
    actions = {
        'w': (0.0, 0.5),    # 직진
        's': (0.0, -0.5),   # 후진
        'a': (-0.5, 0.4),   # 좌회전
        'd': (0.5, 0.4),    # 우회전
        'q': (-1.0, 0.3),   # 급좌회전
        'e': (1.0, 0.3),    # 급우회전
        ' ': (0.0, 0.0),    # 정지 (스페이스바)
    }
    return actions.get(key, (0.0, 0.0))

    print(f"\r조향: {steering:+.1f} | 속도: {throttle:+.1f}   ", end="")

def get_key_nonblocking():
