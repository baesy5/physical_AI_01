    Chapter 22: 자율주행 시스템 최종 통합¶

    Part 7: 프로젝트 완성과 발표

    🎯 이 장에서 배우는 것¶

    • 차선 인식, 장애물 회피, 속도 제어를 하나의 메인 프로그램으로 통합할 수 있다
    • 예외 상황(차선 소실, 센서 오류)에 대한 Failsafe 로직을 구현할 수 있다
    • 전체 코드를 모듈화하여 유지보수가 쉬운 구조로 만들 수 있다
    • 주석과 README를 작성하여 프로젝트를 문서화할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔: 최종 발표에서 우리 차가 완벽하게 달리려면 어떤 마지막 점검이 필요할까?

    여러분은 지금까지 카메라로 차선을 인식하고, 초음파 센서로 장애물을 감지하고, 모터를 제어하는 기능을 각각 따로 만들었습니다. 하지만 이것은 마치 오케스트라 단원들이 각자 연습만 한 상태와 같습니다. 바이올린, 첼로, 플루트가 아무리 실력이 좋아도 지휘자 없이 함께 연주하면 엉망이 되겠죠?

    이 장에서는 지휘자 역할을 하는 메인 프로그램을 만들어, 모든 기능이 조화롭게 동작하는 완성된 자율주행 시스템을 구축합니다. 또한 실제 도로에서는 차선이 갑자기 사라지거나, 센서가 고장 나는 일이 생길 수 있습니다. 이런 예외 상황에서도 안전하게 멈추는 장치(Failsafe)를 추가하는 것은 실제 자율주행 개발에서 가장 중요한 과정입니다.

    마지막으로, 여러분이 만든 코드를 다른 사람도 이해할 수 있도록 정리하는 것은 소프트웨어 엔지니어의 필수 역량입니다. 이 장을 마치면, 여러분은 발표 준비가 완료된 하나의 완성품을 손에 쥐게 됩니다.

    📚 핵심 개념¶

    개념 1: 시스템 통합 (System Integration)¶

    🎵 비유로 시작하기

    오케스트라를 다시 떠올려 봅시다. 바이올린 파트, 관악기 파트, 타악기 파트가 있고, 지휘자가 악보(메인 루프)를 보면서 "지금은 바이올린이 연주하고, 다음은 관악기가 들어와!"라고 순서와 타이밍을 조율합니다. 자율주행 시스템 통합도 정확히 이와 같습니다.

    📖 정확한 정의

    시스템 통합이란 개별적으로 개발하고 테스트한 모듈(기능 단위)들을 하나의 프로그램 안에서 유기적으로 연결하여 전체 시스템이 목표대로 동작하게 만드는 과정입니다. 자율주행에서는 다음 세 모듈을 통합합니다.

    • 인식(Perception): 카메라로 차선 인식, 초음파 센서로 장애물 감지
    • 판단(Decision): 인식 결과를 바탕으로 직진, 좌회전, 우회전, 정지 등을 결정
    • 제어(Control): 판단 결과에 따라 모터 속도와 조향각을 조절

    ✅ 예시로 확인

    flowchart LR A["📷 카메라\n차선 인식"] --> D["🧠 판단 모듈\n주행 방향 결정"] B["📡 초음파 센서\n장애물 감지"] --> D D --> E["⚙️ 모터 제어\n속도·조향"] E --> F["🚗 RC카 주행"] F -->|"반복"| A

    메인 루프가 한 바퀴 돌 때마다 인식 → 판단 → 제어가 순서대로 실행됩니다. 이 루프가 초당 수십 번 반복되면서 RC카가 실시간으로 반응합니다.

    개념 2: Failsafe (안전 장치)¶

    🪂 비유로 시작하기

    비행기에는 엔진이 고장 나도 안전하게 착륙할 수 있는 예비 시스템이 있습니다. 또한 놀이공원 놀이기구는 전원이 갑자기 끊겨도 자동으로 브레이크가 걸리도록 설계되어 있습니다. 이처럼 "문제가 생기면 안전한 상태로 돌아가는 장치"가 바로 Failsafe입니다.

    📖 정확한 정의

    Failsafe(페일세이프)란 시스템에 오류나 예외 상황이 발생했을 때, 피해를 최소화하기 위해 미리 정해둔 안전 동작을 자동으로 수행하는 메커니즘입니다.

    자율주행 RC카에서 대비해야 할 주요 예외 상황:

    • 차선 소실: 카메라가 차선을 인식하지 못하는 경우 → 감속 후 마지막 알려진 방향 유지
    • 센서 오류: 초음파 센서가 비정상 값(0 또는 극단적 큰 값)을 반환 → 안전 정지
    • 통신 두절: 카메라 프레임이 일정 시간 이상 들어오지 않음 → 비상 정지
    • 과열/과부하: 모터 또는 보드가 과열 → 점진적 감속 후 정지

    ✅ 예시로 확인

    flowchart TD A["메인 루프 실행"] --> B{"차선 인식\n성공?"} B -->|"예"| C["정상 주행"] B -->|"아니오"| D{"연속 실패\n횟수 확인"} D -->|"3회 미만"| E["마지막 조향값\n유지 + 감속"] D -->|"3회 이상"| F["🛑 비상 정지"] C --> G{"장애물\n감지?"} G -->|"아니오"| H["계속 주행"] G -->|"예 (30cm 이내)"| F

    개념 3: 코드 모듈화 (Modularization)¶

    🧱 비유로 시작하기

    레고 블록을 생각해 보세요. 작은 블록들을 조합해서 집도 만들고, 자동차도 만듭니다. 만약 바퀴가 마음에 안 들면 바퀴 블록만 교체하면 됩니다. 전체를 부수고 다시 만들 필요가 없죠. 코드 모듈화도 같은 원리입니다. 기능별로 독립적인 블록(모듈)을 만들어두면, 한 부분을 수정해도 다른 부분에 영향을 주지 않습니다.

    📖 정확한 정의

    모듈화란 프로그램을 기능별로 독립된 파일(모듈)이나 클래스로 분리하여, 각 부분이 명확한 역할을 갖고 서로 느슨하게 연결되도록 구조화하는 것입니다.

    ✅ 프로젝트 파일 구조 예시

    autonomous_rc_car/
├── main.py              ← 메인 프로그램 (지휘자)
├── lane_detector.py     ← 차선 인식 모듈
├── obstacle_detector.py ← 장애물 감지 모듈
├── motor_controller.py  ← 모터 제어 모듈
├── failsafe.py          ← 안전 장치 모듈
├── config.py            ← 설정값 모음
└── README.md            ← 프로젝트 설명서

    모듈화의 핵심 장점 세 가지:

    • 가독성: 파일을 열면 해당 기능의 코드만 보입니다
    • 재사용성: 차선 인식 모듈을 다른 프로젝트에서도 그대로 사용할 수 있습니다
    • 디버깅 용이: 문제가 생기면 해당 모듈만 집중적으로 확인합니다

    개념 4: 프로젝트 문서화 (Documentation)¶

    📖 비유로 시작하기

    요리사가 훌륭한 요리를 만들어도 레시피를 기록해두지 않으면 다음에 같은 맛을 재현할 수 없습니다. 다른 요리사에게 전수할 수도 없죠. 프로젝트 문서화는 코드의 레시피를 작성하는 것입니다.

    📖 정확한 정의

    프로젝트 문서화란 코드 내부에 주석(comment)을 달고, 프로젝트 전체에 대한 README 파일을 작성하여, 코드를 처음 보는 사람도 목적, 구조, 사용법을 빠르게 이해할 수 있도록 정리하는 작업입니다.

    좋은 문서화의 3요소:

    • 코드 주석: 함수마다 "이 함수는 무엇을 하는가, 입력은 무엇이고 출력은 무엇인가"를 기록
    • README.md: 프로젝트 개요, 설치 방법, 실행 방법, 팀원 정보를 포함
    • 인라인 주석: 복잡한 로직 옆에 "왜 이렇게 했는지" 이유를 기록

    알아보기 📌: 전문 개발자들은 "코드는 6개월 후의 나를 위해 작성한다"고 합니다. 6개월 후에 자신의 코드를 다시 보면 기억나지 않기 때문에, 미래의 자신을 위해서라도 문서화는 필수입니다.

    🔨 따라하기¶

    이제 실제로 자율주행 RC카의 최종 통합 시스템을 단계별로 만들어 봅시다. 각 단계에서 하나의 모듈 파일을 작성하고, 마지막에 메인 프로그램에서 모두 연결합니다.

    Step 1: 설정 파일 만들기 (config.py)¶

    모든 모듈이 공통으로 사용하는 설정값을 한 곳에 모아둡니다. 나중에 값을 변경할 때 이 파일만 수정하면 됩니다.

    # config.py
# 자율주행 RC카 설정값 모음

# === 카메라 설정 ===
CAMERA_WIDTH = 320          # 카메라 해상도 가로
CAMERA_HEIGHT = 240         # 카메라 해상도 세로
CAMERA_FPS = 30             # 초당 프레임 수

# === 차선 인식 설정 ===
LANE_THRESHOLD = 200        # 이진화 임계값 (흰색 차선 감지용)
ROI_TOP_RATIO = 0.6         # 관심 영역 시작 비율 (화면 아래쪽 40%)

# === 장애물 감지 설정 ===
OBSTACLE_STOP_DIST = 15     # 비상 정지 거리 (cm)
OBSTACLE_SLOW_DIST = 30     # 감속 시작 거리 (cm)

# === 모터 설정 ===
BASE_SPEED = 50             # 기본 속도 (0~100)
SLOW_SPEED = 25             # 감속 시 속도
TURN_SPEED = 35             # 회전 시 속도

# === Failsafe 설정 ===
MAX_LANE_LOSS_COUNT = 3     # 차선 소실 허용 연속 횟수
SENSOR_MIN_VALID = 2        # 센서 최소 유효 거리 (cm)
SENSOR_MAX_VALID = 400      # 센서 최대 유효 거리 (cm)
FRAME_TIMEOUT = 2.0         # 프레임 미수신 타임아웃 (초)

    정리하기 📋: 설정값을 코드 여기저기에 흩어놓으면 수정할 때 빠뜨리기 쉽습니다. config.py 한 곳에 모아두면 "속도를 30으로 낮춰보자"라고 할 때 한 줄만 고치면 됩니다.

    Step 2: 차선 인식 모듈 만들기 (lane_detector.py)¶

    카메라 영상에서 차선을 찾고, RC카가 얼마나 중앙에서 벗어났는지(오프셋)를 계산하는 모듈입니다.

    # lane_detector.py
# 차선 인식 모듈: 카메라 영상에서 차선 위치를 분석한다

import cv2
import numpy as np
import config

class LaneDetector:
    """차선을 인식하고 주행 방향을 계산하는 클래스"""

    def __init__(self):
        """초기화: 이전 프레임의 조향값을 저장해둔다"""
        self.last_offset = 0  # 마지막으로 유효했던 오프셋값

    def detect(self, frame):
        """
        차선을 인식하여 중앙 오프셋을 반환한다.

        매개변수:
            frame: 카메라에서 가져온 BGR 이미지

        반환값:
            (success, offset)
            - success: 차선 인식 성공 여부 (True/False)
            - offset: 화면 중앙 대비 차선 중심의 편차 (픽셀)
                      음수 = 왼쪽으로 치우침, 양수 = 오른쪽으로 치우침
        """
        # 1) 그레이스케일 변환
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

        # 2) 관심 영역(ROI) 추출 - 화면 아래쪽만 본다
        height = gray.shape[0]
        roi_top = int(height * config.ROI_TOP_RATIO)
        roi = gray[roi_top:height, :]

        # 3) 이진화 - 흰색 차선만 추출
        _, binary = cv2.threshold(
            roi, config.LANE_THRESHOLD, 255, cv2.THRESH_BINARY
        )

        # 4) 흰색 픽셀의 x좌표 평균 = 차선 중심
        white_pixels = np.where(binary == 255)

        if len(white_pixels[1]) < 50:
            # 흰색 픽셀이 너무 적으면 차선을 못 찾은 것
            return False, self.last_offset

        lane_center = np.mean(white_pixels[1])
        frame_center = config.CAMERA_WIDTH / 2
        offset = lane_center - frame_center

        # 유효한 오프셋을 저장해둔다 (Failsafe용)
        self.last_offset = offset
        return True, offset

    def get_last_offset(self):
        """마지막으로 유효했던 오프셋값을 반환한다"""
        return self.last_offset

    # obstacle_detector.py
# 장애물 감지 모듈: 초음파 센서로 전방 거리를 측정한다

import time
import config

# 라즈베리파이가 아닌 환경에서도 테스트할 수 있도록 처리
try:
    import RPi.GPIO as GPIO
    GPIO_AVAILABLE = True
except ImportError:
    GPIO_AVAILABLE = False
    print("[경고] RPi.GPIO를 사용할 수 없습니다. 시뮬레이션 모드로 동작합니다.")


class ObstacleDetector:
    """초음파 센서로 장애물을 감지하는 클래스"""

    def __init__(self, trig_pin=23, echo_pin=24):
        """
        초기화: GPIO 핀을 설정한다.

        매개변수:
            trig_pin: 초음파 발신 핀 번호
            echo_pin: 초음파 수신 핀 번호
        """
        self.trig = trig_pin
        self.echo = echo_pin

        if GPIO_AVAILABLE:
            GPIO.setmode(GPIO.BCM)
            GPIO.setup(self.trig, GPIO.OUT)
            GPIO.setup(self.echo, GPIO.IN)

    def get_distance(self):
        """
        전방 장애물까지의 거리를 cm 단위로 반환한다.

        반환값:
            distance: 거리(cm). 오류 시 -1을 반환한다.
        """
        if not GPIO_AVAILABLE:
            return 100.0  # 시뮬레이션: 장애물 없음

        try:
            # 초음파 발사
            GPIO.output(self.trig, True)
            time.sleep(0.00001)
            GPIO.output(self.trig, False)

            # 에코 신호 대기 (타임아웃 0.1초)
            start_time = time.time()
            timeout = start_time + 0.1

            while GPIO.input(self.echo) == 0:
                start_time = time.time()
                if start_time > timeout:
                    return -1  # 타임아웃 → 오류

            while GPIO.input(self.echo) == 1:
                end_time = time.time()
                if end_time > timeout:
                    return -1  # 타임아웃 → 오류

            # 거리 계산: 음속 34300 cm/s, 왕복이므로 2로 나눔
            elapsed = end_time - start_time
            distance = (elapsed * 34300) / 2

            # 유효 범위 검사
            if distance < config.SENSOR_MIN_VALID or distance > config.SENSOR_MAX_VALID:
                return -1  # 비정상 값

            return round(distance, 1)

        except Exception as e:
            print(f"[센서 오류] {e}")
            return -1

    def cleanup(self):
        """GPIO 리소스를 정리한다"""
        if GPIO_AVAILABLE:
            GPIO.cleanup()

    시스템의 핵심 안전 장치입니다. 각종 예외 상황을 감시하고, 위험 시 적절한 조치를 결정합니다.

    # failsafe.py
# 안전 장치 모듈: 예외 상황 발생 시 안전한 동작을 결정한다

import time
import config


class FailsafeManager:
    """시스템 안전 상태를 관리하는 클래스"""

    def __init__(self):
        """초기화: 각종 카운터와 타이머를 설정한다"""
        self.lane_loss_count = 0        # 연속 차선 소실 횟수
        self.last_frame_time = time.time()  # 마지막 프레임 수신 시간
        self.emergency_stop = False     # 비상 정지 플래그

    def check_lane_status(self, lane_found):
        """
        차선 인식 상태를 확인하고 안전 등급을 반환한다.

        매개변수:
            lane_found: 차선 인식 성공 여부 (True/False)

        반환값:
            "normal"    - 정상 주행 가능
            "caution"   - 주의 (감속 필요)
            "emergency" - 비상 정지 필요
        """
        if lane_found:
            self.lane_loss_count = 0  # 성공하면 카운터 초기화
            return "normal"
        else:
            self.lane_loss_count += 1
            if self.lane_loss_count >= config.MAX_LANE_LOSS_COUNT:
                return "emergency"
            else:
                return "caution"

    def check_obstacle(self, distance):
        """
        장애물 거리를 확인하고 안전 등급을 반환한다.

        매개변수:
            distance: 전방 거리(cm). -1이면 센서 오류.

        반환값:
            "normal"    - 장애물 없음
            "slow_down" - 감속 필요
            "emergency" - 비상 정지 필요
            "sensor_error" - 센서 오류
        """
        if distance == -1:
            return "sensor_error"
        elif distance <= config.OBSTACLE_STOP_DIST:
            return "emergency"
        elif distance <= config.OBSTACLE_SLOW_DIST:
            return "slow_down"
        else:
            return "normal"

    def check_frame_timeout(self):
        """
        카메라 프레임 수신 여부를 확인한다.

        반환값:
            True  - 타임아웃 발생 (비상 정지 필요)
            False - 정상
        """
        elapsed = time.time() - self.last_frame_time
        return elapsed > config.FRAME_TIMEOUT

    def update_frame_time(self):
        """프레임 수신 시간을 갱신한다"""
        self.last_frame_time = time.time()

    def get_status_summary(self):
        """현재 안전 상태를 요약하여 문자열로 반환한다"""
        return (
            f"차선소실 연속: {self.lane_loss_count}회 | "
            f"비상정지: {self.emergency_stop}"
        )
