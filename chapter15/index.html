    Q-learning 에이전트 구현¶

    🎯 이 장에서 배우는 것¶

    • 파이썬 딕셔너리 또는 2차원 리스트로 Q-테이블을 초기화할 수 있다
    • Q-learning 업데이트 공식을 파이썬 코드로 구현할 수 있다
    • ε-greedy 행동 선택 로직을 코드로 작성할 수 있다
    • 한 에피소드 동안 Q-테이블이 변화하는 과정을 직접 확인할 수 있다

    💡 왜 이걸 배우나요?¶

    지난 챕터에서 우리는 Q-learning의 이론을 배웠습니다. 수식도 봤고, 개념도 이해했죠. 하지만 수식을 아는 것과 코드로 구현하는 것 사이에는 꽤 큰 간극이 있습니다.

    비유를 하나 들어볼게요. 🍳

    요리 레시피를 읽는 것과 실제로 주방에서 요리하는 것은 완전히 다른 경험입니다. 레시피에는 "중불에서 3분간 볶으세요"라고 적혀 있지만, 실제로 해보면 "중불이 어느 정도지?", "3분이 지났는데 아직 색이 안 변했는데?" 같은 질문이 쏟아지죠.

    이 챕터는 Q-learning의 요리 실습 시간입니다. 수식 한 줄 한 줄을 파이썬 코드로 번역하면서, "아, 이 부분이 이렇게 동작하는구나!"라는 깨달음을 얻게 될 거예요.

    이번에 작성하는 코드는 다음 챕터에서 시뮬레이션 환경과 연결하는 기반이 됩니다. 여기서 탄탄하게 만들어 두면, 나중에 환경만 바꿔 끼우는 식으로 다양한 문제에 적용할 수 있습니다.

    📚 핵심 개념¶

    개념 1: Q-테이블 — 에이전트의 작전 노트 📓¶

    비유로 시작해요

    여러분이 새로운 도시에 여행을 갔다고 상상해보세요. 처음에는 어떤 식당이 맛있는지, 어떤 길이 빠른지 전혀 모릅니다. 그래서 작은 수첩을 하나 꺼내서 이렇게 적기 시작합니다:

    • "서울역 앞 → 왼쪽으로 가기 → 꽤 괜찮았음 (점수: 7)"
    • "서울역 앞 → 오른쪽으로 가기 → 별로였음 (점수: 2)"
    • "명동 → 직진 → 아주 좋았음 (점수: 9)"

    이 수첩이 바로 Q-테이블입니다!

    정확한 정의

    Q-테이블은 (상태, 행동) 쌍마다 하나의 숫자(Q-값)를 저장하는 표입니다. 에이전트가 "이 상태에서 이 행동을 하면 얼마나 좋은 결과를 기대할 수 있는가?"를 기록하는 저장소죠.

    • 행: 가능한 모든 상태
    • 열: 가능한 모든 행동
    • 칸 안의 값: 해당 (상태, 행동)의 Q-값

    처음에는 아무것도 모르니까 모든 칸을 0으로 채웁니다. 경험이 쌓이면서 숫자들이 점점 의미 있는 값으로 바뀌어 가죠.

    파이썬으로 구현하는 두 가지 방법

    방법 ①: 2차원 리스트 — 상태와 행동이 숫자 인덱스일 때 간편합니다.

    # 상태 5개, 행동 3개인 경우
num_states = 5
num_actions = 3

q_table = [[0.0] * num_actions for _ in range(num_states)]

# q_table[상태][행동]으로 접근
print(q_table[0])  # [0.0, 0.0, 0.0] — 상태 0의 모든 행동 Q-값

    방법 ②: 딕셔너리 — 상태가 문자열이거나 튜플일 때 유연합니다.

    from collections import defaultdict

q_table = defaultdict(lambda: [0.0] * num_actions)

# 처음 보는 상태도 자동으로 [0.0, 0.0, 0.0] 생성
print(q_table["서울역"])  # [0.0, 0.0, 0.0]

    💡 어떤 방법을 쓸까요? 이 챕터에서는 격자 세계(Grid World)를 다루므로 상태가 숫자 인덱스입니다. 2차원 리스트를 기본으로 사용하되, 딕셔너리 버전도 함께 보여드릴게요.

    개념 2: Q-값 업데이트 공식 — 경험에서 배우기 🔄¶

    비유로 시작해요

    시험 공부를 한다고 생각해보세요. 처음에 "이 단원은 쉬울 거야"라고 예상했는데(기존 Q-값), 실제로 문제를 풀어보니 생각보다 어려웠습니다(보상). 그래서 예상을 조금 수정합니다. 하지만 한 번의 경험으로 완전히 바꾸진 않죠 — 조금씩, 조금씩 조정합니다. 이 "조금씩"의 정도를 정하는 것이 학습률(α)입니다.

    정확한 정의

    Q-learning의 업데이트 공식은 다음과 같습니다:

    Q(s, a) ← Q(s, a) + α × [r + γ × max Q(s', a') - Q(s, a)]

    각 기호의 의미를 하나씩 풀어볼게요:

    • Q(s, a): 현재 상태 s에서 행동 a의 기존 Q-값
    • α (알파, 학습률): 새 정보를 얼마나 반영할지 (0~1, 보통 0.1~0.5)
    • r: 행동 a를 해서 받은 즉각 보상
    • γ (감마, 할인율): 미래 보상을 얼마나 중요하게 볼지 (0~1, 보통 0.9~0.99)
    • max Q(s', a'): 다음 상태 s'에서 가능한 행동 중 가장 큰 Q-값
    • [r + γ × max Q(s', a') - Q(s, a)]: "예상과 현실의 차이" (TD 오차)

    파이썬 코드로 번역하면:

    alpha = 0.1   # 학습률
gamma = 0.9   # 할인율

# 업데이트 한 줄
best_next = max(q_table[next_state])
q_table[state][action] += alpha * (reward + gamma * best_next - q_table[state][action])

    놀랍지 않나요? 그 복잡해 보이던 수식이 파이썬으로는 딱 두 줄입니다! 🎉

    숫자로 확인해봅시다

    # 현재 Q(상태2, 행동1) = 0.0 (아직 학습 전)
# 보상 r = 1.0을 받았고
# 다음 상태에서 최대 Q-값이 0.5라면

q_value = 0.0
reward = 1.0
best_next = 0.5

new_q = q_value + 0.1 * (reward + 0.9 * best_next - q_value)
print(f"업데이트 후 Q-값: {new_q}")
# 출력: 업데이트 후 Q-값: 0.145

    0에서 0.145로 바뀌었습니다. "이 상태에서 이 행동은 꽤 괜찮다"는 정보가 조금 반영된 거죠.

    개념 3: ε-greedy 행동 선택 — 탐험과 활용의 균형 ⚖️¶

    비유로 시작해요

    매일 점심을 먹으러 갈 때, 두 가지 선택이 있습니다:

    • 활용(Exploitation): 지금까지 가본 식당 중 가장 맛있던 곳에 또 간다 🏆
    • 탐험(Exploration): 안 가본 새 식당을 시도해본다 🗺️

    항상 같은 곳만 가면 더 맛있는 식당을 발견할 기회를 놓칩니다. 하지만 항상 새 곳만 가면 맛있는 곳을 알고도 못 가죠.

    ε-greedy(엡실론-그리디)는 이 딜레마의 간단하면서도 효과적인 해결책입니다.

    정확한 정의

    • 확률 ε(엡실론)으로 → 랜덤 행동 (탐험)
    • 확률 1-ε으로 → Q-값이 가장 높은 행동 (활용)
    import random

def choose_action(state, q_table, epsilon, num_actions):
    if random.random() < epsilon:
        # 탐험: 랜덤 행동
        return random.randint(0, num_actions - 1)
    else:
        # 활용: Q-값이 가장 높은 행동
        return q_table[state].index(max(q_table[state]))

    ε 값의 의미

    • ε = 1.0: 100% 랜덤 (완전 탐험, 학습 초반에 유용)
    • ε = 0.0: 100% 최적 행동 (완전 활용, 학습 후반에 유용)
    • ε = 0.1: 10% 탐험 + 90% 활용 (가장 흔한 설정)

    💡 실전 팁: 학습 초반에는 ε을 크게 시작해서(예: 1.0), 에피소드가 진행될수록 점점 줄여나가는 ε-감쇠(decay) 전략이 많이 쓰입니다. 이 내용은 "더 해보기"에서 다룹니다.

    개념 4: 에피소드 루프 — 모든 것을 하나로 엮기 🔗¶

    비유로 시작해요

    보드게임 한 판을 생각해보세요. 게임이 시작되면(에피소드 시작), 말을 놓고(상태 초기화), 매 턴마다 주사위를 굴려 행동을 하고(행동 선택), 결과를 보고(보상 확인), 다음 턴으로 넘어갑니다. 게임이 끝나면(목표 도달 또는 실패) 한 판이 종료되고, 다시 새 판을 시작하죠.

    정확한 정의

    에피소드(Episode)란 시작 상태에서 종료 상태까지의 한 번의 플레이입니다. Q-learning은 이 에피소드를 수백~수천 번 반복하면서 Q-테이블을 점점 정확하게 만들어갑니다.

    한 에피소드의 흐름을 다이어그램으로 보면:

    flowchart TD A["🎬 에피소드 시작\n상태 초기화"] --> B["👀 현재 상태 관찰"] B --> C{"ε-greedy로\n행동 선택"} C -->|"랜덤 (확률 ε)"| D["🎲 탐험 행동"] C -->|"최적 (확률 1-ε)"| E["🏆 활용 행동"] D --> F["🌍 환경에 행동 전달\n→ 다음 상태, 보상 받기"] E --> F F --> G["📝 Q-테이블 업데이트"] G --> H{"종료 상태\n도달?"} H -->|"아니오"| B H -->|"예"| I["🏁 에피소드 종료"]

    이 흐름을 코드로 옮기면 while 루프 하나로 표현됩니다.

    🔨 따라하기¶

    간단한 1차원 복도 환경을 만들어서 Q-learning 에이전트를 구현해보겠습니다.

    환경 설명: 길이 5인 복도가 있고, 에이전트는 왼쪽 끝(상태 0)에서 시작합니다. 오른쪽 끝(상태 4)에 도달하면 보상 +1을 받고 에피소드가 끝납니다. 그 외에는 보상 0입니다.

    상태:  [0] [1] [2] [3] [4🎁]
행동:  ← 왼쪽(0) / 오른쪽(1) →

    Step 1: 환경 만들기 🌍¶

    먼저 에이전트가 상호작용할 간단한 환경을 만듭니다.

    class SimpleCorridorEnv:
    """1차원 복도 환경"""

    def __init__(self):
        self.num_states = 5
        self.num_actions = 2  # 0: 왼쪽, 1: 오른쪽
        self.goal_state = 4
        self.state = 0  # 현재 위치

    def reset(self):
        """에피소드 시작: 왼쪽 끝으로 돌아가기"""
        self.state = 0
        return self.state

    def step(self, action):
        """행동을 받아서 (다음 상태, 보상, 종료 여부)를 반환"""
        if action == 0:  # 왼쪽
            self.state = max(0, self.state - 1)
        elif action == 1:  # 오른쪽
            self.state = min(self.num_states - 1, self.state + 1)

        # 보상과 종료 여부 결정
        if self.state == self.goal_state:
            return self.state, 1.0, True   # 도착! 보상 +1
        else:
            return self.state, 0.0, False  # 아직 진행 중

    reset()은 에피소드를 시작할 때, step(action)은 매 턴마다 호출합니다. 이 구조는 나중에 다른 환경으로 교체해도 동일하게 사용할 수 있는 표준 패턴입니다.

    # 환경 테스트
env = SimpleCorridorEnv()
state = env.reset()
print(f"시작 상태: {state}")

next_state, reward, done = env.step(1)  # 오른쪽으로 이동
print(f"행동: 오른쪽 → 상태: {next_state}, 보상: {reward}, 종료: {done}")

    시작 상태: 0
행동: 오른쪽 → 상태: 1, 보상: 0.0, 종료: False

    Step 2: Q-테이블 초기화 📓¶

    모든 칸을 0으로 채운 Q-테이블을 만듭니다.

    def create_q_table(num_states, num_actions):
    """Q-테이블을 0으로 초기화"""
    return [[0.0] * num_actions for _ in range(num_states)]

# Q-테이블 생성
q_table = create_q_table(num_states=5, num_actions=2)

# 확인
for s in range(5):
    print(f"  상태 {s}: 왼쪽={q_table[s][0]:.2f}, 오른쪽={q_table[s][1]:.2f}")

  상태 1: 왼쪽=0.00, 오른쪽=0.00
  상태 2: 왼쪽=0.00, 오른쪽=0.00
  상태 3: 왼쪽=0.00, 오른쪽=0.00
  상태 4: 왼쪽=0.00, 오른쪽=0.00

    모두 0인 백지 상태. 여기서부터 학습이 시작됩니다! ✨

    Step 3: ε-greedy 행동 선택 함수 🎲¶

    import random

def choose_action(state, q_table, epsilon, num_actions):
    """ε-greedy 전략으로 행동 선택"""
    if random.random() < epsilon:
        # 탐험: 랜덤 행동
        return random.randint(0, num_actions - 1)
    else:
        # 활용: Q-값이 가장 높은 행동 선택
        q_values = q_table[state]
        max_q = max(q_values)
        # Q-값이 동일한 행동이 여러 개면 그 중 랜덤 선택
        best_actions = [a for a, q in enumerate(q_values) if q == max_q]
        return random.choice(best_actions)

    🔍 세밀한 포인트: q_table[state].index(max(...)) 대신 동점 처리를 넣었습니다. Q-값이 모두 0인 초기 상태에서 항상 행동 0만 선택하는 편향을 방지하기 위해서예요. 작은 차이지만 학습 품질에 큰 영향을 줍니다.

    동작을 확인해봅시다:

    random.seed(42)

# 아직 모든 Q-값이 0이므로, epsilon에 관계없이 랜덤에 가깝게 동작

    Step 4: Q-값 업데이트 함수 📝¶

    수식을 함수로 감싸서 재사용하기 쉽게 만듭니다.

    def update_q_value(q_table, state, action, reward, next_state, alpha, gamma):
    """Q-learning 업데이트 공식 적용"""
    # 다음 상태에서 최대 Q-값 찾기
    best_next_q = max(q_table[next_state])

    # TD 오차 계산
    td_error = reward + gamma * best_next_q - q_table[state][action]

    # Q-값 업데이트
    q_table[state][action] += alpha * td_error

    return td_error  # 디버깅용으로 반환

    수식 Q(s,a) ← Q(s,a) + α[r + γ·max Q(s',a') - Q(s,a)]이 그대로 코드가 되었습니다.

    # 수동 테스트: 상태 3에서 오른쪽(1)으로 가서 목표(상태 4)에 도달
q_table_test = create_q_table(5, 2)
td = update_q_value(q_table_test, state=3, action=1, reward=1.0, 
                     next_state=4, alpha=0.1, gamma=0.9)
print(f"상태 3, 행동 '오른쪽'의 Q-값: {q_table_test[3][1]:.3f}")
print(f"TD 오차: {td:.3f}")

    상태 3, 행동 '오른쪽'의 Q-값: 0.100
TD 오차: 1.000

    보상 1.0을 받았고, 학습률 0.1이니까 Q-값이 0에서 0.1로 올라갔습니다. 한 발짝 나아갔네요! 🚶

    Step 5: 한 에피소드 실행하기 🎬¶

    이제 모든 조각을 합쳐서 한 에피소드를 실행합니다. print문으로 매 스텝을 추적해봅시다.

    def run_one_episode(env, q_table, alpha, gamma, epsilon, verbose=True):
    """Q-learning으로 에피소드 하나를 실행"""
    state = env.reset()
    total_reward = 0
    steps = 0

    if verbose:
        print(f"\n{'='*50}")
        print(f"에피소드 시작! 초기 상태: {state}")
        print(f"{'='*50}")

    while True:
        # 1) 행동 선택
        action = choose_action(state, q_table, epsilon, env.num_actions)
        action_name = "왼쪽" if action == 0 else "오른쪽"

        # 2) 환경에 행동 전달
        next_state, reward, done = env.step(action)

        # 3) Q-테이블 업데이트
        td_error = update_q_value(q_table, state, action, reward, 
                                   next_state, alpha, gamma)

        # 기록
        total_reward += reward
        steps += 1

        if verbose:
            print(f"  Step {steps}: 상태 {state} → {action_name} "
                  f"→ 상태 {next_state} | 보상: {reward:.1f} | "
                  f"Q({state},{action}): {q_table[state][action]:.3f}")

        # 4) 종료 확인
        if done:
            if verbose:
                print(f"\n🎉 목표 도달! (총 {steps}스텝, 총 보상: {total_reward:.1f})")
            break

        # 너무 오래 걸리면 중단
        if steps >= 100:
            if verbose:
                print(f"\n⏰ 100스텝 초과로 중단")
            break

        # 다음 상태로 이동
        state = next_state

    return total_reward, steps

    실행해봅시다!
