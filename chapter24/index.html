    Chapter 24: 최종 발표와 자율주행 시연¶

    Part 7: [2권] 프로젝트 완성과 발표

    🎯 이 장에서 배우는 것¶

    • 완성된 자율주행 RC카를 실제 코스에서 시연하고 성능을 정량적으로 검증할 수 있다
    • 프로젝트의 설계 과정, 기술적 선택, 문제 해결 경험을 체계적으로 발표할 수 있다
    • 시연 결과를 기반으로 시스템의 강점과 개선점을 분석할 수 있다
    • Physical AI의 미래 발전 방향에 대한 자신의 견해를 논리적으로 제시할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분은 지금까지 23차시에 걸쳐 놀라운 여정을 걸어왔습니다. 센서의 원리를 배우고, 모터를 제어하고, 컴퓨터 비전으로 차선을 인식하고, AI 모델을 학습시켜 자율주행 RC카를 만들었습니다.

    하지만 엔지니어의 일은 "만드는 것"에서 끝나지 않습니다. 세상의 모든 위대한 기술은 누군가가 그것을 설명하고, 시연하고, 사람들을 설득했기 때문에 빛을 볼 수 있었습니다.

    🎤 생각해보기: 일론 머스크가 테슬라 자율주행을 발표할 때, 단순히 "차가 혼자 갑니다"라고만 했을까요? 그는 왜 이 기술이 필요한지, 어떻게 작동하는지, 앞으로 어디로 향하는지를 이야기했습니다.

    이 마지막 차시는 여러분이 만든 사람에서 설명할 수 있는 사람으로 성장하는 시간입니다. 코스 위를 달리는 RC카를 보며, 여러분이 8주간 쌓아온 모든 지식이 하나의 시스템으로 작동하는 순간을 경험하게 될 것입니다.

    📚 핵심 개념¶

    개념 1: 시연 설계 — "보여주기"의 기술¶

    1. 비유로 시작

    요리 대회를 떠올려보세요. 아무리 맛있는 요리를 만들어도, 심사위원 앞에서 접시를 떨어뜨리면 좋은 점수를 받을 수 없습니다. 시연(Demo)은 요리 대회의 플레이팅과 같습니다. 잘 만든 결과물이 최고의 모습으로 보이도록 계획하고 준비하는 과정입니다.

    2. 정확한 정의

    시연 설계란, 프로젝트의 핵심 기능을 재현 가능하고 안정적인 방식으로 청중에게 보여주기 위한 계획을 수립하는 것입니다. 여기에는 테스트 코스 설계, 시연 시나리오 구성, 실패 시 대응 계획(Plan B)이 포함됩니다.

    3. 예시로 확인

    자율주행 RC카 시연의 핵심 요소를 정리하면 다음과 같습니다.

    flowchart LR A["🏁 시연 설계"] --> B["코스 구성"] A --> C["시나리오 작성"] A --> D["Plan B 준비"] B --> B1["차선 테이프 부착"] B --> B2["장애물 배치"] C --> C1["기본 주행 → 차선 따라가기"] C --> C2["응용 주행 → 장애물 회피"] C --> C3["안전 기능 → 비상 정지"] D --> D1["녹화 영상 백업"] D --> D2["수동 조작 전환"]

    📌 알아보기: 실리콘밸리에서는 "Demo or Die(시연하거나 죽거나)"라는 말이 있습니다. 어떤 아이디어든 실제로 작동하는 모습을 보여주지 못하면 인정받기 어렵다는 뜻입니다.

    개념 2: 기술 발표의 구조 — STAR-T 프레임워크¶

    1. 비유로 시작

    영화를 생각해보세요. 좋은 영화에는 항상 구조가 있습니다. 배경 설명 → 사건 발생 → 위기 → 해결 → 여운. 기술 발표도 마찬가지입니다. 청중이 여러분의 이야기에 빠져들도록 하려면 이야기의 뼈대가 필요합니다.

    2. 정확한 정의

    STAR-T 프레임워크는 기술 프로젝트 발표를 위한 구조입니다.

    • S (Situation): 프로젝트 배경과 목표 — "무엇을 왜 만들었나?"
    • T (Technical Approach): 기술적 접근 방식 — "어떻게 만들었나?"
    • A (Adversity): 만난 어려움과 해결 과정 — "무엇이 힘들었나?"
    • R (Result): 결과와 시연 — "실제로 어떻게 작동하나?"
    • T (Tomorrow): 미래 개선 방향 — "다음에는 무엇을 할 것인가?"

    3. 예시로 확인

    flowchart TD S["🎯 Situation<br/>자율주행 RC카로<br/>Physical AI 학습"] T["🔧 Technical Approach<br/>OpenCV 차선 인식 +<br/>PID 조향 제어"] A["⚡ Adversity<br/>조명 변화로 차선 인식률 저하<br/>→ HSV 변환으로 해결"] R["📊 Result<br/>코스 완주 성공률 85%<br/>평균 랩타임 42초"] TM["🚀 Tomorrow<br/>딥러닝 모델 적용으로<br/>인식률 향상 계획"] S --> T --> A --> R --> TM

    💡 핵심 팁: 발표에서 가장 인상적인 부분은 A(Adversity)입니다. "모든 게 순조로웠습니다"보다 "이런 문제를 만나서 이렇게 해결했습니다"가 훨씬 강력한 메시지를 전달합니다.

    개념 3: 성능 평가 — 숫자로 말하기¶

    1. 비유로 시작

    병원에서 건강검진을 받을 때, 의사는 "대충 건강해 보입니다"라고 하지 않습니다. 혈압 120/80, 체온 36.5°C처럼 수치로 건강 상태를 알려줍니다. 자율주행 시스템도 마찬가지입니다. "잘 달립니다"가 아니라 구체적인 숫자로 성능을 표현해야 합니다.

    2. 정확한 정의

    성능 평가(Performance Evaluation)란, 시스템이 목표를 얼마나 잘 달성하는지를 정량적 지표(metric)로 측정하고 분석하는 과정입니다.

    자율주행 RC카의 핵심 평가 지표는 다음과 같습니다.

    • 완주율(Completion Rate): 코스를 끝까지 달린 비율 (예: 10회 중 8회 성공 → 80%)
    • 랩타임(Lap Time): 코스 1바퀴를 도는 데 걸린 시간
    • 차선 이탈 횟수(Lane Departure Count): 주행 중 차선을 벗어난 횟수
    • 장애물 회피 성공률: 배치된 장애물을 충돌 없이 회피한 비율
    • 비상 정지 반응 시간: 장애물 감지 후 완전 정지까지 걸린 시간

    3. 예시로 확인

    # 시연 결과를 자동으로 기록하고 분석하는 코드
import time
import json
from datetime import datetime

class DemoEvaluator:
    """자율주행 RC카 시연 성능 평가 도구"""

    def __init__(self, team_name):
        self.team_name = team_name
        self.runs = []          # 각 주행 기록
        self.current_run = None  # 현재 진행 중인 주행

    def start_run(self, run_number):
        """주행 시작"""
        self.current_run = {
            "run_number": run_number,
            "start_time": time.time(),
            "lane_departures": 0,
            "obstacles_total": 0,
            "obstacles_avoided": 0,
            "completed": False,
            "emergency_stops": []
        }
        print(f"🏁 Run #{run_number} 시작!")

    def record_lane_departure(self):
        """차선 이탈 기록"""
        if self.current_run:
            self.current_run["lane_departures"] += 1
            print(f"⚠️ 차선 이탈! (누적: {self.current_run['lane_departures']}회)")

    def record_obstacle(self, avoided=True):
        """장애물 회피 결과 기록"""
        if self.current_run:
            self.current_run["obstacles_total"] += 1
            if avoided:
                self.current_run["obstacles_avoided"] += 1
                print("✅ 장애물 회피 성공!")
            else:
                print("❌ 장애물 충돌!")

    def record_emergency_stop(self, reaction_time_ms):
        """비상 정지 반응 시간 기록 (밀리초)"""
        if self.current_run:
            self.current_run["emergency_stops"].append(reaction_time_ms)
            print(f"🛑 비상 정지! 반응 시간: {reaction_time_ms}ms")

    def end_run(self, completed=True):
        """주행 종료"""
        if self.current_run:
            self.current_run["end_time"] = time.time()
            self.current_run["lap_time"] = round(
                self.current_run["end_time"] - self.current_run["start_time"], 2
            )
            self.current_run["completed"] = completed
            self.runs.append(self.current_run)

            status = "✅ 완주!" if completed else "❌ 미완주"
            print(f"{status} 랩타임: {self.current_run['lap_time']}초")
            self.current_run = None

    def get_summary(self):
        """전체 성능 요약"""
        if not self.runs:
            return "기록된 주행이 없습니다."

        total_runs = len(self.runs)
        completed = sum(1 for r in self.runs if r["completed"])
        completion_rate = round(completed / total_runs * 100, 1)

        completed_times = [r["lap_time"] for r in self.runs if r["completed"]]
        avg_lap_time = round(sum(completed_times) / len(completed_times), 2) if completed_times else 0
        best_lap_time = round(min(completed_times), 2) if completed_times else 0

        total_departures = sum(r["lane_departures"] for r in self.runs)

        obs_total = sum(r["obstacles_total"] for r in self.runs)
        obs_avoided = sum(r["obstacles_avoided"] for r in self.runs)
        obs_rate = round(obs_avoided / obs_total * 100, 1) if obs_total > 0 else 0

        all_stops = []
        for r in self.runs:
            all_stops.extend(r["emergency_stops"])
        avg_reaction = round(sum(all_stops) / len(all_stops), 1) if all_stops else 0

        summary = {
            "team": self.team_name,
            "total_runs": total_runs,
            "completion_rate": f"{completion_rate}%",
            "avg_lap_time": f"{avg_lap_time}초",
            "best_lap_time": f"{best_lap_time}초",
            "total_lane_departures": total_departures,
            "obstacle_avoidance_rate": f"{obs_rate}%",
            "avg_emergency_reaction": f"{avg_reaction}ms"
        }
        return summary

    def print_report(self):
        """결과 리포트 출력"""
        s = self.get_summary()
        if isinstance(s, str):
            print(s)
            return

        print("\n" + "=" * 50)
        print(f"📊 팀 '{s['team']}' 최종 성능 리포트")
        print("=" * 50)
        print(f"  🏁 총 주행 횟수: {s['total_runs']}회")
        print(f"  ✅ 완주율: {s['completion_rate']}")
        print(f"  ⏱️ 평균 랩타임: {s['avg_lap_time']}")
        print(f"  🏆 최고 랩타임: {s['best_lap_time']}")
        print(f"  ↔️ 차선 이탈 총 횟수: {s['total_lane_departures']}회")
        print(f"  🚧 장애물 회피 성공률: {s['obstacle_avoidance_rate']}")
        print(f"  🛑 비상 정지 평균 반응: {s['avg_emergency_reaction']}")
        print("=" * 50)


# 사용 예시: 시연 시뮬레이션
evaluator = DemoEvaluator("Team Alpha")

# Run 1
evaluator.start_run(1)
evaluator.record_obstacle(avoided=True)
evaluator.record_lane_departure()
evaluator.record_obstacle(avoided=True)
evaluator.record_emergency_stop(320)
evaluator.end_run(completed=True)

# Run 2
evaluator.start_run(2)
evaluator.record_obstacle(avoided=True)
evaluator.record_obstacle(avoided=False)
evaluator.end_run(completed=True)

# Run 3
evaluator.start_run(3)
evaluator.record_lane_departure()
evaluator.record_lane_departure()
evaluator.end_run(completed=False)

evaluator.print_report()

    개념 4: Physical AI의 미래 — 자율주행을 넘어서¶

    1. 비유로 시작

    여러분이 지금까지 만든 자율주행 RC카는 마치 첫 번째 도미노와 같습니다. 작은 RC카 하나를 쓰러뜨린 것 같지만, 그 뒤에는 자율주행 자동차, 배달 로봇, 수술 로봇, 우주 탐사 로봇이라는 거대한 도미노들이 줄지어 서 있습니다.

    2. 정확한 정의

    Physical AI란 디지털 세계의 AI가 물리적 세계와 상호작용하는 모든 기술을 말합니다. 센서로 현실을 감지하고, AI로 판단하며, 액추에이터(모터, 로봇 팔 등)로 현실에 영향을 미치는 시스템입니다.

    여러분이 RC카에서 배운 "감지 → 판단 → 행동"의 루프는 모든 Physical AI의 핵심 원리입니다.

    3. 예시로 확인

    # 시연 코스 설계 및 체크리스트 생성
class DemoCourseDesigner:
    """시연 코스를 설계하고 체크리스트를 생성하는 도구"""

    def __init__(self, course_name="Final Demo Course"):
        self.course_name = course_name

        self.checklist = {

                ("조명 상태 확인 (그림자 없는지)", False),
                ("코스 주변 정리 (방해물 제거)", False),
            ],
            "RC카 점검": [

                ("카메라 렌즈 청소", False),
                ("모터 정상 동작 확인", False),
                ("초음파 센서 정상 동작 확인", False),
                ("Wi-Fi 연결 안정성 확인", False),
            ],
            "소프트웨어 점검": [
                ("자율주행 코드 최신 버전 확인", False),
                ("비상 정지 기능 테스트", False),
                ("수동 조작 전환 테스트", False),
                ("성능 기록 코드 준비", False),
            ],
            "발표 준비": [
                ("발표 자료(슬라이드) 준비", False),
                ("시연 시나리오 리허설 완료", False),
                ("역할 분담 확인 (발표자/조작자)", False),
                ("타이머 준비", False),
            ],
        }

    def add_section(self, name, length_m, feature):
        """코스 구간 추가"""
        self.sections.append({
            "name": name,
            "length": length_m,
            "feature": feature
        })
        print(f"📍 구간 추가: {name} ({length_m}m) - {feature}")

    def display_course(self):
        """코스 전체 표시"""
        total = sum(s["length"] for s in self.sections)
        print(f"\n🏁 코스: {self.course_name}")
        print(f"   총 길이: {total}m")
        print(f"   구간 수: {len(self.sections)}")
        print()
        for i, s in enumerate(self.sections, 1):
            print(f"   구간 {i}: {s['name']}")
            print(f"          길이: {s['length']}m")
            print(f"          특징: {s['feature']}")
            print()

    def print_checklist(self):
        """체크리스트 출력"""
        print("\n📋 시연 전 체크리스트")
        print("=" * 45)
        for category, items in self.checklist.items():
            print(f"\n🔹 {category}")
            for item, checked in items:
                mark = "✅" if checked else "⬜"
                print(f"   {mark} {item}")
        print()

    발표 구조 자동 생성기¶

    class PresentationBuilder: """STAR-T 프레임워크 기반 발표 구조 생성기"""

    def __init__(self, team_name, members):
    self.team_name = team_name
    self.members = members
    self.sections = {}

def set_situation(self, goal, background):
    """S: 프로젝트 배경과 목표"""
    self.sections["Situation"] = {
        "goal": goal,
        "background": background,
        "suggested_time": "2분"
    }

def set_technical(self, approaches):
    """T: 기술적 접근 (리스트로 입력)"""
    self.sections["Technical"] = {
        "approaches": approaches,
        "suggested_time": "4분"
    }

def set_adversity(self, challenges):
    """A: 어려움과 해결 (딕셔너리: 문제 → 해결)"""
    self.sections["Adversity"] = {
        "challenges": challenges,
        "suggested_time": "3분"
    }

def set_result(self, metrics):
    """R: 결과 (딕셔너리: 지표명 → 값)"""
    self.sections["Result"] = {
        "metrics": metrics,
        "suggested_time": "3분 (시연 포함)"
    }

def set_tomorrow(self, improvements):
    """T: 미래 개선 방향 (리스트)"""
    self.sections["Tomorrow"] = {
        "improvements": improvements,
        "suggested_time": "2분"
    }

def generate_outline(self):
    """발표 아웃라인 생성"""
    print(f"\n{'='*55}")
    print(f"📋 팀 '{self.team_name}' 발표 아웃라인")
    print(f"   팀원: {', '.join(self.members)}")
    print(f"{'='*55}")

    order = [
        ("Situation", "🎯", "배경과 목표"),
        ("Technical", "🔧", "기술적 접근"),
        ("Adversity", "⚡", "도전과 해결"),
        ("Result", "📊", "결과와 시연"),
        ("Tomorrow", "🚀", "미래 방향"),
    ]

    for key, emoji, title in order:
        section = self.sections.get(key)
        if not section:
            print(f"\n{emoji} {title}: (미작성)")
            continue

        suggested = section.get("suggested_time", "?분")
        print(f"\n{emoji} {title} (권장: {suggested})")
        print(f"   {'─'*40}")

        if key == "Situation":
            print(f"   목표: {section['goal']}")
            print(f"   배경: {section['background']}")

        elif key == "Technical":
            for i, approach in enumerate(section["approaches"], 1):
                print(f"   {i}. {approach}")

        elif key == "Adversity":
            for problem, solution in section["challenges"].items():
                print(f"   ❓ 문제: {problem}")
                print(f"   💡 해결: {solution}")
                print()

        elif key == "Result":
            for metric, value in section["metrics"].items():
                print(f"   📈 {metric}: {value}")

        elif key == "Tomorrow":
            for imp in section["improvements"]:
                print(f"   → {imp}")

    total_time = "약 14분 (시연 시간 별도)"
    print(f"\n{'─'*55}")
    print(f"⏱️ 예상 총 발표 시간: {total_time}")
    print(f"{'='*55}")
