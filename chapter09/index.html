    Chapter 9: 데이터 전처리와 증강¶

    🎯 이 장에서 배우는 것¶

    • 수집된 이미지에서 관심 영역(ROI)을 추출하고 크기를 조정할 수 있다
    • 픽셀값 정규화의 원리를 이해하고 코드로 구현할 수 있다
    • 데이터 증강(augmentation) 기법을 적용하여 학습 데이터의 다양성을 높일 수 있다
    • 전처리된 데이터를 학습·검증·테스트 세트로 분리하고 그 이유를 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    같은 도로를 달리더라도, 맑은 날과 흐린 날의 도로 사진은 매우 다르게 보입니다. 그림자가 길게 드리운 오후와 밝은 정오의 사진도 다릅니다. 사람은 "아, 그래도 같은 도로잖아"라고 쉽게 판단하지만, AI는 이런 변화에 쉽게 혼란을 겪습니다. 어떻게 하면 AI가 다양한 상황에서도 도로를 정확히 인식할 수 있을까요?

    이전 Chapter 8에서 CARLA 시뮬레이터를 통해 주행 데이터를 수집했습니다. 하지만 수집한 데이터를 그대로 AI 모델에 넣으면 좋은 결과를 얻기 어렵습니다. 이유는 크게 세 가지입니다.

    첫째, 불필요한 정보가 포함되어 있습니다. 카메라로 찍은 이미지에는 하늘, 먼 산 등 주행 판단에 관계없는 부분이 많습니다. 이런 정보는 AI를 혼란스럽게 만듭니다.

    둘째, 데이터의 형식이 제각각입니다. 픽셀값의 범위, 이미지 크기가 통일되지 않으면 모델이 학습하기 어렵습니다.

    셋째, 데이터의 다양성이 부족합니다. 시뮬레이터에서 수집한 데이터는 특정 날씨, 특정 시간대에 편중되기 쉽습니다. 현실에서는 비가 오기도 하고, 역광이 생기기도 합니다.

    이번 장에서는 이 세 가지 문제를 해결하는 데이터 전처리(preprocessing)와 데이터 증강(augmentation) 기법을 배웁니다. 요리에 비유하면, 전처리는 "재료 다듬기"이고 증강은 "같은 재료로 다양한 요리법 시도하기"입니다. 이 과정이 끝나면, AI 모델이 학습하기에 최적화된 깨끗하고 다양한 데이터셋을 갖추게 됩니다.

    📚 핵심 개념¶

    개념 1: 관심 영역(ROI) 추출과 크기 조정¶

    비유로 시작 🎬¶

    시험 공부를 할 때 교과서 전체를 읽는 것보다, 중요한 부분에 형광펜을 치고 그 부분만 집중적으로 공부하는 것이 효율적이죠? 이미지도 마찬가지입니다. 자율주행 AI에게 하늘이나 차량 보닛(hood) 부분은 주행 판단에 거의 쓸모가 없습니다. 도로와 차선이 있는 영역만 잘라내는 것이 훨씬 효과적입니다.

    정확한 정의 📖¶

    관심 영역(ROI, Region of Interest)이란 이미지에서 분석 목적에 필요한 특정 영역을 의미합니다. ROI 추출은 이미지의 불필요한 부분을 잘라내어(crop) 모델이 핵심 정보에만 집중하도록 하는 전처리 기법입니다.

    크기 조정(Resize)은 이미지의 해상도를 통일하는 과정입니다. 모델에 입력되는 모든 이미지는 같은 크기여야 합니다.

    예시로 확인 🖼️¶

    CARLA에서 수집한 640×480 이미지를 생각해봅시다.

    graph TD A["원본 이미지<br/>640 × 480"] --> B["ROI 추출<br/>상단 40% 제거<br/>(하늘, 건물)"] B --> C["크롭된 이미지<br/>640 × 288"] C --> D["크기 조정<br/>200 × 66"] D --> E["모델 입력용 이미지<br/>200 × 66"]

    상단 약 40%를 제거하면 하늘과 먼 건물이 사라지고, 도로·차선·주변 차량 등 주행에 필요한 정보만 남습니다. 그 후 200×66 크기로 줄이면 계산량도 크게 감소합니다.

    import cv2
import numpy as np

def preprocess_roi(image):
    """이미지에서 ROI를 추출하고 크기를 조정합니다."""
    # 원본: 640 x 480
    height = image.shape[0]  # 480

    # 상단 40%를 제거 (하늘 영역)
    crop_top = int(height * 0.4)  # 192
    cropped = image[crop_top:, :]  # 288 x 640

    # 모델 입력 크기로 조정
    resized = cv2.resize(cropped, (200, 66))

    return resized

    알아보기 📌

    왜 200×66 크기일까요? 이 크기는 NVIDIA의 자율주행 논문(End-to-End Learning for Self-Driving Cars)에서 사용한 입력 크기입니다. 이미지가 작을수록 모델이 빠르게 학습하지만, 너무 작으면 중요한 정보가 사라집니다. 이 크기는 도로 정보를 충분히 유지하면서도 효율적인 학습이 가능한 균형점입니다.

    개념 2: 픽셀값 정규화¶

    비유로 시작 📏¶

    한국사 점수는 100점 만점이고, 수학 점수는 150점 만점인 시험이 있다고 합시다. 두 과목 점수를 단순히 더하면 수학이 불공평하게 유리해지겠죠? 그래서 두 점수를 같은 기준(예: 0~1 범위)으로 변환합니다. 이미지 픽셀값도 마찬가지입니다. 원래 0~255 범위의 정수값을 0~1 범위의 실수값으로 바꾸면, 모델이 훨씬 안정적으로 학습할 수 있습니다.

    정확한 정의 📖¶

    정규화(Normalization)란 데이터의 값 범위를 일정한 범위로 변환하는 과정입니다. 이미지 정규화에서는 주로 각 픽셀값을 255로 나누어 0~1 범위로 변환합니다.

    정규화가 필요한 이유는 다음과 같습니다.

    • 학습 안정성: 큰 수치(0~255)는 가중치 업데이트를 불안정하게 만듭니다
    • 수렴 속도: 작은 범위의 값은 경사 하강법(gradient descent)이 더 빠르게 최적값에 도달합니다
    • 동등한 중요도: 모든 특성(feature)이 비슷한 범위를 가져야 특정 특성이 과도하게 영향을 주지 않습니다

    예시로 확인 🔢¶

    def normalize_image(image):
    """픽셀값을 0~1 범위로 정규화합니다."""
    return image.astype(np.float32) / 255.0

# 사용 예시
raw_image = cv2.imread("carla_image_001.png")
print(f"정규화 전 - 최소: {raw_image.min()}, 최대: {raw_image.max()}")
# 출력: 정규화 전 - 최소: 0, 최대: 255

normalized = normalize_image(raw_image)
print(f"정규화 후 - 최소: {normalized.min():.2f}, 최대: {normalized.max():.2f}")
# 출력: 정규화 후 - 최소: 0.00, 최대: 1.00

    알아보기 📌

    .astype(np.float32)는 왜 필요할까요? 원본 이미지의 픽셀값은 uint8 타입(0~255 정수)입니다. 이 상태에서 255로 나누면 정수 나눗셈이 되어 대부분 0이 됩니다. 먼저 float32(소수점이 있는 실수)로 변환해야 정확한 나눗셈이 이루어집니다.

    개념 3: 데이터 증강(Data Augmentation)¶

    비유로 시작 🎨¶

    미술 수업에서 사과를 그린다고 합시다. 사과를 정면에서만 100번 보고 그리는 것과, 위, 아래, 옆, 빛이 강할 때, 약할 때 등 다양한 조건에서 20번씩 보고 그리는 것 중, 어느 쪽이 사과를 더 잘 이해할까요? 당연히 후자입니다. 데이터 증강은 기존 데이터를 변형하여 마치 다양한 조건에서 수집한 것처럼 만드는 기법입니다.

    정확한 정의 📖¶

    데이터 증강(Data Augmentation)은 기존 학습 데이터에 다양한 변환을 적용하여 새로운 학습 샘플을 인위적으로 생성하는 기법입니다. 이를 통해 데이터의 양과 다양성을 동시에 늘릴 수 있으며, 모델의 일반화 능력(새로운 데이터에 대한 예측 성능)을 향상시킵니다.

    자율주행에서 자주 사용하는 증강 기법은 다음과 같습니다.

    graph LR A["원본 이미지"] --> B["좌우 반전<br/>Horizontal Flip"] A --> C["밝기 조절<br/>Brightness"] A --> D["그림자 추가<br/>Shadow"] A --> E["색상 변환<br/>Color Shift"]

    예시로 확인 🔧¶

    ① 좌우 반전 (Horizontal Flip)

    좌회전하는 이미지를 좌우 반전하면 우회전하는 이미지가 됩니다. 이때 조향각도 부호를 반전해야 합니다.

    def flip_image(image, steering_angle):
    """이미지를 좌우 반전하고 조향각도 반전합니다."""
    flipped = cv2.flip(image, 1)  # 1: 좌우 반전
    flipped_angle = -steering_angle
    return flipped, flipped_angle

    ② 밝기 조절 (Brightness Adjustment)

    밝기를 무작위로 변경하면 낮/밤, 맑은 날/흐린 날 등 다양한 조명 조건을 시뮬레이션할 수 있습니다.

    def adjust_brightness(image):
    """이미지 밝기를 무작위로 조절합니다."""
    # HSV 색공간으로 변환 (V 채널이 밝기)
    hsv = cv2.cvtColor(image, cv2.COLOR_RGB2HSV)
    hsv = hsv.astype(np.float32)

    # 밝기를 0.4 ~ 1.2 배로 무작위 조절
    brightness_factor = np.random.uniform(0.4, 1.2)
    hsv[:, :, 2] = hsv[:, :, 2] * brightness_factor
    hsv[:, :, 2] = np.clip(hsv[:, :, 2], 0, 255)  # 범위 제한

    hsv = hsv.astype(np.uint8)
    return cv2.cvtColor(hsv, cv2.COLOR_HSV2RGB)

    알아보기 📌

    HSV 색공간이란? RGB(빨강-초록-파랑)와 다르게 HSV는 색상(Hue)-채도(Saturation)-명도(Value)로 색을 표현합니다. 밝기만 바꾸고 싶을 때 HSV로 변환하면 V 채널만 조절하면 되므로 매우 편리합니다.

    ③ 무작위 그림자 추가

    실제 도로에는 건물이나 나무로 인한 그림자가 자주 생깁니다.

    def add_random_shadow(image):
    """이미지에 무작위 그림자를 추가합니다."""
    h, w = image.shape[:2]

    # 무작위 사각형 영역에 그림자 생성
    x1 = np.random.randint(0, w // 2)
    x2 = np.random.randint(w // 2, w)

    shadow_image = image.copy().astype(np.float32)
    shadow_image[:, x1:x2, :] *= np.random.uniform(0.3, 0.7)
    shadow_image = np.clip(shadow_image, 0, 255).astype(np.uint8)

    return shadow_image

    생각해보기 🤔

    증강을 할 때 주의할 점이 있습니다. 이미지를 상하 반전하면 어떻게 될까요? 도로가 위에, 하늘이 아래에 놓이게 되어 현실에서 절대 볼 수 없는 이미지가 만들어집니다. 증강은 현실에서 발생할 수 있는 변형만 적용해야 합니다.

    개념 4: 데이터셋 분리 — 학습/검증/테스트¶

    비유로 시작 📝¶

    시험 준비를 할 때를 생각해봅시다.

    • 교과서 문제(학습 세트): 풀면서 개념을 익히는 문제
    • 모의고사(검증 세트): 중간중간 실력을 확인하는 문제. 틀린 부분을 보고 공부 방법을 조정
    • 수능(테스트 세트): 최종 실력을 평가하는 문제. 딱 한 번만 풀어야 공정

    AI 학습도 똑같습니다. 모든 데이터로 학습만 하면, 그 데이터는 잘 맞추지만 새로운 데이터에서 실패합니다. 이를 과적합(overfitting)이라 하며, 교과서 문제는 달달 외웠지만 수능에서 틀리는 것과 같습니다.

    정확한 정의 📖¶

    graph TD A["전체 데이터셋<br/>100%"] --> B["학습 세트<br/>(Training Set)<br/>70~80%"] A --> C["검증 세트<br/>(Validation Set)<br/>10~15%"] A --> D["테스트 세트<br/>(Test Set)<br/>10~15%"] B --> E["모델이 패턴을<br/>배우는 데이터"] C --> F["학습 중간에<br/>성능 확인용"] D --> G["최종 성능<br/>평가용"]
    • 학습 세트(Training Set): 모델이 직접 학습하는 데이터 (70~80%)
    • 검증 세트(Validation Set): 학습 도중 모델의 성능을 평가하고 하이퍼파라미터를 조정하는 데이터 (10~15%)
    • 테스트 세트(Test Set): 모든 학습이 끝난 후 최종 성능을 평가하는 데이터 (10~15%)

    예시로 확인 🔀¶

    from sklearn.model_selection import train_test_split

def split_dataset(images, labels, test_ratio=0.15, val_ratio=0.15):
    """데이터를 학습/검증/테스트 세트로 분리합니다."""
    # 1단계: 테스트 세트 분리
    X_temp, X_test, y_temp, y_test = train_test_split(
        images, labels,
        test_size=test_ratio,
        random_state=42,       # 재현 가능하도록 시드 고정
        shuffle=True           # 데이터를 섞어서 분리
    )

    # 2단계: 나머지에서 검증 세트 분리
    adjusted_val_ratio = val_ratio / (1 - test_ratio)
    X_train, X_val, y_train, y_val = train_test_split(
        X_temp, y_temp,
        test_size=adjusted_val_ratio,
        random_state=42
    )

    print(f"학습 세트: {len(X_train)}개")
    print(f"검증 세트: {len(X_val)}개")
    print(f"테스트 세트: {len(X_test)}개")

    return X_train, X_val, X_test, y_train, y_val, y_test

    알아보기 📌

    random_state=42는 무엇일까요? 데이터를 무작위로 섞을 때 사용하는 난수 시드(seed)입니다. 같은 시드를 쓰면 코드를 여러 번 실행해도 항상 같은 방식으로 분리됩니다. 실험의 재현성을 위해 꼭 설정합니다. 숫자 42는 관례적으로 많이 쓰이지만, 어떤 숫자든 상관없습니다.

    생각해보기 🤔

    왜 shuffle=True가 중요할까요? CARLA에서 데이터를 수집하면 시간 순서대로 저장됩니다. 앞부분은 직진, 뒷부분은 커브일 수 있습니다. 셔플 없이 분리하면 학습 세트에는 직진만, 테스트 세트에는 커브만 들어갈 수 있어 공정한 평가가 불가능합니다.

    def preprocess_pipeline(image_path):
    """이미지 전처리 파이프라인: 읽기 → ROI → 리사이즈 → 정규화"""
    # 1. 이미지 읽기
    image = cv2.imread(image_path)
    image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

    # 2. ROI 추출 (상단 40%, 하단 10% 제거)
    h = image.shape[0]
    crop_top = int(h * 0.4)    # 하늘 제거
    crop_bottom = int(h * 0.9)  # 차량 보닛 제거
    cropped = image[crop_top:crop_bottom, :]

    # 3. 크기 조정 (200 x 66)
    resized = cv2.resize(cropped, (200, 66))

    # 4. 정규화 (0~1 범위)
    normalized = resized.astype(np.float32) / 255.0

    return normalized

    직진 데이터가 90% 이상이면, 모델은 "항상 직진하면 정답률 90%!"라고 학습해버립니다. 커브에서는 전혀 대응하지 못하겠죠. 이를 해결하기 위해 직진 데이터를 일부 제거하거나, 커브 데이터를 증강으로 늘려야 합니다.

    def balance_data(df, bins=25, max_per_bin=400):
    """조향각 분포를 균형 있게 만듭니다."""
    balanced_indices = []

    # 조향각을 구간(bin)으로 나누기
    hist, bin_edges = np.histogram(df["steering"], bins=bins)

    for i in range(bins):
        # 각 구간에 속하는 데이터 인덱스 찾기
        mask = (df["steering"] >= bin_edges[i]) & (df["steering"] < bin_edges[i+1])
        bin_indices = df[mask].index.tolist()

        # 최대 개수 제한 (초과 시 무작위 샘플링)
        if len(bin_indices) > max_per_bin:
            bin_indices = np.random.choice(bin_indices, max_per_bin, replace=False).tolist()

        balanced_indices.extend(bin_indices)

    balanced_df = df.loc[balanced_indices].reset_index(drop=True)
    print(f"균형화 전: {len(df)}개 → 균형화 후: {len(balanced_df)}개")
    return balanced_df

balanced_df = balance_data(df)
