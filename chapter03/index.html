    함수로 정리하는 로봇 동작¶

    🎯 이 장에서 배우는 것¶

    • 반복되는 로봇 동작 코드를 함수로 정의하여 코드를 깔끔하게 정리할 수 있다
    • 매개변수를 활용하여 속도와 시간을 유연하게 조절하는 함수를 만들 수 있다
    • 여러 함수를 조합하여 복잡한 경로를 이동하는 프로그램을 작성할 수 있다
    • 기본값(default parameter)을 설정하여 더 편리한 함수를 만들 수 있다

    💡 왜 이걸 배우나요?¶

    지난 시간에 햄스터 로봇을 전진, 후진, 회전시키는 코드를 작성해봤죠? 혹시 이런 생각이 들지 않았나요?

    "전진하는 코드를 매번 다시 쓰려니 귀찮은데…" 🤔

    예를 들어, 로봇이 사각형 모양으로 움직이게 하려면 "전진 → 우회전 → 전진 → 우회전 → 전진 → 우회전 → 전진 → 우회전" 이렇게 비슷한 코드를 8번이나 반복해야 합니다. 코드가 길어지면 어디서 실수했는지 찾기도 어렵고, 속도를 바꾸고 싶으면 여러 곳을 하나하나 수정해야 하죠.

    이럴 때 필요한 것이 바로 함수입니다! 📦

    함수는 자주 쓰는 코드를 하나의 이름으로 묶어두는 것입니다. 한 번 만들어두면 이름만 불러서 언제든 재사용할 수 있어요. 이번 장을 마치면, 여러분의 코드가 놀라울 정도로 짧고 읽기 쉽게 변할 거예요!

    📚 핵심 개념¶

    개념 1: 함수란 무엇인가?¶

    🎭 비유로 시작

    여러분이 카페 알바생이라고 상상해보세요. 손님이 "아메리카노 주세요"라고 하면, 여러분은 머릿속에 저장된 레시피대로 만듭니다.

    • 에스프레소를 추출한다
    • 컵에 물을 넣는다
    • 에스프레소를 붓는다

    매번 "에스프레소를 추출하고, 컵에 물을 넣고, 에스프레소를 부어주세요"라고 긴 설명을 하지 않아도 "아메리카노"라는 한마디면 충분하죠. 함수가 바로 이런 역할을 합니다!

    📖 정확한 정의

    함수(function)는 특정 작업을 수행하는 코드 묶음에 이름을 붙인 것입니다. 파이썬에서는 def 키워드로 함수를 만듭니다.

    💻 예시로 확인

    # 함수 정의 (레시피 등록)
def say_hello():
    print("안녕하세요!")
    print("햄스터 로봇과 함께 합니다!")

# 함수 호출 (레시피 실행)
say_hello()
say_hello()   # 두 번째 호출 – 같은 코드가 또 실행됨

    def는 "define(정의하다)"의 줄임말이에요. 함수를 정의하는 것과 호출하는 것은 다릅니다. 정의는 레시피를 등록하는 것이고, 호출은 실제로 요리를 시작하는 것이죠! 🍳

    flowchart LR A["def say_hello():<br/>함수 정의 📝"] --> B["메모리에 저장"] B --> C["say_hello()<br/>함수 호출 ▶️"] C --> D["코드 실행!"]

    개념 2: 매개변수 – 함수에 값 전달하기¶

    🎭 비유로 시작

    다시 카페로 돌아가볼까요? "아메리카노"만으로는 부족할 때가 있어요. "아이스 아메리카노", "핫 아메리카노"처럼 옵션을 지정하고 싶을 때요. 함수에서도 마찬가지로 매개변수를 통해 옵션을 전달할 수 있습니다.

    📖 정확한 정의

    매개변수(parameter)는 함수가 외부에서 받아들이는 값입니다. 함수를 호출할 때 전달하는 실제 값은 인수(argument)라고 합니다.

    💻 예시로 확인

    # speed와 duration이 매개변수
def forward(speed, duration):
    print(f"속도 {speed}으로 {duration}초 전진!")

# 50과 2가 인수
forward(50, 2)   # 속도 50으로 2초 전진!
forward(30, 5)   # 속도 30으로 5초 전진!

    같은 함수인데 전달하는 값에 따라 동작이 달라집니다. 이것이 매개변수의 핵심이에요! ✨

    개념 3: 기본값(Default Parameter)¶

    🎭 비유로 시작

    카페에서 "아메리카노요~"라고만 하면, 보통 레귤러 사이즈로 나오죠? 특별히 "그란데"라고 말할 때만 큰 사이즈가 나옵니다. 이렇게 따로 말하지 않으면 자동으로 적용되는 값이 기본값입니다.

    📖 정확한 정의

    매개변수에 기본값을 지정하면, 함수 호출 시 해당 인수를 생략할 수 있습니다.

    💻 예시로 확인

    def forward(speed=50, duration=1):
    print(f"속도 {speed}으로 {duration}초 전진!")

forward()          # 속도 50으로 1초 전진! (모두 기본값)
forward(80)        # 속도 80으로 1초 전진! (duration만 기본값)
forward(30, 3)     # 속도 30으로 3초 전진! (기본값 사용 안 함)

    기본값이 있으면 자주 쓰는 설정을 매번 입력하지 않아도 되어 편리합니다! 🎉

    개념 4: 함수 조합 – 복잡한 동작 만들기¶

    🎭 비유로 시작

    레고 블록을 생각해보세요. 작은 블록들을 조합하면 집도, 자동차도, 성도 만들 수 있죠. 함수도 마찬가지입니다. 작은 함수들을 순서대로 호출하면 복잡한 동작을 만들 수 있어요!

    📖 정확한 정의

    함수 조합이란 여러 개의 작은 함수를 순서대로 호출하여 하나의 큰 동작을 만드는 프로그래밍 방법입니다.

    💻 예시로 확인

    def forward(speed, duration):
    # 전진 코드
    pass

def turn_right(speed, duration):
    # 우회전 코드
    pass

# 함수 조합으로 사각형 경로 만들기!
def draw_square():
    for i in range(4):
        forward(50, 1)
        turn_right(50, 0.5)
    flowchart TD A["draw_square() 호출"] --> B["forward(50, 1)"] B --> C["turn_right(50, 0.5)"] C --> D{4번 반복했나?} D -- 아니오 --> B D -- 예 --> E["완료! 🎉"]

    작은 함수를 조합해서 draw_square()라는 더 큰 함수까지 만들었습니다. 이것이 프로그래밍의 매력이에요! 🧱

    🔨 따라하기¶

    이제 실제 햄스터 로봇으로 실습해봅시다! 단계별로 따라오세요.

    Step 1: 기본 동작 함수 만들기¶

    먼저 전진, 후진, 정지 함수를 만들어봅시다.

    from roboid import *

hamster = Hamster()

def forward(speed, duration):
    hamster.wheels(speed, speed)
    wait(duration * 1000)  # 초를 밀리초로 변환
    hamster.wheels(0, 0)

def backward(speed, duration):
    hamster.wheels(-speed, -speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

def stop():
    hamster.wheels(0, 0)

    🔍 코드 해설: wait() 함수는 밀리초(1/1000초) 단위를 사용하므로, 우리가 전달하는 초 단위 값에 1000을 곱합니다. 함수 끝에서 바퀴를 멈추는 것도 잊지 마세요!

    직접 해보기: 위 코드를 입력한 뒤 아래 호출 코드를 추가하고 실행해보세요.

    forward(50, 2)    # 속도 50으로 2초 전진
wait(1000)        # 1초 쉬고
backward(30, 1)   # 속도 30으로 1초 후진

    로봇이 앞으로 갔다가 뒤로 오나요? 성공이에요! 👏

    Step 2: 회전 함수 추가하기¶

    좌회전과 우회전 함수를 만들어봅시다.

    def turn_left(speed, duration):
    hamster.wheels(-speed, speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

def turn_right(speed, duration):
    hamster.wheels(speed, -speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

    🔍 코드 해설: 좌회전은 왼쪽 바퀴를 뒤로, 오른쪽 바퀴를 앞으로 돌립니다. 우회전은 그 반대죠! 지난 시간에 배운 내용이에요.

    직접 해보기:

    forward(50, 1)
turn_left(40, 0.5)
forward(50, 1)

    로봇이 전진하다가 왼쪽으로 꺾어서 다시 전진하나요? 🎯

    Step 3: 기본값 설정으로 편리하게 만들기¶

    매번 속도와 시간을 입력하기 귀찮으니, 기본값을 설정해봅시다.

    def forward(speed=50, duration=1):
    hamster.wheels(speed, speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

def turn_left(speed=40, duration=0.5):
    hamster.wheels(-speed, speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

def turn_right(speed=40, duration=0.5):
    hamster.wheels(speed, -speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

    이제 이렇게 간단하게 호출할 수 있어요!

    forward()           # 속도 50, 1초 전진 (기본값)
turn_left()         # 속도 40, 0.5초 좌회전 (기본값)
forward(80, 2)      # 속도 80, 2초 전진 (직접 지정)

    기본값 덕분에 코드가 훨씬 깔끔해졌죠? ✨

    Step 4: 함수 조합으로 사각형 그리기¶

    이제 함수를 조합해서 로봇이 사각형 경로를 따라 움직이게 해봅시다!

    def draw_square():
    for i in range(4):
        forward(50, 1)
        turn_right(40, 0.55)

draw_square()

    💡 팁: 우회전 시간 0.55는 대략 90도 회전에 해당하는 값입니다. 로봇마다 조금씩 다를 수 있으니, 값을 조절해가며 정확한 90도가 되는 시간을 찾아보세요! 이 과정이 바로 튜닝입니다.

    로봇이 출발점으로 돌아왔다면 사각형 완성! 🟧

    Step 5: 지그재그 경로 만들기¶

    이번에는 함수 조합으로 지그재그 움직임을 만들어봅시다.

    def zigzag(count=3):
    for i in range(count):
        forward(50, 1)
        turn_left(40, 0.55)
        forward(50, 1)
        turn_right(40, 0.55)

zigzag()       # 3번 지그재그
zigzag(5)      # 5번 지그재그
    flowchart LR A["시작 🚀"] --> B["전진"] B --> C["좌회전"] C --> D["전진"] D --> E["우회전"] E --> F{반복 끝?} F -- 아니오 --> B F -- 예 --> G["완료 🏁"]

    매개변수 count로 지그재그 횟수까지 조절할 수 있습니다! 🎮

    Step 6: 나만의 경로 도전 – L자 경로¶

    마지막으로 알파벳 L 모양 경로를 만들어봅시다.

    def draw_L():
    forward(50, 2)       # 길게 전진 (L의 세로획)
    turn_right(40, 0.55) # 우회전
    forward(50, 1)       # 짧게 전진 (L의 가로획)

draw_L()

    성공했나요? 그러면 draw_L()을 활용해서 더 재미있는 경로도 상상해보세요! 🎨

    📝 전체 코드¶

    지금까지 만든 함수들을 하나의 완성된 프로그램으로 모았습니다.

    from roboid import *

hamster = Hamster()

# ========== 기본 동작 함수 ==========

def forward(speed=50, duration=1):
    """전진: speed 속도로 duration초 동안 앞으로 이동"""
    hamster.wheels(speed, speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

def backward(speed=50, duration=1):
    """후진: speed 속도로 duration초 동안 뒤로 이동"""
    hamster.wheels(-speed, -speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

def turn_left(speed=40, duration=0.55):
    """좌회전: speed 속도로 duration초 동안 왼쪽 회전"""
    hamster.wheels(-speed, speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

def turn_right(speed=40, duration=0.55):
    """우회전: speed 속도로 duration초 동안 오른쪽 회전"""
    hamster.wheels(speed, -speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

def stop():
    """정지"""
    hamster.wheels(0, 0)

# ========== 조합 동작 함수 ==========

def draw_square():
    """사각형 경로로 이동"""
    for i in range(4):
        forward(50, 1)
        turn_right(40, 0.55)

def zigzag(count=3):
    """지그재그 경로로 이동"""
    for i in range(count):
        forward(50, 1)
        turn_left(40, 0.55)
        forward(50, 1)
        turn_right(40, 0.55)

def draw_L():
    """L자 경로로 이동"""
    forward(50, 2)
    turn_right(40, 0.55)
    forward(50, 1)

# ========== 실행 ==========
draw_square()

    💡 함수 아래의 """설명""" 부분은 독스트링(docstring)이라고 합니다. 함수가 무엇을 하는지 메모해두는 거예요. 나중에 코드를 다시 볼 때 큰 도움이 됩니다!

    ⚠️ 자주 하는 실수¶

    실수 1: 함수를 정의만 하고 호출하지 않기 🙈¶

    # ❌ 이렇게 하면 아무 일도 일어나지 않아요!
def forward(speed, duration):
    hamster.wheels(speed, speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

# ✅ 반드시 호출해야 실행됩니다!
forward(50, 1)

    함수를 정의하는 것은 레시피를 적어두는 것이고, 호출하는 것은 실제로 요리를 시작하는 것입니다. 레시피만 적어두면 요리가 나오지 않겠죠? 😄

    실수 2: 들여쓰기를 빠뜨리기 🔤¶

    # ❌ 들여쓰기가 없으면 오류!
def forward(speed, duration):
hamster.wheels(speed, speed)
wait(duration * 1000)

# ✅ 함수 안의 코드는 반드시 들여쓰기!
def forward(speed, duration):
    hamster.wheels(speed, speed)
    wait(duration * 1000)

    파이썬은 들여쓰기로 "이 코드는 함수 안에 속한다"를 판단합니다. 스페이스 4칸 또는 Tab 1번을 사용하세요.

    실수 3: 매개변수 순서를 헷갈리기 🔄¶

    def forward(speed, duration):
    hamster.wheels(speed, speed)
    wait(duration * 1000)
    hamster.wheels(0, 0)

# ❌ 순서를 바꾸면 의도와 다르게 동작!
forward(2, 50)   # 속도 2, 시간 50초?! 😱

# ✅ 올바른 순서로 전달
forward(50, 2)   # 속도 50, 시간 2초 ✅

# 💡 헷갈릴 때는 이름을 직접 지정할 수 있어요!
forward(speed=50, duration=2)

    forward(speed=50, duration=2)처럼 이름을 명시하면 순서가 바뀌어도 괜찮습니다. 이것을 키워드 인수라고 해요!

    실수 4: 함수 호출 시 괄호를 빠뜨리기¶

    # ❌ 괄호 없이 쓰면 함수가 실행되지 않아요!
stop     # 아무 일도 안 일어남

# ✅ 괄호를 꼭 붙여주세요!
stop()   # 로봇 정지!
