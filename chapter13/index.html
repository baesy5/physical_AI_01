    탐험과 활용 – 모험할까, 안전하게 갈까?¶

    Part 3 | [2권] 강화학습의 세계로 – 핵심 개념 이해하기 | 13차시

    🎯 이 장에서 배우는 것¶

    • 탐험(Exploration)과 활용(Exploitation)의 딜레마가 무엇인지 설명할 수 있다
    • ε-greedy 전략의 원리를 이해하고 코드로 구현할 수 있다
    • ε 값을 점차 줄이는 ε-decay 기법의 효과를 설명할 수 있다
    • 탐험과 활용의 균형이 학습 성능에 미치는 영향을 실험으로 확인할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분, 점심시간을 상상해 보세요. 🍜

    회사 근처에 늘 가던 맛집이 있습니다. 8점짜리 맛이에요. 꽤 만족스럽죠. 그런데 골목 안쪽에 새로 생긴 가게가 눈에 띕니다. 가본 적이 없으니 맛을 모릅니다. 10점짜리 천국일 수도, 3점짜리 지옥일 수도 있어요.

    매일 같은 가게만 가면? → 안전하지만, 더 맛있는 곳을 영영 발견하지 못합니다. 매번 새 가게만 가면? → 새로운 발견은 있지만, 이미 찾은 좋은 곳의 가치를 제대로 누리지 못합니다.

    이 고민이 바로 강화학습의 가장 핵심적인 딜레마입니다. 에이전트는 이미 아는 좋은 행동을 활용해야 할까요, 아니면 아직 모르는 행동을 탐험해야 할까요? 이 균형을 잘 잡지 못하면 학습이 아예 실패합니다.

    이 장에서 배우는 ε-greedy 전략은 이 딜레마를 다루는 가장 기본적이고 강력한 해법입니다. 다음 장에서 Q-learning을 직접 구현할 때, 이 전략이 코드의 핵심 부분을 차지하게 됩니다. 오늘 확실히 이해해 두면 다음 장이 훨씬 수월해질 거예요! 💪

    📚 핵심 개념¶

    개념 1: 탐험-활용 딜레마 (Exploration-Exploitation Dilemma)¶

    🍦 비유로 시작

    아이스크림 가게에 31가지 맛이 있습니다. 여러분은 5번 방문할 수 있어요.

    • 전략 A (활용 올인): 첫 번째 방문에서 초콜릿을 먹고 만족했으니, 나머지 4번도 전부 초콜릿! → 총 만족도: 안정적이지만, 혹시 민트초코가 인생 맛이었다면 큰 손해
    • 전략 B (탐험 올인): 5번 모두 다른 맛! → 다양한 정보를 얻지만, 제일 맛있는 걸 찾아도 다시 먹을 기회가 없음
    • 전략 C (균형): 처음 2~3번은 새 맛을 시도하고, 그중 최고를 나머지 횟수에 반복 → 가장 높은 총 만족도!

    📖 정확한 정의

    • 탐험(Exploration): 아직 잘 모르는 행동을 시도해서 새로운 정보를 얻는 것
    • 활용(Exploitation): 현재까지 알고 있는 정보 중 가장 좋은 행동을 선택하는 것
    • 딜레마: 한 번에 하나만 할 수 있기 때문에, 탐험과 활용 사이에서 항상 선택해야 하는 갈등 상황

    🔍 예시로 확인

    강화학습 에이전트가 미로를 탐색한다고 해봅시다.

    • 활용: "지금까지 찾은 경로 중 가장 빠른 길로 간다" → Q-테이블에서 가장 높은 Q값의 행동 선택
    • 탐험: "아직 안 가본 방향으로 가본다" → 랜덤하게 행동 선택
    • 활용만 하면 지역 최적(local optimum) 에 갇힐 수 있고, 탐험만 하면 학습한 보상을 전혀 써먹지 못합니다
    graph LR A[행동 선택 순간] --> B{탐험 vs 활용?} B -->|탐험| C[랜덤 행동 선택] B -->|활용| D[Q값이 가장 높은 행동 선택] C --> E[새로운 정보 획득] D --> F[현재 지식으로 최대 보상] E --> G[장기적으로 더 좋은 전략 발견 가능] F --> H[단기적으로 안정적 보상]

    개념 2: ε-greedy 전략¶

    🎲 비유로 시작

    주사위를 하나 굴린다고 생각하세요. 주사위 눈이 1이 나오면 "오늘은 모험의 날!"이라며 새 식당에 갑니다. 2~6이 나오면 "오늘은 단골집으로!" 합니다. 이게 바로 ε-greedy의 원리예요. 일정 확률로 모험하고, 나머지는 아는 최선을 선택하는 것이죠.

    📖 정확한 정의

    ε(엡실론)은 0과 1 사이의 값으로, 탐험할 확률을 의미합니다.

    • ε의 확률로 → 랜덤한 행동을 선택 (탐험)
    • 1-ε의 확률로 → Q값이 가장 높은 행동을 선택 (활용, 즉 greedy)

    "대부분은 greedy하게 가되, ε만큼은 랜덤하게 간다" → 그래서 ε-greedy!

    🔍 예시로 확인

    ε = 0.1이라면:

    • 10% 확률로 랜덤 행동 (탐험) 🎲
    • 90% 확률로 최선의 행동 (활용) 🎯

    ε = 0.5라면:

    • 50% 확률로 랜덤 행동 → 탐험을 많이 함
    • 50% 확률로 최선의 행동

    ε = 0.0이라면:

    • 탐험 없음, 항상 greedy → 새로운 것을 전혀 시도하지 않음
    # ε-greedy의 핵심 로직 (딱 이것만 기억하세요!)
import random

def epsilon_greedy(Q, state, epsilon, num_actions):
    if random.random() < epsilon:
        # 탐험: 랜덤 행동
        return random.randint(0, num_actions - 1)
    else:
        # 활용: Q값이 가장 높은 행동
        return max(range(num_actions), key=lambda a: Q[state][a])

    이 함수 하나가 탐험-활용 딜레마를 해결하는 핵심입니다! 🎉

    개념 3: ε-decay (엡실론 감소)¶

    🧒→🧑 비유로 시작

    새 도시로 이사 온 첫 주에는 이것저것 많이 돌아다니며 탐색하죠? 하지만 6개월이 지나면 이미 좋은 곳을 알기 때문에 탐색할 필요가 줄어듭니다. 학습 초반에는 많이 탐험하고, 점차 활용 위주로 전환하는 것이 자연스럽습니다.

    📖 정확한 정의

    ε-decay는 학습이 진행됨에 따라 ε 값을 점차 줄여나가는 기법입니다.

    • 초반: ε이 높음 (예: 1.0) → 거의 랜덤하게 행동하며 환경을 탐색
    • 중반: ε이 중간 (예: 0.3) → 탐험과 활용을 적절히 섞음
    • 후반: ε이 낮음 (예: 0.01) → 거의 항상 최선의 행동을 선택

    가장 흔한 감소 방식은 곱하기 감소입니다:

    새로운 ε = 기존 ε × decay_rate

    예를 들어 decay_rate = 0.995이면, 매 에피소드마다 ε이 0.5%씩 줄어듭니다.

    🔍 예시로 확인

    epsilon = 1.0          # 시작값: 100% 탐험
epsilon_min = 0.01     # 최소값: 1%는 탐험 유지
decay_rate = 0.995     # 매번 0.5%씩 감소

for episode in range(1000):
    # ... 학습 진행 ...

    # 에피소드가 끝날 때마다 ε 감소
    epsilon = max(epsilon_min, epsilon * decay_rate)
    graph LR A["에피소드 1<br/>ε=1.0<br/>🎲 탐험 위주"] --> B["에피소드 200<br/>ε≈0.37<br/>⚖️ 균형"] B --> C["에피소드 500<br/>ε≈0.08<br/>🎯 활용 위주"] C --> D["에피소드 1000<br/>ε≈0.01<br/>🏆 거의 최적"]

    💡 왜 최소값(epsilon_min)을 두나요? ε을 완전히 0으로 만들면 환경이 바뀌었을 때 전혀 적응하지 못합니다. 아주 작은 탐험이라도 남겨두는 것이 안전합니다.

    개념 4: 탐험-활용 균형이 학습에 미치는 영향¶

    이론만으로는 와닿지 않죠? 세 가지 전략을 비교해 봅시다.

    • ε=0 (탐험 없음): 처음 발견한 괜찮은 행동에 고착 → 더 좋은 행동을 절대 찾지 못함
    • ε=1 (탐험만): 항상 랜덤 → 학습한 것을 전혀 활용하지 못함
    • ε-decay (균형): 초반 탐험 → 후반 활용 → 최적에 수렴

    이 차이를 실습에서 직접 눈으로 확인해 볼 거예요!

    🔨 따라하기¶

    간단한 10-Armed Bandit 문제로 ε-greedy를 직접 체험해 봅시다. 10개의 슬롯머신이 있고, 각 머신의 당첨 확률이 다릅니다. 어떤 전략이 가장 많은 보상을 얻을까요?

    Step 1: 환경 만들기¶

    import numpy as np
import random

# 재현성을 위한 시드 설정
np.random.seed(42)
random.seed(42)

# 10개 슬롯머신의 "진짜" 평균 보상 (에이전트는 이걸 모릅니다!)
true_rewards = np.random.normal(loc=0, scale=1, size=10)
print("각 머신의 진짜 평균 보상:")
for i, r in enumerate(true_rewards):
    print(f"  머신 {i}: {r:.2f}", end="")
    if i == np.argmax(true_rewards):
        print(" ⭐ 최고!", end="")
    print()

    에이전트는 true_rewards를 모릅니다. 직접 당겨봐야만 알 수 있어요!

    Step 2: 슬롯머신 당기기 함수¶

    def pull_arm(arm):
    """선택한 머신을 당기면 진짜 평균 + 노이즈 보상이 나옴"""
    return true_rewards[arm] + np.random.normal(0, 1)

    Step 3: ε-greedy 에이전트 구현¶

    def run_bandit(epsilon, num_steps=1000, decay=False, decay_rate=0.995, epsilon_min=0.01):
    """ε-greedy 전략으로 슬롯머신 문제를 풀기"""
    num_arms = 10
    Q = np.zeros(num_arms)        # 각 머신의 추정 보상값
    N = np.zeros(num_arms)        # 각 머신을 당긴 횟수
    rewards = []                  # 매 스텝의 보상 기록
    current_epsilon = epsilon

    for step in range(num_steps):
        # ε-greedy 행동 선택
        if random.random() < current_epsilon:
            action = random.randint(0, num_arms - 1)  # 탐험
        else:
            action = np.argmax(Q)                      # 활용

        # 보상 받기
        reward = pull_arm(action)
        rewards.append(reward)

        # Q값 업데이트 (증분 평균)
        N[action] += 1
        Q[action] += (reward - Q[action]) / N[action]

        # ε 감소 (decay 모드일 때)
        if decay:
            current_epsilon = max(epsilon_min, current_epsilon * decay_rate)

    return rewards

    📌 Q값 업데이트 공식이 생소하다면 걱정 마세요! Q[action] += (reward - Q[action]) / N[action]은 단순히 지금까지의 평균을 효율적으로 계산하는 공식입니다. 새 보상이 올 때마다 평균을 조금씩 조정하는 것이죠.

    Step 4: 세 가지 전략 비교 실험¶

    # 실험: 각 전략을 200번 반복해서 평균을 구합니다
num_runs = 200
num_steps = 1000

results = {
    "탐험 없음 (ε=0)": np.zeros(num_steps),
    "ε=0.1 (고정)": np.zeros(num_steps),
    "ε-decay (1.0→0.01)": np.zeros(num_steps),
}

for run in range(num_runs):
    np.random.seed(run)
    random.seed(run)
    # 매 실행마다 새로운 진짜 보상
    true_rewards = np.random.normal(0, 1, 10)

    r1 = run_bandit(epsilon=0.0, num_steps=num_steps)

    np.random.seed(run)
    random.seed(run)
    true_rewards = np.random.normal(0, 1, 10)
    r2 = run_bandit(epsilon=0.1, num_steps=num_steps)

    np.random.seed(run)
    random.seed(run)
    true_rewards = np.random.normal(0, 1, 10)
    r3 = run_bandit(epsilon=1.0, num_steps=num_steps, 
                     decay=True, decay_rate=0.995)

    results["탐험 없음 (ε=0)"] += r1
    results["ε=0.1 (고정)"] += r2
    results["ε-decay (1.0→0.01)"] += r3

# 평균 계산
for key in results:
    results[key] /= num_runs

    Step 6: 결과 해석¶

    실행하면 이런 패턴이 보입니다:

    • ε=0 (탐험 없음) 🔴: 초반에 빠르게 올라가지만 금방 정체됩니다. 처음 몇 번 시도에서 운 좋게 좋은 머신을 찾으면 괜찮지만, 그렇지 않으면 나쁜 머신에 갇힙니다.
    • ε=0.1 (고정) 🟡: 꾸준히 좋은 성능을 보이지만, 후반에도 10%는 랜덤 행동을 하기 때문에 최적에 도달하지 못합니다.
    • ε-decay 🟢: 초반에는 넓게 탐색하고, 후반에는 찾은 최적 행동을 집중 활용합니다. 장기적으로 가장 높은 보상을 얻습니다!

    🎉 핵심 교훈: "처음에는 과감하게 탐험하고, 점점 알게 된 것을 활용하라!" 이것이 ε-decay의 힘입니다.

    📝 전체 코드¶

    아래 코드를 통째로 복사해서 실행할 수 있습니다.

    import numpy as np
import random
import matplotlib.pyplot as plt

# --- 환경 설정 ---
true_rewards = None  # 전역 변수로 사용

def pull_arm(arm):
    return true_rewards[arm] + np.random.normal(0, 1)

# --- ε-greedy 에이전트 ---
def run_bandit(epsilon, num_steps=1000, decay=False, 
               decay_rate=0.995, epsilon_min=0.01):
    global true_rewards
    num_arms = 10
    Q = np.zeros(num_arms)
    N = np.zeros(num_arms)
    rewards = []
    current_epsilon = epsilon

    for step in range(num_steps):
        if random.random() < current_epsilon:
            action = random.randint(0, num_arms - 1)
        else:
            action = np.argmax(Q)

        reward = pull_arm(action)
        rewards.append(reward)

        N[action] += 1
        Q[action] += (reward - Q[action]) / N[action]

        if decay:
            current_epsilon = max(epsilon_min, current_epsilon * decay_rate)

    return rewards

# --- 실험 실행 ---
num_runs = 200
num_steps = 1000

results = {
    "탐험 없음 (ε=0)": np.zeros(num_steps),
    "ε=0.1 (고정)": np.zeros(num_steps),
    "ε-decay (1.0→0.01)": np.zeros(num_steps),
}

for run in range(num_runs):
    np.random.seed(run); random.seed(run)
    true_rewards = np.random.normal(0, 1, 10)
    r1 = run_bandit(epsilon=0.0, num_steps=num_steps)

    np.random.seed(run); random.seed(run)
    true_rewards = np.random.normal(0, 1, 10)
    r2 = run_bandit(epsilon=0.1, num_steps=num_steps)

    np.random.seed(run); random.seed(run)
    true_rewards = np.random.normal(0, 1, 10)
    r3 = run_bandit(epsilon=1.0, num_steps=num_steps, 
                     decay=True, decay_rate=0.995)

    results["탐험 없음 (ε=0)"] += r1
    results["ε=0.1 (고정)"] += r2
    results["ε-decay (1.0→0.01)"] += r3

for key in results:
    results[key] /= num_runs

# --- 시각화 ---
plt.figure(figsize=(10, 6))
window = 50
for label, rewards in results.items():
    smoothed = np.convolve(rewards, np.ones(window)/window, mode='valid')
    plt.plot(smoothed, label=label, linewidth=2)

plt.xlabel("Step"); plt.ylabel("Average Reward")
plt.title("Exploration vs Exploitation Strategy Comparison")
plt.legend(); plt.grid(True, alpha=0.3)
plt.tight_layout(); plt.show()

    ⚠️ 자주 하는 실수¶

    실수 1: ε을 처음부터 너무 낮게 설정한다 😰

    초보자분들이 "빨리 학습하고 싶어서" ε=0.01로 시작하는 경우가 많습니다. 하지만 이러면 탐험이 거의 없어서 처음 우연히 선택한 행동이 최선이라고 착각하게 됩니다. 학습 초반에는 ε을 넉넉히(0.5~1.0) 잡으세요!

    실수 2: ε을 완전히 0으로 떨어뜨린다 🚫

    epsilon_min = 0으로 설정하면 어느 시점부터 탐험을 완전히 멈춥니다. 환경에 변화가 있거나, 초기에 운 나쁘게 잘못된 Q값을 학습했다면 영원히 빠져나오지 못합니다. 최소 0.01 정도는 유지하는 것이 안전합니다.

    실수 3: decay_rate를 너무 공격적으로 설정한다 ⚡

    decay_rate = 0.9로 하면 ε이 너무 빠르게 줄어듭니다. 예를 들어 시작값 1.0에서 50스텝만 지나면 ε ≈ 0.005가 됩니다. 충분히 탐험하기도 전에 활용 모드로 전환되는 셈이죠. 보통 0.99~0.999 범위가 적당합니다. 전체 학습 에피소드 수를 고려해서 설정하세요.

    ✅ 스스로 점검하기¶

    Q1. ε-greedy에서 ε=0.2일 때, 에이전트가 Q값이 가장 높은 행동을 선택할 확률은?

    정답 확인 80% (= 1 - 0.2)입니다. ε의 확률로 탐험(랜덤), 나머지 1-ε의 확률로 활용(greedy)하기 때문입니다.

    Q2. 학습 초반에 ε을 높게, 후반에 낮게 하는 이유는?

    정답 확인 초반에는 환경에 대해 아는 것이 적으므로 다양한 행동을 시도(탐험)해서 정보를 모아야 합니다. 후반에는 이미 좋은 행동을 알고 있으므로 그것을 집중적으로 활용하는 것이 보상을 극대화합니다.

    Q3. ε=0으로 학습하면 발생할 수 있는 문제를 한 문장으로 설명해 보세요.

    정답 확인 처음 시도한 행동 중 우연히 보상이 높았던 행동에 고착되어, 실제로 더 좋은 행동을 전혀 발견하지 못하는 지역 최적(local optimum) 문제가 발생합니다.

    Q4. decay_rate = 0.99와 decay_rate = 0.999 중 ε이 더 천천히 줄어드는 것은?

    정답 확인 `decay_rate = 0.999`입니다. 매번 곱해지는 값이 1에 더 가까우므로 ε이 더 느리게 감소합니다. 0.99는 매 에피소드마다 1%씩, 0.999는 0.1%씩 줄어든다고 생각하면 됩니다.
