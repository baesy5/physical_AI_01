    Chapter 17: 통합 자율주행 시스템 완성 (시뮬레이션)¶

    Part 5: [2권] 시뮬레이션 고급 기능과 안전 주행

    🎯 이 장에서 배우는 것¶

    • 차선 유지, 장애물 회피, 속도 제어를 하나의 통합 시스템으로 결합할 수 있다
    • 상태 머신(State Machine) 기반으로 자율주행 로직을 설계할 수 있다
    • 날씨 변화, 교통 상황 등 다양한 시나리오에서 시스템 강건성을 테스트할 수 있다
    • 시뮬레이션 결과를 분석하여 Sim-to-Real 전환 계획을 수립할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기: 지금까지 우리는 차선 인식, 장애물 감지, 비상 정지, End-to-End 모델을 각각 만들어봤습니다. 그런데 이 기능들을 한꺼번에 켜면 정말 자율주행이 될까요? 🤔

    레스토랑을 생각해보세요. 최고의 셰프, 최고의 웨이터, 최고의 캐셔가 각각 있어도, 서로 소통하지 않으면 레스토랑은 엉망이 됩니다. 주문이 꼬이고, 음식이 늦게 나오고, 계산이 잘못됩니다. 자율주행도 마찬가지입니다.

    차선 인식 모듈은 "왼쪽으로 꺾어!"라고 하는데, 장애물 감지 모듈은 "왼쪽에 사람이 있어!"라고 외칩니다. 이때 누구의 말을 들어야 할까요? 이런 충돌을 해결하고 모든 기능을 조화롭게 운영하는 것이 바로 통합 시스템의 역할입니다.

    이 장은 지금까지 배운 모든 것의 최종 집대성입니다. 여러분은 진짜 자율주행 시스템을 완성하고, 이것을 현실 세계로 가져갈 준비를 하게 됩니다.

    📚 핵심 개념¶

    개념 1: 상태 머신(State Machine) — 자율주행의 두뇌¶

    🎭 비유로 시작

    여러분이 등교하는 상황을 생각해보세요.

    • 🚶 걷기 상태: 평소처럼 걸어갑니다
    • 🛑 정지 상태: 빨간 신호를 만나면 멈춥니다
    • 🏃 회피 상태: 앞에 웅덩이가 있으면 돌아갑니다
    • ⚠️ 비상 상태: 차가 갑자기 튀어나오면 급히 멈춥니다

    여러분은 상황에 따라 자동으로 행동을 전환합니다. 이것이 바로 상태 머신입니다!

    📖 정확한 정의

    상태 머신(State Machine, 유한 상태 기계)은 시스템이 가질 수 있는 유한한 개수의 상태를 정의하고, 특정 조건(이벤트)에 따라 상태 간 전환이 이루어지는 설계 패턴입니다. 자율주행에서는 각 상태마다 차량이 수행할 행동이 다르며, 센서 정보에 따라 상태가 변합니다.

    🔍 예시로 확인

    우리 자율주행 시스템의 상태를 정의해봅시다:

    stateDiagram-v2 [*] --> LANE_FOLLOWING: 시스템 시작 LANE_FOLLOWING --> OBSTACLE_AVOIDANCE: 전방 장애물 감지\n(거리 < 15m) LANE_FOLLOWING --> EMERGENCY_STOP: 긴급 장애물\n(거리 < 5m) OBSTACLE_AVOIDANCE --> LANE_FOLLOWING: 장애물 회피 완료 OBSTACLE_AVOIDANCE --> EMERGENCY_STOP: 회피 불가\n(거리 < 3m) EMERGENCY_STOP --> LANE_FOLLOWING: 장애물 사라짐\n(3초 대기 후) LANE_FOLLOWING --> SPEED_CONTROL: 선행 차량 감지\n(거리 < 20m) SPEED_CONTROL --> LANE_FOLLOWING: 선행 차량 없음 SPEED_CONTROL --> EMERGENCY_STOP: 급접근\n(거리 < 5m)

    알아보기: 상태 머신의 핵심 장점은 예측 가능성입니다. "지금 시스템이 무엇을 하고 있는가?"를 항상 명확히 알 수 있어 디버깅과 안전 보장이 쉬워집니다.

    개념 2: 모듈 통합 아키텍처 — 레고 블록처럼 조립하기¶

    🧱 비유로 시작

    레고로 로봇을 만든다고 생각해보세요. 팔 블록, 다리 블록, 머리 블록을 따로 만든 뒤 하나로 조립합니다. 이때 중요한 것은 각 블록의 연결 부분(인터페이스)이 맞아야 한다는 것입니다.

    📖 정확한 정의

    모듈 통합 아키텍처란 독립적으로 개발된 각 기능 모듈(인지, 판단, 제어)을 표준화된 인터페이스로 연결하여 하나의 시스템으로 구성하는 설계 방식입니다.

    🔍 예시로 확인

    우리 시스템의 전체 구조를 봅시다:

    flowchart TB subgraph 인지["🔍 인지 계층 (Perception)"] CAM[카메라 센서] LID[라이다 센서] LANE[차선 인식 모듈] OBJ[장애물 감지 모듈] CAM --> LANE LID --> OBJ CAM --> OBJ end subgraph 판단["🧠 판단 계층 (Decision)"] SM[상태 머신] PATH[경로 판단] LANE --> SM OBJ --> SM SM --> PATH end subgraph 제어["🎮 제어 계층 (Control)"] STEER[조향 제어] SPEED[속도 제어] BRAKE[비상 정지] PATH --> STEER PATH --> SPEED PATH --> BRAKE end subgraph 실행["🚗 실행 계층 (Actuation)"] VEHICLE[차량 제어 명령] STEER --> VEHICLE SPEED --> VEHICLE BRAKE --> VEHICLE end

    각 계층은 독립적으로 동작하면서, 위에서 아래로 데이터가 흐릅니다. 인지 결과를 판단에 전달하고, 판단 결과를 제어에 전달하는 깔끔한 구조입니다.

    개념 3: 강건성 테스트 — 어떤 상황에서도 안전하게¶

    🌧️ 비유로 시작

    맑은 날에만 운전할 수 있는 운전자는 좋은 운전자가 아닙니다. 비가 와도, 안개가 껴도, 밤이 되어도 안전하게 운전해야 진짜 실력입니다. 자율주행 시스템도 다양한 악조건에서 테스트해야 합니다.

    📖 정확한 정의

    강건성(Robustness)이란 시스템이 예상치 못한 환경 변화나 입력 데이터의 노이즈에도 안정적으로 동작하는 능력입니다. 강건성 테스트는 의도적으로 까다로운 조건을 만들어 시스템의 한계를 파악하는 과정입니다.

    🔍 예시로 확인

    CARLA에서 테스트할 시나리오 목록:

    • 날씨 변화: 맑음 → 비 → 짙은 안개 → 폭우
    • 시간 변화: 낮(정오) → 석양 → 밤(가로등 있음) → 깜깜한 밤
    • 교통 상황: 차량 없음 → 보행자 횡단 → 차량 혼잡 → 갑작스러운 끼어들기
    • 복합 상황: 비 오는 밤 + 보행자 횡단 + 선행 차량 급정거

    개념 4: Sim-to-Real 전환 — 시뮬레이션에서 현실로¶

    🎮 비유로 시작

    비행 시뮬레이션 게임을 아무리 잘 해도, 실제 비행기 조종은 다릅니다. 바람이 불고, 계기판이 미세하게 떨리고, 긴장감도 다릅니다. 하지만 시뮬레이션에서 기본기를 익혀두면 실제 전환이 훨씬 수월합니다.

    📖 정확한 정의

    Sim-to-Real(시뮬레이션-현실 전환)은 시뮬레이션 환경에서 학습하고 검증한 알고리즘과 모델을 실제 물리 환경(RC카, 실차 등)에 이식하는 과정입니다. 시뮬레이션과 현실 사이의 차이를 도메인 갭(Domain Gap)이라 하며, 이를 최소화하는 것이 핵심입니다.

    🔍 예시로 확인

    시뮬레이션과 현실의 주요 차이점:

    flowchart LR subgraph SIM["🖥️ 시뮬레이션"] S1[완벽한 센서 데이터] S2[정확한 물리 모델] S3[무한 반복 가능] S4[사고 위험 없음] end subgraph GAP["⚡ 도메인 갭"] G1[센서 노이즈] G2[물리적 마찰/관성] G3[통신 지연] G4[조명/날씨 차이] end subgraph REAL["🚗 현실"] R1[노이즈 있는 센서] R2[복잡한 물리 현상] R3[실시간 제약] R4[안전 고려 필수] end SIM --> GAP --> REAL

    정리하기: 시뮬레이션에서 95% 성능이 나와도, 현실에서는 70~80% 정도로 떨어질 수 있습니다. 이 갭을 줄이는 전략이 Sim-to-Real의 핵심입니다.

    🔨 따라하기: 통합 자율주행 시스템 구축¶

    Step 1: 상태 머신 프레임워크 만들기¶

    먼저 자율주행의 두뇌 역할을 할 상태 머신을 만듭니다.

    """
autonomous_state_machine.py
자율주행 상태 머신 - 상황에 따라 행동을 결정하는 두뇌
"""
from enum import Enum

class DrivingState(Enum):
    """자율주행 상태 정의"""
    LANE_FOLLOWING = "차선 추종"
    OBSTACLE_AVOIDANCE = "장애물 회피"
    SPEED_CONTROL = "속도 조절"
    EMERGENCY_STOP = "비상 정지"

class StateMachine:
    """
    상태 머신: 센서 정보를 받아 현재 상태를 결정합니다.

    동작 원리:
    1. 매 프레임마다 센서 데이터를 받음
    2. 현재 상태와 센서 데이터를 기반으로 다음 상태 결정
    3. 상태에 따른 제어 명령 생성
    """

    def __init__(self):
        self.current_state = DrivingState.LANE_FOLLOWING
        self.previous_state = None
        self.emergency_timer = 0  # 비상 정지 후 대기 시간

        # 거리 임계값 설정 (미터 단위)
        self.emergency_distance = 5.0    # 5m 이내: 비상!
        self.avoidance_distance = 15.0   # 15m 이내: 회피
        self.following_distance = 20.0   # 20m 이내: 속도 조절

    def update(self, sensor_data):
        """
        센서 데이터를 받아 상태를 업데이트합니다.

        sensor_data 딕셔너리 구조:
        - 'obstacle_distance': 전방 장애물까지 거리 (float, 미터)
        - 'obstacle_detected': 장애물 감지 여부 (bool)
        - 'lane_detected': 차선 감지 여부 (bool)
        - 'lane_offset': 차선 중심에서 벗어난 정도 (float)
        """
        self.previous_state = self.current_state

        obstacle_dist = sensor_data.get('obstacle_distance', float('inf'))
        obstacle_detected = sensor_data.get('obstacle_detected', False)

        # 우선순위 1: 비상 정지 (가장 높은 우선순위)
        if obstacle_detected and obstacle_dist < self.emergency_distance:
            self.current_state = DrivingState.EMERGENCY_STOP
            self.emergency_timer = 0

        # 우선순위 2: 비상 정지 상태에서 복귀 판단
        elif self.current_state == DrivingState.EMERGENCY_STOP:
            if not obstacle_detected or obstacle_dist > self.avoidance_distance:
                self.emergency_timer += 1
                # 약 3초(30프레임) 대기 후 복귀
                if self.emergency_timer > 30:
                    self.current_state = DrivingState.LANE_FOLLOWING
                    self.emergency_timer = 0

        # 우선순위 3: 장애물 회피
        elif obstacle_detected and obstacle_dist < self.avoidance_distance:
            self.current_state = DrivingState.OBSTACLE_AVOIDANCE

        # 우선순위 4: 속도 조절 (선행 차량 추종)
        elif obstacle_detected and obstacle_dist < self.following_distance:
            self.current_state = DrivingState.SPEED_CONTROL

        # 기본: 차선 추종
        else:
            self.current_state = DrivingState.LANE_FOLLOWING

        # 상태 변경 로그
        if self.current_state != self.previous_state:
            print(f"🔄 상태 전환: {self.previous_state.value} → {self.current_state.value}")

        return self.current_state

    알아보기: 코드에서 우선순위가 중요합니다! 비상 정지가 항상 1순위입니다. 차선이 아무리 잘 보여도 앞에 사람이 있으면 무조건 멈춰야 합니다.

    Step 2: 인지 모듈 통합 (센서 데이터 수집)¶

    카메라와 라이다 센서에서 정보를 수집하여 표준 형식으로 변환합니다.

    """
perception_module.py
인지 모듈: 센서 데이터를 분석하여 주행 환경을 이해합니다.
"""
import carla
import numpy as np
import cv2

class PerceptionModule:
    """
    인지 모듈: 카메라와 라이다 데이터를 분석합니다.

    역할:
    - 카메라 이미지에서 차선 인식
    - 라이다 포인트 클라우드에서 장애물 감지
    - 분석 결과를 표준 형식으로 출력
    """

    def __init__(self):
        self.latest_image = None
        self.latest_lidar = None
        self.lane_offset = 0.0
        self.lane_detected = False

    def process_camera(self, image):
        """
        카메라 이미지에서 차선을 인식합니다.
        (이전 챕터에서 배운 차선 인식 로직 활용)
        """
        # CARLA 이미지를 numpy 배열로 변환
        array = np.frombuffer(image.raw_data, dtype=np.uint8)
        array = array.reshape((image.height, image.width, 4))[:, :, :3]
        self.latest_image = array

        # 관심 영역 (하단 1/3)
        height, width = array.shape[:2]
        roi = array[int(height * 0.6):height, :]

        # 색상 변환 및 엣지 검출
        gray = cv2.cvtColor(roi, cv2.COLOR_BGR2GRAY)
        blur = cv2.GaussianBlur(gray, (5, 5), 0)
        edges = cv2.Canny(blur, 50, 150)

        # 허프 변환으로 차선 검출
        lines = cv2.HoughLinesP(edges, 1, np.pi/180, 50,
                                minLineLength=50, maxLineGap=100)

        if lines is not None and len(lines) > 0:
            self.lane_detected = True
            # 검출된 선들의 중심 x좌표 계산
            x_positions = []
            for line in lines:
                x1, _, x2, _ = line[0]
                x_positions.extend([x1, x2])

            lane_center = np.mean(x_positions)
            image_center = width / 2
            # -1.0(왼쪽) ~ +1.0(오른쪽) 정규화
            self.lane_offset = (lane_center - image_center) / (width / 2)
        else:
            self.lane_detected = False
            self.lane_offset = 0.0

    def process_lidar(self, lidar_data):
        """
        라이다 데이터에서 전방 장애물을 감지합니다.
        """
        # 라이다 포인트 클라우드 파싱
        points = np.frombuffer(lidar_data.raw_data, dtype=np.float32)
        points = points.reshape(-1, 4)[:, :3]  # x, y, z

        # 전방 영역 필터링 (x > 0: 앞쪽, |y| < 2: 차량 폭 내)
        forward_mask = (points[:, 0] > 0) & \
                       (points[:, 0] < 50) & \
                       (np.abs(points[:, 1]) < 2.0) & \
                       (points[:, 2] > -1.5)  # 지면 제외

        forward_points = points[forward_mask]

        obstacle_detected = False
        obstacle_distance = float('inf')

        if len(forward_points) > 10:  # 최소 10개 포인트 이상
            obstacle_detected = True
            obstacle_distance = float(np.min(forward_points[:, 0]))

        return {
            'obstacle_detected': obstacle_detected,
            'obstacle_distance': obstacle_distance,
            'lane_detected': self.lane_detected,
            'lane_offset': self.lane_offset
        }

    Step 3: 제어 모듈 구현 (상태별 행동 정의)¶

    각 상태에서 차량이 어떻게 행동할지 구체적으로 정의합니다.

    """
control_module.py
제어 모듈: 상태 머신의 결정에 따라 차량을 조종합니다.
"""
import carla

class ControlModule:
    """
    제어 모듈: 각 상태에 맞는 조향, 가속, 브레이크 값을 계산합니다.

    PID 제어 기반으로 부드러운 주행을 구현합니다.
    """

    def __init__(self):
        # PID 제어 파라미터
        self.steer_kp = 0.8   # 비례 게인
        self.steer_ki = 0.01  # 적분 게인
        self.steer_kd = 0.1   # 미분 게인

        # PID 내부 변수
        self.steer_integral = 0.0
        self.steer_prev_error = 0.0

        # 속도 설정
        self.target_speed = 30.0  # 기본 목표 속도 (km/h)
        self.min_speed = 10.0

    def get_control(self, state, sensor_data, current_speed):
        """
        현재 상태와 센서 데이터를 받아 제어 명령을 반환합니다.

        반환값: carla.VehicleControl 객체
        """
        control = carla.VehicleControl()

        if state == DrivingState.LANE_FOLLOWING:
            control = self._lane_following(sensor_data, current_speed)

        elif state == DrivingState.OBSTACLE_AVOIDANCE:
            control = self._obstacle_avoidance(sensor_data, current_speed)

        elif state == DrivingState.SPEED_CONTROL:
            control = self._speed_control(sensor_data, current_speed)

        elif state == DrivingState.EMERGENCY_STOP:
            control = self._emergency_stop()

        return control

    def _lane_following(self, sensor_data, current_speed):
        """차선 추종: 차선 중앙을 따라 주행"""
        control = carla.VehicleControl()

        # PID 조향 제어
        error = sensor_data.get('lane_offset', 0.0)
        self.steer_integral += error
        # 적분 와인드업 방지 (값이 너무 커지지 않도록)
        self.steer_integral = max(-10, min(10, self.steer_integral))
        derivative = error - self.steer_prev_error

        steer = (self.steer_kp * error + 
                 self.steer_ki * self.steer_integral + 
                 self.steer_kd * derivative)

        self.steer_prev_error = error

        # 조향값 제한 (-1.0 ~ 1.0)
        control.steer = max(-1.0, min(1.0, steer))

        # 속도 제어
        if current_speed < self.target_speed:
            control.throttle = 0.5
            control.brake = 0.0
        else:
            control.throttle = 0.0
            control.brake = 0.1

        return control

    def _obstacle_avoidance(self, sensor_data, current_speed):
        """장애물 회피: 감속하며 장애물을 피해 조향"""
        control = carla.VehicleControl()

        obstacle_dist = sensor_data.get('obstacle_distance', 30.0)

        # 거리에 비례하여 감속 (가까울수록 더 많이 감속)
        speed_ratio = max(0.2, obstacle_dist / self.avoidance_distance)

        # 회피 방향 결정 (차선 오프셋 기반)
        lane_offset = sensor_data.get('lane_offset', 0.0)
        # 장애물 반대 방향으로 조향
        avoidance_steer = -0.3 if lane_offset >= 0 else 0.3

        control.steer = avoidance_steer
        control.throttle = 0.3 * speed_ratio
        control.brake = 0.2 * (1.0 - speed_ratio)

        return control

    def _speed_control(self, sensor_data, current_speed):
        """속도 조절: 선행 차량과 안전거리 유지"""
        control = carla.VehicleControl()

        obstacle_dist = sensor_data.get('obstacle_distance', 30.0)

        # 안전거리 기반 속도 조절
        safe_speed = self.target_speed * (obstacle_dist / self.following_distance)
        safe_speed = max(self.min_speed, safe_speed)

        # 차선 추종도 동시에 수행
        control.steer = max(-1.0, min(1.0, 
                           self.steer_kp * sensor_data.get('lane_offset', 0.0)))

        if current_speed < safe_speed:
            control.throttle = 0.3
            control.brake = 0.0
        else:
            control.throttle = 0.0
            control.brake = 0.3

        return control

    def _emergency_stop(self):
        """비상 정지: 즉시 최대 제동"""
        control = carla.VehicleControl()
        control.throttle = 0.0
        control.steer = 0.0
        control.brake = 1.0  # 최대 브레이크!
        control.hand_brake = True
        return control
