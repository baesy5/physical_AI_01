    Chapter 18: 라즈베리파이와 RC카 하드웨어 구성¶

    Part 6: RC카로 현실 세계에 도전하기

    🎯 이 장에서 배우는 것¶

    • 라즈베리파이의 기본 구조와 GPIO 핀의 역할을 설명할 수 있다
    • 라즈베리파이 OS를 설치하고 Python 개발 환경을 설정할 수 있다
    • RC카에 모터 드라이버(L298N)를 연결하는 회로를 구성할 수 있다
    • Python으로 모터를 제어하여 RC카를 전진·후진·좌회전·우회전시킬 수 있다
    • 키보드 입력으로 RC카를 원격 조종하는 프로그램을 작성할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    지금까지 시뮬레이터 속에서 자율주행 차량을 달리게 했습니다. 그 차량의 "두뇌" 역할은 여러분의 PC가 했죠. 그렇다면 현실 세계의 RC카에서는 누가 두뇌 역할을 할까요?

    바로 라즈베리파이(Raspberry Pi) 입니다!

    시뮬레이터에서 배운 모든 것—카메라 영상 처리, 조향 판단, 속도 제어—을 현실로 옮기려면 작고 강력한 컴퓨터가 RC카 위에 올라가야 합니다. 라즈베리파이는 신용카드 크기이면서도 Linux가 돌아가는 완전한 컴퓨터입니다. 여기에 카메라를 달고, 모터를 연결하면 진짜 달리는 자율주행 RC카가 탄생합니다.

    이번 장은 그 첫걸음입니다. 하드웨어를 조립하고, 코드 한 줄로 모터가 돌아가는 순간의 짜릿함을 직접 경험해 보세요!

    📚 핵심 개념¶

    개념 1: 라즈베리파이 — 손바닥 위의 컴퓨터 🖥️¶

    비유로 시작

    여러분이 매일 사용하는 데스크톱 PC를 떠올려 보세요. 모니터, 키보드, 마우스, 본체가 있죠? 라즈베리파이는 그 본체를 카드 한 장 크기로 압축한 것입니다. 모니터를 연결하면 PC처럼 쓸 수 있고, 아무것도 연결하지 않으면 RC카 위에서 조용히 두뇌 역할만 합니다.

    정확한 정의

    라즈베리파이(Raspberry Pi)는 영국 라즈베리파이 재단이 만든 싱글 보드 컴퓨터(SBC) 입니다. CPU, RAM, USB 포트, Wi-Fi, Bluetooth가 하나의 보드에 통합되어 있으며, GPIO(General Purpose Input/Output) 핀을 통해 외부 장치(모터, 센서, LED 등)를 직접 제어할 수 있습니다.

    예시로 확인

    우리가 사용할 라즈베리파이 4B의 주요 사양을 살펴봅시다.

    • CPU: Broadcom BCM2711, 쿼드코어 1.5GHz (ARM 기반)
    • RAM: 2GB / 4GB / 8GB 선택 가능
    • 저장장치: microSD 카드 사용
    • 연결: Wi-Fi 5GHz, Bluetooth 5.0, USB 3.0 × 2, USB 2.0 × 2
    • 영상 출력: micro HDMI × 2
    • GPIO: 40핀 헤더
    • 전원: USB-C, 5V / 3A 권장

    알아보기 📘

    싱글 보드 컴퓨터(SBC) 란 CPU, 메모리, 입출력 장치가 하나의 회로 기판에 모두 들어간 컴퓨터를 말합니다. 일반 PC는 메인보드, 그래픽카드, RAM 등이 분리되어 있지만, SBC는 모든 것이 한 보드에 있어 크기가 매우 작습니다.

    개념 2: GPIO — 라즈베리파이가 세상과 대화하는 통로 📡¶

    비유로 시작

    사람의 손가락을 생각해 보세요. 손가락으로 버튼을 누르고, 물건을 집고, 신호를 보내죠. GPIO 핀은 라즈베리파이의 손가락입니다. 이 핀들을 통해 라즈베리파이가 외부 세계(모터, 센서, LED)와 소통합니다.

    정확한 정의

    GPIO(General Purpose Input/Output) 는 범용 입출력 핀으로, 프로그래밍을 통해 전기 신호를 보내거나(Output) 받을(Input) 수 있는 물리적 핀입니다. 라즈베리파이 4B에는 총 40개의 핀 헤더가 있으며, 이 중 26개가 GPIO로 사용 가능합니다.

    예시로 확인

    40핀 헤더에는 세 종류의 핀이 있습니다.

    • 전원 핀: 3.3V(2개), 5V(2개) — 외부 장치에 전원을 공급
    • GND(접지) 핀: 8개 — 전기 회로의 기준점(마이너스 역할)
    • GPIO 핀: 26개 — 프로그래밍으로 HIGH(3.3V) 또는 LOW(0V) 신호를 제어
    graph LR subgraph GPIO_Types["GPIO 핀의 세 가지 유형"] A["⚡ 전원 핀<br/>3.3V / 5V<br/>장치에 전력 공급"] B["⏚ GND 핀<br/>접지(0V)<br/>회로의 기준점"] C["🔌 GPIO 핀<br/>26개 사용 가능<br/>신호 입출력"] end C --> D["OUTPUT 모드<br/>LED 켜기, 모터 제어"] C --> E["INPUT 모드<br/>버튼 읽기, 센서 감지"]

    알아보기 📘

    PWM(Pulse Width Modulation, 펄스 폭 변조) 이란 디지털 신호(ON/OFF)를 빠르게 반복하여 마치 아날로그 신호처럼 중간 값을 표현하는 기술입니다. 예를 들어 ON 시간이 50%면 모터는 절반 속도로, 100%면 최대 속도로 회전합니다. 이 ON 비율을 듀티 사이클(Duty Cycle) 이라고 부릅니다.

    개념 3: 모터 드라이버(L298N) — 두뇌와 근육 사이의 통역사 🔧¶

    비유로 시작

    여러분의 뇌가 "오른팔을 들어!"라고 명령하면, 신경과 근육이 협력해서 팔이 올라갑니다. 라즈베리파이(뇌)가 "모터 회전!"이라고 GPIO 신호를 보내면, 모터 드라이버(신경)가 그 약한 신호를 증폭해서 모터(근육)를 실제로 돌립니다.

    정확한 정의

    모터 드라이버는 마이크로컨트롤러(라즈베리파이)의 작은 전류 신호를 받아 모터가 필요로 하는 큰 전류로 변환해주는 회로입니다. L298N은 DC 모터 2개를 독립적으로 제어할 수 있는 듀얼 H-브릿지 모터 드라이버입니다.

    왜 모터 드라이버가 필요할까요?

    • 라즈베리파이 GPIO 핀의 출력 전류: 약 16mA (매우 약함)
    • DC 모터가 필요한 전류: 200mA~2A (수십~수백 배 강함)
    • GPIO 핀으로 모터를 직접 연결하면 라즈베리파이가 손상됩니다! 😱
    graph LR RPI["🖥️ 라즈베리파이<br/>GPIO 신호<br/>(3.3V, 16mA)"] --> L298N["🔧 L298N<br/>모터 드라이버<br/>(신호 증폭)"] --> MOTOR["⚙️ DC 모터<br/>(6~12V, 1~2A)"] BAT["🔋 배터리<br/>(7.4V)"] --> L298N

    L298N의 주요 핀 구성

    • IN1, IN2: 모터 A의 방향 제어 (GPIO에서 신호 입력)
    • IN3, IN4: 모터 B의 방향 제어
    • ENA: 모터 A의 속도 제어 (PWM 신호 입력)
    • ENB: 모터 B의 속도 제어
    • OUT1, OUT2: 모터 A 연결 단자
    • OUT3, OUT4: 모터 B 연결 단자
    • +12V: 모터 전원 입력 (배터리 연결)
    • GND: 접지 (라즈베리파이와 배터리 공통)
    • +5V: 내부 레귤레이터에서 5V 출력 (점퍼 장착 시)

    모터 방향 제어 원리

    • IN1=HIGH, IN2=LOW → 모터 A 정회전 (전진)
    • IN1=LOW, IN2=HIGH → 모터 A 역회전 (후진)
    • IN1=LOW, IN2=LOW → 모터 A 정지
    • IN1=HIGH, IN2=HIGH → 모터 A 브레이크

    개념 4: RC카 전체 시스템 구조 — 모든 것을 하나로 🚗¶

    비유로 시작

    RC카를 사람의 몸에 비유해 봅시다. 라즈베리파이는 뇌, 카메라는 눈, 모터 드라이버는 신경계, 모터는 근육, 배터리는 심장(에너지원), 바퀴는 발입니다. 이 모든 부품이 조화롭게 연결되어야 RC카가 움직입니다.

    전체 시스템 구성도

    graph TB subgraph 전원계통["🔋 전원 계통"] BAT1["리튬 배터리<br/>7.4V (모터용)"] BAT2["보조 배터리<br/>5V (라즈베리파이용)"] end subgraph 두뇌["🧠 두뇌"] RPI["라즈베리파이 4B"] end subgraph 감각["👁️ 감각"] CAM["Pi 카메라 모듈"] end subgraph 신경["🔧 신경계"] DRIVER["L298N 모터 드라이버"] end subgraph 근육["⚙️ 근육"] ML["왼쪽 모터"] MR["오른쪽 모터"] end BAT2 --> |"5V USB-C"| RPI BAT1 --> |"7.4V"| DRIVER CAM --> |"CSI 케이블"| RPI RPI --> |"GPIO 신호"| DRIVER DRIVER --> |"전류 공급"| ML DRIVER --> |"전류 공급"| MR RPI -.-> |"Wi-Fi"| PC["💻 노트북<br/>(SSH 원격접속)"]

    필요한 부품 목록

    • 라즈베리파이 4B (4GB RAM 권장) × 1
    • microSD 카드 (32GB 이상, Class 10) × 1
    • 라즈베리파이 카메라 모듈 V2 × 1
    • L298N 모터 드라이버 모듈 × 1
    • 2WD RC카 섀시 키트 (DC 모터 2개, 바퀴, 캐스터 포함) × 1
    • 리튬 배터리 7.4V (18650 2S 또는 리포 배터리) × 1
    • 5V 보조 배터리 (라즈베리파이 전원용) × 1
    • 점퍼 와이어 (암-암, 암-수) 여러 개
    • USB-C 케이블 × 1

    ⚠️ 안전 주의사항

    • 리튬 배터리는 합선(쇼트) 시 화재 위험이 있습니다. 양극(+)과 음극(-)이 직접 닿지 않도록 주의하세요.
    • 회로 연결은 반드시 전원을 끈 상태에서 진행하세요.
    • GPIO 핀에 5V를 직접 입력하면 라즈베리파이가 손상됩니다. GPIO는 3.3V 로직입니다.

    🔨 따라하기¶

    Step 1: 라즈베리파이 OS 설치하기 💿¶

    라즈베리파이를 사용하려면 먼저 운영체제를 설치해야 합니다. microSD 카드에 라즈베리파이 OS를 구워(flash) 넣겠습니다.

    준비물: 노트북/PC, microSD 카드, microSD 카드 리더기

    1-1. Raspberry Pi Imager 다운로드

    공식 사이트(https://www.raspberrypi.com/software/)에서 Raspberry Pi Imager를 다운로드하여 설치합니다.

    1-2. OS 이미지 굽기

    1. Raspberry Pi Imager를 실행합니다
    2. "CHOOSE OS" 클릭 → "Raspberry Pi OS (64-bit)" 선택
    3. "CHOOSE STORAGE" 클릭 → microSD 카드 선택
    4. ⚙️ 설정 아이콘(톱니바퀴) 클릭 — 여기가 중요합니다!

    사전 설정에서 반드시 입력할 항목들:

    • 호스트명 설정: rccar (원하는 이름)
    • SSH 활성화: 체크 ✅ (비밀번호 인증 사용)
    • 사용자 이름과 비밀번호 설정: 사용자명 pi, 비밀번호는 기억할 수 있는 것으로
    • Wi-Fi 설정: SSID(와이파이 이름)와 비밀번호 입력, 국가 KR

    • 로캘 설정: 시간대 Asia/Seoul, 키보드 레이아웃 us

    • "WRITE" 클릭 → 완료까지 대기 (약 5~10분)

    생각해보기 💭

    SSH를 미리 활성화하는 이유가 뭘까요? RC카 위에 올라간 라즈베리파이에는 모니터와 키보드를 연결하기 어렵습니다. SSH를 통해 노트북에서 원격으로 라즈베리파이를 제어할 수 있습니다. 이것을 헤드리스(Headless) 설정이라고 합니다.

    Step 2: 라즈베리파이 부팅 및 SSH 접속 🌐¶

    2-1. 부팅

    1. 구운 microSD 카드를 라즈베리파이에 삽입합니다
    2. USB-C 전원을 연결합니다
    3. 빨간 LED(전원)와 초록 LED(디스크 활동)가 켜지면 정상입니다
    4. 첫 부팅 시 약 1~2분 대기합니다 (자동 설정 진행 중)

    2-2. SSH 접속

    노트북에서 터미널(Windows: PowerShell 또는 CMD)을 열고 다음을 입력합니다.

    ssh pi@rccar.local

    비밀번호를 입력하면 접속 완료! 만약 rccar.local이 안 된다면, 공유기 관리 페이지에서 라즈베리파이의 IP 주소를 확인한 후 다음과 같이 접속합니다.

    ssh pi@192.168.0.xxx

    2-3. 시스템 업데이트

    접속 후 시스템을 최신 상태로 업데이트합니다.

    sudo apt update && sudo apt upgrade -y

    python3 --version

    Python 3.9 이상이 출력되면 정상입니다.

    3-3. GPIO 테스트 — LED 깜빡이기

    하드웨어가 정상 작동하는지 확인하기 위해 간단한 테스트를 해봅시다. GPIO 핀 하나에 LED를 연결하고 깜빡여 보겠습니다.

    이 테스트는 선택사항입니다. LED가 없다면 코드만 확인하고 넘어가도 됩니다.

    # gpio_test.py
import RPi.GPIO as GPIO
import time

# GPIO 핀 번호 체계 설정 (BCM 모드 = 핀의 기능 번호 사용)
GPIO.setmode(GPIO.BCM)

# GPIO 18번 핀을 출력 모드로 설정
GPIO.setup(18, GPIO.OUT)

try:
    for i in range(5):
        GPIO.output(18, GPIO.HIGH)  # 켜기
        print(f"LED ON  ({i+1}/5)")
        time.sleep(0.5)

        GPIO.output(18, GPIO.LOW)   # 끄기
        print(f"LED OFF ({i+1}/5)")
        time.sleep(0.5)

    print("테스트 완료!")

finally:
    GPIO.cleanup()  # GPIO 핀 상태 초기화 (매우 중요!)

    실행:

    python3 gpio_test.py

    알아보기 📘

    GPIO.setmode(GPIO.BCM) vs GPIO.setmode(GPIO.BOARD): BCM 모드는 칩의 GPIO 번호를 사용하고, BOARD 모드는 보드의 물리적 핀 번호를 사용합니다. 대부분의 프로젝트에서 BCM 모드를 사용하므로 우리도 BCM을 사용합니다.

    Step 4: L298N 모터 드라이버와 배선 연결하기 🔌¶

    이제 가장 중요한 단계입니다. 라즈베리파이와 L298N, 그리고 모터를 연결합니다.

    ⚠️ 반드시 모든 전원을 끈 상태에서 배선하세요!

    배선 연결표

    라즈베리파이 → L298N 연결 (점퍼 와이어 사용)

    • GPIO 17 → L298N IN1 (왼쪽 모터 방향 1)
    • GPIO 27 → L298N IN2 (왼쪽 모터 방향 2)
    • GPIO 12 → L298N ENA (왼쪽 모터 속도, PWM)
    • GPIO 22 → L298N IN3 (오른쪽 모터 방향 1)
    • GPIO 23 → L298N IN4 (오른쪽 모터 방향 2)
    • GPIO 13 → L298N ENB (오른쪽 모터 속도, PWM)
    • GND (아무 GND 핀) → L298N GND

    L298N → 모터 연결

    • L298N OUT1 → 왼쪽 모터 +
    • L298N OUT2 → 왼쪽 모터 -
    • L298N OUT3 → 오른쪽 모터 +
    • L298N OUT4 → 오른쪽 모터 -

    전원 연결

    • 7.4V 배터리 + → L298N +12V 단자
    • 7.4V 배터리 - → L298N GND 단자
    • L298N GND ↔ 라즈베리파이 GND (공통 접지, 매우 중요!)

    ⚠️ ENA, ENB 점퍼 제거 잊지 마세요!

    L298N 보드에는 기본적으로 ENA, ENB 위에 점퍼 캡이 끼워져 있습니다. 이 점퍼를 반드시 제거해야 PWM으로 속도 제어가 가능합니다. 점퍼가 꽂혀 있으면 항상 최대 속도로만 동작합니다.
