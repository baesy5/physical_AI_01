    Chapter 21: RC카 자율주행 실전 테스트¶

    🎯 이 장에서 배우는 것¶

    • RC카에서 카메라 입력 → 모델 추론 → 모터 제어의 전체 자율주행 루프를 실행할 수 있다
    • 실제 주행에서 발생하는 문제(지연, 노이즈, 미끄러짐 등)를 진단하고 해결할 수 있다
    • 테스트 코스를 설계하고 반복 테스트를 통해 자율주행 성능을 체계적으로 개선할 수 있다
    • PID 제어와 안전 장치를 적용하여 안정적인 자율주행을 달성할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분은 지금까지 카메라로 영상을 찍고, 딥러닝 모델을 훈련시키고, RC카에 모델을 탑재하는 과정을 거쳤습니다. 이제 진짜 시험의 순간입니다.

    🏁 드디어 우리가 만든 RC카가 스스로 달릴 시간입니다!

    하지만 시뮬레이션에서 완벽하게 작동하던 모델이 현실에서는 전혀 다르게 행동하는 경우가 많습니다. 이것을 "sim-to-real gap"(시뮬레이션과 현실의 차이)이라고 합니다. 바닥이 미끄럽거나, 카메라에 빛이 반사되거나, 모터가 예상과 다르게 반응하는 등 수많은 변수가 존재합니다.

    이 장에서는 실전 테스트를 통해 이런 문제들을 하나씩 발견하고 해결하는 과정을 배웁니다. 이 과정이야말로 실제 엔지니어들이 자율주행차를 개발할 때 가장 많은 시간을 보내는 단계입니다. 문제를 찾고, 원인을 파악하고, 해결책을 적용하고, 다시 테스트하는 이 반복 과정이 바로 진짜 엔지니어링입니다.

    📚 핵심 개념¶

    개념 1: 자율주행 루프 (Autonomous Driving Loop)¶

    🎭 비유로 시작하기

    자전거를 타는 것을 떠올려 보세요. 눈으로 앞길을 보고(감지) → 뇌가 "왼쪽으로 틀어야겠다"고 판단하고(추론) → 손이 핸들을 돌립니다(제어). 이 과정이 끊임없이 반복됩니다. RC카 자율주행도 정확히 같은 원리입니다.

    📖 정확한 정의

    자율주행 루프란 카메라 입력 → 이미지 전처리 → 모델 추론 → 조향/속도 결정 → 모터 제어가 하나의 순환 고리로 반복 실행되는 시스템입니다. 이 고리가 1초에 몇 번 돌아가는지를 FPS(Frames Per Second)라고 하며, 이 숫자가 클수록 RC카가 더 민첩하게 반응합니다.

    graph LR A["📷 카메라 촬영"] --> B["🔄 이미지 전처리"] B --> C["🧠 모델 추론"] C --> D["📐 조향각 결정"] D --> E["⚡ 모터 제어"] E --> F["🚗 RC카 이동"] F --> A style A fill:#4CAF50,color:#fff style C fill:#2196F3,color:#fff style E fill:#FF9800,color:#fff

    ✅ 예시로 확인

    • FPS가 10이면: 1초에 10번 판단 → 0.1초마다 한 번 방향 결정
    • FPS가 3이면: 1초에 3번 판단 → 0.33초마다 한 번 방향 결정 → 급커브에서 반응 늦음
    • 일반적으로 RC카 자율주행에서 최소 10 FPS 이상이 필요합니다

    개념 2: Sim-to-Real Gap (시뮬레이션과 현실의 차이)¶

    🎭 비유로 시작하기

    수영장에서 수영을 완벽하게 배웠다고 해서 바다에서도 잘 수영할 수 있을까요? 파도, 조류, 수온 차이 때문에 전혀 다른 경험이 됩니다. 마찬가지로 컴퓨터에서 훈련된 모델이 현실에서는 다르게 동작합니다.

    📖 정확한 정의

    Sim-to-Real Gap이란 훈련 환경과 실제 환경의 차이로 인해 모델 성능이 저하되는 현상입니다. 조명 조건, 바닥 재질, 카메라 각도, 모터 특성 등 수많은 요인이 이 차이를 만듭니다.

    ✅ 현실에서 발생하는 주요 문제들

    • 카메라 지연(Latency): 이미지를 캡처하고 처리하는 데 시간이 걸려 RC카가 이미 지나간 위치의 정보로 판단
    • 모터 반응 차이: 왼쪽 모터와 오른쪽 모터의 출력이 미세하게 달라서 직진이 안 됨
    • 바닥 미끄러짐: 체육관 바닥과 교실 바닥의 마찰력 차이로 회전 반경이 달라짐
    • 조명 변화: 창문 근처와 교실 안쪽의 밝기 차이로 차선 인식 실패

    개념 3: PID 제어 (비례-적분-미분 제어)¶

    🎭 비유로 시작하기

    샤워할 때 물 온도를 맞추는 상황을 생각해 보세요.

    • 비례(P): 물이 너무 차면 뜨거운 물을 많이 틀고, 조금 차면 조금만 트는 것
    • 적분(I): 계속 약간 차가운 상태가 이어지면 "아, 좀 더 틀어야겠다"고 보정하는 것
    • 미분(D): 온도가 급격히 올라가면 "너무 빨리 뜨거워지니까 미리 줄이자"라고 예측하는 것

    📖 정확한 정의

    PID 제어는 현재 오차(P), 누적된 오차(I), 오차의 변화 속도(D)를 종합하여 제어 신호를 생성하는 방법입니다. RC카에서는 차선 중앙에서 벗어난 정도를 오차로 두고, 조향각을 제어합니다.

    조향각 = Kp × (현재 오차) + Ki × (오차 누적합) + Kd × (오차 변화량)
    graph TD A["목표: 차선 중앙"] --> B["오차 = 목표 - 현재 위치"] B --> C["P: 현재 오차 × Kp"] B --> D["I: 누적 오차 × Ki"] B --> E["D: 오차 변화량 × Kd"] C --> F["조향각 = P + I + D"] D --> F E --> F F --> G["모터에 전달"] style A fill:#4CAF50,color:#fff style F fill:#FF5722,color:#fff

    ✅ 파라미터 조정 가이드

    • Kp를 높이면: 반응이 빨라지지만, 좌우로 심하게 흔들릴 수 있음 (과잉 반응)
    • Ki를 높이면: 지속적인 편향을 교정하지만, 너무 높으면 흔들림이 커짐
    • Kd를 높이면: 급격한 변화를 억제하지만, 너무 높으면 반응이 느려짐

    💡 알아보기: 실전에서는 P만 먼저 조정하고, 그다음 D를 추가하고, 마지막에 I를 미세 조정하는 순서가 효과적입니다.

    개념 4: 안전 시스템 (Safety System)¶

    🎭 비유로 시작하기

    자동차에는 브레이크, 에어백, ABS 등 여러 겹의 안전 장치가 있습니다. 우리 RC카에도 비상 정지, 속도 제한, 충돌 감지 같은 안전 장치가 반드시 필요합니다. 실전 테스트에서 RC카가 벽에 부딪히거나 테이블에서 떨어지면 안 되니까요!

    📖 정확한 정의

    안전 시스템이란 자율주행 중 예상치 못한 상황에서 RC카를 보호하기 위한 소프트웨어 및 하드웨어 장치입니다. 가장 기본적인 것은 키보드를 누르면 즉시 멈추는 비상 정지(E-Stop) 기능입니다.

    ✅ 우리가 구현할 안전 기능 3가지

    • 비상 정지(E-Stop): 특정 키를 누르면 모든 모터를 즉시 정지
    • 속도 제한(Speed Limit): 최대 속도를 제한하여 통제 불능 상태 방지
    • 신뢰도 기반 감속: 모델의 예측 신뢰도가 낮으면 자동으로 속도를 줄임

    🔨 따라하기¶

    Step 1: 테스트 코스 설계하기 🏗️¶

    실전 테스트의 첫 단계는 테스트 환경을 만드는 것입니다. 교실이나 체육관 바닥에 테이프로 차선을 만듭니다.

    준비물

    • 검정색 또는 색상 테이프 (폭 2~3cm)
    • 넓은 바닥 공간 (최소 3m × 5m)
    • 직선 구간, 완만한 곡선 구간, 급커브 구간 포함

    코스 설계 원칙

    graph LR subgraph "레벨 1: 기본" A["직선 2m"] end subgraph "레벨 2: 중급" B["직선 + 완만한 곡선"] end subgraph "레벨 3: 고급" C["S자 코스 + 급커브"] end A --> B --> C style A fill:#4CAF50,color:#fff style B fill:#FF9800,color:#fff style C fill:#f44336,color:#fff

    🔍 생각해보기: 왜 처음부터 복잡한 코스에서 테스트하지 않고, 직선부터 시작할까요? 문제가 생겼을 때 원인을 찾기 쉽기 때문입니다. 직선에서도 실패하면 모델이나 모터에 근본적인 문제가 있는 것이고, 직선은 성공하지만 곡선에서 실패하면 조향 로직의 문제입니다.

    코스 설계 코드 (코스 위의 체크포인트를 기록하여 성능 측정에 활용합니다)

    # course_design.py
# 테스트 코스의 체크포인트를 정의하는 코드

class TestCourse:
    def __init__(self, name):
        self.name = name
        self.checkpoints = []
        self.total_distance = 0

    def add_checkpoint(self, label, distance_from_start):
        """체크포인트 추가"""
        self.checkpoints.append({
            'label': label,
            'distance': distance_from_start
        })
        self.total_distance = max(self.total_distance, distance_from_start)
        print(f"  ✅ 체크포인트 추가: {label} ({distance_from_start}m 지점)")

    def show_course(self):
        """코스 정보 출력"""
        print(f"\n🏁 코스: {self.name}")
        print(f"   총 거리: {self.total_distance}m")
        print(f"   체크포인트 {len(self.checkpoints)}개:")
        for cp in self.checkpoints:
            print(f"   - {cp['distance']}m: {cp['label']}")

# 레벨별 코스 생성
level1 = TestCourse("직선 코스")
level1.add_checkpoint("출발", 0)
level1.add_checkpoint("중간", 1.0)
level1.add_checkpoint("도착", 2.0)
level1.show_course()

level2 = TestCourse("곡선 코스")
level2.add_checkpoint("출발", 0)
level2.add_checkpoint("직선 끝", 1.0)
level2.add_checkpoint("곡선 중간", 2.0)
level2.add_checkpoint("도착", 3.0)
level2.show_course()

level3 = TestCourse("S자 코스")
level3.add_checkpoint("출발", 0)
level3.add_checkpoint("첫 번째 커브", 1.0)
level3.add_checkpoint("S자 전환점", 2.0)
level3.add_checkpoint("두 번째 커브", 3.0)
level3.add_checkpoint("급커브", 4.0)
level3.add_checkpoint("도착", 5.0)
level3.show_course()

    Step 2: 자율주행 루프 구현하기 🔄¶

    이제 RC카의 핵심인 자율주행 루프를 코드로 구현합니다. 카메라로 이미지를 읽고 → 모델이 조향각을 예측하고 → 모터를 제어하는 과정이 끊임없이 반복됩니다.

    # autonomous_loop.py
# RC카 자율주행 메인 루프

import cv2
import numpy as np
import time

class AutonomousDriver:
    def __init__(self, model, camera, motor_controller):
        self.model = model              # 훈련된 딥러닝 모델
        self.camera = camera            # 카메라 객체
        self.motor = motor_controller   # 모터 컨트롤러
        self.is_running = False
        self.base_speed = 30            # 기본 속도 (0~100)
        self.max_speed = 50             # 최대 속도 제한
        self.fps_history = []           # FPS 기록용

    def preprocess_image(self, frame):
        """카메라 이미지를 모델 입력 형태로 변환"""
        # 1. 관심 영역(ROI) 잘라내기 - 하단 절반만 사용
        height = frame.shape[0]
        roi = frame[height // 2:, :]

        # 2. 크기 조정 (모델 입력 크기에 맞춤)
        resized = cv2.resize(roi, (200, 66))

        # 3. 색상 변환 (RGB로)
        rgb = cv2.cvtColor(resized, cv2.COLOR_BGR2RGB)

        # 4. 정규화 (0~1 범위로)
        normalized = rgb / 255.0

        # 5. 배치 차원 추가
        input_data = np.expand_dims(normalized, axis=0)

        return input_data

    def predict_steering(self, frame):
        """이미지로부터 조향각 예측"""
        input_data = self.preprocess_image(frame)
        steering_angle = self.model.predict(input_data, verbose=0)[0][0]
        return float(steering_angle)

    def calculate_speed(self, steering_angle):
        """조향각에 따라 속도 조절 - 커브에서는 감속"""
        # 조향각이 클수록 속도를 줄임
        angle_factor = 1.0 - abs(steering_angle) * 0.5
        speed = self.base_speed * max(angle_factor, 0.4)

        # 최대 속도 제한 적용
        speed = min(speed, self.max_speed)
        return speed

    def run(self):
        """자율주행 메인 루프"""
        self.is_running = True
        print("🚗 자율주행을 시작합니다!")
        print("   ESC 키를 누르면 정지합니다.\n")

        frame_count = 0
        start_time = time.time()

        try:
            while self.is_running:
                loop_start = time.time()

                # 1단계: 카메라에서 이미지 읽기
                ret, frame = self.camera.read()
                if not ret:
                    print("⚠️ 카메라 읽기 실패!")
                    continue

                # 2단계: 모델로 조향각 예측
                steering = self.predict_steering(frame)

                # 3단계: 속도 계산
                speed = self.calculate_speed(steering)

                # 4단계: 모터 제어
                self.motor.set_steering(steering)
                self.motor.set_speed(speed)

                # FPS 계산
                frame_count += 1
                loop_time = time.time() - loop_start
                fps = 1.0 / loop_time if loop_time > 0 else 0

                # 상태 출력 (10프레임마다)
                if frame_count % 10 == 0:
                    print(f"  프레임 {frame_count:4d} | "
                          f"조향: {steering:+.3f} | "
                          f"속도: {speed:.1f} | "
                          f"FPS: {fps:.1f}")

                # ESC 키 확인 (비상 정지)
                key = cv2.waitKey(1) & 0xFF
                if key == 27:  # ESC
                    print("\n🛑 비상 정지!")
                    break

        finally:
            # 안전하게 종료
            self.motor.stop()
            elapsed = time.time() - start_time
            avg_fps = frame_count / elapsed if elapsed > 0 else 0
            print(f"\n📊 주행 결과:")
            print(f"   총 프레임: {frame_count}")
            print(f"   주행 시간: {elapsed:.1f}초")
            print(f"   평균 FPS: {avg_fps:.1f}")
            self.is_running = False

    💡 알아보기: run() 함수의 try-finally 구조에 주목하세요. 어떤 오류가 발생하더라도 finally 블록에서 반드시 모터를 정지시킵니다. 이것이 안전 프로그래밍의 기본입니다.

    Step 3: 안전 시스템 추가하기 🛡️¶

    자율주행에서 가장 중요한 것은 안전입니다. RC카가 통제 불능이 되면 장비가 파손되거나 다칠 수 있습니다.

    # safety_system.py
# 안전 기능이 추가된 자율주행 시스템

class SafetySystem:
    """RC카 안전 시스템"""

    def __init__(self):
        self.emergency_stop = False
        self.max_steering_change = 0.3   # 한 번에 최대 조향 변화량
        self.min_fps = 5                 # 최소 FPS (이하면 정지)
        self.prev_steering = 0.0
        self.confidence_threshold = 0.4  # 최소 신뢰도

    def check_steering_safety(self, new_steering):
        """조향각 급변 방지 (스무딩)"""
        change = new_steering - self.prev_steering

        # 변화량이 너무 크면 제한
        if abs(change) > self.max_steering_change:
            limited = self.prev_steering + np.sign(change) * self.max_steering_change
            print(f"  ⚠️ 조향 스무딩: {new_steering:.3f} → {limited:.3f}")
            new_steering = limited

        self.prev_steering = new_steering
        return new_steering

    def check_fps_safety(self, current_fps):
        """FPS가 너무 낮으면 경고/정지"""
        if current_fps < self.min_fps and current_fps > 0:
            print(f"  🚨 FPS 경고! 현재 {current_fps:.1f} FPS "
                  f"(최소 {self.min_fps} 필요)")
            return False  # 안전하지 않음
        return True  # 안전함

    def calculate_safe_speed(self, base_speed, steering, confidence):
        """상황에 따른 안전 속도 계산"""
        speed = base_speed

        # 1. 급커브 감속
        if abs(steering) > 0.5:
            speed *= 0.5

        # 2. 신뢰도 낮으면 감속
        if confidence < self.confidence_threshold:
            speed *= 0.3
            print(f"  ⚠️ 낮은 신뢰도({confidence:.2f}) → 감속")

        return max(speed, 0)  # 음수 속도 방지


class SafeAutonomousDriver(AutonomousDriver):
    """안전 시스템이 통합된 자율주행 드라이버"""

    def __init__(self, model, camera, motor_controller):
        super().__init__(model, camera, motor_controller)
        self.safety = SafetySystem()

    def predict_with_confidence(self, frame):
        """조향각과 함께 신뢰도도 반환"""
        input_data = self.preprocess_image(frame)
        prediction = self.model.predict(input_data, verbose=0)[0]

        steering = float(prediction[0])
        # 간단한 신뢰도 추정: 예측값이 극단적이지 않을수록 높음
        confidence = 1.0 - abs(steering) * 0.5

        return steering, confidence

    def run_safe(self):
        """안전 기능이 포함된 자율주행 루프"""
        self.is_running = True
        print("🚗 안전 모드 자율주행을 시작합니다!")
        print("   ESC: 비상 정지 | S: 속도 변경 | Q: 종료\n")

        frame_count = 0

        try:
            while self.is_running:
                loop_start = time.time()

                ret, frame = self.camera.read()
                if not ret:
                    continue

                # 예측 (신뢰도 포함)
                steering, confidence = self.predict_with_confidence(frame)

                # 안전 검사 1: 조향 스무딩
                steering = self.safety.check_steering_safety(steering)

                # 안전 검사 2: 안전 속도 계산
                speed = self.safety.calculate_safe_speed(
                    self.base_speed, steering, confidence
                )

                # 모터 제어
                self.motor.set_steering(steering)
                self.motor.set_speed(speed)

                # FPS 계산 및 안전 검사
                loop_time = time.time() - loop_start
                fps = 1.0 / loop_time if loop_time > 0 else 0

                # 안전 검사 3: FPS 확인
                if not self.safety.check_fps_safety(fps):
                    self.motor.set_speed(speed * 0.5)  # FPS 낮으면 감속

                frame_count += 1

                # 키 입력 처리
                key = cv2.waitKey(1) & 0xFF
                if key == 27:  # ESC - 비상 정지
                    print("\n🛑 비상 정지 활성화!")
                    break
                elif key == ord('q'):  # Q - 정상 종료
                    print("\n✅ 정상 종료")
                    break

        finally:
            self.motor.stop()
            print("🏁 모터 정지 완료. 안전하게 종료되었습니다.")

    class PIDController: """PID 제어기"""

    def __init__(self, kp=0.5, ki=0.01, kd=0.1):
    self.kp = kp  # 비례 계수
    self.ki = ki  # 적분 계수
    self.kd = kd  # 미분 계수

    self.prev_error = 0.0
    self.integral = 0.0
    self.integral_limit = 1.0  # 적분 누적 제한 (와인드업 방지)

def compute(self, error, dt=0.1):
    """
    PID 제어값 계산

    error: 현재 오차 (차선 중앙에서 벗어난 정도)
    dt: 시간 간격 (초)
    """
    # P (비례): 현재 오차에 비례
    p_term = self.kp * error

    # I (적분): 오차의 누적합
    self.integral += error * dt
    # 적분 와인드업 방지
    self.integral = np.clip(self.integral, 
                            -self.integral_limit, 
                            self.integral_limit)
    i_term = self.ki * self.integral
