    센서로 세상을 느끼다 – 바닥 센서와 근접 센서¶

    🎯 이 장에서 배우는 것¶

    • 햄스터 로봇의 바닥 센서(좌·우)가 무엇인지 설명할 수 있다
    • 바닥 센서 값을 읽어 화면에 출력하는 프로그램을 작성할 수 있다
    • 근접 센서 값을 활용하여 장애물 감지 로직을 작성할 수 있다
    • 센서 값과 조건문을 결합하여 로봇의 행동을 분기할 수 있다

    💡 왜 이걸 배우나요?¶

    지금까지 우리는 로봇에게 "앞으로 가", "왼쪽으로 돌아"처럼 일방적으로 명령만 내렸습니다. 로봇은 시키는 대로만 움직였죠. 마치 눈을 감고 걷는 것과 같습니다. 🙈

    하지만 진짜 똑똑한 로봇은 주변 상황을 스스로 감지하고 반응합니다. 자율주행 자동차가 차선을 인식하고, 로봇청소기가 벽을 피하는 것처럼요.

    햄스터 로봇에도 이런 능력을 줄 수 있습니다! 로봇 배 밑에 달린 바닥 센서는 바닥 색상을 감지하고, 앞에 달린 근접 센서는 앞에 무언가가 있는지 느낍니다.

    이번 장에서 센서를 다루는 법을 익히면, 다음 장의 라인트레이싱(검은 선을 따라 이동)은 물론, 나중에 배울 강화학습에서도 핵심 기초가 됩니다. 센서는 로봇의 눈과 귀입니다! 👀

    📚 핵심 개념¶

    개념 1: 바닥 센서 – 로봇의 눈 👁️¶

    비유부터 시작할게요. 여러분이 눈을 감고 발바닥의 감촉만으로 걷는다고 상상해보세요. 카펫 위인지, 타일 위인지 발바닥으로 느낄 수 있죠? 햄스터 로봇의 바닥 센서가 바로 이 역할입니다.

    정확한 정의: 바닥 센서는 로봇 밑면에 왼쪽·오른쪽 2개가 달려 있으며, 바닥에 적외선 빛을 쏘고 반사되는 양을 측정합니다. 밝은 바닥(흰색)은 빛을 많이 반사하고, 어두운 바닥(검은색)은 빛을 적게 반사합니다.

    예시로 확인: - 흰 종이 위: 센서 값이 높음 (약 80~100 정도) - 검은 선 위: 센서 값이 낮음 (약 10~30 정도) - 값의 범위는 0~100입니다

    graph LR A["🤖 햄스터 로봇 밑면"] --> B["왼쪽 바닥 센서"] A --> C["오른쪽 바닥 센서"] B --> D["흰 바닥 → 높은 값 80~100"] B --> E["검은 선 → 낮은 값 10~30"] C --> D C --> E

    개념 2: 근접 센서 – 로봇의 더듬이 🐜¶

    비유부터 시작할게요. 개미가 더듬이로 앞에 뭐가 있는지 탐색하는 것을 본 적 있나요? 근접 센서는 로봇의 더듬이입니다. 앞에 물체가 가까이 있으면 큰 값을, 아무것도 없으면 0에 가까운 값을 반환합니다.

    정확한 정의: 근접 센서는 로봇 앞면에 있으며, 적외선을 앞으로 쏘아서 반사되는 양으로 앞에 물체가 있는지 감지합니다.

    예시로 확인: - 앞에 아무것도 없을 때: 값이 0에 가까움 - 손을 5cm 앞에 놓으면: 값이 50 이상으로 올라감 - 손을 바짝 가까이 대면: 값이 거의 100에 근접 - 값의 범위는 0~100입니다

    개념 3: 센서 값 읽기 – 로봇에게 물어보기 🗣️¶

    지난 장에서 hamster.wheels(50, 50) 같은 명령은 로봇에게 "이렇게 해!"라고 지시하는 것이었죠.

    센서 값 읽기는 반대입니다. 로봇에게 "지금 뭐가 보여?"라고 질문하는 거예요.

    파이썬에서 센서 값을 읽는 코드는 이렇게 생겼습니다:

    • 왼쪽 바닥 센서: hamster.left_floor()
    • 오른쪽 바닥 센서: hamster.right_floor()
    • 왼쪽 근접 센서: hamster.left_proximity()
    • 오른쪽 근접 센서: hamster.right_proximity()

    이 값들은 숫자(정수)로 돌아오기 때문에 변수에 저장하거나 print()로 출력할 수 있습니다.

    개념 4: 센서 + 조건문 = 반응하는 로봇 🧠¶

    센서 값을 읽는 것만으로는 의미가 없습니다. "이 값이 얼마 이상이면 이렇게 해라"라는 판단 기준을 만들어야 합니다.

    3장에서 배운 if문이 바로 여기서 빛을 발합니다!

    # 패턴: 센서 읽기 → 조건 판단 → 행동
if 센서값 > 기준값:
    행동A()
else:
    행동B()

    이 센서 → 조건 → 행동 패턴은 로봇 프로그래밍의 가장 기본적이고 중요한 구조입니다. 앞으로 계속 반복해서 사용하게 됩니다.

    graph TD A["센서 값 읽기"] --> B{"기준값과 비교"} B -->|"조건 만족"| C["행동 A 실행"] B -->|"조건 불만족"| D["행동 B 실행"] C --> A D --> A

    이 흐름이 빠르게 반복되면서 로봇이 마치 스스로 생각하는 것처럼 움직이게 됩니다! 🎉

    🔨 따라하기¶

    Step 1: 바닥 센서 값을 실시간으로 확인하기¶

    가장 먼저 할 일은 센서가 실제로 어떤 값을 보내는지 눈으로 확인하는 것입니다. 아래 코드를 입력하고 실행해보세요.

    from roboid import *

hamster = Hamster()

for i in range(50):
    left = hamster.left_floor()
    right = hamster.right_floor()
    print("왼쪽:", left, " 오른쪽:", right)
    wait(100)

    실행 방법: 1. 햄스터 로봇을 흰 종이 위에 올려놓으세요 2. 코드를 실행하면 숫자가 쭉 출력됩니다 3. 로봇을 손으로 들어서 검은 선 위로 옮겨보세요 4. 숫자가 어떻게 변하는지 관찰하세요!

    💡 관찰 포인트: 흰 바닥에서는 80~100 근처, 검은 선 위에서는 10~30 근처 값이 나올 거예요. 여러분의 환경에 따라 구체적인 숫자는 다를 수 있습니다.

    Step 2: 근접 센서 값 확인하기¶

    이번에는 앞에 달린 근접 센서를 확인해봅시다.

    from roboid import *

hamster = Hamster()

for i in range(50):
    left_p = hamster.left_proximity()
    right_p = hamster.right_proximity()
    print("왼쪽근접:", left_p, " 오른쪽근접:", right_p)
    wait(100)

    실행 후 이렇게 해보세요: 1. 처음에는 로봇 앞에 아무것도 두지 마세요 → 값이 0에 가깝습니다 2. 손을 로봇 앞 20cm 정도에 놓아보세요 → 값이 살짝 올라갑니다 3. 손을 5cm까지 가까이 가져가보세요 → 값이 확 올라갑니다! 4. 왼쪽에서 손을 대면 왼쪽 값만, 오른쪽에서 대면 오른쪽 값만 변하는 것도 확인해보세요

    Step 3: 나만의 센서 기준값 찾기 📊¶

    로봇 프로그래밍에서 매우 중요한 단계입니다. "얼마부터 검은 선이라고 판단할 것인가?"를 정해야 하거든요.

    Step 1에서 관찰한 값을 바탕으로 기록해보세요:

    • 흰 바닥에서 바닥 센서 값: 대략 _____ (예: 90)
    • 검은 선에서 바닥 센서 값: 대략 _____ (예: 15)
    • 기준값(임계값): 두 값의 중간쯤 → 대략 _____ (예: 50)

    🎯 임계값(threshold)이란? 두 상태를 구분하는 기준선입니다. 예를 들어 기준값을 50으로 정하면, 50 이상이면 "흰 바닥", 50 미만이면 "검은 선"으로 판단합니다.

    Step 4: 검은 선을 만나면 멈추는 로봇¶

    이제 센서와 조건문을 결합해봅시다! 로봇이 앞으로 가다가 검은 선을 만나면 멈추는 프로그램을 만들어봅니다.

    from roboid import *

hamster = Hamster()

hamster.wheels(30, 30)  # 천천히 전진

while True:
    left = hamster.left_floor()
    right = hamster.right_floor()

    if left < 50 or right < 50:  # 둘 중 하나라도 검은 선이면
        hamster.wheels(0, 0)     # 멈추기
        print("검은 선 발견! 멈춥니다.")
        break                     # 반복 종료

    wait(10)

    준비물: 흰 종이 위에 검은 테이프나 매직으로 굵은 선을 그어주세요.

    실행 방법: 1. 로봇을 흰 종이 위에 놓고 검은 선을 향하도록 방향을 맞춥니다 2. 코드를 실행하면 로봇이 천천히 전진합니다 3. 검은 선에 도달하면 자동으로 멈춥니다! 🎉

    💡 while True는 "계속 반복하라"는 뜻이고, break는 "반복을 멈추고 빠져나와"라는 뜻입니다. 센서를 계속 확인하다가 조건을 만족하면 멈추는 구조예요.

    Step 5: 장애물을 만나면 멈추는 로봇¶

    이번에는 근접 센서를 활용합니다. 앞에 손이나 물체를 감지하면 멈추는 프로그램입니다.

    from roboid import *

hamster = Hamster()

hamster.wheels(30, 30)  # 천천히 전진

while True:
    prox = hamster.left_proximity()

    if prox > 40:                # 앞에 뭔가 감지되면
        hamster.wheels(0, 0)     # 멈추기
        print("장애물 발견! 멈춥니다.")
        break

    wait(10)

    실행 후 이렇게 해보세요: 1. 코드를 실행하면 로봇이 전진합니다 2. 로봇 앞에 손을 가져다 대보세요 3. 감지되면 즉시 멈춥니다!

    🧪 기준값 40을 20이나 60으로 바꿔보세요. 값을 낮추면 더 가까이 와야 반응하고, 높이면 더 먼 거리에서도 반응합니다. 직접 실험해보는 게 가장 좋은 공부입니다!

    Step 6: 장애물을 피하며 전진하는 로봇 🏃¶

    마지막으로 조금 더 재미있는 프로그램을 만들어봅시다. 장애물을 만나면 멈추는 대신 방향을 바꿔서 계속 움직이는 로봇입니다.

    from roboid import *

hamster = Hamster()

for i in range(500):
    left_p = hamster.left_proximity()
    right_p = hamster.right_proximity()

    if left_p > 40:              # 왼쪽에 장애물
        hamster.wheels(50, -50)  # 오른쪽으로 회전
    elif right_p > 40:           # 오른쪽에 장애물
        hamster.wheels(-50, 50)  # 왼쪽으로 회전
    else:                        # 장애물 없음
        hamster.wheels(30, 30)   # 직진

    wait(10)

hamster.wheels(0, 0)

    동작 원리: 1. 매 반복마다 왼쪽·오른쪽 근접 센서를 확인합니다 2. 왼쪽에 장애물이 있으면 → 오른쪽으로 회전 3. 오른쪽에 장애물이 있으면 → 왼쪽으로 회전 4. 아무것도 없으면 → 직진 5. 이것이 500번 반복되면 종료합니다

    🎮 책이나 상자로 간단한 통로를 만들고 로봇을 넣어보세요. 벽을 피하면서 움직이는 모습이 꽤 신기할 거예요!

    📝 전체 코드¶

    이번 장에서 가장 핵심적인 두 프로그램을 정리합니다.

    프로그램 1: 검은 선 감지 후 정지

    from roboid import *

hamster = Hamster()

hamster.wheels(30, 30)

while True:
    left = hamster.left_floor()
    right = hamster.right_floor()

    if left < 50 or right < 50:
        hamster.wheels(0, 0)
        print("검은 선 발견! 멈춥니다.")
        break

    wait(10)

    프로그램 2: 장애물 회피 주행

    from roboid import *

hamster = Hamster()

for i in range(500):
    left_p = hamster.left_proximity()
    right_p = hamster.right_proximity()

    if left_p > 40:
        hamster.wheels(50, -50)
    elif right_p > 40:
        hamster.wheels(-50, 50)
    else:
        hamster.wheels(30, 30)

    wait(10)

hamster.wheels(0, 0)

    ⚠️ 자주 하는 실수¶

    실수 1: 기준값을 환경에 맞게 조정하지 않는 경우 😅

    교재에 적힌 기준값 50이 모든 환경에서 통하지는 않습니다. 바닥 재질, 조명, 테이프 색상에 따라 센서 값이 달라져요. 반드시 Step 1~2에서 자기 환경의 센서 값을 먼저 확인하고, Step 3에서 기준값을 정하세요.

    실수 2: wait() 없이 센서를 읽는 경우 ⚡

    # ❌ 이렇게 하면 안 돼요
while True:
    left = hamster.left_floor()
    if left < 50:
        break
    # wait()가 없으면 너무 빠르게 반복해서 문제 발생!

# ✅ 이렇게 하세요
while True:
    left = hamster.left_floor()
    if left < 50:
        break
    wait(10)  # 잠깐 쉬어주기!

    wait(10)은 10밀리초(0.01초)만 쉬는 것이지만, 이것 없이 반복하면 프로그램이 너무 빠르게 돌아서 센서 값을 제대로 못 읽거나 컴퓨터에 부담을 줍니다.

    실수 3: 센서 함수 이름을 틀리는 경우 📝

    # ❌ 자주 틀리는 이름들
hamster.floor_left()       # 순서가 반대!
hamster.leftfloor()        # 언더바(_) 빠짐
hamster.proximity()        # left/right 안 붙임

# ✅ 올바른 이름
hamster.left_floor()
hamster.right_floor()
hamster.left_proximity()
hamster.right_proximity()

    기억하기 쉬운 패턴: 방향(left/right)이 먼저, 그 다음 센서 종류(floor/proximity)!

    ✅ 스스로 점검하기¶

    아래 항목을 하나씩 체크해보세요. 모두 체크할 수 있으면 이번 장은 완벽합니다! ✨

    • 바닥 센서가 로봇 어디에 있고, 어떤 원리로 작동하는지 설명할 수 있다
    • hamster.left_floor()와 hamster.right_floor()로 센서 값을 읽을 수 있다
    • 흰 바닥과 검은 선에서 센서 값이 어떻게 다른지 알고 있다
    • 근접 센서로 장애물까지의 거리를 대략 감지할 수 있다
    • 센서 값과 if문을 결합하여 로봇이 스스로 반응하는 프로그램을 작성할 수 있다
    • 나의 환경에 맞는 기준값(임계값)을 직접 측정해서 정할 수 있다
