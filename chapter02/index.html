    Chapter 2. 자율주행의 원리: 인지-판단-제어¶

    Part 1: Physical AI의 세계로 | 2차시

    🎯 이 장에서 배우는 것¶

    • 자율주행의 3대 핵심 파이프라인(인지-판단-제어)을 설명할 수 있다
    • 각 파이프라인 단계에서 사용되는 센서와 알고리즘의 역할을 구분할 수 있다
    • 자율주행 레벨(L0~L5)의 차이를 이해하고 현재 기술 수준을 파악할 수 있다
    • 간단한 코드로 인지-판단-제어 파이프라인의 흐름을 시뮬레이션할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분이 학교에서 집까지 자전거를 탈 때를 떠올려 보세요. 앞에서 갑자기 고양이가 뛰어나옵니다. 여러분의 뇌는 이렇게 반응합니다.

    1. 👀 눈으로 본다 — "앗, 고양이다!"
    2. 🧠 판단한다 — "브레이크를 잡고 왼쪽으로 피해야지"
    3. 🤲 손과 발로 실행한다 — 브레이크를 잡고 핸들을 꺾는다

    이 모든 과정이 1초도 안 되는 시간 안에 일어납니다. 자율주행차는 바로 이 과정을 사람 대신 기계가 수행하는 기술입니다. 이 원리를 이해하면, 단순히 "AI가 운전한다"는 막연한 이해를 넘어 어떤 기술이 어떤 역할을 하는지 구체적으로 파악할 수 있습니다. 이것은 Physical AI의 핵심 동작 원리이기도 합니다.

    📚 핵심 개념¶

    개념 1: 인지-판단-제어 파이프라인 🔄¶

    비유로 시작¶

    축구 경기를 생각해 봅시다. 골키퍼가 상대 선수의 슈팅을 막으려면 어떻게 할까요?

    • 인지: 공이 날아오는 방향과 속도를 눈으로 파악한다
    • 판단: "왼쪽 위로 뛰어야 막을 수 있겠다"고 결정한다
    • 제어: 실제로 몸을 날려 공을 막는다

    자율주행차도 정확히 같은 구조입니다. 센서가 눈 역할을, AI가 뇌 역할을, 액추에이터(작동 장치)가 근육 역할을 합니다.

    정확한 정의¶

    인지-판단-제어 파이프라인이란, 자율주행 시스템이 외부 환경 정보를 수집(인지)하고, 수집된 정보를 바탕으로 최적의 행동을 결정(판단)하며, 결정된 행동을 차량에 전달(제어)하는 3단계 순환 처리 구조를 말합니다.

    flowchart LR A["🔍 인지\nPerception"] --> B["🧠 판단\nPlanning"] B --> C["🎮 제어\nControl"] C --> D["🚗 차량 동작"] D --> A style A fill:#4ECDC4,stroke:#333,color:#000 style B fill:#FFE66D,stroke:#333,color:#000 style C fill:#FF6B6B,stroke:#333,color:#000 style D fill:#95E1D3,stroke:#333,color:#000

    예시로 확인¶

    자율주행차가 교차로에서 좌회전하는 상황을 분해해 봅시다.

    • 인지 단계: 카메라가 신호등(녹색 좌회전 화살표)을 인식하고, 라이다가 맞은편 차량의 거리(30m)를 측정하며, 레이더가 옆 차선 차량의 속도(시속 40km)를 감지합니다.
    • 판단 단계: AI가 "신호는 좌회전 허용, 맞은편 차량은 충분히 멀리 있음, 좌회전 경로 안전"이라고 결정합니다.
    • 제어 단계: 핸들을 왼쪽으로 30도 회전, 속도를 시속 15km로 감속, 좌회전 완료 후 핸들 복귀를 실행합니다.

    💡 생각해보기: 만약 좌회전 중에 보행자가 갑자기 횡단보도에 나타난다면? 인지-판단-제어 파이프라인이 수십 밀리초(0.0X초) 안에 다시 순환하며 급정거 명령을 내립니다.

    개념 2: 인지(Perception) — 자율주행차의 눈과 귀 👁️¶

    비유로 시작¶

    여러분이 눈을 감고 방 안을 걸어 다닌다고 상상해 보세요. 무섭죠? 그래서 우리는 눈, 귀, 피부 감각 등 여러 감각을 동시에 사용합니다. 자율주행차도 하나의 센서만으로는 부족합니다. 여러 센서를 함께 사용하는데, 이를 센서 퓨전(Sensor Fusion)이라고 합니다.

    정확한 정의¶

    인지(Perception)란 자율주행차가 주변 환경을 감지하고 이해하는 단계입니다. 다양한 센서로 수집한 데이터를 결합하여 "지금 차량 주변에 무엇이 있는가?"를 파악합니다.

    주요 센서 3총사:

    • 카메라 📷: 색상과 형태를 인식합니다. 신호등 색깔, 차선, 표지판 등을 읽을 수 있습니다. 사람의 눈과 가장 비슷한 센서입니다. 단점은 비나 안개, 야간에 성능이 떨어질 수 있다는 점입니다.
    • 라이다(LiDAR) 💫: Light Detection And Ranging의 약자로, 레이저 빔을 쏘고 반사되어 돌아오는 시간을 측정하여 3D 지도를 만듭니다. 마치 박쥐가 초음파로 주변을 파악하는 것과 비슷합니다. 정밀도가 매우 높지만 가격이 비쌉니다.
    • 레이더(Radar) 📡: 전파를 이용해 물체의 거리와 속도를 측정합니다. 날씨의 영향을 거의 받지 않아 비, 눈, 안개 속에서도 잘 작동합니다. 단점은 형태를 구분하기 어렵다는 것입니다.
    flowchart TB subgraph 센서["🔍 인지 센서들"] CAM["📷 카메라\n색상, 형태 인식\n차선, 신호등, 표지판"] LID["💫 라이다\n3D 거리 측정\n정밀한 공간 지도"] RAD["📡 레이더\n속도·거리 감지\n악천후에도 작동"] end CAM --> FUSION["🔗 센서 퓨전\n데이터 통합 분석"] LID --> FUSION RAD --> FUSION FUSION --> RESULT["✅ 주변 환경 인식 완료\n물체 위치, 종류, 속도 파악"] style FUSION fill:#4ECDC4,stroke:#333,color:#000 style RESULT fill:#95E1D3,stroke:#333,color:#000

    예시로 확인¶

    고속도로에서 앞차와의 거리를 유지하는 상황을 봅시다.

    • 카메라: 앞차의 브레이크 등이 빨간색으로 켜진 것을 감지 → "앞차가 감속 중"
    • 레이더: 앞차와의 거리 50m, 상대 속도 차이 시속 20km 감지 → "빠르게 가까워지고 있음"
    • 라이다: 앞차의 정확한 크기와 위치를 3D로 측정 → "대형 트럭, 내 차선 정중앙"

    이 세 가지 정보를 센서 퓨전으로 합치면: "내 차선 정중앙 50m 앞에 대형 트럭이 있고, 감속 중이며, 우리 차와 빠르게 가까워지고 있다"는 종합적인 상황 인식이 완성됩니다.

    📌 알아보기: 테슬라는 카메라 중심의 인지 시스템을 사용하고, 웨이모(Waymo)는 라이다를 핵심 센서로 사용합니다. 어느 것이 더 좋다고 단정할 수는 없으며, 각각 장단점이 있어 업계에서 활발한 논쟁이 이어지고 있습니다.

    개념 3: 판단(Planning) — 자율주행차의 두뇌 🧠¶

    비유로 시작¶

    네비게이션 앱을 사용할 때를 떠올려 보세요. 앱은 "서울에서 부산까지"라는 큰 경로를 먼저 정하고, "이 교차로에서 우회전"이라는 작은 경로를 안내하며, 앞에 사고가 나면 즉시 경로를 변경합니다. 자율주행의 판단도 이와 같은 3단계 계층 구조로 이루어집니다.

    정확한 정의¶

    판단(Planning)이란 인지 단계에서 파악한 환경 정보를 바탕으로, 차량이 목적지까지 안전하고 효율적으로 이동하기 위한 경로와 행동을 결정하는 단계입니다.

    판단의 3가지 레벨:

    • 경로 계획(Route Planning): 출발지에서 목적지까지의 전체 경로를 결정합니다. "어떤 도로를 타고 갈까?"에 해당합니다.
    • 행동 계획(Behavior Planning): 현재 상황에서 어떤 행동을 할지 결정합니다. "차선을 변경할까? 이 차를 추월할까? 정지할까?"에 해당합니다.
    • 동작 계획(Motion Planning): 결정된 행동을 구체적인 궤적(이동 경로)으로 변환합니다. "핸들을 몇 도 꺾고, 속도를 얼마로 할까?"에 해당합니다.
    flowchart TB A["🗺️ 경로 계획\nRoute Planning"] --> B["🚦 행동 계획\nBehavior Planning"] B --> C["📐 동작 계획\nMotion Planning"] A1["서울 → 부산\n고속도로 경유"] --> A B1["앞차 추월 결정\n차선 변경 필요"] --> B C1["3초간 좌측으로 이동\n속도 80km/h 유지"] --> C style A fill:#FFE66D,stroke:#333,color:#000 style B fill:#FFD93D,stroke:#333,color:#000 style C fill:#FFC107,stroke:#333,color:#000

    예시로 확인¶

    학교 앞 스쿨존(어린이보호구역)을 지나는 상황을 봅시다.

    • 경로 계획: "스쿨존을 포함한 이 경로가 최단 경로다"
    • 행동 계획: "스쿨존이므로 시속 30km 이하로 감속, 보행자 우선, 추월 금지"
    • 동작 계획: "현재 시속 50km → 3초에 걸쳐 시속 30km로 감속, 브레이크 압력 40% 적용"

    💡 생각해보기: 만약 스쿨존에서 공이 갑자기 도로로 굴러 나온다면? AI는 "공 뒤에 아이가 따라올 수 있다"고 예측하여 미리 더 감속하는 판단을 내립니다. 이것이 단순 규칙 기반과 AI 기반 판단의 차이입니다.

    개념 4: 자율주행 레벨(SAE L0~L5) 📊¶

    비유로 시작¶

    수영을 배우는 과정을 생각해 봅시다. 처음에는 코치가 옆에서 잡아주고(L0), 점점 킥보드를 잡고 혼자 발차기를 하고(L1~L2), 코치가 지켜보는 가운데 자유형을 치고(L3), 코치 없이 혼자 수영하고(L4), 마침내 어떤 바다에서든 자유롭게 수영하는(L5) 단계를 거칩니다.

    정확한 정의¶

    SAE 자율주행 레벨은 미국자동차공학회(SAE International)가 정한 자율주행 기술의 6단계 분류 체계(L0~L5)입니다. 숫자가 높을수록 차량이 더 많은 운전 작업을 담당합니다.

    각 레벨 상세 설명:

    • L0 (자동화 없음): 운전자가 모든 것을 합니다. 후방 카메라 경고음 정도만 있습니다.
    • L1 (운전자 보조): 조향 또는 가감속 중 하나만 보조합니다. 예: 크루즈 컨트롤(속도 자동 유지)
    • L2 (부분 자동화): 조향 과 가감속을 동시에 보조합니다. 하지만 운전자가 항상 전방을 주시해야 합니다. 예: 테슬라 오토파일럿, 현대 HDA2
    • L3 (조건부 자동화): 특정 조건(고속도로, 저속 정체 등)에서 차량이 스스로 운전합니다. 운전자는 시스템이 요청할 때만 개입하면 됩니다. 예: 메르세데스-벤츠 드라이브 파일럿(고속도로 정체 시)
    • L4 (고도 자동화): 정해진 영역(지오펜싱 구역) 안에서 사람 개입 없이 완전 자율주행합니다. 예: 웨이모 택시(미국 피닉스, 샌프란시스코 일부 지역)
    • L5 (완전 자동화): 어떤 도로, 어떤 날씨, 어떤 상황에서든 사람 없이 운전합니다. 아직 실현되지 않았습니다.

    예시로 확인 — 실제 차량 사례¶

    • 테슬라 오토파일럿: L2 수준입니다. 고속도로에서 차선 유지와 앞차 따라가기를 동시에 하지만, 운전자가 항상 핸들을 잡고 있어야 합니다.
    • 웨이모 원(Waymo One): L4 수준입니다. 미국 일부 도시에서 운전석에 아무도 없이 승객을 태우고 운행합니다. 다만 허가된 지역에서만 운행 가능합니다.

    📌 알아보기: 2024년 기준, 대부분의 상용 자율주행차는 L2~L3 수준입니다. L5 완전 자율주행은 기술적으로도, 법·제도적으로도 아직 갈 길이 멀다는 것이 전문가들의 의견입니다.

    🔨 따라하기: 인지-판단-제어 시뮬레이션¶

    간단한 Python 코드로 자율주행의 인지-판단-제어 파이프라인을 체험해 봅시다. 실제 자율주행은 훨씬 복잡하지만, 핵심 구조가 동일하다는 것을 이해하는 것이 목표입니다.

    Step 1: 환경 설정¶

    Python이 설치된 환경이면 어디서든 실행할 수 있습니다. 특별한 라이브러리는 필요하지 않습니다.

    # 자율주행 인지-판단-제어 파이프라인 시뮬레이션
# 필요한 라이브러리: 없음 (기본 Python만 사용)
import random

    Step 2: 인지(Perception) 단계 구현¶

    센서가 주변 환경 정보를 수집하는 과정을 시뮬레이션합니다.

    def perceive(environment):
    """인지 단계: 센서로 환경을 감지한다"""
    perception = {
        "앞차_거리": environment["앞차_거리"],       # 라이다가 측정
        "앞차_속도": environment["앞차_속도"],       # 레이더가 측정
        "신호등": environment["신호등"],             # 카메라가 인식
        "보행자_발견": environment["보행자_발견"],   # 카메라 + 라이다
    }
    print(f"[인지] 앞차 거리: {perception['앞차_거리']}m, "
          f"앞차 속도: {perception['앞차_속도']}km/h, "
          f"신호등: {perception['신호등']}, "
          f"보행자: {'있음' if perception['보행자_발견'] else '없음'}")
    return perception

    Step 3: 판단(Planning) 단계 구현¶

    인지 결과를 바탕으로 어떤 행동을 할지 결정합니다.

    def plan(perception, my_speed):
    """판단 단계: 인지 결과를 바탕으로 행동을 결정한다"""
    decision = {"행동": "유지", "목표_속도": my_speed}

    # 규칙 1: 보행자가 있으면 무조건 정지
    if perception["보행자_발견"]:
        decision["행동"] = "긴급정지"
        decision["목표_속도"] = 0
    # 규칙 2: 빨간 신호면 정지
    elif perception["신호등"] == "빨강":
        decision["행동"] = "정지"
        decision["목표_속도"] = 0
    # 규칙 3: 앞차가 너무 가까우면 감속
    elif perception["앞차_거리"] < 20:
        decision["행동"] = "감속"
        decision["목표_속도"] = max(0, perception["앞차_속도"] - 10)
    # 규칙 4: 앞차가 적당히 있으면 속도 맞추기
    elif perception["앞차_거리"] < 50:
        decision["행동"] = "속도조절"
        decision["목표_속도"] = perception["앞차_속도"]
    # 규칙 5: 앞이 비어있고 초록 신호면 정상 주행
    else:
        decision["행동"] = "유지"
        decision["목표_속도"] = 60  # 제한속도

    print(f"[판단] 행동: {decision['행동']}, 목표 속도: {decision['목표_속도']}km/h")
    return decision

    Step 4: 제어(Control) 단계 구현¶

    판단 결과를 실제 차량 명령으로 변환합니다.

    def control(decision, current_speed):
    """제어 단계: 판단 결과를 차량 명령으로 변환한다"""
    target = decision["목표_속도"]

    if target < current_speed:
        brake = min(100, (current_speed - target) * 3)  # 브레이크 강도
        new_speed = max(0, current_speed - 15)  # 한 단계에 15km/h씩 감속
        print(f"[제어] 🛑 브레이크 {brake:.0f}% → 속도 {current_speed} → {new_speed}km/h")
    elif target > current_speed:
        throttle = min(100, (target - current_speed) * 2)  # 가속 강도
        new_speed = min(target, current_speed + 10)  # 한 단계에 10km/h씩 가속
        print(f"[제어] 🟢 가속 {throttle:.0f}% → 속도 {current_speed} → {new_speed}km/h")
    else:
        new_speed = current_speed
        print(f"[제어] ➡️ 속도 유지 {new_speed}km/h")

    return new_speed

    Step 5: 전체 파이프라인 실행¶

    여러 시나리오를 만들어 파이프라인이 어떻게 동작하는지 확인합니다.

    def run_simulation():
    """자율주행 시뮬레이션 실행"""

    # 다양한 주행 시나리오
    scenarios = [
        {"이름": "🛣️ 고속도로 정상 주행",
         "앞차_거리": 80, "앞차_속도": 60, "신호등": "없음", "보행자_발견": False},
        {"이름": "🚦 교차로 빨간불",
         "앞차_거리": 30, "앞차_속도": 0, "신호등": "빨강", "보행자_발견": False},
        {"이름": "🚶 스쿨존 보행자 발견",
         "앞차_거리": 50, "앞차_속도": 30, "신호등": "초록", "보행자_발견": True},
        {"이름": "🚗 앞차 급접근",
         "앞차_거리": 10, "앞차_속도": 20, "신호등": "없음", "보행자_발견": False},
    ]

    my_speed = 60  # 초기 속도 60km/h

    for scenario in scenarios:
        print(f"\n{'='*50}")
        print(f"📍 시나리오: {scenario['이름']}")
        print(f"   현재 내 속도: {my_speed}km/h")
        print(f"{'='*50}")

        # 파이프라인 실행: 인지 → 판단 → 제어
        perception = perceive(scenario)
        decision = plan(perception, my_speed)
        my_speed = control(decision, my_speed)

        print(f"결과: 현재 속도 = {my_speed}km/h")

# 실행!
run_simulation()
