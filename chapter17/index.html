    하이퍼파라미터 실험 – 학습률, 할인율, 탐험률 조정하기¶

    🎯 이 장에서 배우는 것¶

    • 학습률(α)을 변경했을 때 학습 속도와 안정성의 변화를 관찰하고 설명할 수 있다
    • 할인율(γ)의 크기에 따라 에이전트가 단기 보상과 장기 보상 중 무엇을 중시하는지 분석할 수 있다
    • 탐험률(ε)과 감소 전략을 조정하며 최적의 조합을 탐색할 수 있다
    • 여러 실험 결과를 그래프로 비교하고 최적의 하이퍼파라미터 조합을 선택할 수 있다

    💡 왜 이걸 배우나요?¶

    지난 챕터까지 우리는 Q-러닝 에이전트가 트랙을 달리는 모습을 확인했습니다. 그런데 혹시 이런 의문이 들지 않았나요?

    "학습률을 0.1 대신 0.5로 하면 더 빨리 배울까?" "할인율을 낮추면 어떻게 될까?"

    강화학습에서 하이퍼파라미터는 요리의 불 세기와 양념 비율 같은 존재입니다. 🍳 같은 재료(알고리즘)를 쓰더라도 불이 너무 세면 타버리고, 약하면 설익죠. 양념 비율이 맞지 않으면 맛이 엉망이 됩니다.

    이번 장에서는 시뮬레이션의 최대 장점인 "실패해도 비용이 0원" 이라는 특성을 살려, 다양한 조합을 직접 실험합니다. 과학자처럼 한 번에 하나씩 변수를 바꾸고, 결과를 기록하고, 비교 분석하는 과정을 경험해 보세요. 이 능력은 어떤 강화학습 프로젝트에서든 핵심 역량이 됩니다. 💪

    📚 핵심 개념¶

    개념 1: 학습률(α) – 새 경험을 얼마나 믿을 것인가¶

    비유로 시작 🎓

    시험공부를 하는데, 친구가 "이 문제 답은 3번이야!"라고 말합니다.

    • α = 0.9 (높은 학습률): "오케이! 3번으로 바꿀게!" → 새 정보를 거의 그대로 수용
    • α = 0.1 (낮은 학습률): "음… 내 기존 답도 있으니까 살짝만 참고할게" → 기존 지식을 대부분 유지

    정확한 정의

    Q-값 업데이트 공식에서 α는 새로운 추정값을 얼마나 반영할지 결정합니다.

    Q(s,a) ← Q(s,a) + α × [새로운 정보 - 기존 Q(s,a)]
    • α가 크면: 빠르게 배우지만, 값이 크게 흔들려서 불안정
    • α가 작으면: 천천히 배우지만, 값이 부드럽게 수렴하여 안정적

    예시로 확인

    • α = 0.9 → 초반 10회 만에 좋은 경로 발견, 하지만 이후에도 값이 계속 흔들림
    • α = 0.1 → 100회가 지나서야 경로 발견, 하지만 한번 안정되면 견고하게 유지

    개념 2: 할인율(γ) – 미래를 얼마나 중시할 것인가¶

    비유로 시작 🍰

    • γ = 0.99: "1년 뒤에 케이크 100개를 받을 수 있다면 기꺼이 기다리겠어!" → 장기 보상 중시
    • γ = 0.1: "지금 당장 사탕 1개가 더 좋아!" → 단기 보상 중시

    정확한 정의

    γ(감마)는 미래 보상의 현재 가치를 결정하는 비율입니다. 0과 1 사이의 값입니다.

    미래 보상의 가치 = γ⁰×r₀ + γ¹×r₁ + γ²×r₂ + ...
    • γ → 1: 먼 미래의 보상도 거의 같은 가치 → 장기적 전략을 세움
    • γ → 0: 바로 다음 보상만 중요 → 근시안적으로 행동

    예시로 확인

    트랙 주행에서 γ가 낮은 에이전트는 "당장 앞으로 가기"만 반복하여 커브에서 충돌합니다. γ가 높은 에이전트는 "커브 전에 미리 감속하면 나중에 더 빠르다"는 것을 학습합니다.

    개념 3: 탐험률(ε)과 감소 전략 – 탐험과 활용의 균형¶

    비유로 시작 🗺️

    새 도시에 여행 왔습니다.

    • 첫째 날(ε = 1.0): 아는 맛집이 없으니 아무 데나 들어가 봅니다 → 탐험
    • 마지막 날(ε = 0.05): 이미 맛집을 찾았으니 거기만 갑니다 → 활용
    • 감소 속도: 며칠 만에 탐험을 줄일지가 핵심!

    정확한 정의

    • ε(엡실론): 무작위 행동을 선택할 확률
    • ε-decay(감소 전략): 에피소드가 진행될수록 ε을 줄여나가는 방법

    대표적인 감소 방식:

    • 선형 감소: 매 에피소드마다 일정량 감소 → ε = ε - decay_amount
    • 지수 감소: 매 에피소드마다 일정 비율 감소 → ε = ε × decay_rate

    예시로 확인

    • 감소가 너무 빠르면(ε이 금방 0): 초반에 발견한 "그럭저럭 괜찮은 경로"에 갇힘
    • 감소가 너무 느리면(ε이 오래 높음): 이미 좋은 경로를 알면서도 계속 엉뚱한 곳을 탐험

    개념 4: 과학적 실험 설계 – 변수 하나씩만 바꾸기¶

    비유로 시작 🔬

    라면을 끓이는데 물 양도 바꾸고, 스프 양도 바꾸고, 면 삶는 시간도 바꾸면 뭐 때문에 맛이 변했는지 알 수 없습니다. 한 번에 하나만 바꿔야 원인을 파악할 수 있죠!

    실험 설계 원칙

    • 통제 변수: 실험에서 고정하는 값들
    • 독립 변수: 의도적으로 바꾸는 값 (한 번에 하나만!)
    • 종속 변수: 관찰하는 결과 (총 보상, 수렴 에피소드 수 등)
    flowchart LR A["독립 변수<br/>예: α 변경"] --> B["실험 실행<br/>에이전트 학습"] B --> C["종속 변수 관찰<br/>학습 곡선, 총 보상"] D["통제 변수<br/>γ, ε 고정"] --> B

    이제 이 원칙을 코드로 실천해 봅시다! 🚀

    🔨 따라하기¶

    Step 1: 실험 환경 준비하기¶

    먼저 그리드 트랙 환경과 Q-러닝 에이전트를 하나의 파일에 준비합니다. 이전 챕터에서 만든 환경을 간결하게 정리한 버전입니다.

    import numpy as np
import matplotlib.pyplot as plt
from collections import defaultdict

# --- 간단한 그리드 트랙 환경 ---
class SimpleTrack:
    def __init__(self, rows=5, cols=8):
        self.rows = rows
        self.cols = cols
        self.start = (4, 0)    # 좌하단 출발
        self.goal = (0, 7)     # 우상단 도착
        self.walls = [(2, 3), (2, 4), (3, 3)]  # 장애물

    def reset(self):
        self.pos = self.start
        return self.pos

    def step(self, action):
        # 행동: 0=위, 1=오른쪽, 2=아래, 3=왼쪽
        moves = [(-1, 0), (0, 1), (1, 0), (0, -1)]
        dr, dc = moves[action]
        new_r = max(0, min(self.rows - 1, self.pos[0] + dr))
        new_c = max(0, min(self.cols - 1, self.pos[1] + dc))
        new_pos = (new_r, new_c)

        if new_pos in self.walls:
            new_pos = self.pos  # 벽이면 제자리

        self.pos = new_pos

        if self.pos == self.goal:
            return self.pos, 100, True   # 도착 보상
        else:
            return self.pos, -1, False   # 매 스텝 패널티

# --- Q-러닝 에이전트 ---
class QLearningAgent:
    def __init__(self, alpha=0.1, gamma=0.99, epsilon=1.0,
                 epsilon_min=0.01, epsilon_decay=0.995):
        self.alpha = alpha
        self.gamma = gamma
        self.epsilon = epsilon
        self.epsilon_min = epsilon_min
        self.epsilon_decay = epsilon_decay
        self.q_table = defaultdict(lambda: np.zeros(4))

    def choose_action(self, state):
        if np.random.random() < self.epsilon:
            return np.random.randint(4)
        return np.argmax(self.q_table[state])

    def learn(self, state, action, reward, next_state, done):
        best_next = np.max(self.q_table[next_state]) if not done else 0
        td_target = reward + self.gamma * best_next
        td_error = td_target - self.q_table[state][action]
        self.q_table[state][action] += self.alpha * td_error

    def decay_epsilon(self):
        self.epsilon = max(self.epsilon_min,
                          self.epsilon * self.epsilon_decay)

print("✅ 환경과 에이전트 준비 완료!")

    Step 2: 실험 실행 함수 만들기¶

    여러 조합을 반복 실험할 수 있도록, 학습 → 결과 반환을 하나의 함수로 만듭니다.

    def run_experiment(alpha=0.1, gamma=0.99, epsilon=1.0,
                   epsilon_decay=0.995, episodes=500, max_steps=200):
    """하이퍼파라미터를 받아 학습을 실행하고 에피소드별 보상을 반환"""
    env = SimpleTrack()
    agent = QLearningAgent(alpha=alpha, gamma=gamma,
                           epsilon=epsilon, epsilon_decay=epsilon_decay)

    rewards_per_episode = []

    for ep in range(episodes):
        state = env.reset()
        total_reward = 0

        for step in range(max_steps):
            action = agent.choose_action(state)
            next_state, reward, done = env.step(action)
            agent.learn(state, action, reward, next_state, done)
            state = next_state
            total_reward += reward

            if done:
                break

        rewards_per_episode.append(total_reward)
        agent.decay_epsilon()

    return rewards_per_episode

print("✅ 실험 함수 준비 완료!")

    핵심 포인트: 이 함수 하나로 어떤 조합이든 실험할 수 있습니다. 하이퍼파라미터만 바꿔서 호출하면 됩니다!

    Step 3: 실험 1 – 학습률(α) 비교¶

    α만 바꾸고 나머지는 모두 고정합니다 (γ=0.99, ε-decay=0.995).

    # 실험 1: 학습률 비교
alphas = [0.1, 0.5, 0.9]
results_alpha = {}

for a in alphas:
    print(f"🔄 α={a} 실험 중...")
    rewards = run_experiment(alpha=a, gamma=0.99, epsilon_decay=0.995)
    results_alpha[a] = rewards

# 학습 곡선 시각화 (이동 평균으로 부드럽게)
plt.figure(figsize=(10, 5))
for a, rewards in results_alpha.items():
    # 20 에피소드 이동 평균
    smoothed = np.convolve(rewards, np.ones(20)/20, mode='valid')
    plt.plot(smoothed, label=f'α={a}')

plt.xlabel('Episode')
plt.ylabel('Total Reward (20-ep Moving Avg)')
plt.title('📊 실험 1: 학습률(α)에 따른 학습 곡선')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('experiment1_alpha.png', dpi=100)
plt.show()

# 마지막 50 에피소드 평균 보상 비교
print("\n📋 결과 요약 (마지막 50 에피소드 평균 보상):")
for a, rewards in results_alpha.items():
    avg = np.mean(rewards[-50:])
    print(f"  α={a}: 평균 보상 = {avg:.1f}")

    관찰 포인트 👀

    • α=0.9는 초반에 빠르게 올라가지만, 곡선이 울퉁불퉁 합니까?
    • α=0.1은 천천히 올라가지만, 후반부에 더 안정적입니까?
    • α=0.5는 두 가지의 중간쯤에 위치합니까?

    Step 4: 실험 2 – 할인율(γ) 비교¶

gammas = [0.1, 0.5, 0.99]
results_gamma = {}

for g in gammas:

    📝 전체 코드¶

    아래는 위의 모든 실험을 하나의 파일로 정리한 전체 코드입니다.

    ```python """ Chapter 17: 하이퍼파라미터 실험 - 학습률(α), 할인율(γ), 탐험률 감소(ε-decay) 비교 """ import numpy as np import matplotlib.pyplot as plt from collections import defaultdict

    ===== 환경 =====¶

    class SimpleTrack: def init(self, rows=5, cols=8): self.rows, self.cols = rows, cols self.start, self.goal = (4, 0), (0, 7) self.walls = [(2, 3), (2, 4), (3, 3)]

    def reset(self):
    self.pos = self.start
    return self.pos

def step(self, action):
    moves = [(-1,0),(0,1),(1,0),(0,-1)]
    dr, dc = moves[action]
    nr = max(0, min(self.rows-1, self.pos[0]+dr))
    nc = max(0, min(self.cols-1, self.pos[1]+dc))
    new_pos = (nr, nc)
    if new_pos in self.walls:
        new_pos = self.pos
    self.pos = new_pos
    if self.pos == self.goal:
        return self.pos, 100, True
    return self.pos, -1, False

    ===== 에이전트 =====¶

    class QLearningAgent: def init(self, alpha=0.1, gamma=0.99, epsilon=1.0, epsilon_min=0.01, epsilon_decay=0.995): self.alpha, self.gamma = alpha, gamma self.epsilon = epsilon self.epsilon_min, self.epsilon_decay = epsilon_min, epsilon_decay self.q_table = defaultdict(lambda: np.zeros(4))

    def choose_action(self, state):
    if np.random.random() < self.epsilon:
        return np.random.randint(4)
    return np.argmax(self.q_table[state])

def learn(self, s, a, r, s2, done):
    best_next = np.max(self.q_table[s2]) if not done else 0
    td_target = r + self.gamma * best_next
    self.q_table[s][a] += self.alpha * (td_target - self.q_table[s][a])

def decay_epsilon(self):
    self.epsilon = max(self.epsilon_min,
                      self.epsilon * self.epsilon_decay)

    ===== 실험 실행 함수 =====¶

    def run_experiment(alpha=0.1, gamma=0.99, epsilon=1.0, epsilon_decay=0.995, episodes=500, max_steps=200): env = SimpleTrack() agent = QLearningAgent(alpha=alpha, gamma=gamma, epsilon=epsilon, epsilon_decay=epsilon_decay) rewards = [] for _ in range(episodes): state, total = env.reset(), 0 for _ in range(max_steps): action = agent.choose_action(state) next_state, reward, done = env.step(action) agent.learn(state, action, reward, next_state, done) state, total = next_state, total + reward if done: break rewards.append(total) agent.decay_epsilon() return rewards
