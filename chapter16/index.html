    Chapter 16: 장애물 감지와 비상 정지¶

    Part 5: [2권] 시뮬레이션 고급 기능과 안전 주행

    🎯 이 장에서 배우는 것¶

    • 초음파·라이다 센서의 원리를 이해하고, CARLA에서 센서를 부착하여 데이터를 수집할 수 있다
    • 전방 장애물까지의 거리를 계산하는 감지 로직을 구현할 수 있다
    • 거리 임계값에 따라 감속→정지하는 비상 정지(Emergency Brake) 시스템을 작성할 수 있다
    • 자율주행 안전의 윤리적 측면을 이해하고 자신의 의견을 표현할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔: 자율주행 차가 달리고 있는데, 갑자기 어린아이의 공이 도로 위로 굴러옵니다. 0.5초 뒤에 아이가 공을 쫓아 뛰어나올 수도 있습니다. 이 차는 어떻게 해야 할까요?

    사람 운전자는 "위험하다!"는 직감으로 브레이크를 밟습니다. 하지만 자율주행 차에는 직감이 없습니다. 대신 센서 데이터를 분석해서 "장애물이 있다"는 사실을 인식하고, 프로그램된 규칙에 따라 감속하거나 정지해야 합니다.

    이 과정이 바로 장애물 감지(Obstacle Detection) 와 비상 정지(Emergency Stop) 입니다. 자율주행 기술에서 가장 중요한 기능이며, 이것이 실패하면 생명이 위험해집니다. 오늘은 CARLA 시뮬레이터에서 이 시스템을 직접 만들어 보겠습니다.

    📚 핵심 개념¶

    개념 1: 초음파 센서 — 가까운 곳의 눈 👀¶

    1. 비유로 시작

    박쥐가 어둠 속에서 날아다닐 수 있는 비결을 아시나요? 박쥐는 초음파를 발사하고, 물체에 반사되어 돌아오는 시간을 측정해서 거리를 파악합니다. 초음파 센서도 정확히 같은 원리입니다.

    2. 정확한 정의

    초음파 센서(Ultrasonic Sensor) 는 사람이 들을 수 없는 높은 주파수의 음파를 발사하여, 물체에 부딪혀 돌아오는 시간(Time of Flight)으로 거리를 측정하는 장치입니다.

    3. 주요 특성

    • 측정 범위: 보통 0.2m ~ 5m (가까운 거리 전문)
    • 장점: 가격이 저렴하고, 날씨에 비교적 강함
    • 단점: 측정 범위가 짧고, 정밀도가 떨어짐
    • 실차 활용: 주차 보조 시스템의 "삐삐삐" 소리가 바로 초음파 센서!
    graph LR A["🔊 초음파 발사"] --> B["🧱 장애물에 반사"] B --> C["🎤 반사파 수신"] C --> D["⏱️ 왕복 시간 측정"] D --> E["📏 거리 = 속도 × 시간 / 2"]

    알아보기 📖: 왜 "÷ 2"를 하나요? 음파가 장애물까지 갔다가 돌아오는 왕복 거리이기 때문에, 실제 거리는 절반입니다.

    개념 2: 라이다 센서 — 먼 곳까지 보는 레이저 눈 🔴¶

    1. 비유로 시작

    손전등을 켜서 벽에 빛을 비추면, 빛이 닿는 점을 볼 수 있죠? 이제 이 손전등이 초고속으로 회전하면서 주변 360도를 비춘다고 상상해보세요. 그 점들을 모두 모으면 주변 환경의 3D 지도가 만들어집니다. 이것이 라이다입니다.

    2. 정확한 정의

    라이다(LiDAR, Light Detection And Ranging) 는 레이저 펄스를 발사하고 반사되어 돌아오는 시간을 측정하여, 주변 물체까지의 거리를 3차원 점 구름(Point Cloud) 형태로 측정하는 센서입니다.

    3. 주요 특성

    • 측정 범위: 최대 100m 이상 (먼 거리까지 측정 가능)
    • 장점: 높은 정밀도, 3D 공간 인식 가능
    • 단점: 가격이 비싸고, 비·안개에 성능 저하
    • 데이터 형태: 수천~수십만 개의 (x, y, z, intensity) 포인트
    graph TD subgraph 라이다 작동 원리 L["🔴 레이저 펄스 발사<br/>(초당 수십만 회)"] --> R["회전하며 360° 스캔"] R --> P["반사 포인트 수집"] P --> C["포인트 클라우드 생성<br/>(3D 점 구름)"] end

    알아보기 📖: CARLA에서 라이다 데이터는 numpy 배열로 제공됩니다. 각 포인트는 [x, y, z, intensity] 4개 값을 가집니다. x는 전방, y는 좌우, z는 높이 방향입니다.

    개념 3: 거리 기반 안전 제어 — 가까워지면 멈춰라 🛑¶

    1. 비유로 시작

    여러분이 복도를 걸어가는데, 앞에 사람이 보입니다. 멀리 있으면 그냥 걷고, 가까워지면 속도를 줄이고, 아주 가까우면 멈추겠죠? 자율주행 차도 같은 원리입니다. 다만 거리를 숫자로 정확히 계산하고, 규칙에 따라 반응합니다.

    2. 정확한 정의

    거리 기반 안전 제어란, 센서로 측정한 장애물까지의 거리를 미리 정해둔 임계값(threshold) 과 비교하여, 차량의 속도를 자동으로 조절하는 제어 방식입니다.

    3. 3단계 제어 로직

    graph TD S["센서로 거리 측정"] --> D{"거리 판단"} D -->|"거리 > 15m<br/>안전 구간"| G["🟢 정상 주행<br/>throttle = 0.5"] D -->|"5m < 거리 ≤ 15m<br/>경고 구간"| Y["🟡 감속<br/>throttle = 0.2"] D -->|"거리 ≤ 5m<br/>위험 구간"| R["🔴 비상 정지<br/>brake = 1.0"]
    • 안전 구간 (> 15m): 장애물이 충분히 멀어 정상 속도로 주행
    • 경고 구간 (5m ~ 15m): 장애물 접근 중, 서서히 감속
    • 위험 구간 (≤ 5m): 즉시 브레이크, 차량 정지

    개념 4: 자율주행 안전 윤리 — 기술의 사회적 책임 ⚖️¶

    1. 비유로 시작

    유명한 사고 실험이 있습니다. 트롤리 딜레마(Trolley Problem): 브레이크가 고장난 전차가 달려옵니다. 직진하면 5명이 다치고, 방향을 틀면 1명이 다칩니다. 여러분이라면 어떻게 하시겠습니까? 이 질문이 자율주행 차에도 적용됩니다.

    2. 왜 중요한가

    자율주행 차의 비상 정지 시스템은 단순히 "멈추면 끝"이 아닙니다. 현실에서는 다양한 상황이 발생합니다.

    • 장애물을 피하면 옆 차선의 다른 차와 부딪힐 수 있다
    • 급정거하면 뒤따라오는 차가 추돌할 수 있다
    • 보행자와 탑승자 중 누구의 안전을 우선해야 하는가

    3. 핵심 원칙

    자율주행 개발에서 국제적으로 합의된 원칙은 다음과 같습니다.

    • 안전 최우선(Safety First): 모든 기능보다 안전이 우선
    • 예측 가능한 행동: 차량의 반응이 일관되고 예측 가능해야 함
    • 투명성: 왜 그런 결정을 했는지 설명 가능해야 함

    생각해보기 🤔: 자율주행 차가 "급정거 vs 핸들 꺾기"를 선택해야 한다면, 프로그래머가 미리 어떤 규칙을 정해야 할까요? 여러분이 프로그래머라면 어떤 기준을 세우겠습니까?

    🔨 따라하기¶

    준비 사항¶

    이 실습은 CARLA 시뮬레이터(0.9.13 이상)가 실행 중인 상태에서 진행합니다. 이전 챕터에서 설치한 환경을 그대로 사용합니다.

    Step 1: CARLA에 차량 생성하고 초음파 센서 부착하기¶

    먼저 차량을 하나 만들고, 차량 전방에 초음파 센서를 부착합니다.

    import carla
import time
import math
import numpy as np

# ── 1. CARLA 서버 연결 ──
client = carla.Client('localhost', 2000)
client.set_timeout(10.0)
world = client.get_world()

# ── 2. 차량 스폰 ──
blueprint_library = world.get_blueprint_library()
vehicle_bp = blueprint_library.filter('vehicle.tesla.model3')[0]
spawn_points = world.get_map().get_spawn_points()
spawn_point = spawn_points[0]
vehicle = world.spawn_actor(vehicle_bp, spawn_point)
print(f"차량 생성 완료: {vehicle.type_id}")

# ── 3. 초음파 센서(Radar 센서로 대체) 부착 ──
# CARLA에서는 Radar 센서를 초음파 센서처럼 근거리 감지에 활용합니다
radar_bp = blueprint_library.find('sensor.other.radar')
radar_bp.set_attribute('horizontal_fov', '30')    # 수평 시야각 30도
radar_bp.set_attribute('vertical_fov', '10')      # 수직 시야각 10도
radar_bp.set_attribute('range', '20')             # 최대 감지 거리 20m
radar_bp.set_attribute('sensor_tick', '0.1')      # 0.1초마다 측정

# 차량 전방 범퍼 위치에 부착
radar_transform = carla.Transform(carla.Location(x=2.5, z=0.7))
radar_sensor = world.spawn_actor(radar_bp, radar_transform, attach_to=vehicle)
print("레이더(초음파 대용) 센서 부착 완료")

    알아보기 📖: CARLA에서 sensor.other.radar는 레이더 센서입니다. 초음파 센서와 비슷하게 전방 물체의 거리와 속도를 측정할 수 있어서, 근거리 장애물 감지 용도로 활용합니다. x=2.5는 차량 중심에서 전방 2.5m 위치, 즉 범퍼 근처를 의미합니다.

    Step 2: 센서 데이터 수신 콜백 작성하기¶

    센서가 데이터를 보내면 자동으로 호출되는 콜백 함수(callback function) 를 만듭니다.

    # ── 전역 변수: 감지된 최소 거리를 저장 ──
detected_min_distance = float('inf')  # 초기값: 무한대 (장애물 없음)

def radar_callback(radar_data):
    """레이더 센서 콜백: 감지된 포인트 중 가장 가까운 거리를 저장"""
    global detected_min_distance

    if len(radar_data) == 0:
        detected_min_distance = float('inf')
        return

    min_dist = float('inf')
    for detection in radar_data:
        # detection.depth = 장애물까지의 거리(m)
        # detection.azimuth = 수평 각도(rad)
        # detection.altitude = 수직 각도(rad)
        # detection.velocity = 상대 속도(m/s)

        if detection.depth < min_dist:
            min_dist = detection.depth

    detected_min_distance = min_dist

# 콜백 등록
radar_sensor.listen(radar_callback)
print("센서 데이터 수신 시작")

    알아보기 📖: float('inf')는 파이썬에서 "무한대"를 나타내는 특별한 값입니다. 장애물이 감지되지 않았을 때, "거리가 무한히 멀다"는 의미로 사용합니다. 어떤 실수와 비교해도 inf가 항상 더 크므로, 최솟값 찾기에서 초기값으로 매우 유용합니다.

    Step 3: 라이다 센서 추가 부착하기¶

    더 정밀한 장애물 감지를 위해 라이다 센서도 함께 부착합니다.

    # ── 라이다 센서 부착 ──
lidar_bp = blueprint_library.find('sensor.lidar.ray_cast')
lidar_bp.set_attribute('channels', '16')           # 16개 레이저 채널
lidar_bp.set_attribute('points_per_second', '100000')  # 초당 10만 포인트
lidar_bp.set_attribute('range', '30')              # 최대 30m

# ── 라이다 콜백: 전방 장애물 거리 계산 ──
lidar_min_distance = float('inf')

def lidar_callback(point_cloud):
    """라이다 포인트 클라우드에서 전방 장애물 최소 거리를 계산"""
    global lidar_min_distance

    # 포인트 클라우드를 numpy 배열로 변환
    data = np.frombuffer(point_cloud.raw_data, dtype=np.float32)
    data = data.reshape((-1, 4))  # [x, y, z, intensity]

    # 전방 필터링: x > 0 (전방), |y| < 1.5 (차량 폭 내), z > -1.5 (지면 제외)
    forward_mask = (data[:, 0] > 0) & \
                   (np.abs(data[:, 1]) < 1.5) & \
                   (data[:, 2] > -1.5)

    forward_points = data[forward_mask]

    if len(forward_points) == 0:
        lidar_min_distance = float('inf')
        return

    # 각 포인트까지의 거리 계산 (유클리드 거리)
    distances = np.sqrt(forward_points[:, 0]**2 + forward_points[:, 1]**2)
    lidar_min_distance = float(np.min(distances))

lidar_sensor.listen(lidar_callback)
print("라이다 데이터 수신 시작")

    이 코드에서 핵심은 전방 필터링입니다. 라이다는 360도 전체를 스캔하므로, 우리가 필요한 전방 영역만 골라내야 합니다.

    Step 4: 비상 정지 제어 시스템 구현하기¶

    이제 가장 중요한 부분입니다. 센서 데이터를 바탕으로 차량을 제어하는 비상 정지 시스템을 만듭니다.

    def get_obstacle_distance():
    """레이더와 라이다 중 더 가까운 거리를 반환 (센서 융합)"""
    return min(detected_min_distance, lidar_min_distance)

def calculate_control(distance):
    """
    거리에 따른 차량 제어값 계산

    반환값: (throttle, brake, 상태_문자열)
    - throttle: 가속 페달 (0.0 ~ 1.0)
    - brake: 브레이크 페달 (0.0 ~ 1.0)
    """
    DANGER_DIST = 5.0     # 위험 구간: 5m 이내
    WARNING_DIST = 15.0   # 경고 구간: 15m 이내

    if distance <= DANGER_DIST:
        # 🔴 위험! 비상 정지
        return 0.0, 1.0, "🔴 비상 정지 (EMERGENCY STOP)"

    elif distance <= WARNING_DIST:
        # 🟡 경고! 감속
        # 거리에 비례하여 부드럽게 감속
        brake_strength = 1.0 - (distance - DANGER_DIST) / (WARNING_DIST - DANGER_DIST)
        throttle = 0.2 * (distance - DANGER_DIST) / (WARNING_DIST - DANGER_DIST)
        return throttle, brake_strength * 0.5, "🟡 감속 중 (SLOWING DOWN)"

    else:
        # 🟢 안전! 정상 주행
        return 0.5, 0.0, "🟢 정상 주행 (NORMAL)"

print("비상 정지 제어 시스템 준비 완료")

    알아보기 📖: min(detected_min_distance, lidar_min_distance) — 두 센서 중 더 가까운 거리를 채택합니다. 이것을 센서 융합(Sensor Fusion) 의 가장 단순한 형태라고 합니다. "더 위험한 쪽"을 기준으로 판단하는 보수적 접근이죠. 안전 시스템에서는 이런 보수적 판단이 매우 중요합니다.

    Step 6: 메인 제어 루프 실행하기¶

    모든 요소를 연결하여, 실시간으로 장애물을 감지하고 차량을 제어하는 루프를 실행합니다.

    def main_loop(duration=30):
    """
    메인 제어 루프
    duration: 실행 시간(초)
    """
    print("\n" + "="*50)
    print("🚗 비상 정지 시스템 가동!")
    print("="*50 + "\n")

    start_time = time.time()

    try:
        while time.time() - start_time < duration:
            # 1. 장애물 거리 측정
            distance = get_obstacle_distance()

            # 2. 제어값 계산
            throttle, brake, status = calculate_control(distance)

            # 3. 차량에 제어 명령 전달
            control = carla.VehicleControl()
            control.throttle = throttle
            control.brake = brake
            control.steer = 0.0  # 직진
            vehicle.apply_control(control)

            # 4. 현재 속도 확인
            velocity = vehicle.get_velocity()
            speed_kmh = 3.6 * math.sqrt(
                velocity.x**2 + velocity.y**2 + velocity.z**2
            )

            # 5. 상태 출력
            if distance == float('inf'):
                dist_str = "감지 없음"
            else:
                dist_str = f"{distance:.1f}m"

            print(f"거리: {dist_str:>8s} | "
                  f"속도: {speed_kmh:5.1f} km/h | "
                  f"가속: {throttle:.2f} | "
                  f"브레이크: {brake:.2f} | "
                  f"{status}")

            time.sleep(0.1)

    except KeyboardInterrupt:
        print("\n사용자가 중단했습니다.")

    finally:
        # 차량 정지
        vehicle.apply_control(carla.VehicleControl(brake=1.0))
        print("\n차량 정지 완료")

# 실행!
main_loop(duration=30)
