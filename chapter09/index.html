    강화학습이란 무엇인가 – 에이전트, 환경, 보상¶

    Part 3 | [2권] 강화학습의 세계로 – 핵심 개념 이해하기

    🎯 이 장에서 배우는 것¶

    • 강화학습의 정의를 자신의 말로 설명할 수 있다
    • 지도학습·비지도학습·강화학습의 차이를 구분할 수 있다
    • 에이전트, 환경, 상태, 행동, 보상 다섯 가지 핵심 용어를 정확히 정의할 수 있다
    • 햄스터 로봇 라인트레이싱 상황에 강화학습 요소를 구체적으로 대응시킬 수 있다

    💡 왜 이걸 배우나요?¶

    여러분, 처음 해보는 게임을 떠올려 보세요. 🎮

    아무런 설명서도 없이 게임을 시작했습니다. 버튼을 이것저것 눌러봅니다. 어떤 버튼을 누르면 캐릭터가 점프하면서 코인을 먹고 점수가 올라갑니다. 다른 버튼을 누르면 구덩이에 빠져서 "Game Over"가 뜹니다. 몇 번 실패하다 보면 자연스럽게 "이 상황에서는 이 버튼을 눌러야 하는구나" 를 깨닫게 되죠.

    이것이 바로 강화학습의 핵심 아이디어입니다.

    지금까지 우리가 배운 머신러닝은 대부분 "정답이 있는 데이터를 보고 배우는" 방식이었습니다. 하지만 현실에서는 정답을 미리 알 수 없는 상황이 훨씬 많습니다. 자율주행 자동차가 도로를 달릴 때, 로봇이 미로를 탈출할 때, 바둑 AI가 수를 둘 때 — 이 모든 상황에서 "시행착오를 통해 스스로 배우는" 강화학습이 빛을 발합니다.

    이번 챕터에서 배우는 용어와 개념은 앞으로 모든 강화학습 챕터의 기초가 됩니다. 건물의 기초 공사라고 생각하고, 하나하나 확실히 다져봅시다! 🧱

    📚 핵심 개념¶

    개념 1: 강화학습이란 무엇인가¶

    🎯 비유로 시작해 봅시다

    강아지에게 "앉아"를 가르치는 장면을 상상해 보세요. 🐕

    강아지가 우연히 앉으면 간식을 줍니다(+보상). 엉뚱한 행동을 하면 간식을 주지 않습니다(보상 없음). 이걸 반복하면 강아지는 "앉으면 좋은 일이 생기는구나!"를 학습합니다. 여기서 중요한 포인트가 있습니다 — 우리는 강아지의 다리 근육을 어떻게 움직여야 하는지 일일이 알려주지 않았습니다. 강아지가 스스로 시도하고, 결과를 보고, 더 나은 행동을 선택하게 된 것이죠.

    📖 정확한 정의

    강화학습(Reinforcement Learning) 이란, 에이전트(학습 주체) 가 환경(주변 세계) 과 상호작용하면서, 보상(reward)을 최대화하는 행동 방식을 스스로 학습하는 머신러닝의 한 분야입니다.

    핵심 키워드 세 가지를 기억하세요:

    • 시행착오(trial and error): 직접 해보면서 배운다
    • 보상 신호(reward signal): 잘했는지 못했는지 알려주는 피드백
    • 순차적 의사결정(sequential decision making): 한 번이 아니라 연속된 상황에서 계속 결정을 내린다

    🔍 예시로 확인

    바둑 AI 알파고를 생각해 보세요. 알파고는 바둑판이라는 환경에서 돌을 놓는 행동을 반복합니다. 게임이 끝나면 이겼으면 +보상, 졌으면 -보상을 받습니다. 수백만 번의 대국을 통해 "이 상황에서는 이 수가 좋다"를 스스로 터득한 것입니다.

    개념 2: 지도학습 · 비지도학습 · 강화학습 비교¶

    🎯 비유로 시작해 봅시다

    세 가지 학습 방법을 요리 배우기에 비유해 봅시다. 🍳

    • 지도학습: 레시피 책을 보고 따라 만든다. "달걀 2개, 소금 약간, 약불에서 3분" — 정답이 주어져 있다
    • 비지도학습: 냉장고에 있는 재료들을 보고 "이건 과일류, 이건 채소류"로 스스로 분류한다. 정답 없이 패턴을 발견한다
    • 강화학습: 일단 요리를 해본다. 맛있으면 그 방법을 기억하고, 맛없으면 다음에 다르게 해본다. 시행착오로 배운다

    📖 정확한 정의와 비교

    graph LR A[머신러닝] --> B[지도학습] A --> C[비지도학습] A --> D[강화학습] B --> B1["정답 라벨 O<br/>입력→정답 매핑 학습<br/>예: 사진→고양이/개 분류"] C --> C1["정답 라벨 X<br/>데이터 속 패턴 발견<br/>예: 고객 그룹 나누기"] D --> D1["보상 신호 O<br/>시행착오로 최적 행동 학습<br/>예: 게임 AI, 로봇 제어"]

    핵심 차이를 정리하면:

    • 지도학습 — "이 문제의 정답은 이거야"라고 선생님이 매번 알려준다
    • 비지도학습 — 정답도 보상도 없이, 데이터 자체에서 숨은 구조를 찾는다
    • 강화학습 — 정답은 모르지만, 행동의 결과가 좋았는지 나빴는지 피드백을 받는다

    🔍 예시로 확인

    햄스터 로봇으로 비교해 볼까요?

    • 지도학습 방식: "센서값이 (50, 80)이면 왼쪽으로 틀어라"라는 정답 데이터를 미리 수천 개 만들어서 학습시킨다
    • 비지도학습 방식: 센서 데이터를 모아서 "비슷한 센서 패턴끼리 묶어보자" 정도의 분석을 한다
    • 강화학습 방식: 로봇이 직접 달리면서, 선 위에 있으면 +1점, 벗어나면 -1점을 받고, 점점 선을 잘 따라가는 법을 스스로 깨우친다

    개념 3: 다섯 가지 핵심 요소¶

    강화학습의 세계에는 다섯 명의 주인공이 있습니다. 이들이 어떻게 상호작용하는지 이해하면, 강화학습의 절반은 이해한 것입니다! 🎭

    🎯 비유로 시작해 봅시다

    미로 탈출 게임을 하는 여러분을 상상해 보세요.

    • 에이전트(Agent) 🤖 = 미로 속의 나 (결정을 내리는 주체)
    • 환경(Environment) 🌍 = 미로 전체 (에이전트를 둘러싼 세계)
    • 상태(State) 📍 = 내가 지금 서 있는 위치와 주변 정보 ("왼쪽은 벽, 오른쪽은 길")
    • 행동(Action) 🏃 = 내가 선택하는 움직임 (위/아래/왼쪽/오른쪽으로 이동)
    • 보상(Reward) ⭐ = 행동의 결과 점수 (출구에 가까워지면 +1, 벽에 부딪히면 -1)

    📖 정확한 정의

    • 에이전트(Agent): 환경을 관찰하고 행동을 선택하는 학습 주체
    • 환경(Environment): 에이전트가 상호작용하는 외부 세계. 에이전트의 행동에 반응하여 새로운 상태와 보상을 돌려준다
    • 상태(State, s): 특정 시점에서 환경이 에이전트에게 알려주는 정보
    • 행동(Action, a): 에이전트가 특정 상태에서 선택할 수 있는 동작
    • 보상(Reward, r): 에이전트가 행동을 취한 후 환경으로부터 받는 수치적 피드백

    이 다섯 요소의 상호작용을 그림으로 나타내면 이렇습니다:

    graph LR Agent["🤖 에이전트<br/>(의사결정자)"] Env["🌍 환경<br/>(외부 세계)"] Agent -- "행동(Action)" --> Env Env -- "상태(State) + 보상(Reward)" --> Agent

    이 순환이 한 번 돌아가는 것을 한 스텝(step) 이라고 합니다. 강화학습은 이 스텝이 수없이 반복되면서 에이전트가 점점 똑똑해지는 과정입니다.

    🔍 예시로 확인 — 시간 순서로 보기

    sequenceDiagram participant A as 🤖 에이전트 participant E as 🌍 환경 E->>A: 상태 s₀ 전달 (현재 상황) A->>E: 행동 a₀ 선택 (움직임) E->>A: 보상 r₁ + 새 상태 s₁ A->>E: 행동 a₁ 선택 E->>A: 보상 r₂ + 새 상태 s₂ Note over A,E: 이 과정이 계속 반복!

    개념 4: 햄스터 로봇에 매핑하기¶

    🎯 비유는 이미 충분합니다 — 바로 실전으로!

    우리의 햄스터 로봇이 검은 선을 따라 달리는 라인트레이싱 상황을 강화학습으로 설계해 봅시다.

    📖 구체적 매핑

    • 에이전트 🤖 = 햄스터 로봇 (정확히는 로봇을 제어하는 프로그램)
    • 환경 🌍 = 라인트레이싱 트랙 (검은 선이 그려진 바닥)
    • 상태(State) 📍 = 왼쪽 바닥 센서값과 오른쪽 바닥 센서값의 조합
    • 예: (왼쪽=30, 오른쪽=85) → "왼쪽에 검은 선이 있다"
    • 행동(Action) 🏃 = 모터 제어 방법
    • 직진, 좌회전, 우회전, 정지 등
    • 보상(Reward) ⭐ = 설계하기 나름!
    • 두 센서 모두 선 위 → +1 (잘 따라가고 있다!)
    • 한쪽만 선 위 → 0 (약간 벗어남)
    • 둘 다 선 밖 → -1 (완전히 이탈!)
    graph TD subgraph "🤖 에이전트 (햄스터 로봇)" Brain["제어 프로그램<br/>→ 행동 결정"] end subgraph "🌍 환경 (트랙)" Track["검은 선 트랙"] Sensor["바닥 센서값<br/>왼쪽/오른쪽"] end Brain -- "행동: 좌회전/직진/우회전" --> Track Track --> Sensor Sensor -- "상태: (30, 85)" --> Brain Track -- "보상: +1 / 0 / -1" --> Brain

    💡 핵심 포인트: 보상을 어떻게 설계하느냐에 따라 로봇의 학습 결과가 완전히 달라집니다. 이것을 보상 설계(Reward Design) 라고 하며, 강화학습에서 가장 중요한 기술 중 하나입니다.

    🔨 따라하기¶

    이제 Python 코드로 강화학습의 기본 구조를 직접 만들어 봅시다! 🐍

    햄스터 로봇 라인트레이싱을 시뮬레이션하는 간단한 환경을 만들고, 에이전트가 랜덤으로 행동하면서 보상을 받는 과정을 구현합니다.

    📌 이번 실습에서는 "학습"까지는 하지 않습니다. 강화학습의 기본 골격 — 에이전트가 환경과 상호작용하는 루프 — 를 이해하는 것이 목표입니다.

    Step 1: 환경 클래스 만들기¶

    환경은 에이전트에게 상태를 알려주고, 에이전트의 행동을 받아 새로운 상태와 보상을 돌려주는 역할입니다.

    import random

class LineTrackEnv:
    """햄스터 로봇 라인트레이싱 시뮬레이션 환경"""

    def __init__(self):
        # 로봇의 위치: 0(선 중앙) 기준, -2~+2 범위
        # -2: 완전 왼쪽 이탈, +2: 완전 오른쪽 이탈
        self.position = 0

    def reset(self):
        """환경을 초기 상태로 되돌린다"""
        self.position = 0
        return self.get_state()

    def get_state(self):
        """현재 상태를 반환한다"""
        return self.position

    def step(self, action):
        """
        에이전트의 행동을 받아 처리한다.
        action: 0=좌회전, 1=직진, 2=우회전
        반환: (새로운 상태, 보상, 종료 여부)
        """
        # 행동에 따라 위치 변화
        if action == 0:    # 좌회전
            self.position -= 1
        elif action == 1:  # 직진
            self.position += 0  # 위치 변화 없음
        elif action == 2:  # 우회전
            self.position += 1

        # 트랙에 약간의 커브 추가 (무작위)
        curve = random.choice([-1, 0, 0, 0, 1])
        self.position += curve

        # 위치 제한 (-3 ~ +3)
        self.position = max(-3, min(3, self.position))

        # 보상 계산
        if abs(self.position) == 0:
            reward = 1    # 선 정중앙: 최고!
        elif abs(self.position) == 1:
            reward = 0    # 살짝 벗어남
        else:
            reward = -1   # 많이 벗어남

        # 완전히 이탈하면 종료
        done = abs(self.position) >= 3

        return self.get_state(), reward, done

print("✅ 환경 클래스 생성 완료!")

    Step 2: 에이전트 클래스 만들기¶

    에이전트는 상태를 관찰하고 행동을 선택합니다. 지금은 랜덤으로 선택하는 가장 단순한 에이전트를 만듭니다.

    class RandomAgent:
    """무작위로 행동을 선택하는 에이전트"""

    def __init__(self):
        # 가능한 행동: 0=좌회전, 1=직진, 2=우회전
        self.actions = [0, 1, 2]
        self.action_names = ["좌회전", "직진", "우회전"]

    def choose_action(self, state):
        """상태를 보고 행동을 선택한다 (지금은 무작위!)"""
        action = random.choice(self.actions)
        return action

print("✅ 에이전트 클래스 생성 완료!")

    Step 3: 강화학습 루프 실행하기¶

    이제 에이전트와 환경을 연결하여 상호작용 루프를 돌려봅시다!

    # 환경과 에이전트 생성
env = LineTrackEnv()
agent = RandomAgent()

# 환경 초기화 → 첫 번째 상태 받기
state = env.reset()

print("🚀 라인트레이싱 시뮬레이션 시작!\n")

total_reward = 0
step_count = 0

for step in range(15):  # 최대 15스텝
    # 에이전트가 행동 선택
    action = agent.choose_action(state)

    # 환경에 행동 전달 → 결과 받기
    new_state, reward, done = env.step(action)

    total_reward += reward
    step_count += 1

    # 현재 상황 출력
    position_visual = "." * (new_state + 3) + "🤖" + "." * (3 - new_state)
    print(f"스텝 {step+1:2d} | "
          f"상태: {state:+d} → 행동: {agent.action_names[action]} → "
          f"새 상태: {new_state:+d} | 보상: {reward:+d} | "
          f"{position_visual}")

    state = new_state

    if done:
        print(f"\n💥 트랙 이탈! 시뮬레이션 종료")
        break

print(f"\n📊 결과: {step_count}스텝 동안 총 보상 = {total_reward}")

    Step 4: 여러 번 실행하여 비교하기¶

    print("📊 랜덤 에이전트 성능 테스트 (10회 시도)\n")

results = []

for episode in range(10):

avg_reward = sum(results) / len(results)
print(f"\n  평균 보상: {avg_reward:.1f}")
print(f"\n💡 랜덤으로는 좋은 성적을 내기 어렵습니다!")

    Step 5: 간단한 규칙 기반 에이전트와 비교¶

    학습 전에, "상식적인 규칙"을 넣은 에이전트를 만들어 비교해 봅시다.

    class SimpleRuleAgent:
    """간단한 규칙으로 행동하는 에이전트"""

    def __init__(self):
        self.action_names = ["좌회전", "직진", "우회전"]

    def choose_action(self, state):
        if state > 0:      # 오른쪽으로 치우쳤으면
            return 0        # 좌회전!
        elif state < 0:     # 왼쪽으로 치우쳤으면
            return 2        # 우회전!
        else:               # 중앙이면
            return 1        # 직진!

# 규칙 기반 에이전트 테스트
rule_agent = SimpleRuleAgent()
print("📊 규칙 기반 에이전트 vs 랜덤 에이전트 (10회 평균)\n")

for name, test_agent in [("랜덤", agent), ("규칙", rule_agent)]:
    rewards = []
    for episode in range(10):
        state = env.reset()
        total_reward = 0
        for step in range(20):
            action = test_agent.choose_action(state)
            state, reward, done = env.step(action)
            total_reward += reward
            if done:
                break
        rewards.append(total_reward)

    avg = sum(rewards) / len(rewards)
    print(f"  {name} 에이전트 평균 보상: {avg:+.1f}")

print(f"\n🎯 규칙 기반이 훨씬 낫죠?")

    📝 전체 코드¶

    아래 코드를 복사해서 한 번에 실행할 수 있습니다.

    """
챕터 9: 강화학습 기본 구조 - 에이전트, 환경, 보상
햄스터 로봇 라인트레이싱 시뮬레이션
"""
import random

# ── 환경 ──
class LineTrackEnv:
    def __init__(self):
        self.position = 0

    def reset(self):
        self.position = 0
        return self.position

    def step(self, action):
        if action == 0:
            self.position -= 1
        elif action == 2:
            self.position += 1

        curve = random.choice([-1, 0, 0, 0, 1])
        self.position += curve
        self.position = max(-3, min(3, self.position))

        if abs(self.position) == 0:
            reward = 1
        elif abs(self.position) == 1:
            reward = 0
        else:
            reward = -1

        done = abs(self.position) >= 3
        return self.position, reward, done

# ── 에이전트 ──
class RandomAgent:
    def __init__(self):
        self.action_names = ["좌회전", "직진", "우회전"]

    def choose_action(self, state):
        return random.choice([0, 1, 2])

class SimpleRuleAgent:
    def __init__(self):
        self.action_names = ["좌회전", "직진", "우회전"]

    def choose_action(self, state):
        if state > 0:
            return 0
        elif state < 0:
            return 2
        else:
            return 1

# ── 실행 ──
env = LineTrackEnv()

print("=" * 50)
print("🚀 라인트레이싱 강화학습 시뮬레이션")
print("=" * 50)

for name, agent in [("랜덤", RandomAgent()), ("규칙", SimpleRuleAgent())]:
    rewards = []
    for episode in range(10):
        state = env.reset()
        total_reward = 0
        for step in range(20):
            action = agent.choose_action(state)
            state, reward, done = env.step(action)
            total_reward += reward
            if done:
                break
        rewards.append(total_reward)

    avg = sum(rewards) / len(rewards)
    print(f"\n🤖 {name} 에이전트 - 10회 에피소드 결과:")
    for i, r in enumerate(rewards):
        bar = "█" * max(0, r + 10)
        print(f"   에피소드 {i+1:2d}: 보상 {r:+3d} {bar}")
    print(f"   → 평균 보상: {avg:+.1f}")

print(f"\n💡 강화학습은 '규칙 기반'처럼 좋은 행동을")
print(f"   사람이 프로그래밍하지 않아도 스스로 발견합니다!")

    ⚠️ 자주 하는 실수¶

    실수 1: "보상 = 정답"이라고 생각하기 🚫

    지도학습의 라벨(정답)과 강화학습의 보상은 다릅니다. 보상은 "얼마나 좋았는지"만 알려줄 뿐, "정확히 무엇을 해야 하는지"는 알려주지 않습니다. 센서값이 (30, 85)일 때 보상이 -1이라면, 이건 "지금 안 좋은 상태"라는 신호이지 "좌회전해라"라는 정답이 아닙니다.

    실수 2: 에이전트와 환경의 경계를 혼동하기 🚫

    환경은 에이전트가 직접 바꿀 수 없는 것입니다.
