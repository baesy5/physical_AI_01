    Chapter 4. Python 핵심 복습: 자율주행에 쓰이는 문법¶

    Part 2 | [1권] Python과 개발 환경 준비

    🎯 이 장에서 배우는 것¶

    • 리스트와 딕셔너리를 사용하여 센서 데이터와 차량 상태를 저장·관리할 수 있다
    • 반복문과 조건문을 활용하여 연속적인 센서 데이터를 판단하는 코드를 작성할 수 있다
    • 함수를 정의하여 규칙 기반 주행 로직(정지, 감속, 전진)을 구현할 수 있다
    • 클래스를 사용하여 센서와 차량을 하나의 객체로 묶어 관리할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔 자율주행 차량에는 카메라, 라이다, 레이더, GPS 등 수많은 센서가 달려 있습니다. 매 순간 수백 개의 숫자 데이터가 쏟아져 들어옵니다. 이 데이터를 어디에 저장하고, 어떻게 반복해서 읽고, 어떤 조건일 때 어떻게 행동할지 결정하는 것—이 모든 작업의 기초가 바로 Python 문법입니다.

    Chapter 3에서 개발 환경을 구축했으니, 이제는 그 환경 위에서 실제로 코드를 작성할 차례입니다. 이 장에서는 Python 문법을 "자율주행"이라는 맥락 안에서 복습합니다. 단순한 문법 나열이 아니라, "센서 값을 리스트에 저장한다", "장애물 거리에 따라 정지·감속·전진을 판단한다"처럼 목적이 있는 코드를 작성합니다.

    flowchart LR A["🛰️ 센서 데이터 수집"] --> B["📦 자료구조에 저장<br/>(리스트, 딕셔너리)"] B --> C["🔄 반복문으로 처리"] C --> D["❓ 조건문으로 판단"] D --> E["🚗 주행 명령 출력"]

    위 흐름이 바로 이 장에서 만들어볼 코드의 전체 구조입니다.

    📚 핵심 개념¶

    개념 1: 리스트(List) — 센서 데이터의 줄 세우기¶

    1) 비유로 시작

    놀이공원 매표소 앞에 사람들이 한 줄로 서 있는 모습을 떠올려 보세요. 첫 번째 사람, 두 번째 사람… 순서가 있고, 몇 번째 사람인지 번호로 찾을 수 있습니다. Python의 리스트가 정확히 이런 구조입니다. 자율주행에서는 라이다 센서가 측정한 거리값들을 시간 순서대로 한 줄로 저장할 때 리스트를 사용합니다.

    2) 정확한 정의

    리스트는 순서가 있는 데이터의 모음입니다. 대괄호 [] 안에 쉼표로 구분하여 값을 넣으며, 각 값에는 인덱스(index)라는 번호가 0번부터 부여됩니다.

    3) 예시로 확인

    # 라이다 센서가 측정한 전방 장애물까지의 거리 (단위: 미터)
lidar_distances = [12.5, 8.3, 5.1, 3.7, 2.0]

# 첫 번째 측정값 (인덱스 0)
print(lidar_distances[0])   # 출력: 12.5

# 마지막 측정값 (인덱스 -1)
print(lidar_distances[-1])  # 출력: 2.0

# 새로운 측정값 추가
lidar_distances.append(1.5)
print(lidar_distances)      # 출력: [12.5, 8.3, 5.1, 3.7, 2.0, 1.5]

# 데이터 개수 확인
print(len(lidar_distances)) # 출력: 6

    알아보기 📌 - append(): 리스트 끝에 값을 추가합니다. - len(): 리스트에 들어있는 값의 개수를 반환합니다. - 인덱스는 0부터 시작합니다. 5개의 데이터가 있으면 인덱스는 0~4입니다.

    슬라이싱(Slicing)으로 리스트의 일부분만 꺼낼 수도 있습니다.

    # 최근 3개 측정값만 가져오기
recent = lidar_distances[-3:]
print(recent)  # 출력: [2.0, 1.5] → 위 append 후 기준 [3.7, 2.0, 1.5]

    개념 2: 딕셔너리(Dictionary) — 차량 상태 이름표 붙이기¶

    1) 비유로 시작

    도서관의 카드 목록을 생각해 보세요. "제목 → 책의 위치"처럼, 이름(키, key)을 말하면 값(value)을 바로 찾아줍니다. 리스트가 "몇 번째?"로 찾는다면, 딕셔너리는 "무슨 이름으로?"로 찾습니다.

    2) 정확한 정의

    딕셔너리는 키(key)와 값(value)의 쌍으로 이루어진 자료구조입니다. 중괄호 {} 안에 키: 값 형태로 저장하며, 키를 통해 값에 빠르게 접근합니다.

    3) 예시로 확인

    # 자율주행 차량의 현재 상태
vehicle_status = {
    "speed": 60,           # 현재 속도 (km/h)
    "gear": "D",           # 기어 상태
    "battery": 85,         # 배터리 잔량 (%)
    "is_moving": True      # 주행 중 여부
}

# 현재 속도 확인
print(vehicle_status["speed"])      # 출력: 60

# 속도 변경
vehicle_status["speed"] = 40
print(vehicle_status["speed"])      # 출력: 40

# 새로운 정보 추가
vehicle_status["steering_angle"] = 5.2
print(vehicle_status)

    알아보기 📌 - 키는 보통 문자열(str) 을 사용합니다. - 존재하지 않는 키로 접근하면 KeyError가 발생합니다. 안전하게 접근하려면 .get() 메서드를 사용하세요.

    # 안전한 접근 방법
temp = vehicle_status.get("temperature", "정보 없음")
print(temp)  # 출력: 정보 없음
    flowchart TB subgraph 리스트["📋 리스트 (List)"] L0["[0] 12.5"] L1["[1] 8.3"] L2["[2] 5.1"] end subgraph 딕셔너리["📖 딕셔너리 (Dictionary)"] D1["'speed' → 60"] D2["'gear' → 'D'"] D3["'battery' → 85"] end

    정리하기 ✏️ - 리스트: 순서가 중요할 때 (시간순 센서 데이터) - 딕셔너리: 이름으로 빠르게 찾을 때 (차량 상태 정보)

    개념 3: 반복문과 조건문 — 데이터를 훑고 판단하기¶

    1) 비유로 시작

    공장 컨베이어 벨트 위를 흘러가는 제품을 검사원이 하나씩 살펴보며 "합격/불합격"을 판정하는 모습을 떠올려 보세요. 반복문(for)은 컨베이어 벨트처럼 데이터를 하나씩 꺼내주고, 조건문(if)은 검사원처럼 "이 값이 기준을 넘는가?"를 판단합니다.

    2) 정확한 정의

    • for문: 리스트 등의 자료구조에서 값을 하나씩 꺼내 반복 실행합니다.
    • if-elif-else문: 조건이 참(True)인지 거짓(False)인지에 따라 다른 코드를 실행합니다.

    3) 예시로 확인

    # 라이다 센서 거리 데이터
lidar_distances = [12.5, 8.3, 5.1, 3.7, 2.0, 1.5]

# 각 거리에 대해 위험도 판단
for distance in lidar_distances:
    if distance < 3.0:
        print(f"거리 {distance}m → 🔴 위험! 정지 필요")
    elif distance < 7.0:
        print(f"거리 {distance}m → 🟡 주의! 감속 필요")
    else:
        print(f"거리 {distance}m → 🟢 안전, 전진 가능")

    실행 결과: 

    거리 12.5m → 🟢 안전, 전진 가능
거리 8.3m → 🟢 안전, 전진 가능
거리 5.1m → 🟡 주의! 감속 필요
거리 3.7m → 🟡 주의! 감속 필요
거리 2.0m → 🔴 위험! 정지 필요
거리 1.5m → 🔴 위험! 정지 필요

    while문은 조건이 참인 동안 계속 반복합니다. 자율주행에서는 "차량이 동작하는 동안 계속 센서를 읽어라"와 같은 상황에 사용합니다.

    # 간단한 주행 루프 시뮬레이션
import random

is_running = True
step = 0

while is_running:
    # 가상 센서값 생성 (1~20m 사이 랜덤)
    distance = round(random.uniform(1.0, 20.0), 1)
    step += 1
    print(f"[Step {step}] 전방 거리: {distance}m")

    if distance < 2.0:
        print("  → 긴급 정지! 주행 종료.")
        is_running = False

    if step >= 10:  # 안전장치: 최대 10번만 반복
        print("  → 시뮬레이션 종료.")
        is_running = False

    생각해보기 🤔 위 코드에서 if step >= 10 안전장치가 없으면 어떻게 될까요? distance가 계속 2.0 이상이면 무한 반복(infinite loop)에 빠집니다. while문을 쓸 때는 항상 종료 조건을 확인하세요!

    논리 연산자로 여러 조건을 조합할 수도 있습니다.

    speed = 45
distance = 4.5

# and: 두 조건 모두 참일 때
if speed > 30 and distance < 5.0:
    print("속도가 빠르고 거리가 가까움 → 강한 감속!")

# or: 하나라도 참이면
if speed > 80 or distance < 2.0:
    print("긴급 상황!")

# not: 조건 반전
is_raining = False
if not is_raining:
    print("맑은 날씨 → 일반 모드 주행")

    개념 4: 함수와 클래스 — 코드를 깔끔하게 정리하기¶

    1) 비유로 시작

    레스토랑에서 "스테이크 하나 주세요"라고 주문하면, 셰프가 알아서 고기를 굽고 소스를 뿌려 완성된 접시를 내줍니다. 주문하는 사람은 요리 과정을 몰라도 됩니다. 함수(function)가 바로 이런 역할입니다—복잡한 과정을 이름 하나로 묶어두고, 필요할 때 호출하면 됩니다.

    그리고 클래스(class)는 이 레스토랑 자체를 설계하는 설계도입니다. "이 레스토랑에는 셰프가 있고, 메뉴가 있고, 주문을 받는 기능이 있다"처럼, 관련된 데이터와 기능을 하나로 묶습니다.

    2) 정확한 정의

    • 함수: 특정 작업을 수행하는 코드 블록. def 키워드로 정의하며, 입력(매개변수)을 받아 결과(반환값)를 돌려줍니다.
    • 클래스: 관련 데이터(속성)와 함수(메서드)를 하나의 틀로 묶은 설계도. class 키워드로 정의합니다.

    3) 함수 예시

    def decide_action(distance):
    """
    전방 거리(m)를 받아 주행 명령을 반환하는 함수

    매개변수:
        distance (float): 전방 장애물까지의 거리 (미터)
    반환값:
        str: "STOP", "SLOW", "GO" 중 하나
    """
    if distance < 3.0:
        return "STOP"
    elif distance < 7.0:
        return "SLOW"
    else:
        return "GO"

# 함수 호출
action = decide_action(4.5)
print(f"주행 명령: {action}")  # 출력: 주행 명령: SLOW

    알아보기 📌 - def: 함수를 정의하는 키워드 - distance: 매개변수(parameter) — 함수에 전달되는 입력값 - return: 함수의 결과를 돌려주는 키워드 - """...""": 독스트링(docstring) — 함수의 설명을 적는 곳

    4) 클래스 예시

    class AutonomousVehicle:
    """자율주행 차량을 표현하는 클래스"""

    def __init__(self, name):
        """생성자: 차량 객체가 만들어질 때 실행"""
        self.name = name        # 차량 이름
        self.speed = 0          # 현재 속도
        self.is_running = False  # 주행 상태

    def start(self):
        """차량 시동 걸기"""
        self.is_running = True
        print(f"{self.name}: 시동이 걸렸습니다.")

    def drive(self, distance):
        """센서 거리에 따라 주행 판단"""
        if not self.is_running:
            print(f"{self.name}: 먼저 시동을 걸어주세요.")
            return

        if distance < 3.0:
            self.speed = 0
            print(f"{self.name}: 정지! (거리 {distance}m)")
        elif distance < 7.0:
            self.speed = 20
            print(f"{self.name}: 감속 → {self.speed}km/h (거리 {distance}m)")
        else:
            self.speed = 60
            print(f"{self.name}: 전진 → {self.speed}km/h (거리 {distance}m)")

# 객체(인스턴스) 생성 및 사용
my_car = AutonomousVehicle("테스트카 1호")
my_car.start()
my_car.drive(10.0)
my_car.drive(5.5)
my_car.drive(1.8)

    Step 2: 주행 판단 함수 만들기¶

    def decide_action(distance):
    """
    전방 거리를 기반으로 주행 명령을 결정한다.

    규칙:
        - 3m 미만: STOP (정지)
        - 3m 이상 7m 미만: SLOW (감속, 20km/h)
        - 7m 이상: GO (전진, 60km/h)
    """
    if distance < 3.0:
        return "STOP", 0
    elif distance < 7.0:
        return "SLOW", 20
    else:
        return "GO", 60

    알아보기 📌 함수가 return "STOP", 0처럼 쉼표로 두 개의 값을 반환하면, Python은 이를 튜플(tuple)로 묶어 돌려줍니다. 호출할 때 action, speed = decide_action(5.0)처럼 받을 수 있습니다.

    class SimpleAutoPilot:
    """간단한 규칙 기반 자율주행 시뮬레이터"""

    def __init__(self, name):
        self.name = name
        self.speed = 0
        self.action = "READY"
        self.total_stops = 0
        self.log = []  # 주행 기록 저장

    def decide(self, distance):
        """거리에 따른 주행 판단"""
        if distance < 3.0:
            self.action = "STOP"
            self.speed = 0
            self.total_stops += 1
        elif distance < 7.0:
            self.action = "SLOW"
            self.speed = 20
        else:
            self.action = "GO"
            self.speed = 60

        # 기록 저장
        self.log.append({
            "distance": distance,
            "action": self.action,
            "speed": self.speed
        })

    def run(self, sensor_data):
        """센서 데이터 리스트를 받아 전체 시뮬레이션 실행"""
        print(f"\n🚗 [{self.name}] 시뮬레이션 시작!")
        print("-" * 45)

        for i, distance in enumerate(sensor_data):
            self.decide(distance)

            if self.action == "STOP":
                emoji = "🔴"
            elif self.action == "SLOW":
                emoji = "🟡"
            else:
                emoji = "🟢"

            print(f"[{i+1}초] {distance:>5.1f}m | "
                  f"{emoji} {self.action:>4} | {self.speed}km/h")

        print("-" * 45)
        print(f"총 정지: {self.total_stops}회 | "
              f"기록 수: {len(self.log)}개\n")
