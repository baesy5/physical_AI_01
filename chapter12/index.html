    Q-테이블과 Q-learning – 경험에서 배우는 로봇¶

    Part 3 | [2권] 강화학습의 세계로 – 핵심 개념 이해하기 | 12차시

    🎯 이 장에서 배우는 것¶

    • Q-값이 무엇을 의미하는지 자신의 말로 설명할 수 있다
    • Q-테이블의 구조(행: 상태, 열: 행동)를 이해하고 직접 그릴 수 있다
    • Q-learning 업데이트 공식의 네 가지 요소(학습률, 할인율, 현재 보상, 미래 가치)의 역할을 각각 설명할 수 있다
    • 종이 위에서 Q-테이블 업데이트를 수작업으로 수행하여 알고리즘의 동작을 추적할 수 있다

    💡 왜 이걸 배우나요?¶

    지난 장에서 우리는 보상, 상태, 행동이라는 강화학습의 기본 언어를 배웠습니다. 에이전트가 환경과 상호작용하며 보상을 받는다는 큰 그림을 이해했죠.

    그런데 한 가지 핵심적인 질문이 남아 있습니다.

    "에이전트는 경험을 어디에, 어떻게 기록하는 걸까?" 🤔

    여러분이 새로운 도시에 여행을 갔다고 상상해 보세요. 첫날은 아무것도 모르니까 아무 식당이나 들어갑니다. 어떤 곳은 맛있고, 어떤 곳은 별로입니다. 며칠이 지나면 머릿속에 자연스럽게 "이 골목에서는 이 식당이 좋다"라는 정보가 쌓이죠. 이 머릿속 지도가 바로 오늘 배울 Q-테이블입니다.

    그리고 이 지도를 업데이트하는 규칙, 즉 "새로운 경험이 들어왔을 때 기존 평가를 어떻게 수정할까?"를 정하는 것이 Q-learning 알고리즘입니다.

    Q-learning은 강화학습에서 가장 유명하고 근본적인 알고리즘입니다. 이걸 이해하면 이후에 배울 딥러닝 기반 강화학습(DQN 등)의 기초가 탄탄해집니다. 오늘 이 장을 마치면, 종이와 연필만으로 로봇이 학습하는 과정을 직접 시뮬레이션할 수 있게 됩니다! ✏️

    📚 핵심 개념¶

    개념 1: Q-값 – "이 상태에서 이 행동, 얼마나 좋을까?"¶

    🍽️ 비유로 시작하기

    여러분이 맛집 앱을 만든다고 해볼게요. 이 앱은 단순히 "이 식당 별점 4.2"라고만 알려주지 않습니다. 대신 이렇게 알려줍니다:

    • "강남역 근처에서 → 한식을 선택하면 → 기대 만족도 4.5"
    • "강남역 근처에서 → 패스트푸드를 선택하면 → 기대 만족도 2.1"
    • "홍대 근처에서 → 한식을 선택하면 → 기대 만족도 3.8"

    핵심을 보셨나요? "어디서(상태)" + "뭘 하면(행동)" = "얼마나 좋을지(기대값)", 이 세 가지가 조합되어 있습니다.

    📖 정확한 정의

    Q-값(Q-value) 이란, 특정 상태(s) 에서 특정 행동(a) 을 했을 때, 지금 당장의 보상뿐 아니라 앞으로 받을 수 있는 보상까지 모두 고려한 기대 가치를 나타내는 숫자입니다.

    수학적으로 Q(s, a)라고 표기합니다. "Q"는 Quality(품질) 의 첫 글자예요. 말 그대로 "이 상태에서 이 행동의 품질이 얼마인가?"를 숫자로 매긴 것입니다.

    ✅ 예시로 확인

    간단한 미로를 생각해봅시다. 로봇이 방 A에 있고, "오른쪽으로 이동"이라는 행동을 할 수 있습니다.

    • Q(방A, 오른쪽) = 8.5 → "방A에서 오른쪽으로 가면 앞으로 꽤 좋은 결과를 기대할 수 있어!"
    • Q(방A, 왼쪽) = 2.0 → "방A에서 왼쪽으로 가면 별로 좋지 않을 거야..."

    로봇은 Q-값이 높은 행동을 선택하면 됩니다. 간단하죠? 😄

    개념 2: Q-테이블 – 모든 Q-값을 정리한 커닝 페이퍼¶

    📋 비유로 시작하기

    시험공부를 할 때 핵심 내용을 한 장짜리 요약표로 정리해 본 적 있으신가요? Q-테이블은 에이전트의 커닝 페이퍼입니다. 모든 상태와 모든 행동의 조합에 대해 "얼마나 좋은지"를 한눈에 볼 수 있도록 정리한 표예요.

    📖 정확한 정의

    Q-테이블은 행(row)이 상태, 열(column)이 행동인 표로, 각 칸에 해당 Q(s, a) 값이 저장된 자료구조입니다.

    graph LR subgraph Q-테이블 구조 direction TB A["행 = 상태(State)"] --> C["각 칸 = Q(s,a) 값"] B["열 = 행동(Action)"] --> C end D["에이전트가 참조"] --> C C --> E["가장 큰 Q값의 행동 선택!"]

    ✅ 예시로 확인

    3개의 방(A, B, C)과 2개의 행동(왼쪽, 오른쪽)이 있는 미로를 생각해봅시다. 처음에는 아무 경험이 없으므로 모든 Q-값이 0으로 시작합니다.

    • 방A, 왼쪽 → Q = 0.0
    • 방A, 오른쪽 → Q = 0.0
    • 방B, 왼쪽 → Q = 0.0
    • 방B, 오른쪽 → Q = 0.0
    • 방C, 왼쪽 → Q = 0.0
    • 방C, 오른쪽 → Q = 0.0

    총 3(상태) × 2(행동) = 6칸이 있고, 모두 0입니다. 이제 에이전트가 경험을 쌓으면서 이 값들을 점점 업데이트해 나갑니다. 마치 빈 노트에 맛집 평점을 하나씩 적어가는 것처럼요! 📝

    개념 3: Q-learning 업데이트 공식 – 경험을 지식으로 바꾸는 마법 수식¶

    드디어 이 장의 핵심입니다! Q-learning의 업데이트 공식을 배워봅시다.

    🏫 비유로 시작하기

    여러분이 어떤 식당의 평점을 관리한다고 해보세요. 기존 평점이 4.0인데, 오늘 새로 가봤더니 경험이 좀 달랐습니다. 이때 평점을 어떻게 수정할까요?

    • 기존 평점을 완전히 버리고 새 경험으로 대체한다? → ❌ 너무 변덕스럽습니다
    • 기존 평점을 절대 바꾸지 않는다? → ❌ 새로운 정보를 무시합니다
    • 기존 평점에 새 경험을 "조금씩" 반영한다! → ✅ 이게 Q-learning의 방식입니다

    📖 정확한 정의

    Q-learning의 업데이트 공식은 다음과 같습니다:

    Q(s, a) ← Q(s, a) + α [ R + γ · max Q(s', a') − Q(s, a) ]

    처음 보면 복잡해 보이지만, 하나씩 뜯어보면 완전히 이해할 수 있습니다! 각 요소를 분해해 볼게요. 🔍

    요소 1: Q(s, a) – 현재 내 평가 (기존 평점)

    지금까지 쌓인 경험을 바탕으로 "상태 s에서 행동 a를 하면 이 정도 될 거야"라고 적어둔 현재 값입니다.

    요소 2: R – 방금 받은 보상 (오늘의 경험)

    행동 a를 실행한 직후 환경에서 받은 즉각적인 보상입니다. 맛집 비유에서는 "오늘 이 식당에서 먹은 음식의 만족도"에 해당해요.

    요소 3: γ (감마) – 할인율 (미래를 얼마나 중요하게 볼까?)

    0과 1 사이의 값입니다. - γ = 0.9 → "미래 보상도 꽤 중요하게 봐!" (먼 미래까지 고려) - γ = 0.1 → "당장의 보상이 훨씬 중요해!" (근시안적) - γ = 0 → 미래는 완전히 무시, 당장의 R만 신경 씀

    요소 4: max Q(s', a') – 다음 상태에서의 최고 기대값

    행동 a를 한 뒤 도착한 새 상태 s'에서, 할 수 있는 모든 행동 중 가장 Q-값이 높은 것을 골랐을 때의 값입니다. "다음 동네에서 최고의 맛집 평점"이라고 생각하면 됩니다.

    요소 5: α (알파) – 학습률 (새 경험을 얼마나 반영할까?)

    0과 1 사이의 값입니다. - α = 0.1 → "기존 평가를 90% 유지하고, 새 경험은 10%만 반영" - α = 0.9 → "새 경험을 대폭 반영!" - α가 크면 빨리 배우지만 불안정하고, 작으면 안정적이지만 느립니다

    요소들의 조합: R + γ · max Q(s', a') = TD 타겟

    이 부분은 "실제로 경험해보니 이 정도가 적절한 것 같아" 라는 새로운 추정값입니다. 당장 받은 보상(R)에, 다음에 기대할 수 있는 최고의 미래 가치(γ·max Q)를 더한 것이죠.

    그리고 R + γ · max Q(s', a') − Q(s, a) = TD 오차

    새로운 추정값에서 기존 추정값을 빼면 "내가 얼마나 틀렸는지" 가 나옵니다. 이걸 TD 오차(Temporal Difference Error) 라고 부릅니다.

    • TD 오차가 양수(+) → "생각보다 좋았네! Q-값을 올리자"
    • TD 오차가 음수(-) → "생각보다 별로였네... Q-값을 내리자"
    • TD 오차가 0 → "예상이 정확했어! 수정 불필요"

    전체 흐름을 그림으로 정리하면:

    flowchart TD A["1️⃣ 현재 상태 s에서 행동 a 선택"] --> B["2️⃣ 환경에서 보상 R을 받고, 새 상태 s'에 도착"] B --> C["3️⃣ TD 타겟 계산: R + γ · max Q(s', a')"] C --> D["4️⃣ TD 오차 계산: TD타겟 − Q(s,a)"] D --> E["5️⃣ Q-값 업데이트: Q(s,a) + α · TD오차"] E --> F["6️⃣ s ← s' (새 상태로 이동)"] F --> A

    이 과정을 수천, 수만 번 반복하면 Q-테이블의 값들이 점점 정확해지고, 에이전트는 최적의 행동을 찾아가게 됩니다!

    개념 4: 학습률(α)과 할인율(γ) – 학습의 성격을 결정하는 두 손잡이¶

    이 두 하이퍼파라미터는 에이전트의 "학습 성격"을 결정합니다. 오디오 믹서의 볼륨 노브라고 생각하면 이해하기 쉬워요. 🎛️

    🎚️ 학습률 α – "변화의 속도" 노브

    • α가 클 때 (예: 0.9): 최근 경험에 크게 흔들립니다. 빨리 배우지만, 한 번의 나쁜 경험에도 크게 영향을 받아 불안정합니다.
    • α가 작을 때 (예: 0.1): 천천히, 조심스럽게 의견을 바꿉니다. 안정적이지만 학습이 느립니다.
    • 현실 비유: α가 큰 사람은 "어제 그 식당 최악이었어, 다시는 안 가!"라고 바로 평가를 바꾸는 사람. α가 작은 사람은 "한 번 좀 별로였다고 평점을 확 바꿀 순 없지"라고 신중한 사람.

    🎚️ 할인율 γ – "미래 시야" 노브

    • γ가 클 때 (예: 0.99): 먼 미래의 보상까지 중요하게 여깁니다. 장기적인 계획을 세울 수 있지만, 학습이 복잡해집니다.
    • γ가 작을 때 (예: 0.1): 당장 눈앞의 보상에 집중합니다. 빠르게 결정하지만 근시안적입니다.
    • 현실 비유: γ가 큰 사람은 "지금 당장은 힘들지만 3년 후를 보고 투자하자"라는 장기 투자자. γ가 작은 사람은 "오늘 행복한 게 최고야!"라는 현재 즐기기 주의자.
    quadrantChart title α와 γ에 따른 에이전트 성격 x-axis "α 작음 (신중)" --> "α 큼 (적극)" y-axis "γ 작음 (근시안)" --> "γ 큼 (장기적)" quadrant-1 "빠른 학습 + 장기 계획" quadrant-2 "느린 학습 + 장기 계획" quadrant-3 "느린 학습 + 눈앞 보상" quadrant-4 "빠른 학습 + 눈앞 보상"

    💡 실용 팁: 입문 수준에서는 α = 0.1, γ = 0.9 정도로 시작하는 것이 일반적입니다. 이후 문제에 맞게 조절해 나가면 됩니다!

    🔨 따라하기: 종이 위에서 Q-테이블 직접 업데이트하기¶

    이제 가장 중요한 실습입니다! 코드를 치기 전에, 손으로 직접 계산해보며 Q-learning이 어떻게 동작하는지 완전히 체화합시다. ✍️

    실습 환경 설정¶

    아주 간단한 미로를 사용합니다:

    flowchart LR A["🤖 방A<br/>(시작)"] -->|오른쪽| B["방B"] B -->|오른쪽| C["🏆 방C<br/>(목표! 보상+10)"] B -->|왼쪽| A A -->|왼쪽| A["방A<br/>(벽! 제자리)"]

    규칙 정리: - 상태: 방A, 방B, 방C (총 3개) - 행동: 왼쪽(L), 오른쪽(R) (총 2개) - 보상: 방C에 도착하면 +10, 그 외에는 0 - 설정값: α = 0.5 (학습률), γ = 0.9 (할인율) - 초기 Q-테이블: 모든 값 0.0

    초기 Q-테이블 (종이에 이렇게 적어보세요!):

    • Q(A, L) = 0.0
    • Q(A, R) = 0.0
    • Q(B, L) = 0.0
    • Q(B, R) = 0.0

    (방C는 목표 상태이므로, 도착하면 에피소드가 끝납니다. Q-값을 업데이트할 필요가 없어요.)

    Step 1: 첫 번째 경험 – 방A에서 오른쪽으로!¶

    에이전트가 방A에서 오른쪽(R)을 선택했습니다.

    일어난 일: - 현재 상태: s = 방A - 선택한 행동: a = 오른쪽(R) - 받은 보상: R = 0 (방B는 목표가 아니니까) - 도착한 새 상태: s' = 방B

    Q-값 업데이트 계산:

    Q(A, R) ← Q(A, R) + α [ R + γ · max Q(B, a') − Q(A, R) ]

    하나씩 대입합니다: - Q(A, R) = 0.0 (현재 값) - α = 0.5 - R = 0 - γ = 0.9 - max Q(B, a') = max(Q(B,L), Q(B,R)) = max(0.0, 0.0) = 0.0

    Q(A, R) ← 0.0 + 0.5 × [ 0 + 0.9 × 0.0 − 0.0 ]
         = 0.0 + 0.5 × [ 0 ]
         = 0.0

    결과: Q(A, R) = 0.0 (변화 없음!)

    처음에는 미래 가치도 0이고 보상도 0이니 당연히 변화가 없습니다. 괜찮아요, 계속 가봅시다! 🚶

    Step 2: 두 번째 경험 – 방B에서 오른쪽으로! 🎯¶

    이어서 에이전트가 방B에서 오른쪽(R)을 선택했습니다.

    일어난 일: - 현재 상태: s = 방B - 선택한 행동: a = 오른쪽(R) - 받은 보상: R = 10 🎉 (방C 도착! 목표 달성!) - 도착한 새 상태: s' = 방C (종료 상태)

    Q-값 업데이트 계산:

    Q(B, R) ← Q(B, R) + α [ R + γ · max Q(C, a') − Q(B, R) ]

    대입합니다: - Q(B, R) = 0.0 - α = 0.5 - R = 10 - γ = 0.9 - max Q(C, a') = 0 (종료 상태이므로 미래 가치 없음!)

    Q(B, R) ← 0.0 + 0.5 × [ 10 + 0.9 × 0 − 0.0 ]
         = 0.0 + 0.5 × [ 10 ]
         = 5.0

    결과: Q(B, R) = 5.0 ✨

    드디어 변화가 생겼습니다! "방B에서 오른쪽으로 가면 꽤 좋다(5.0)"는 정보가 기록되었어요.

    업데이트된 Q-테이블: - Q(A, L) = 0.0 - Q(A, R) = 0.0 - Q(B, L) = 0.0 - Q(B, R) = 5.0 ← 업데이트!

    Step 3: 에피소드 2 시작 – 다시 방A에서 오른쪽으로!¶

    새 에피소드가 시작됩니다. 에이전트는 다시 방A로 돌아갑니다.

    일어난 일: - 현재 상태: s = 방A - 선택한 행동: a = 오른쪽(R) - 받은 보상: R = 0 - 도착한 새 상태: s' = 방B

    Q-값 업데이트 계산:

    Q(A, R) ← Q(A, R) + α [ R + γ · max Q(B, a') − Q(A, R) ]

    대입합니다: - Q(A, R) = 0.0 - α = 0.5 - R = 0 - γ = 0.9 - max Q(B, a') = max(Q(B,L), Q(B,R)) = max(0.0, 5.0) = 5.0 ← 여기가 핵심!

    Q(A, R) ← 0.0 + 0.5 × [ 0 + 0.9 × 5.0 − 0.0 ]
         = 0.0 + 0.5 × [ 4.5 ]
         = 2.25

    결과: Q(A, R) = 2.25 🌊

    보셨나요? 방A에서는 보상을 직접 받지 않았는데도, 방B의 좋은 Q-값(5.0)이 역으로 전파되어 방A의 Q-값도 올라갔습니다! 이것이 Q-learning의 핵심 메커니즘입니다. 보상 정보가 목표 지점에서 출발점 쪽으로 역전파됩니다.

    업데이트된 Q-테이블: - Q(A, L) = 0.0 - Q(A, R) = 2.25 ← 업데이트! - Q(B, L) = 0.0 - Q(B, R) = 5.0

    flowchart LR A["방A<br/>L: 0.0 | R: 2.25"] -->|"오른쪽 선택!"| B["방B<br/>L: 0.0 | R: 5.0"] B -->|"오른쪽 선택!"| C["🏆 방C<br/>보상 +10"] style C fill:#FFD700,color:#000

    이제 에이전트가 방A에 있으면, Q(A,R)=2.25 > Q(A,L)=0.0 이므로 오른쪽을 선택합니다. 방B에서도 Q(B,R)=5.0 > Q(B,L)=0.0 이므로 오른쪽을 선택합니다. 벌써 최적 경로를 찾았네요! 🎯

    🔑 핵심 인사이트: Q-learning에서는 목표 근처의 Q-값이 먼저 업데이트되고, 그 값이 점점 뒤쪽(시작 지점)으로 전파됩니다. 마치 물결이 퍼지듯이요!

    Step 4: 직접 해보기 – 연습 문제¶

    이번에는 에피소드 2의 두 번째 스텝을 여러분이 직접 계산해보세요!

    상황: - 현재 상태: s = 방B - 행동: a = 오른쪽(R) - 보상: R = 10 (방C 도착!) - 새 상태: s' = 방C (종료) - 현재 Q(B, R) = 5.0

    직접 계산해보세요! (α = 0.5, γ = 0.9)

    Q(B, R) ← 5.0 + 0.5 × [ 10 + 0.9 × 0 − 5.0 ]
         = 5.0 + 0.5 × [ ??? ]
         = ???

    . . . (스크롤하기 전에 직접 계산해보세요! 🤓) . . .

    Q(B, R) ← 5.0 + 0.5 × [ 10 + 0 − 5.0 ]

         = 5.0 + 2.5
