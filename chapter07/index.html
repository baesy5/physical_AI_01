    Chapter 7: CARLA 센서 시스템 이해하기¶

    Part 3: CARLA에서 데이터 수집과 전처리

    🎯 이 장에서 배우는 것¶

    • CARLA의 주요 센서(카메라, 라이다, 충돌 센서, GPS) 종류와 역할을 설명할 수 있다
    • 센서를 차량에 부착하고 데이터를 수집하는 Python 코드를 작성할 수 있다
    • 각 센서가 출력하는 데이터 형식(이미지, 포인트 클라우드, 좌표 등)의 차이를 비교·분석할 수 있다
    • 여러 센서를 동시에 부착하여 복합 데이터를 수집하는 시스템을 구성할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기: 여러분이 자전거를 탈 때를 떠올려보세요. 눈으로 앞을 보고, 귀로 뒤에서 오는 차 소리를 듣고, 피부로 바람의 세기를 느끼며 방향과 속도를 결정합니다. 만약 눈을 감고 자전거를 탄다면? 상상만 해도 아찔하죠.

    자율주행 AI도 마찬가지입니다. AI가 안전하게 운전하려면 디지털 감각기관, 즉 센서가 필요합니다. CARLA 시뮬레이터는 실제 자율주행 차량에 장착되는 것과 동일한 종류의 센서를 가상으로 제공합니다.

    이번 장에서는 CARLA의 센서를 하나씩 차량에 부착하고, 각 센서가 어떤 형태의 데이터를 만들어내는지 직접 확인합니다. 이 과정을 통해 "어떤 센서 조합이 자율주행에 적합한가?" 라는 질문에 스스로 답할 수 있게 됩니다.

    📚 핵심 개념¶

    개념 1: CARLA 센서의 분류 체계¶

    🎭 비유부터 시작합시다

    센서를 인간의 감각에 대응시키면 이해가 쉽습니다.

    • 카메라 계열 → 👁️ 눈 (빛을 감지하여 시각 정보 획득)
    • 라이다(LiDAR) → 🦇 박쥐의 초음파 (레이저를 쏘고 반사된 시간으로 거리 측정)
    • 충돌 센서 → 🖐️ 촉각 (부딪힘을 감지)
    • GPS/IMU → 🧭 위치 감각 (지금 어디에 있는지, 어느 방향인지)

    📖 정확한 정의

    CARLA의 센서는 크게 세 가지 범주로 나뉩니다.

    • 영상 센서(Image-based): RGB 카메라, 시맨틱 세그멘테이션 카메라, 깊이(Depth) 카메라 — 2D 이미지 데이터를 생성
    • 거리 센서(Range-based): 라이다(LiDAR), 레이더(Radar) — 3D 포인트 클라우드 또는 거리 데이터를 생성
    • 상태 센서(State-based): 충돌 감지, 차선 침범 감지, GPS, IMU — 이벤트 또는 수치 데이터를 생성
    graph TB A["🚗 CARLA 센서 시스템"] --> B["📷 영상 센서"] A --> C["📡 거리 센서"] A --> D["📊 상태 센서"] B --> B1["RGB 카메라<br/>컬러 이미지"] B --> B2["시맨틱 세그멘테이션<br/>객체별 색상 분류"] B --> B3["깊이 카메라<br/>거리 정보 이미지"] C --> C1["LiDAR<br/>3D 포인트 클라우드"] C --> C2["Radar<br/>속도+거리 데이터"] D --> D1["충돌 감지"] D --> D2["차선 침범 감지"] D --> D3["GPS + IMU"]

    🔍 예시로 확인

    실제 자율주행 차량인 Waymo의 차량을 보면, 지붕 위에 LiDAR가, 전후좌우에 카메라가, 범퍼에 레이더가 장착되어 있습니다. CARLA에서는 이 모든 것을 코드 몇 줄로 가상 차량에 부착할 수 있습니다.

    개념 2: 카메라 센서와 이미지 데이터¶

    🎭 비유부터 시작합시다

    RGB 카메라는 여러분의 스마트폰 카메라와 같습니다. 하지만 시맨틱 세그멘테이션 카메라는 좀 특별합니다. 마치 "이 사진 속에서 사람은 빨간색, 도로는 보라색, 차량은 파란색으로 자동 색칠해주는 마법 카메라" 와 같습니다.

    📖 정확한 정의

    • RGB 카메라: 사람이 보는 것과 유사한 컬러 이미지를 생성합니다. 각 픽셀은 R(빨강), G(초록), B(파랑) 3개 채널의 0~255 값으로 구성됩니다.
    • 시맨틱 세그멘테이션 카메라: 각 픽셀이 어떤 객체에 속하는지 라벨(태그)로 분류된 이미지를 생성합니다. 도로, 보행자, 차량, 건물 등을 색상으로 구분합니다.
    • 깊이 카메라: 카메라로부터 각 픽셀까지의 거리 정보를 인코딩한 이미지를 생성합니다.

    🔍 예시로 확인

    같은 장면을 세 카메라로 동시에 촬영하면 이런 차이가 납니다.

    • RGB: 우리가 눈으로 보는 것과 같은 자연스러운 사진
    • 시맨틱: 도로는 보라색, 차량은 파란색, 보행자는 빨간색으로 칠해진 그림
    • 깊이: 가까운 물체는 밝고, 먼 물체는 어두운 회색조 이미지

    알아보기: 시맨틱 세그멘테이션 데이터는 실제로는 구하기 매우 어렵습니다. 사람이 사진의 모든 픽셀에 일일이 라벨을 붙여야 하기 때문입니다. CARLA에서는 시뮬레이터가 이 정보를 자동으로 제공하므로, AI 학습 데이터를 만들기에 매우 유리합니다.

    개념 3: LiDAR와 포인트 클라우드¶

    🎭 비유부터 시작합시다

    어두운 방에서 레이저 포인터를 사방으로 빠르게 돌린다고 상상해보세요. 레이저가 벽이나 가구에 닿으면 빨간 점이 찍힙니다. 이 점들을 모두 모으면 방의 3D 구조를 알 수 있겠죠? LiDAR가 바로 이 원리입니다.

    📖 정확한 정의

    LiDAR(Light Detection and Ranging)는 레이저 빔을 360도로 쏘아 반사되어 돌아오는 시간을 측정하여 주변 환경의 3D 거리 정보를 수집하는 센서입니다. 수집된 데이터는 포인트 클라우드(Point Cloud) 라고 불리며, 수천~수만 개의 3D 좌표점 (x, y, z) 집합입니다.

    🔍 예시로 확인

    CARLA의 LiDAR 데이터 한 프레임에는 약 수만 개의 점이 포함됩니다. 각 점은 4개의 값을 가집니다.

    • x: 좌우 위치 (미터)
    • y: 앞뒤 위치 (미터)
    • z: 높낮이 (미터)
    • intensity: 반사 강도 (재질에 따라 다름)

    이 점들을 시각화하면 주변 건물, 차량, 보행자의 3D 윤곽이 뚜렷이 드러납니다.

    개념 4: 상태 센서 (충돌·GPS·IMU)¶

    🎭 비유부터 시작합시다

    상태 센서는 차량의 건강 상태 모니터와 같습니다. 충돌 센서는 "방금 뭔가에 부딪혔어!"라고 알려주는 경보기이고, GPS는 "지금 여기야!"라고 위치를 알려주는 내비게이션이며, IMU는 "지금 기울어지고 있어!"라고 자세를 알려주는 수평계입니다.

    📖 정확한 정의

    • 충돌 센서(Collision Sensor): 차량이 다른 물체와 충돌할 때 이벤트를 발생시킵니다. 충돌 대상 액터(actor)와 충격 강도를 반환합니다.
    • 차선 침범 센서(Lane Invasion Sensor): 차량이 차선 경계를 넘을 때 이벤트를 발생시킵니다.
    • GNSS(GPS) 센서: 차량의 위도(latitude), 경도(longitude), 고도(altitude) 좌표를 반환합니다.
    • IMU 센서: 가속도계(accelerometer)와 자이로스코프(gyroscope) 데이터, 그리고 나침반(compass) 방향을 반환합니다.

    🔍 예시로 확인

    자율주행 AI를 학습시킬 때, 충돌 센서 데이터는 "이런 상황에서 이렇게 하면 사고가 난다" 는 부정적 피드백(negative feedback)으로 활용됩니다. GPS 데이터는 목적지까지의 경로를 계산하는 데 사용됩니다.

    🔨 따라하기¶

    준비물: CARLA 서버가 실행 중이어야 합니다. 이전 장에서 배운 대로 CARLA 서버를 먼저 시작하세요.

    Step 1: 기본 설정 — 세계와 차량 생성하기¶

    가장 먼저 CARLA에 연결하고 차량을 생성합니다. 이전 장에서 배운 내용의 복습입니다.

    import carla
import numpy as np
import time

# 1) CARLA 서버에 연결
client = carla.Client('localhost', 2000)
client.set_timeout(10.0)
world = client.get_world()

# 2) 차량 스폰 (생성)
blueprint_library = world.get_blueprint_library()
vehicle_bp = blueprint_library.filter('model3')[0]  # Tesla Model 3

spawn_points = world.get_map().get_spawn_points()
spawn_point = spawn_points[0]

vehicle = world.spawn_actor(vehicle_bp, spawn_point)
print(f"차량 생성 완료: {vehicle.type_id}")

    정리하기: world.get_blueprint_library()에서 센서의 설계도(blueprint)도 가져올 수 있습니다. 차량뿐 아니라 센서도 하나의 "액터(actor)"로 취급됩니다.

    Step 2: RGB 카메라 부착하기¶

    센서를 부착하는 과정은 항상 동일한 3단계입니다.

    graph LR A["1️⃣ 센서 Blueprint 찾기"] --> B["2️⃣ 속성 설정하기<br/>(해상도, 위치 등)"] B --> C["3️⃣ 차량에 부착하고<br/>콜백 함수 등록"]
    # RGB 카메라 센서 부착
camera_bp = blueprint_library.find('sensor.camera.rgb')
camera_bp.set_attribute('image_size_x', '800')   # 가로 해상도
camera_bp.set_attribute('image_size_y', '600')   # 세로 해상도
camera_bp.set_attribute('fov', '90')              # 시야각(Field of View)

# 카메라 위치: 차량 지붕 위 (x=앞뒤, z=높이)
camera_transform = carla.Transform(carla.Location(x=1.5, z=2.4))

# 차량에 부착
camera = world.spawn_actor(camera_bp, camera_transform, attach_to=vehicle)

# 데이터 수신 콜백 함수
def rgb_callback(image):
    # 이미지를 numpy 배열로 변환
    array = np.frombuffer(image.raw_data, dtype=np.uint8)
    array = array.reshape((image.height, image.width, 4))  # BGRA 형식
    array = array[:, :, :3]  # BGR만 추출 (알파 채널 제거)
    print(f"[RGB] 프레임 {image.frame}: {array.shape} 크기 이미지 수신")

camera.listen(rgb_callback)

    알아보기: attach_to=vehicle 파라미터가 핵심입니다! 이것이 센서를 차량에 "부착"하는 부분입니다. 차량이 움직이면 센서도 함께 움직입니다.

    Step 3: 시맨틱 세그멘테이션 카메라 부착하기¶

    RGB 카메라와 거의 동일한 코드이지만, blueprint 이름만 다릅니다.

    # 시맨틱 세그멘테이션 카메라
sem_bp = blueprint_library.find('sensor.camera.semantic_segmentation')
sem_bp.set_attribute('image_size_x', '800')
sem_bp.set_attribute('image_size_y', '600')

sem_transform = carla.Transform(carla.Location(x=1.5, z=2.4))
sem_camera = world.spawn_actor(sem_bp, sem_transform, attach_to=vehicle)

def semantic_callback(image):
    # CityScapesPalette 형식으로 저장하면 컬러 분류 이미지가 됨
    image.save_to_disk(f'output/sem_{image.frame:06d}.png',
                       carla.ColorConverter.CityScapesPalette)
    print(f"[Semantic] 프레임 {image.frame}: 세그멘테이션 이미지 저장")

sem_camera.listen(semantic_callback)

    생각해보기: RGB 카메라와 시맨틱 카메라를 같은 위치에 부착했습니다. 왜 같은 위치에 둘까요? 나중에 두 이미지를 픽셀 단위로 정확히 대응시켜 AI 학습 데이터 쌍(pair)으로 사용하기 위해서입니다!

    Step 4: LiDAR 센서 부착하기¶

    # LiDAR 센서
lidar_bp = blueprint_library.find('sensor.lidar.ray_cast')
lidar_bp.set_attribute('channels', '32')            # 레이저 채널 수
lidar_bp.set_attribute('points_per_second', '100000') # 초당 포인트 수
lidar_bp.set_attribute('range', '50')                # 감지 범위 (미터)
lidar_bp.set_attribute('rotation_frequency', '10')   # 초당 회전 수

lidar_transform = carla.Transform(carla.Location(x=0, z=2.5))
lidar = world.spawn_actor(lidar_bp, lidar_transform, attach_to=vehicle)

def lidar_callback(point_cloud):
    # 포인트 클라우드를 numpy 배열로 변환
    data = np.frombuffer(point_cloud.raw_data, dtype=np.float32)
    data = data.reshape((-1, 4))  # 각 포인트: [x, y, z, intensity]
    print(f"[LiDAR] 프레임 {point_cloud.frame}: {data.shape[0]}개 포인트 수신")

lidar.listen(lidar_callback)

    알아보기: channels=32는 레이저 빔이 32줄이라는 뜻입니다. 실제 자율주행 차량의 Velodyne LiDAR는 16, 32, 64, 128채널 등 다양한 모델이 있습니다. 채널이 많을수록 더 정밀하지만 비용도 높아집니다.

    Step 5: 상태 센서 (충돌·GPS) 부착하기¶

    # 충돌 센서
collision_bp = blueprint_library.find('sensor.other.collision')
collision_sensor = world.spawn_actor(collision_bp, carla.Transform(), attach_to=vehicle)

def collision_callback(event):
    other_actor = event.other_actor  # 충돌한 상대 객체
    impulse = event.normal_impulse   # 충격 벡터
    intensity = (impulse.x**2 + impulse.y**2 + impulse.z**2) ** 0.5
    print(f"[충돌!] 대상: {other_actor.type_id}, 강도: {intensity:.1f}")

collision_sensor.listen(collision_callback)

# GNSS (GPS) 센서
gnss_bp = blueprint_library.find('sensor.other.gnss')
gnss_sensor = world.spawn_actor(gnss_bp, carla.Transform(), attach_to=vehicle)

def gnss_callback(gnss_data):
    print(f"[GPS] 위도: {gnss_data.latitude:.6f}, "
          f"경도: {gnss_data.longitude:.6f}, "
          f"고도: {gnss_data.altitude:.2f}")

gnss_sensor.listen(gnss_callback)

    Step 6: 차량 주행 및 데이터 확인¶

    모든 센서를 부착했으니, 차량을 움직여서 데이터가 실제로 수집되는지 확인합니다.

    # 차량에 자동 조종(autopilot) 켜기
vehicle.set_autopilot(True)

# 30초간 데이터 수집
print("\n=== 30초간 데이터 수집 시작 ===\n")
time.sleep(30)

# 정리: 모든 센서와 차량 제거
print("\n=== 수집 종료, 정리 중 ===")
camera.stop()
sem_camera.stop()
lidar.stop()
collision_sensor.stop()
gnss_sensor.stop()

camera.destroy()
sem_camera.destroy()
lidar.destroy()
collision_sensor.destroy()
gnss_sensor.destroy()
vehicle.destroy()

print("모든 액터 제거 완료!")

    ⚠️ 중요: destroy()를 호출하지 않으면 센서와 차량이 시뮬레이터에 계속 남아 메모리를 차지합니다. 프로그램 종료 전 반드시 정리하세요!

    📝 전체 코드¶

    아래는 위의 모든 단계를 하나로 합친 실행 가능한 전체 코드입니다.

    """
CARLA 센서 시스템 실습 - 멀티 센서 데이터 수집
Chapter 7: CARLA 센서 시스템 이해하기
"""
import carla
import numpy as np
import time
import os

# 출력 폴더 생성
os.makedirs('output', exist_ok=True)

# ── 1. CARLA 연결 및 차량 생성 ──
client = carla.Client('localhost', 2000)
client.set_timeout(10.0)
world = client.get_world()

blueprint_library = world.get_blueprint_library()
vehicle_bp = blueprint_library.filter('model3')[0]
spawn_point = world.get_map().get_spawn_points()[0]
vehicle = world.spawn_actor(vehicle_bp, spawn_point)

# 센서 리스트 (나중에 일괄 정리용)
sensor_list = []

# ── 2. RGB 카메라 ──
camera_bp = blueprint_library.find('sensor.camera.rgb')
camera_bp.set_attribute('image_size_x', '800')
camera_bp.set_attribute('image_size_y', '600')
camera_bp.set_attribute('fov', '90')
camera = world.spawn_actor(
    camera_bp,
    carla.Transform(carla.Location(x=1.5, z=2.4)),
    attach_to=vehicle
)
camera.listen(lambda img: img.save_to_disk(f'output/rgb_{img.frame:06d}.png'))
sensor_list.append(camera)

# ── 3. 시맨틱 세그멘테이션 카메라 ──
sem_bp = blueprint_library.find('sensor.camera.semantic_segmentation')
sem_bp.set_attribute('image_size_x', '800')
sem_bp.set_attribute('image_size_y', '600')
sem_camera = world.spawn_actor(
    sem_bp,
    carla.Transform(carla.Location(x=1.5, z=2.4)),
    attach_to=vehicle
)
sem_camera.listen(lambda img: img.save_to_disk(
    f'output/sem_{img.frame:06d}.png',
    carla.ColorConverter.CityScapesPalette
))
sensor_list.append(sem_camera)

# ── 4. LiDAR ──
lidar_bp = blueprint_library.find('sensor.lidar.ray_cast')
lidar_bp.set_attribute('channels', '32')
lidar_bp.set_attribute('points_per_second', '100000')
lidar_bp.set_attribute('range', '50')
lidar = world.spawn_actor(
    lidar_bp,
    carla.Transform(carla.Location(x=0, z=2.5)),
    attach_to=vehicle
)

def save_lidar(point_cloud):
    data = np.frombuffer(point_cloud.raw_data, dtype=np.float32)
    data = data.reshape((-1, 4))
    np.save(f'output/lidar_{point_cloud.frame:06d}.npy', data)

lidar.listen(save_lidar)
sensor_list.append(lidar)

# ── 5. 충돌 센서 ──
col_bp = blueprint_library.find('sensor.other.collision')
col_sensor = world.spawn_actor(col_bp, carla.Transform(), attach_to=vehicle)
col_sensor.listen(lambda e: print(f"[충돌!] {e.other_actor.type_id}"))
sensor_list.append(col_sensor)

# ── 6. GPS 센서 ──
gnss_bp = blueprint_library.find('sensor.other.gnss')
gnss_sensor = world.spawn_actor(gnss_bp, carla.Transform(), attach_to=vehicle)
gnss_sensor.listen(lambda g: print(
    f"[GPS] ({g.latitude:.4f}, {g.longitude:.4f}, {g.altitude:.1f})"
))
sensor_list.append(gnss_sensor)

# ── 7. 주행 및 수집 ──
vehicle.set_autopilot(True)
print("데이터 수집 중... (30초)")

try:
    time.sleep(30)
finally:
    # ── 8. 정리 ──
    for sensor in sensor_list:
        sensor.stop()
        sensor.destroy()
    vehicle.destroy()
    print("정리 완료!")

    ⚠️ 자주 하는 실수¶

    1. 센서를 부착했는데 데이터가 안 나와요 😱

    listen() 호출을 빠뜨리는 경우입니다. 센서를 spawn_actor()로 생성하는 것만으로는 데이터가 수집되지 않습니다. 반드시 .listen(콜백함수)를 호출하여 데이터 수신을 시작해야 합니다.

    # ❌ 이러면 데이터가 수집되지 않음
camera = world.spawn_actor(camera_bp, transform, attach_to=vehicle)

# ✅ listen()까지 호출해야 수집 시작
camera = world.spawn_actor(camera_bp, transform, attach_to=vehicle)
camera.listen(my_callback)  # 이 줄이 필수!

    2. 프로그램을 강제 종료하면 차량·센서가 유령처럼 남아요 👻

    destroy()를 호출하지 않고 프로그램을 종료하면, CARLA 서버에 액터들이 계속 남아있습니다. 이런 경우 아래 코드로 모두 정리할 수 있습니다.

    # 유령 액터 일괄 정리
for actor in world.get_actors().filter('*vehicle*'):
    actor.destroy()
for actor in world.get_actors().filter('*sensor*'):
    actor.destroy()

    3. 이미지 데이터가 BGRA 순서라는 걸 모르고 색상이 이상하게 나와요 🎨

    CARLA의 카메라는 이미지를 BGRA 형식(파랑-초록-빨강-알파)으로 반환합니다. OpenCV는 BGR을 사용하므로 그대로 쓸 수 있지만, matplotlib이나 PIL은 RGB 순서를 기대합니다.

    # matplotlib에서 표시할 때
array = array[:, :, :3]    # BGRA → BGR (알파 제거)
array = array[:, :, ::-1]  # BGR → RGB (채널 순서 반전)
