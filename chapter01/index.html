    챕터 1: 햄스터 로봇 소개와 개발 환경 설정¶

    🎯 이 장에서 배우는 것¶

    • 햄스터 로봇의 주요 부품(모터, 센서, LED 등)의 위치와 역할을 설명할 수 있다
    • 파이썬 개발 환경을 설치하고 햄스터 로봇 라이브러리를 설정할 수 있다
    • 블루투스 동글로 로봇과 컴퓨터를 연결할 수 있다
    • LED를 켜는 테스트 코드를 실행하여 환경 설정이 완료되었는지 확인할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분이 처음 스마트폰을 샀을 때를 떠올려 보세요. 박스를 열고, 전원 버튼이 어디 있는지 찾고, 충전기를 꽂고, Wi-Fi에 연결하는 과정을 거쳐야 비로소 앱을 사용할 수 있었죠? 🎁

    로봇 프로그래밍도 똑같습니다. 아무리 멋진 코드를 작성해도 개발 환경이 준비되지 않으면 로봇은 꿈쩍도 하지 않습니다. 이 장은 앞으로 19개 차시 동안 여러분이 자유롭게 로봇을 제어하기 위한 첫 번째이자 가장 중요한 준비 과정입니다.

    오늘 이 과정을 잘 마치면, 여러분의 햄스터 로봇이 빛을 내며 "나 준비됐어!"라고 인사할 거예요. ✨

    📚 핵심 개념¶

    개념 1: 햄스터 로봇의 하드웨어 구성 🐹¶

    비유로 시작해 볼까요?

    햄스터 로봇을 사람의 몸에 비유해 봅시다. 사람에게 눈(보는 것), 귀(듣는 것), 다리(움직이는 것)가 있듯이, 로봇에도 감지하는 부품(센서) 과 행동하는 부품(액추에이터) 이 있습니다.

    정확한 정의

    햄스터 로봇은 교육용 소형 로봇으로, 다양한 센서와 출력 장치가 하나의 작은 본체에 통합되어 있습니다.

    주요 부품을 살펴봅시다

    graph TB A["🐹 햄스터 로봇"] --> B["감지하는 부품<br/>(센서)"] A --> C["행동하는 부품<br/>(액추에이터)"] B --> B1["📏 근접 센서 x2<br/>전방 좌우 장애물 감지"] B --> B2["💡 바닥 센서 x2<br/>바닥 밝기 감지"] B --> B3["📐 가속도 센서<br/>기울기/충격 감지"] C --> C1["⚙️ DC 모터 x2<br/>좌우 바퀴 회전"] C --> C2["🔴 LED x2<br/>좌우 다양한 색상 표현"] C --> C3["🔊 버저<br/>소리/멜로디 출력"]

    각 부품이 하는 일을 정리하면 이렇습니다

    • 근접 센서 2개 — 로봇 앞쪽 좌우에 위치하며, 적외선을 쏘고 반사되는 양을 측정합니다. 벽이나 손이 가까이 오면 값이 커집니다. 사람의 "눈"과 비슷해요.
    • 바닥 센서 2개 — 로봇 아래쪽 좌우에 위치하며, 바닥의 밝고 어두움을 감지합니다. 검은 선을 따라가는 라인트레이싱에 활용됩니다.
    • 가속도 센서 — 로봇이 기울어지거나 흔들릴 때 이를 감지합니다. 스마트폰을 기울이면 화면이 회전하는 것과 같은 원리입니다.
    • DC 모터 2개 — 좌우 바퀴를 각각 독립적으로 회전시킵니다. 두 바퀴의 속도 차이로 방향 전환이 가능합니다.
    • LED 2개 — 좌우에 하나씩 있으며, 빨강·초록·파랑을 조합해 다양한 색상을 만들어 냅니다.
    • 버저 — 다양한 주파수의 소리를 내어 멜로디를 연주할 수 있습니다.

    개념 2: 개발 환경이란? 🛠️¶

    비유로 시작해 볼까요?

    요리를 하려면 주방(공간), 칼과 도마(도구), 레시피(지식)가 필요하죠. 프로그래밍도 마찬가지입니다. 개발 환경은 코드를 작성하고 실행하기 위한 "주방 세팅"과 같습니다.

    정확한 정의

    개발 환경(Development Environment)이란 프로그램을 작성하고, 테스트하고, 실행하기 위해 필요한 소프트웨어 도구들의 조합을 말합니다.

    우리가 설치할 것들

    • Python (파이썬) — 우리가 사용할 프로그래밍 언어입니다. 로봇에게 "이렇게 해!"라고 명령을 내리는 언어예요.
    • IDLE 또는 VS Code — 코드를 편하게 작성할 수 있는 편집기(IDE)입니다. 메모장에 글을 쓸 수도 있지만, 워드프로세서가 더 편하듯이요.
    • roboid 라이브러리 — 햄스터 로봇과 파이썬을 연결해 주는 전용 도구입니다. 이것이 없으면 파이썬이 햄스터의 "언어"를 이해할 수 없습니다.
    graph LR A["👩‍💻 여러분이<br/>작성한 코드"] --> B["🐍 Python +<br/>roboid 라이브러리"] B --> C["📡 블루투스<br/>동글"] C --> D["🐹 햄스터<br/>로봇"]

    개념 3: 블루투스 통신 📡¶

    비유로 시작해 볼까요?

    친구와 대화할 때 전화기가 필요하듯, 컴퓨터와 로봇이 대화하려면 통신 수단이 필요합니다. 햄스터 로봇은 블루투스라는 무선 통신을 사용합니다.

    정확한 정의

    블루투스(Bluetooth)는 가까운 거리에서 기기 간 데이터를 무선으로 주고받는 통신 기술입니다. 햄스터 로봇은 전용 USB 블루투스 동글을 통해 컴퓨터와 연결됩니다.

    연결 과정 요약

    • USB 동글을 컴퓨터에 꽂으면, 동글이 "중간 번역가" 역할을 합니다
    • 컴퓨터가 보낸 명령을 동글이 블루투스 신호로 변환하여 로봇에 전달합니다
    • 로봇의 센서 데이터도 반대 방향으로 컴퓨터에 전달됩니다

    💬 알아두기: 햄스터 로봇 패키지에는 전용 USB 동글이 포함되어 있습니다. 일반 블루투스 동글과는 다르니 반드시 전용 동글을 사용하세요!

    개념 4: 라이브러리란? 📦¶

    비유로 시작해 볼까요?

    레고 블록을 생각해 보세요. 바퀴, 창문, 지붕 블록이 이미 만들어져 있으니 우리는 그걸 조립만 하면 멋진 집을 만들 수 있죠. 직접 플라스틱을 깎아서 만들 필요가 없습니다.

    정확한 정의

    라이브러리(Library)란 다른 개발자가 미리 만들어 놓은 코드 모음입니다. 우리는 이 코드를 가져다 쓰기만 하면, 복잡한 기능을 간단하게 구현할 수 있습니다.

    예시로 확인

    roboid 라이브러리가 없다면, 블루투스 통신 프로토콜을 직접 구현하고, 바이트 단위로 데이터를 주고받는 코드를 수백 줄 작성해야 합니다. 하지만 라이브러리 덕분에 이렇게 간단해집니다.

    # 라이브러리 없이? → 수백 줄의 블루투스 통신 코드 필요 😱
# 라이브러리 있으면? → 딱 한 줄!
from roboid import *

    이 한 줄로 햄스터 로봇의 모든 기능을 사용할 준비가 끝납니다! 🎉

    🔨 따라하기¶

    이제 직접 개발 환경을 설정해 봅시다. 총 6단계로 진행됩니다.

    Step 1: 파이썬 설치하기 🐍¶

    1-1. 웹 브라우저에서 python.org에 접속합니다.

    1-2. 상단 메뉴에서 Downloads를 클릭하면 현재 운영체제에 맞는 최신 버전 다운로드 버튼이 보입니다.

    1-3. 다운로드된 설치 파일을 실행합니다.

    1-4. ⚠️ 매우 중요! 설치 첫 화면에서 "Add Python to PATH" 체크박스를 반드시 체크하세요! 이걸 빼먹으면 나중에 명령어가 작동하지 않습니다.

    1-5. "Install Now" 를 클릭하고 설치가 완료될 때까지 기다립니다.

    1-6. 설치 확인 — 명령 프롬프트(Windows) 또는 터미널(Mac)을 열고 다음을 입력합니다.

    python --version

    Python 3.x.x 형태의 버전 번호가 출력되면 성공입니다! 🎊

    💬 Mac 사용자: python3 --version으로 입력해야 할 수 있습니다.

    Step 2: roboid 라이브러리 설치하기 📦¶

    명령 프롬프트(또는 터미널)에서 다음 명령어를 입력합니다.

    pip install roboid

    설치가 진행되면서 여러 줄의 텍스트가 출력됩니다. 마지막에 Successfully installed roboid-...라는 메시지가 나오면 성공입니다.

    💬 Mac 사용자: pip3 install roboid로 입력하세요.

    💬 오류가 나면?: pip가 인식되지 않는다는 오류는 Step 1에서 "Add Python to PATH"를 체크하지 않았을 가능성이 높습니다. 파이썬을 제거 후 다시 설치하면서 체크박스를 꼭 확인하세요.

    Step 3: 코드 편집기 준비하기 ✏️¶

    파이썬을 설치하면 IDLE이라는 기본 편집기가 함께 설치됩니다.

    IDLE 실행 방법 - Windows: 시작 메뉴에서 "IDLE" 검색 → 클릭 - Mac: 응용 프로그램 → Python 폴더 → IDLE 클릭

    IDLE이 열리면 File → New File을 클릭해서 새 편집 창을 엽니다. 여기에 코드를 작성하고 저장한 뒤 실행하게 됩니다.

    💬 VS Code를 이미 사용하고 있다면? VS Code도 좋은 선택입니다! 다만 이 교재에서는 별도 설치가 필요 없는 IDLE 기준으로 설명합니다.

    Step 4: 블루투스 동글 연결하기 📡¶

    4-1. 햄스터 로봇 패키지에 포함된 전용 USB 블루투스 동글을 컴퓨터의 USB 포트에 꽂습니다.

    4-2. 동글의 LED가 깜빡이기 시작하면 정상입니다.

    4-3. 햄스터 로봇의 전원 스위치를 켭니다. 로봇 밑면에 있는 작은 스위치를 밀어 주세요.

    4-4. 로봇에 전원이 들어오면 잠시 후 동글의 LED가 깜빡임에서 계속 켜진 상태로 바뀝니다. 이는 로봇과 동글이 연결(페어링)되었다는 뜻입니다.

    💬 연결이 안 되면? 로봇의 배터리를 확인하세요. 충전이 필요할 수 있습니다. 또한 동글과 로봇 사이 거리가 너무 멀면(1m 이상) 연결이 불안정할 수 있습니다.

    Step 5: 첫 번째 테스트 코드 작성하기 💡¶

    드디어 코드를 작성할 시간입니다! IDLE에서 새 파일을 열고 다음 코드를 그대로 입력하세요.

    from roboid import *

hamster = Hamster()

hamster.leds(LED_RED, LED_GREEN)

wait(3000)

    코드를 한 줄씩 이해해 봅시다

    • from roboid import * — roboid 라이브러리의 모든 기능을 가져옵니다
    • hamster = Hamster() — 햄스터 로봇 객체를 만들고 연결합니다. 이 순간 컴퓨터가 로봇을 찾습니다
    • hamster.leds(LED_RED, LED_GREEN) — 왼쪽 LED를 빨간색, 오른쪽 LED를 초록색으로 켭니다
    • wait(3000) — 3000밀리초(3초) 동안 유지합니다. 이 시간 동안 LED가 켜져 있습니다

    파일을 저장합니다. File → Save As → 파일 이름을 test_led.py로 저장하세요.

    ⚠️ 파일 이름에 한글이나 공백을 넣지 마세요! 오류의 원인이 됩니다.

    Step 6: 코드 실행하기 🚀¶

    6-1. IDLE 편집 창에서 Run → Run Module (또는 단축키 F5)을 누릅니다.

    6-2. 잠시 기다리면 콘솔에 연결 메시지가 나타납니다.

    6-3. 햄스터 로봇을 확인하세요!

    • 왼쪽 LED가 빨간색 🔴으로 켜졌나요?
    • 오른쪽 LED가 초록색 🟢으로 켜졌나요?
    • 3초 후에 프로그램이 자동으로 종료되었나요?

    세 가지 모두 확인되었다면 축하합니다! 🎉 개발 환경 설정이 완벽하게 완료되었습니다!

    📝 전체 코드¶

    이 장에서 작성한 최종 코드입니다. 복사해서 바로 실행할 수 있습니다.

    # 챕터 1: 햄스터 로봇 LED 테스트
# 환경 설정이 올바른지 확인하는 코드입니다.

from roboid import *

# 햄스터 로봇에 연결합니다
hamster = Hamster()

# 왼쪽 LED를 빨간색, 오른쪽 LED를 초록색으로 켭니다
hamster.leds(LED_RED, LED_GREEN)

# 3초 동안 유지합니다
wait(3000)

# 프로그램이 끝나면 LED가 자동으로 꺼집니다

    ⚠️ 자주 하는 실수¶

    실수 1: "Add Python to PATH" 체크 깜빡하기 😅¶

    파이썬 설치 시 PATH 옵션을 체크하지 않으면, 명령 프롬프트에서 python이나 pip 명령어를 인식하지 못합니다. "python은(는) 내부 또는 외부 명령이 아닙니다" 라는 오류가 나타나요.

    • 해결법: 파이썬을 제거(제어판 → 프로그램 제거)한 후, 다시 설치하면서 체크박스를 반드시 선택하세요.

    실수 2: 로봇 전원을 안 켜고 코드 실행하기 🔋¶

    코드를 실행했는데 아무 반응이 없다면? 로봇의 전원 스위치가 꺼져 있을 가능성이 높습니다. Hamster() 실행 시 로봇을 찾지 못해 계속 대기 상태에 빠집니다.

    • 해결법: 코드 실행 전에 로봇 전원을 켜고, 동글 LED가 연결 상태(계속 켜짐)인지 확인하세요.

    실수 3: 파일 이름을 roboid.py로 저장하기 🚫¶

    여러분이 만든 파일 이름이 roboid.py이면, 파이썬이 라이브러리 대신 여러분의 파일을 불러오려다 오류가 발생합니다. 라이브러리 이름과 같은 파일 이름은 절대 사용하면 안 됩니다!

    • 해결법: test_led.py, my_hamster.py 등 라이브러리와 겹치지 않는 이름을 사용하세요.

    실수 4: wait() 없이 프로그램이 바로 종료되는 경우 ⏱️¶

    wait(3000)을 빼먹으면 LED가 켜지자마자 프로그램이 끝나면서 LED도 꺼집니다. 너무 빨라서 눈으로 확인할 수 없어요.

    • 해결법: 동작을 확인하고 싶은 시간만큼 wait()을 넣어주세요. 숫자 단위는 밀리초(1000 = 1초)입니다.

# LED_OFF, LED_BLUE, LED_GREEN, LED_CYAN,
# LED_RED, LED_MAGENTA, LED_YELLOW, LED_WHITE

hamster.leds(LED_YELLOW, LED_YELLOW)
wait(1000)
hamster.leds(LED_GREEN, LED_GREEN)
wait(1000)
