    Chapter 8: 자율주행 학습 데이터 수집하기¶

    🎯 이 장에서 배우는 것¶

    • CARLA 자동 파일럿(autopilot)을 활용하여 카메라 이미지와 조향값을 동시에 수집할 수 있다
    • 수집된 데이터를 이미지 파일 + CSV 메타데이터로 체계적으로 저장하는 구조를 설계할 수 있다
    • 직진 편향(straight-driving bias) 문제를 인식하고 데이터 균형을 맞추는 전략을 적용할 수 있다
    • 다양한 환경(날씨·시간대)에서 데이터를 수집하여 강건한 데이터셋을 구성할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    여러분이 운전면허 시험을 준비한다고 상상해보세요. 교재 없이, 영상 없이, 그냥 "운전해봐!"라고 하면 배울 수 있을까요? AI도 마찬가지입니다. AI가 운전을 배우려면 '교재'가 필요합니다. 이 교재가 바로 학습 데이터(training data) 입니다.

    자율주행 AI 모델은 "이 상황에서는 핸들을 얼마나 꺾어야 하는가?"를 배워야 합니다. 이를 위해 필요한 것은 딱 두 가지입니다.

    • 📷 카메라 이미지: 차량 앞에서 보이는 도로 장면
    • 🎯 조향각(steering angle): 그 장면에서 실제로 핸들을 얼마나 돌렸는지

    이 두 가지를 수천, 수만 쌍 모아야 AI가 패턴을 학습할 수 있습니다. 실제 도로에서 이 데이터를 모으려면 차량, 장비, 시간, 비용이 엄청나게 듭니다. 하지만 우리에게는 CARLA 시뮬레이터가 있습니다! 가상 세계에서 안전하고 빠르게, 원하는 만큼 데이터를 수집할 수 있죠.

    이번 장에서는 CARLA에서 자동 파일럿이 운전하는 동안 데이터를 자동으로 기록하는 데이터 수집 파이프라인을 직접 만들어 봅니다.

    📚 핵심 개념¶

    개념 1: 학습 데이터의 구조 — 이미지-조향값 쌍¶

    🎒 비유로 시작하기

    수학 문제집을 떠올려보세요. 왼쪽에는 문제가, 오른쪽에는 정답이 있습니다. AI의 학습 데이터도 같은 구조입니다.

    • 문제(입력): 카메라가 촬영한 도로 이미지
    • 정답(레이블): 그 순간의 조향각 값
    이미지(입력)          →    조향각(정답)
도로가 왼쪽으로 휘는 사진  →    -0.3 (왼쪽으로 꺾기)
직선 도로 사진           →     0.0 (직진)
도로가 오른쪽으로 휘는 사진 →    +0.25 (오른쪽으로 꺾기)

    📖 정확한 정의

    학습 데이터(Training Data) 란 AI 모델이 패턴을 학습하기 위해 사용하는 입력-출력 쌍의 모음입니다. 자율주행에서는 (이미지, 조향각) 쌍이 하나의 데이터 샘플이 되며, 이러한 샘플을 수천~수만 개 모은 것을 데이터셋(dataset) 이라고 합니다.

    ✏️ 예시로 확인

    CARLA에서 수집하는 데이터 하나를 구체적으로 살펴보면 다음과 같습니다.

    • 파일명: frame_000142.png
    • 조향각(steer): -0.1523 (약간 왼쪽)
    • 스로틀(throttle): 0.75 (가속 중)
    • 브레이크(brake): 0.0 (브레이크 미사용)
    • 속도(speed): 28.4 km/h

    이 정보들이 모이면 AI는 "이런 도로에서는 핸들을 이만큼 꺾어야 하는구나"라고 학습하게 됩니다.

    개념 2: 데이터 저장 구조 — 파일 시스템 설계¶

    🎒 비유로 시작하기

    사진을 1만 장 찍었는데, 이름도 없이 한 폴더에 다 넣어두면 어떻게 될까요? 나중에 특정 사진을 찾는 것이 불가능에 가까워집니다. 데이터 수집도 마찬가지로 처음부터 체계적인 정리 체계를 만들어야 합니다.

    📖 정확한 정의

    데이터 저장 구조란 수집된 데이터를 효율적으로 관리하기 위한 폴더·파일 체계입니다. 이미지는 개별 파일로, 메타데이터(조향값, 속도 등)는 CSV 파일 하나에 정리하는 것이 일반적입니다.

    ✏️ 예시로 확인 — 우리가 만들 폴더 구조

    dataset/
├── images/
│   ├── frame_000000.png
│   ├── frame_000001.png
│   ├── frame_000002.png
│   └── ...
└── driving_log.csv

    driving_log.csv 파일 내부는 이런 형태입니다.

    frame,image_path,steer,throttle,brake,speed
0,images/frame_000000.png,0.0,0.8,0.0,25.3
1,images/frame_000001.png,-0.05,0.75,0.0,26.1
2,images/frame_000002.png,-0.12,0.7,0.0,27.8

    알아보기 📘

    CSV(Comma-Separated Values) 란 쉼표로 구분된 텍스트 파일입니다. 엑셀에서 열 수도 있고, Python의 pandas 라이브러리로 쉽게 읽을 수 있어 데이터 과학에서 가장 널리 쓰이는 형식 중 하나입니다.

    개념 3: 데이터 수집 파이프라인¶

    🎒 비유로 시작하기

    공장의 컨베이어 벨트를 생각해보세요. 원재료가 들어가면 자동으로 가공되어 완제품이 나옵니다. 데이터 수집 파이프라인도 마찬가지입니다. CARLA 시뮬레이터에서 주행 → 카메라가 이미지 캡처 → 조향값 기록 → 파일로 저장까지 자동으로 흘러가는 시스템을 만드는 것입니다.

    📖 정확한 정의

    데이터 수집 파이프라인(Data Collection Pipeline) 이란 데이터의 생성부터 저장까지의 전 과정을 자동화한 일련의 처리 흐름입니다.

    우리가 만들 파이프라인의 흐름

    flowchart LR A["🚗 CARLA 차량\n자동 파일럿 모드"] --> B["📷 카메라 센서\n이미지 캡처"] B --> C["📊 차량 제어값 읽기\n조향각, 속도 등"] C --> D["💾 파일 저장\nPNG + CSV"]

    이 파이프라인에서 핵심적인 구성 요소는 세 가지입니다.

    • 자동 파일럿(Autopilot): CARLA에 내장된 AI가 차량을 자동으로 운전합니다. 사람이 직접 조작하지 않아도 데이터가 쌓입니다.
    • 카메라 센서 콜백(Callback): 카메라가 새 이미지를 찍을 때마다 자동으로 호출되는 함수입니다. 여기서 이미지를 저장합니다.
    • 동기화(Synchronization): 이미지와 조향값이 같은 시점의 것인지 확인해야 합니다. 시간이 어긋나면 엉뚱한 데이터가 됩니다.

    개념 4: 데이터 편향(Bias) 문제¶

    🎒 비유로 시작하기

    영어 단어를 공부하는데 단어장의 80%가 "apple"이라면 어떨까요? 시험에서 모르는 단어가 나오면 무조건 "apple"이라고 답하게 될 겁니다. AI도 같은 문제를 겪습니다.

    📖 정확한 정의

    데이터 편향(Data Bias) 이란 데이터셋에서 특정 유형의 데이터가 과도하게 많거나 적어서, 모델이 편향된 예측을 하게 되는 문제입니다. 자율주행에서는 직진 주행 데이터가 압도적으로 많은 것이 대표적인 편향 문제입니다.

    ✏️ 예시로 확인

    실제 도로를 생각해보세요. 대부분의 시간은 직진입니다. 커브나 회전은 전체 주행의 일부에 불과하죠. CARLA에서도 마찬가지입니다.

    pie title 편향된 데이터 분포 (수집 직후) "직진 (steer ≈ 0)" : 75 "좌회전 (steer < -0.1)" : 12 "우회전 (steer > 0.1)" : 13

    이 데이터로 학습하면 AI는 "일단 직진하면 되겠지?" 라고 학습합니다. 커브에서는 제대로 대응하지 못하고 도로를 이탈하게 됩니다.

    해결 전략은 크게 세 가지입니다.

    • ➀ 언더샘플링(Undersampling): 직진 데이터를 일부 삭제하여 비율을 맞춤
    • ➁ 오버샘플링(Oversampling): 커브 데이터를 복제하거나 증강하여 수를 늘림
    • ➂ 가중치 부여(Weighting): 학습 시 커브 데이터에 더 높은 가중치를 줌

    생각해보기 🤔

    직진 데이터를 너무 많이 삭제하면 어떤 문제가 생길 수 있을까요? 직진도 중요한 주행 상황입니다. 데이터 균형을 맞추되, 직진 능력을 잃지 않도록 적절한 비율을 찾는 것이 중요합니다.

    🔨 따라하기¶

    준비 사항¶

    시작하기 전에 다음이 준비되어 있어야 합니다.

    • CARLA 시뮬레이터가 설치되어 실행 중일 것 (이전 챕터에서 완료)
    • Python 3.7 이상
    • 필요한 라이브러리: numpy, opencv-python, pandas
    pip install numpy opencv-python pandas

    Step 1: 프로젝트 폴더 구조 만들기¶

    가장 먼저 데이터를 저장할 폴더를 만듭니다.

    # setup_folders.py
import os

def create_dataset_folders(base_dir="dataset"):
    """데이터셋 저장을 위한 폴더 구조를 생성합니다."""
    images_dir = os.path.join(base_dir, "images")

    # 폴더가 없으면 생성
    os.makedirs(images_dir, exist_ok=True)

    print(f"✅ 데이터셋 폴더 생성 완료!")
    print(f"   기본 폴더: {base_dir}/")
    print(f"   이미지 폴더: {images_dir}/")

    return base_dir, images_dir

if __name__ == "__main__":
    create_dataset_folders()

    이 스크립트를 실행하면 dataset/images/ 폴더가 만들어집니다.

    dataset/
└── images/      ← 여기에 프레임 이미지가 저장됩니다

    Step 2: CARLA 연결 및 차량·카메라 설정¶

    CARLA 시뮬레이터에 연결하고, 차량을 생성하고, 카메라 센서를 부착합니다.

    # collect_data.py - Part 1: CARLA 환경 설정

import carla
import numpy as np
import cv2
import os
import csv
import time
import random

# ─── 기본 설정 ───
DATASET_DIR = "dataset"
IMAGES_DIR = os.path.join(DATASET_DIR, "images")
CSV_PATH = os.path.join(DATASET_DIR, "driving_log.csv")
IMAGE_WIDTH = 320
IMAGE_HEIGHT = 160
FPS = 10  # 초당 저장할 프레임 수

# 폴더 생성
os.makedirs(IMAGES_DIR, exist_ok=True)

def setup_carla():
    """CARLA 서버에 연결하고 차량과 카메라를 생성합니다."""

    # 1) CARLA 서버 연결
    client = carla.Client('localhost', 2000)
    client.set_timeout(10.0)
    world = client.get_world()

    print("✅ CARLA 서버에 연결되었습니다.")

    # 2) 차량 생성
    blueprint_library = world.get_blueprint_library()
    vehicle_bp = blueprint_library.filter('model3')[0]  # Tesla Model 3

    # 랜덤 스폰 포인트에서 차량 생성
    spawn_points = world.get_map().get_spawn_points()
    spawn_point = random.choice(spawn_points)
    vehicle = world.spawn_actor(vehicle_bp, spawn_point)

    print(f"✅ 차량 생성 완료! 위치: {spawn_point.location}")

    # 3) 카메라 센서 부착
    camera_bp = blueprint_library.find('sensor.camera.rgb')
    camera_bp.set_attribute('image_size_x', str(IMAGE_WIDTH))
    camera_bp.set_attribute('image_size_y', str(IMAGE_HEIGHT))
    camera_bp.set_attribute('fov', '110')  # 시야각 110도
    camera_bp.set_attribute('sensor_tick', str(1.0 / FPS))

    # 카메라 위치: 차량 앞쪽 상단 (운전자 시점과 유사)
    camera_transform = carla.Transform(
        carla.Location(x=1.5, z=2.4),  # 앞으로 1.5m, 위로 2.4m
        carla.Rotation(pitch=-15)        # 약간 아래를 봄
    )
    camera = world.spawn_actor(camera_bp, camera_transform, attach_to=vehicle)

    print("✅ 카메라 센서 부착 완료!")

    return client, world, vehicle, camera

    Step 3: 데이터 수집 콜백 함수 만들기¶

    카메라가 새 이미지를 캡처할 때마다 자동으로 호출되는 함수를 만듭니다. 이 함수에서 이미지를 저장하고 조향값을 기록합니다.

    # collect_data.py - Part 2: 데이터 수집 핵심 로직

class DataCollector:
    """카메라 이미지와 차량 제어값을 동시에 수집하는 클래스"""

    def __init__(self, vehicle, images_dir, csv_path):
        self.vehicle = vehicle
        self.images_dir = images_dir
        self.csv_path = csv_path
        self.frame_count = 0
        self.is_collecting = False

        # CSV 파일 초기화 (헤더 작성)
        with open(self.csv_path, 'w', newline='') as f:
            writer = csv.writer(f)
            writer.writerow([
                'frame', 'image_path', 'steer', 
                'throttle', 'brake', 'speed'
            ])

        print("✅ 데이터 수집기 초기화 완료!")

    def camera_callback(self, image):
        """카메라가 새 이미지를 찍을 때마다 호출되는 함수"""

        if not self.is_collecting:
            return

        # 1) CARLA 이미지를 NumPy 배열로 변환
        array = np.frombuffer(image.raw_data, dtype=np.uint8)
        array = array.reshape((IMAGE_HEIGHT, IMAGE_WIDTH, 4))  # BGRA 형식
        rgb_image = array[:, :, :3]  # BGR만 추출 (알파 채널 제거)

        # 2) 현재 차량의 제어값 읽기
        control = self.vehicle.get_control()
        steer = round(control.steer, 4)       # 조향각: -1.0(좌) ~ +1.0(우)
        throttle = round(control.throttle, 4)  # 가속: 0.0 ~ 1.0
        brake = round(control.brake, 4)        # 브레이크: 0.0 ~ 1.0

        # 3) 현재 속도 계산 (m/s → km/h)
        velocity = self.vehicle.get_velocity()
        speed = round(3.6 * np.sqrt(
            velocity.x**2 + velocity.y**2 + velocity.z**2
        ), 2)

        # 4) 이미지 파일 저장
        filename = f"frame_{self.frame_count:06d}.png"
        filepath = os.path.join(self.images_dir, filename)
        cv2.imwrite(filepath, rgb_image)

        # 5) CSV에 메타데이터 기록
        relative_path = os.path.join("images", filename)
        with open(self.csv_path, 'a', newline='') as f:
            writer = csv.writer(f)
            writer.writerow([
                self.frame_count, relative_path, 
                steer, throttle, brake, speed
            ])

        self.frame_count += 1

        # 진행 상황 출력 (100프레임마다)
        if self.frame_count % 100 == 0:
            print(f"📸 {self.frame_count}프레임 수집 완료 "
                  f"| 조향: {steer:+.3f} | 속도: {speed:.1f} km/h")

    def start(self):
        """데이터 수집 시작"""
        self.is_collecting = True
        print("🟢 데이터 수집을 시작합니다!")

    def stop(self):
        """데이터 수집 중지"""
        self.is_collecting = False
        print(f"🔴 데이터 수집 중지! 총 {self.frame_count}프레임 수집됨")

    이 코드의 흐름을 따라가 봅시다

    Step 4: 자동 파일럿으로 데이터 수집 실행¶

    모든 구성 요소를 조합하여 실제로 데이터를 수집합니다.

    # collect_data.py - Part 3: 메인 실행 코드

def main():
    """데이터 수집 메인 함수"""

    actor_list = []  # 정리할 액터 목록

    try:
        # 1) CARLA 환경 설정
        client, world, vehicle, camera = setup_carla()
        actor_list.extend([camera, vehicle])

        # 2) 데이터 수집기 생성
        collector = DataCollector(vehicle, IMAGES_DIR, CSV_PATH)

        # 3) 카메라에 콜백 함수 연결
        camera.listen(collector.camera_callback)

        # 4) 자동 파일럿 활성화
        vehicle.set_autopilot(True)
        print("🤖 자동 파일럿 활성화!")

        # 5) 3초 대기 후 수집 시작 (차량이 안정될 때까지)
        print("⏳ 3초 후 수집을 시작합니다...")
        time.sleep(3)
        collector.start()

        # 6) 지정된 시간 동안 수집
        collection_time = 120  # 2분간 수집
        print(f"⏱️ {collection_time}초 동안 데이터를 수집합니다...")
        time.sleep(collection_time)

        # 7) 수집 중지
        collector.stop()

    finally:
        # 8) 리소스 정리
        print("\n🧹 리소스를 정리합니다...")
        camera.stop()  # 카메라 리스닝 중지
        for actor in actor_list:
            actor.destroy()
        print("✅ 정리 완료!")

if __name__ == "__main__":
    main()
