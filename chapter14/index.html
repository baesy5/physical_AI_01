    Chapter 14: CARLA에서 자율주행 테스트¶

    🎯 이 장에서 배우는 것¶

    • 학습된 딥러닝 모델을 CARLA 시뮬레이터에 연동하여 실시간 자율주행 루프를 구현할 수 있다
    • 카메라 이미지를 모델에 입력하고, 예측된 조향각으로 차량을 제어할 수 있다
    • 차선 이탈, 충돌 횟수, 주행 거리 등 정량적 평가 지표를 설정하고 측정할 수 있다
    • 테스트 결과를 분석하여 모델의 약점을 파악하고 개선 방향을 제시할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기: 드디어 우리가 만든 AI가 직접 운전할 시간입니다! 🚗 과연 잘 달릴까요?

    여러분이 요리를 배웠다고 상상해보세요. 레시피를 외우고(학습), 재료를 준비했지만(데이터 수집), 실제로 요리를 해보기 전까지는 맛이 어떤지 알 수 없습니다. 지금까지 우리는 이미지 데이터를 모으고, 조향각을 예측하는 딥러닝 모델을 훈련시켰습니다. 하지만 진짜 실력은 실전에서 드러납니다.

    이 장에서는 학습된 모델을 CARLA 시뮬레이터에 연결하여 AI가 실시간으로 운전하는 모습을 직접 확인합니다. 잘 달리는 구간도 있고, 실패하는 구간도 있을 것입니다. 중요한 것은 왜 실패했는지 분석하고, 어떻게 개선할지 방향을 잡는 것입니다. 이 과정이 바로 실제 자율주행 엔지니어들이 매일 하는 일입니다.

    📚 핵심 개념¶

    개념 1: 자율주행 추론 루프 (Inference Loop)¶

    🎯 비유로 시작하기

    운전을 배울 때를 떠올려보세요. 눈으로 도로를 보고(카메라 입력) → 머릿속으로 판단하고(모델 추론) → 핸들을 돌리는(차량 제어) 과정을 끊임없이 반복합니다. 1초에도 수십 번 이 과정이 이루어지죠. 자율주행 추론 루프도 정확히 같은 원리입니다.

    📖 정확한 정의

    추론 루프(Inference Loop)란 시뮬레이터에서 카메라 이미지를 받아오고, 학습된 모델이 조향각을 예측하고, 그 값으로 차량을 제어하는 과정을 매 프레임마다 반복하는 실시간 순환 구조입니다.

    flowchart LR A["📷 카메라 이미지 캡처"] --> B["🔄 이미지 전처리"] B --> C["🧠 모델 추론\n(조향각 예측)"] C --> D["🎮 차량 제어\n(스티어링 적용)"] D --> E["🚗 CARLA 시뮬레이션\n한 프레임 진행"] E --> A

    ✅ 예시로 확인

    추론 루프가 초당 10회 실행된다면, 1초 동안 카메라 이미지 10장을 분석하고 10번의 조향 명령을 내리는 것입니다. 이 속도가 너무 느리면 차량이 커브에서 반응이 늦어 차선을 이탈하고, 적절하면 부드럽게 주행합니다.

    알아보기: 추론 루프의 속도를 FPS(Frames Per Second)로 측정합니다. 자율주행 테스트에서는 최소 10 FPS 이상이 권장됩니다. GPU가 있으면 더 빠른 추론이 가능합니다.

    개념 2: 모델-시뮬레이터 연동 파이프라인¶

    🎯 비유로 시작하기

    모델과 시뮬레이터의 연동은 통역사와 비슷합니다. CARLA는 게임 엔진 언어를 쓰고, PyTorch 모델은 텐서(Tensor) 언어를 씁니다. 이 둘 사이에서 이미지를 변환하고 결과를 전달하는 "통역" 코드가 필요합니다.

    📖 정확한 정의

    모델-시뮬레이터 연동 파이프라인이란 CARLA에서 출력하는 원본 이미지를 모델이 요구하는 형식(크기, 정규화 등)으로 변환하고, 모델 출력값을 CARLA의 차량 제어 명령 형식으로 변환하는 전체 데이터 흐름을 말합니다.

    flowchart TD subgraph CARLA["🎮 CARLA 시뮬레이터"] A1["원본 이미지\n800×600 RGB"] A2["차량 제어 API\nVehicleControl"] end subgraph 변환["🔄 변환 계층"] B1["리사이즈\n200×66"] B2["정규화\n0~1 범위"] B3["텐서 변환\nNumPy → Tensor"] end subgraph 모델["🧠 PyTorch 모델"] C1["CNN 추론\n조향각 출력"] end A1 --> B1 --> B2 --> B3 --> C1 C1 -->|"예측 조향각\n예: -0.15"| A2

    핵심 변환 과정 정리

    • 입력 변환: CARLA 이미지(800×600) → 리사이즈(200×66) → 정규화(0~1) → PyTorch 텐서
    • 출력 변환: 모델 예측값(float) → CARLA의 VehicleControl.steer 값(-1.0 ~ 1.0)

    알아보기: 전처리 과정은 반드시 학습할 때 사용한 것과 동일해야 합니다. 학습 시 이미지를 200×66으로 리사이즈했다면, 추론 시에도 같은 크기로 리사이즈해야 합니다. 이것이 다르면 모델이 엉뚱한 예측을 합니다.

    개념 3: 정량적 평가 지표¶

    🎯 비유로 시작하기

    운전면허 시험을 생각해보세요. "잘 달렸다"라는 막연한 평가가 아니라 "차선 이탈 3회, 신호 위반 0회, 합격"처럼 숫자로 된 기준이 있습니다. 자율주행 모델도 마찬가지입니다.

    📖 정확한 정의

    정량적 평가 지표(Quantitative Metrics)란 자율주행 모델의 성능을 객관적인 숫자로 측정하는 기준입니다. 감이 아니라 데이터에 기반하여 모델이 얼마나 잘 주행하는지 판단합니다.

    주요 평가 지표

    • 🛣️ 주행 거리(Distance Traveled): 충돌 없이 자율주행한 총 거리(미터). 길수록 좋음
    • 💥 충돌 횟수(Collision Count): 다른 차량, 보행자, 구조물과 충돌한 횟수. 0이 이상적
    • ↔️ 차선 이탈 횟수(Lane Invasion Count): 차선 경계를 넘어간 횟수. 적을수록 좋음
    • 📏 평균 중앙 편차(Mean Center Deviation): 차선 중앙에서 얼마나 벗어났는지의 평균값
    flowchart LR subgraph 입력["📊 측정 데이터"] M1["충돌 감지 센서"] M2["차선 이탈 감지 센서"] M3["GPS/위치 센서"] end subgraph 지표["📈 평가 지표"] R1["충돌 횟수: 2회"] R2["차선 이탈: 5회"] R3["주행 거리: 1,200m"] R4["종합 점수: 75점"] end M1 --> R1 M2 --> R2 M3 --> R3 R1 & R2 & R3 --> R4

    정리하기: 하나의 지표만으로는 모델을 평가할 수 없습니다. 주행 거리가 길어도 차선 이탈이 많다면 좋은 모델이 아닙니다. 여러 지표를 종합적으로 판단해야 합니다.

    개념 4: 실패 분석과 반복적 개선¶

    🎯 비유로 시작하기

    시험을 보고 나서 틀린 문제를 그냥 넘기면 다음 시험에서도 같은 문제를 틀립니다. 오답 노트를 작성하고 약점을 보강해야 성적이 오르죠. 자율주행도 마찬가지입니다. 실패 장면을 기록하고, 원인을 분석하고, 데이터나 모델을 수정하는 반복적 개선(Iterative Improvement) 과정이 핵심입니다.

    📖 정확한 정의

    반복적 개선이란 테스트 → 실패 분석 → 원인 파악 → 개선(데이터 보강 또는 모델 수정) → 재테스트의 사이클을 반복하여 모델 성능을 점진적으로 향상시키는 프로세스입니다.

    flowchart TD A["🚗 자율주행 테스트"] --> B["📊 결과 기록\n영상, 지표, 로그"] B --> C{"❌ 실패 발생?"} C -->|"예"| D["🔍 원인 분석\n어디서, 왜 실패?"] D --> E["💡 개선 전략 수립"] E --> F{"어떤 유형?"} F -->|"데이터 부족"| G["📸 데이터 보강\n해당 시나리오 추가 수집"] F -->|"모델 한계"| H["🧠 모델 수정\n구조 변경, 하이퍼파라미터 조정"] F -->|"전처리 문제"| I["🔧 파이프라인 수정"] G & H & I --> J["🔄 재학습"] --> A C -->|"아니오"| K["✅ 배포 준비"]

    흔한 실패 유형과 개선 방향

    • 급커브에서 차선 이탈 → 커브 구간 데이터 추가 수집
    • 그림자 지역에서 오작동 → 다양한 조명 조건의 데이터 보강
    • 직진만 하려는 경향 → 데이터 불균형 해소 (직진 데이터가 너무 많은 경우)

    🔨 따라하기¶

    이 실습에서는 이전 장에서 학습한 CNN 모델을 CARLA에 연동하여 실시간 자율주행을 테스트합니다.

    Step 1: 사전 준비 — 학습된 모델 로드¶

    먼저 학습이 완료된 모델 파일(.pth)을 불러옵니다. 이전 장에서 저장한 모델을 사용합니다.

    import torch
import torch.nn as nn
import numpy as np
import cv2
import time

# 이전 장에서 정의한 것과 동일한 모델 구조
class DrivingModel(nn.Module):
    def __init__(self):
        super(DrivingModel, self).__init__()
        self.conv_layers = nn.Sequential(
            nn.Conv2d(3, 24, kernel_size=5, stride=2),
            nn.ReLU(),
            nn.Conv2d(24, 36, kernel_size=5, stride=2),
            nn.ReLU(),
            nn.Conv2d(36, 48, kernel_size=5, stride=2),
            nn.ReLU(),
            nn.Conv2d(48, 64, kernel_size=3),
            nn.ReLU(),
            nn.Conv2d(64, 64, kernel_size=3),
            nn.ReLU(),
        )
        self.fc_layers = nn.Sequential(
            nn.Linear(64 * 1 * 18, 100),
            nn.ReLU(),
            nn.Linear(100, 50),
            nn.ReLU(),
            nn.Linear(50, 10),
            nn.ReLU(),
            nn.Linear(10, 1),  # 조향각 1개 출력
        )

    def forward(self, x):
        x = self.conv_layers(x)
        x = x.view(x.size(0), -1)  # Flatten
        x = self.fc_layers(x)
        return x

# 모델 로드
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = DrivingModel().to(device)
model.load_state_dict(torch.load("driving_model.pth", map_location=device))
model.eval()  # 추론 모드로 전환 (중요!)

print(f"모델 로드 완료! 디바이스: {device}")

    알아보기: model.eval()을 호출하는 것은 매우 중요합니다. 이것을 빠뜨리면 Dropout이나 BatchNorm 같은 레이어가 학습 모드로 동작하여 예측 결과가 불안정해집니다.

    Step 2: CARLA 연결 및 차량·센서 설정¶

    CARLA 서버에 연결하고, 자율주행을 테스트할 차량과 카메라 센서를 설정합니다.

    import carla
import random

# CARLA 서버 연결
client = carla.Client('localhost', 2000)
client.set_timeout(10.0)
world = client.get_world()

# 동기 모드 설정 (프레임 단위 제어를 위해 필수)
settings = world.get_settings()
settings.synchronous_mode = True
settings.fixed_delta_seconds = 0.1  # 10 FPS
world.apply_settings(settings)

# 차량 스폰 (생성)
blueprint_library = world.get_blueprint_library()
vehicle_bp = blueprint_library.filter('model3')[0]  # Tesla Model 3
spawn_points = world.get_map().get_spawn_points()
spawn_point = random.choice(spawn_points)
vehicle = world.spawn_actor(vehicle_bp, spawn_point)

print(f"차량 생성 완료! 위치: {spawn_point.location}")

# 카메라 센서 부착
camera_bp = blueprint_library.find('sensor.camera.rgb')
camera_bp.set_attribute('image_size_x', '800')
camera_bp.set_attribute('image_size_y', '600')
camera_bp.set_attribute('fov', '90')

# 카메라 위치: 차량 앞쪽 위에 부착
camera_transform = carla.Transform(carla.Location(x=1.5, z=2.4))
camera = world.spawn_actor(camera_bp, camera_transform, attach_to=vehicle)

latest_image = None

def process_image(image):
    """CARLA 카메라 콜백: 이미지를 NumPy 배열로 변환"""
    global latest_image
    array = np.frombuffer(image.raw_data, dtype=np.uint8)
    array = array.reshape((600, 800, 4))  # BGRA 형식
    latest_image = array[:, :, :3]  # BGR만 사용 (알파 채널 제거)

camera.listen(process_image)

    알아보기: synchronous_mode = True로 설정하면 world.tick()을 호출할 때만 시뮬레이션이 한 프레임 진행됩니다. 비동기 모드에서는 시뮬레이터가 멈추지 않고 계속 돌아가기 때문에, 모델 추론이 느리면 프레임을 놓칠 수 있습니다. 동기 모드가 테스트에 더 안정적입니다.

    Step 3: 이미지 전처리 함수 구현¶

    CARLA에서 받은 원본 이미지를 모델이 이해할 수 있는 형식으로 변환합니다. 학습 시 사용한 전처리와 반드시 동일해야 합니다.

    def preprocess_image(image):
    """
    CARLA 원본 이미지를 모델 입력 형식으로 변환
    학습 시 전처리와 동일하게 적용해야 함!
    """
    # 1. 관심 영역 자르기 (하늘 부분 제거)
    # 상단 200px(하늘)과 하단 80px(차량 보닛) 제거
    cropped = image[200:520, :, :]

    # 2. 리사이즈 (학습 시 사용한 크기와 동일: 200x66)
    resized = cv2.resize(cropped, (200, 66))

    # 3. 색상 변환 (BGR → RGB, 학습 데이터와 일치)
    rgb = cv2.cvtColor(resized, cv2.COLOR_BGR2RGB)

    # 4. 정규화 (0~255 → 0.0~1.0)
    normalized = rgb.astype(np.float32) / 255.0

    # 5. PyTorch 텐서 변환 (H, W, C) → (C, H, W)
    tensor = torch.from_numpy(normalized).permute(2, 0, 1)

    # 6. 배치 차원 추가 (C, H, W) → (1, C, H, W)
    tensor = tensor.unsqueeze(0).to(device)

    return tensor

    이 과정을 그림으로 정리하면 다음과 같습니다.

    flowchart LR A["원본 이미지\n800×600 BGR"] --> B["관심 영역 자르기\n800×320"] B --> C["리사이즈\n200×66"] C --> D["BGR → RGB"] D --> E["정규화\n0.0 ~ 1.0"] E --> F["텐서 변환\n(1, 3, 66, 200)"]

    Step 4: 평가 지표 수집을 위한 센서 설정¶

    충돌과 차선 이탈을 자동으로 감지하는 CARLA 내장 센서를 활용합니다.

    # 평가 지표 저장용 클래스
class DrivingMetrics:
    def __init__(self):
        self.collision_count = 0
        self.lane_invasion_count = 0
        self.start_location = None
        self.total_distance = 0.0
        self.prev_location = None
        self.collision_log = []      # 충돌 상세 기록
        self.lane_invasion_log = []  # 차선 이탈 상세 기록
        self.frame_count = 0

    def on_collision(self, event):
        """충돌 발생 시 호출되는 콜백"""
        self.collision_count += 1
        other_actor = event.other_actor.type_id
        self.collision_log.append({
            'frame': self.frame_count,
            'object': other_actor,
            'intensity': event.normal_impulse
        })
        print(f"💥 충돌 감지! 대상: {other_actor} (총 {self.collision_count}회)")

    def on_lane_invasion(self, event):
        """차선 이탈 시 호출되는 콜백"""
        self.lane_invasion_count += 1
        lane_types = [str(lt) for lt in event.crossed_lane_markings]
        self.lane_invasion_log.append({
            'frame': self.frame_count,
            'lane_types': lane_types
        })
        print(f"↔️ 차선 이탈! (총 {self.lane_invasion_count}회)")

    def update_distance(self, current_location):
        """매 프레임 주행 거리 업데이트"""
        if self.prev_location is not None:
            dx = current_location.x - self.prev_location.x
            dy = current_location.y - self.prev_location.y
            self.total_distance += (dx**2 + dy**2)**0.5
        self.prev_location = current_location
        self.frame_count += 1

    def get_summary(self):
        """결과 요약 출력"""
        print("\n" + "=" * 50)
        print("📊 자율주행 테스트 결과 요약")
        print("=" * 50)
        print(f"🛣️ 총 주행 거리: {self.total_distance:.1f}m")
        print(f"💥 충돌 횟수: {self.collision_count}회")
        print(f"↔️ 차선 이탈 횟수: {self.lane_invasion_count}회")
        print(f"🖼️ 총 프레임 수: {self.frame_count}")
        if self.total_distance > 0:
            score = max(0, 100 - self.collision_count * 20
                        - self.lane_invasion_count * 5)
            print(f"⭐ 종합 점수: {score}/100")
        print("=" * 50)

# 평가 지표 인스턴스 생성
metrics = DrivingMetrics()

# 충돌 감지 센서

                                      carla.Transform(),

    Step 5: 자율주행 루프 실행 — AI가 직접 운전하다! 🚗¶

    이제 모든 준비가 끝났습니다. 모델이 직접 운전하는 자율주행 루프를 실행합니다.

    def run_autonomous_driving(duration_seconds=120):
    """
    자율주행 테스트 실행

    Args:
        duration_seconds: 테스트 시간 (초)
    """
    print("\n🚀 자율주행 테스트 시작!")
    print(f"⏱️ 테스트 시간: {duration_seconds}초\n")

    start_time = time.time()
    frame_times = []  # FPS 계산용

    try:
        while (time.time() - start_time) < duration_seconds:
            frame_start = time.time()

            # 1. 시뮬레이션 한 프레임 진행
            world.tick()

            # 2. 카메라 이미지가 준비될 때까지 대기
            if latest_image is None:
                continue

            # 3. 이미지 전처리
            input_tensor = preprocess_image(latest_image)

            # 4. 모델 추론 (기울기 계산 불필요 → 메모리 절약)
            with torch.no_grad():
                steering_pred = model(input_tensor)
                steering_angle = steering_pred.item()

            # 5. 조향각 범위 제한 (-1.0 ~ 1.0)
            steering_angle = max(-1.0, min(1.0, steering_angle))

            # 6. 차량 제어 명령 전송
            control = carla.VehicleControl()
            control.steer = steering_angle       # 모델이 예측한 조향각
            control.throttle = 0.4               # 일정 속도 유지
            control.brake = 0.0
            vehicle.apply_control(control)

            # 7. 평가 지표 업데이트
            location = vehicle.get_location()
            metrics.update_distance(location)

            # 8. FPS 계산 및 상태 출력 (10프레임마다)
            frame_time = time.time() - frame_start
            frame_times.append(frame_time)

            if metrics.frame_count % 10 == 0:
                avg_fps = 1.0 / np.mean(frame_times[-10:])
                elapsed = time.time() - start_time
                print(f"[{elapsed:.0f}s] 조향: {steering_angle:+.3f} | "
                      f"거리: {metrics.total_distance:.0f}m | "
                      f"FPS: {avg_fps:.1f}")

    except KeyboardInterrupt:
        print("\n⚠️ 사용자가 테스트를 중단했습니다.")

    finally:
        # 차량 정지
        vehicle.apply_control(carla.VehicleControl(brake=1.0))
        print("\n🛑 차량 정지")

    # 결과 요약 출력
    metrics.get_summary()

    return metrics

# 자율주행 실행! (2분 테스트)
test_results = run_autonomous_driving(duration_seconds=120)

    생각해보기: throttle = 0.4로 고정한 이유는 무엇일까요? 이 값을 높이면 속도가 빨라지는데, 모델의 반응 시간은 그대로이므로 커브에서 더 많이 실패할 가능성이 높아집니다. 실제 자율주행에서는 속도도 모델이 예측하게 합니다.
