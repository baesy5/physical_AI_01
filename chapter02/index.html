    앞으로, 뒤로, 회전! – 모터 제어의 기초¶

    🎯 이 장에서 배우는 것¶

    • 왼쪽·오른쪽 모터의 속도 값을 조절하여 로봇을 전진, 후진, 정지시킬 수 있다
    • 좌회전과 우회전의 원리를 이해하고 코드로 구현할 수 있다
    • time 모듈을 활용하여 로봇의 동작 시간을 제어할 수 있다
    • 여러 동작을 연결하여 정사각형 경로로 이동하는 프로그램을 작성할 수 있다

    💡 왜 이걸 배우나요?¶

    지난 시간에 햄스터 로봇과 처음 만나서 연결하는 법을 배웠죠? 이제 본격적으로 로봇을 내 마음대로 움직여 볼 차례입니다! 🎮

    생각해 보세요. 자동차를 운전할 때 가장 먼저 배우는 게 뭔가요? 바로 전진, 후진, 회전, 정지입니다. 로봇도 마찬가지예요. 이 네 가지만 자유자재로 다룰 수 있으면, 나중에 장애물을 피하거나 미로를 탈출하는 똑똑한 로봇도 만들 수 있습니다.

    이번 시간이 끝나면, 여러분은 로봇에게 "앞으로 2초 가다가 왼쪽으로 돌아!" 같은 명령을 코드로 내릴 수 있게 됩니다. 꽤 멋지지 않나요? 😎

    📚 핵심 개념¶

    개념 1: 두 바퀴의 비밀 – 차동 구동¶

    🎳 비유로 시작해요

    쇼핑카트를 밀어본 적 있나요? 쇼핑카트는 네 바퀴가 같은 속도로 움직이기 때문에 방향을 바꾸려면 손잡이를 꺾어야 합니다. 하지만 휠체어를 생각해 보세요. 왼쪽 바퀴와 오른쪽 바퀴를 각각 따로 돌릴 수 있죠? 왼쪽만 빠르게 돌리면 오른쪽으로 꺾이고, 오른쪽만 빠르게 돌리면 왼쪽으로 꺾입니다.

    정확한 정의: 햄스터 로봇은 왼쪽 바퀴와 오른쪽 바퀴에 각각 독립된 모터가 있습니다. 두 모터의 속도 조합으로 전진, 후진, 회전을 모두 만들어내는 방식을 차동 구동(Differential Drive)이라고 합니다.

    예시로 확인:

    • 양쪽 바퀴 같은 속도 → 직진! 🏃
    • 한쪽만 회전 → 그 반대쪽으로 회전! 🔄
    • 양쪽 반대 방향 → 제자리 회전! 💫
    graph LR A["왼쪽 30 + 오른쪽 30"] --> B["⬆️ 직진"] C["왼쪽 0 + 오른쪽 30"] --> D["↩️ 좌회전"] E["왼쪽 30 + 오른쪽 0"] --> F["↪️ 우회전"] G["왼쪽 -30 + 오른쪽 -30"] --> H["⬇️ 후진"]

    개념 2: 속도 값의 의미¶

    🎚️ 비유로 시작해요

    에어컨 리모컨의 온도 설정을 떠올려 보세요. 18도부터 30도까지 숫자로 세기를 조절하죠? 모터 속도도 비슷합니다. 숫자로 "얼마나 빠르게 돌릴지"를 지정합니다.

    정확한 정의: 햄스터 로봇의 모터 속도는 -100부터 100까지의 정수로 설정합니다.

    • 양수(+): 앞으로 회전 (전진 방향)
    • 음수(-): 뒤로 회전 (후진 방향)
    • 0: 정지

    예시로 확인:

    • 30 → 적당한 속도로 앞으로
    • 100 → 최고 속도로 앞으로 (꽤 빠릅니다!)
    • -30 → 적당한 속도로 뒤로
    • 0 → 멈춤

    💡 팁: 처음에는 30~50 정도의 속도로 시작하세요. 100은 생각보다 빨라서 로봇이 책상에서 떨어질 수 있어요! ⚠️

    개념 3: time.sleep() – 동작 시간 조절하기¶

    ⏰ 비유로 시작해요

    요리할 때 "중불에서 3분간 볶으세요"라는 레시피를 따르죠? 로봇에게도 마찬가지로 "앞으로 2초간 가세요"라고 알려줘야 합니다. 시간을 지정하지 않으면 로봇이 언제 멈춰야 할지 모르니까요.

    정확한 정의: time.sleep(초) 함수는 프로그램을 지정한 시간(초 단위)만큼 일시 정지시킵니다. 이 동안 로봇은 마지막으로 받은 명령을 계속 수행합니다.

    예시로 확인:

    import time

# "2초 동안 기다려라"는 뜻
time.sleep(2)

# 0.5초(반 초)도 가능!
time.sleep(0.5)

    로봇 제어의 기본 패턴은 항상 이 세 단계입니다:

    graph LR A["1️⃣ 명령 내리기<br/>모터 속도 설정"] --> B["2️⃣ 기다리기<br/>time.sleep()"] --> C["3️⃣ 다음 동작<br/>정지 또는 변경"]

    개념 4: 회전의 두 가지 방법¶

    🔄 비유로 시작해요

    운동장에서 친구와 손을 잡고 도는 걸 상상해 보세요. 한 명이 제자리에 서 있고 다른 한 명이 돌면 큰 원을 그립니다. 반면에 두 명이 반대 방향으로 움직이면 제자리에서 빙글 돌죠!

    정확한 정의: 햄스터 로봇의 회전에는 두 가지 방식이 있습니다.

    한쪽 바퀴 회전 (피벗 턴) - 한쪽 모터만 작동, 다른 쪽은 0 - 넓은 호를 그리며 회전 - 예: 왼쪽=0, 오른쪽=30 → 왼쪽으로 부드럽게 회전

    양쪽 반대 방향 회전 (스핀 턴) - 양쪽 모터가 반대 방향으로 작동 - 제자리에서 빠르게 회전 - 예: 왼쪽=-30, 오른쪽=30 → 제자리에서 왼쪽으로 회전

    graph TB subgraph 피벗턴["🔄 피벗 턴 (한쪽 정지)"] P1["왼쪽: 0"] --- P2["오른쪽: 30"] P3["➡️ 왼쪽으로 넓게 회전"] end subgraph 스핀턴["💫 스핀 턴 (반대 방향)"] S1["왼쪽: -30"] --- S2["오른쪽: 30"] S3["➡️ 제자리에서 왼쪽 회전"] end

    🔨 따라하기¶

    자, 이제 직접 코드를 작성하면서 로봇을 움직여 봅시다! 🚀

    Step 1: 전진과 정지¶

    로봇을 2초간 앞으로 이동시킨 후 멈추는 가장 기본적인 코드입니다.

    from roboid import *

hamster = Hamster()

import time

# 전진! 양쪽 바퀴 모두 30의 속도로
hamster.wheels(30, 30)
time.sleep(2)

# 정지! 양쪽 바퀴 모두 0으로
hamster.wheels(0, 0)

    코드를 실행해 보세요. 로봇이 앞으로 쭉 나가다가 2초 후 멈추나요? 성공입니다! 🎉

    🔍 코드 해설: hamster.wheels(왼쪽속도, 오른쪽속도) – 이 한 줄이 핵심입니다. 괄호 안의 첫 번째 숫자가 왼쪽 바퀴, 두 번째 숫자가 오른쪽 바퀴의 속도예요.

    Step 2: 후진해 보기¶

    이번엔 뒤로 가 봅시다. 속도 값을 음수(-)로 바꾸면 됩니다!

    from roboid import *

hamster = Hamster()

import time

# 후진! 양쪽 바퀴 모두 -30
hamster.wheels(-30, -30)
time.sleep(2)

# 정지
hamster.wheels(0, 0)

    로봇이 뒤로 물러나죠? 양수는 전진, 음수는 후진. 정말 간단하죠! 😊

    Step 3: 좌회전과 우회전¶

    이제 방향을 바꿔봅시다. 한쪽 바퀴만 돌려볼게요.

    from roboid import *

hamster = Hamster()

import time

# 좌회전: 왼쪽 바퀴 정지, 오른쪽 바퀴만 전진
hamster.wheels(0, 30)
time.sleep(1)

# 정지
hamster.wheels(0, 0)
time.sleep(1)

# 우회전: 왼쪽 바퀴만 전진, 오른쪽 바퀴 정지
hamster.wheels(30, 0)
time.sleep(1)

# 정지
hamster.wheels(0, 0)

    🤔 왜 왼쪽 바퀴를 멈추면 왼쪽으로 도나요? 오른쪽 바퀴만 앞으로 나가니까, 로봇이 멈춰있는 왼쪽 바퀴를 중심으로 왼쪽 방향으로 꺾이는 거예요. 마치 한쪽 발을 고정하고 도는 것처럼요!

    Step 4: 제자리 회전 (스핀!)¶

    양쪽 바퀴를 반대 방향으로 돌려서 제자리 회전을 해봅시다.

    from roboid import *

hamster = Hamster()

import time

# 제자리 좌회전: 왼쪽 뒤로, 오른쪽 앞으로
hamster.wheels(-30, 30)
time.sleep(1)

# 정지
hamster.wheels(0, 0)
time.sleep(1)

# 제자리 우회전: 왼쪽 앞으로, 오른쪽 뒤로
hamster.wheels(30, -30)
time.sleep(1)

# 정지
hamster.wheels(0, 0)

    피벗 턴보다 훨씬 빠르게, 좁은 공간에서도 방향을 바꿀 수 있어요! 💫

    Step 5: 동작 연결하기 – 전진 후 회전¶

    여러 동작을 이어 붙여서 로봇이 앞으로 갔다가 왼쪽으로 도는 프로그램을 만들어 봅시다.

    from roboid import *

hamster = Hamster()

import time

# 1. 전진 2초
hamster.wheels(30, 30)
time.sleep(2)

# 2. 제자리 좌회전 0.5초
hamster.wheels(-30, 30)
time.sleep(0.5)

# 3. 다시 전진 2초
hamster.wheels(30, 30)
time.sleep(2)

# 4. 정지
hamster.wheels(0, 0)

    보이시죠? 명령 → 대기 → 명령 → 대기 패턴이 반복됩니다. 이 패턴만 기억하면 어떤 경로든 만들 수 있어요!

    graph LR A["⬆️ 전진 2초"] --> B["↩️ 좌회전 0.5초"] --> C["⬆️ 전진 2초"] --> D["🛑 정지"]

    Step 6: 🏆 도전! 정사각형 그리기¶

    드디어 이번 장의 하이라이트! 로봇이 정사각형 경로를 따라 이동하게 만들어 봅시다.

    정사각형은 "전진 → 90도 회전"을 4번 반복하면 됩니다.

    💡 90도 회전 시간 찾기: 로봇마다, 바닥 재질마다 회전 시간이 조금씩 다릅니다. time.sleep() 안의 숫자를 조금씩 바꿔가며 약 90도가 되는 시간을 찾아보세요. 대략 0.5초 전후가 될 거예요.

    from roboid import *

hamster = Hamster()

import time

# 정사각형 한 변 이동 + 90도 회전을 4번 반복
for i in range(4):
    # 전진 1초
    hamster.wheels(30, 30)
    time.sleep(1)

    # 제자리 우회전 (약 90도)
    hamster.wheels(30, -30)
    time.sleep(0.5)

# 정지
hamster.wheels(0, 0)

    🔍 for i in range(4):가 뭔가요? "아래 들여쓴 코드를 4번 반복해!"라는 뜻이에요. 같은 코드를 네 번 복사해서 쓰는 것보다 훨씬 깔끔하죠? 반복문에 대해서는 뒤에서 자세히 배울 거예요. 지금은 "4번 반복하는구나!" 정도만 이해하면 충분합니다. 😊

    로봇이 정확한 정사각형을 그리지 못해도 괜찮아요! time.sleep() 안의 숫자를 조금씩 조절해 보면서 여러분만의 정사각형을 완성해 보세요. 이 시행착오 과정 자체가 진짜 공부입니다. 🧪

    📝 전체 코드¶

    이번 장에서 가장 중요한 정사각형 그리기 전체 코드를 정리합니다.

    # chapter02_square.py
# 햄스터 로봇으로 정사각형 경로 이동하기

from roboid import *

hamster = Hamster()

import time

print("정사각형 경로를 시작합니다!")

for i in range(4):
    print(f"{i+1}번째 변 이동 중...")

    # 전진
    hamster.wheels(30, 30)
    time.sleep(1)

    # 우회전 (약 90도)
    hamster.wheels(30, -30)
    time.sleep(0.5)  # 이 값을 조절해서 90도를 맞춰보세요!

# 정지
hamster.wheels(0, 0)
print("정사각형 완성! 🎉")

    ⚠️ 자주 하는 실수¶

    실수 1: 정지를 깜빡하는 경우 🏃‍♂️💨¶

    # ❌ 잘못된 코드 – 로봇이 영원히 달린다!
hamster.wheels(30, 30)
time.sleep(2)
# 여기서 끝나면 로봇은 계속 전진...

    # ✅ 올바른 코드 – 반드시 마지막에 정지!
hamster.wheels(30, 30)
time.sleep(2)
hamster.wheels(0, 0)  # 꼭 멈춰주세요!

    프로그램이 끝나도 로봇은 마지막 명령을 기억하고 있을 수 있어요. 항상 마지막에 hamster.wheels(0, 0)으로 정지시키는 습관을 들이세요!

    실수 2: 왼쪽과 오른쪽을 헷갈리는 경우 🔄¶

    # "왼쪽으로 돌고 싶은데 오른쪽으로 돌아요!"
# 왼쪽 바퀴가 첫 번째, 오른쪽 바퀴가 두 번째입니다.

# ❌ 헷갈림
hamster.wheels(30, 0)  # 이건 우회전!

# ✅ 좌회전을 하려면
hamster.wheels(0, 30)  # 왼쪽=0, 오른쪽=30 → 좌회전!

    기억법: "왼쪽 바퀴를 멈추면 왼쪽으로, 오른쪽 바퀴를 멈추면 오른쪽으로" 🧠

    실수 3: time.sleep() 없이 명령을 연달아 쓰는 경우 ⚡¶

    # ❌ 잘못된 코드 – 전진이 무시되고 바로 회전!
hamster.wheels(30, 30)    # 전진 명령
hamster.wheels(-30, 30)   # 즉시 회전 명령으로 덮어씌워짐!

    # ✅ 올바른 코드 – sleep으로 전진 시간 확보
hamster.wheels(30, 30)
time.sleep(2)             # 2초간 전진 유지!
hamster.wheels(-30, 30)
time.sleep(0.5)

    time.sleep()이 없으면 컴퓨터가 너무 빨리 다음 줄로 넘어가서, 첫 번째 명령이 실행될 틈이 없어요. 명령과 명령 사이에는 반드시 time.sleep()을 넣어주세요!

    ✅ 스스로 점검하기¶

    아래 질문에 답해보며 이번 장의 내용을 잘 이해했는지 확인해 보세요!

    1. hamster.wheels(30, 30)을 실행하면 로봇은 어떻게 움직이나요?

    정답: 양쪽 바퀴가 같은 속도(30)로 전진하므로, 로봇이 앞으로 직진합니다.

    2. 로봇을 후진시키려면 어떤 코드를 써야 하나요?

    정답: hamster.wheels(-30, -30) – 양쪽 모두 음수 값을 줍니다.

    3. hamster.wheels(0, 30)을 실행하면 어느 방향으로 회전하나요?

    정답: 왼쪽 바퀴는 멈추고 오른쪽 바퀴만 전진하므로, 왼쪽(좌회전)으로 회전합니다.

    4. 제자리 우회전을 하려면 어떤 코드를 써야 하나요?

    정답: hamster.wheels(30, -30) – 왼쪽은 앞으로, 오른쪽은 뒤로 돌립니다.

    5. time.sleep(2)과 time.sleep(0.5)의 차이는 무엇인가요?

    정답: time.sleep(2)는 2초 대기, time.sleep(0.5)는 0.5초(반 초) 대기입니다.
