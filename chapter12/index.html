    Chapter 12: End-to-End 자율주행 모델 설계¶

    🎯 이 장에서 배우는 것¶

    • End-to-End 학습의 개념과 전통적 자율주행 방식과의 차이를 설명할 수 있다
    • NVIDIA PilotNet 아키텍처의 구조와 각 레이어의 역할을 이해할 수 있다
    • 카메라 이미지 → 조향각을 예측하는 회귀 모델을 Keras로 직접 구현할 수 있다
    • 학습 곡선(Loss 그래프)을 분석하여 모델의 학습 상태를 진단할 수 있다
    • End-to-End 접근법의 장점과 한계를 비판적으로 분석할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    만약 AI가 전방 카메라 사진 한 장만 보고, 핸들을 얼마나 돌릴지 바로 결정할 수 있다면 어떨까요?

    여러분이 자전거를 탈 때를 떠올려 보세요. 앞에 커브가 보이면 "커브의 곡률을 계산하고, 현재 속도를 고려하여, 최적의 조향 각도를 산출한 뒤…" 이런 복잡한 과정을 거치지 않습니다. 그냥 눈으로 보고 자연스럽게 핸들을 꺾죠. 수백, 수천 번의 경험이 쌓이면서 뇌가 알아서 학습한 겁니다.

    End-to-End 자율주행은 바로 이 아이디어입니다. 복잡한 중간 단계 없이, 입력(카메라 이미지)에서 출력(조향각)까지 하나의 신경망이 한 번에 처리합니다. 2016년 NVIDIA가 발표한 PilotNet 모델은 이 개념을 실제 자동차에 적용하여 세상을 놀라게 했습니다.

    이번 장에서는 이 혁신적인 모델을 직접 만들어 봅니다. 앞 장에서 수집하고 전처리한 CARLA 시뮬레이터 데이터를 활용하여, 사진 한 장으로 핸들을 조종하는 AI를 Keras로 구현합니다.

    📚 핵심 개념¶

    개념 1: End-to-End 학습이란?¶

    🎨 비유로 시작

    자율주행을 만드는 방법을 요리에 비유해 봅시다.

    전통적 방식 = "레시피를 단계별로 따라가는 것" 1. 재료 손질 (이미지에서 차선 검출) 2. 양념 준비 (경로 계획) 3. 볶기 (제어 명령 생성) 4. 완성 (조향각 출력)

    각 단계를 전문가가 하나하나 설계해야 합니다.

    End-to-End 방식 = "맛있는 음식을 수백 번 먹어본 사람이 감으로 요리하는 것" 1. 재료를 보면 → 바로 완성 요리가 나온다

    중간 과정을 사람이 설계하지 않고, 신경망이 데이터에서 스스로 학습합니다.

    graph LR subgraph "전통적 자율주행 파이프라인" A[카메라 이미지] --> B[차선 검출] B --> C[물체 인식] C --> D[경로 계획] D --> E[조향각 출력] end
    graph LR subgraph "End-to-End 자율주행" F[카메라 이미지] --> G["하나의 신경망<br/>(모든 것을 한 번에)"] G --> H[조향각 출력] end

    📖 정확한 정의

    End-to-End 학습(End-to-End Learning) 이란, 입력 데이터(이미지)에서 최종 출력(조향각)까지의 전체 과정을 하나의 신경망이 직접 학습하는 방식입니다. 중간 단계(차선 검출, 물체 인식 등)를 사람이 별도로 설계하지 않습니다.

    💡 예시로 확인

    • 입력: 전방 카메라로 촬영한 도로 이미지 (200×66 픽셀)
    • 출력: 조향각 하나의 숫자 (예: -0.3은 왼쪽, +0.5는 오른쪽)
    • 학습 데이터: 사람(또는 시뮬레이터)이 운전한 수만 장의 (이미지, 조향각) 쌍

    신경망은 "이런 도로 모습일 때 운전자는 이만큼 핸들을 꺾었다"를 반복적으로 학습하여, 새로운 이미지가 들어와도 적절한 조향각을 예측합니다.

    개념 2: NVIDIA PilotNet 아키텍처¶

    🎨 비유로 시작

    PilotNet의 구조를 깔때기에 비유해 봅시다. 넓은 입구(큰 이미지)로 데이터가 들어가면, 점점 좁아지면서(특징이 압축) 마지막에 아주 작은 출구(조향각 숫자 하나)로 나옵니다.

    graph TD A["📸 입력 이미지<br/>200 × 66 × 3"] --> B["정규화 레이어<br/>픽셀값 0~1 변환"] B --> C["Conv2D 24개 필터<br/>5×5, stride 2"] C --> D["Conv2D 36개 필터<br/>5×5, stride 2"] D --> E["Conv2D 48개 필터<br/>5×5, stride 2"] E --> F["Conv2D 64개 필터<br/>3×3"] F --> G["Conv2D 64개 필터<br/>3×3"] G --> H["Flatten<br/>1차원으로 펼치기"] H --> I["Dense 100"] I --> J["Dense 50"] J --> K["Dense 10"] K --> L["🎯 출력: 조향각 1개"]

    📖 정확한 정의

    PilotNet은 NVIDIA가 2016년 논문 "End to End Learning for Self-Driving Cars"에서 발표한 CNN 기반 자율주행 모델입니다. 5개의 합성곱(Convolutional) 레이어와 3개의 완전연결(Dense) 레이어로 구성되며, 전방 카메라 이미지 한 장을 입력받아 조향각 하나를 출력하는 회귀(Regression) 모델입니다.

    💡 각 레이어의 역할

    • 정규화(Normalization): 픽셀값을 0~255에서 0~1로 바꿔서 학습을 안정화
    • Conv2D 레이어들 (5개): 이미지에서 특징을 추출
    • 앞쪽 레이어: 선, 모서리 같은 저수준 특징 감지
    • 뒤쪽 레이어: 차선, 도로 경계 같은 고수준 특징 감지
    • Flatten: 2D 특징 맵을 1D 벡터로 변환
    • Dense 레이어들 (3개): 추출된 특징을 조합하여 최종 조향각 결정
    • 출력 뉴런 1개: 조향각 (연속적인 숫자 하나)

    알아보기 📌

    회귀(Regression)란? 출력이 "고양이/강아지" 같은 범주가 아니라, "-0.35" 같은 연속적인 숫자인 문제를 말합니다. 분류(Classification)와 대비되는 개념이에요. 조향각은 -1.0(최대 좌회전)부터 +1.0(최대 우회전)까지 무한히 많은 값을 가질 수 있으므로 회귀 문제입니다.

    개념 3: 손실 함수와 학습 곡선¶

    🎨 비유로 시작

    시험을 보고 나면 점수를 확인하죠? 신경망도 마찬가지입니다. 매 학습 단계마다 "나의 예측이 정답과 얼마나 다른가?"를 점수로 매기는데, 이것이 손실(Loss)입니다.

    📖 정확한 정의

    MSE(Mean Squared Error, 평균 제곱 오차) 는 회귀 문제에서 가장 많이 쓰는 손실 함수입니다. 예측값과 실제값의 차이를 제곱하여 평균을 냅니다.

    수식으로 보면: - 예측 조향각이 0.3인데, 실제 조향각이 0.5라면 - 오차 = (0.3 - 0.5)² = 0.04 - 이런 오차들의 평균이 MSE

    MSE가 작을수록 모델의 예측이 정확하다는 뜻입니다.

    💡 학습 곡선 읽는 법

    학습이 진행되면서 Loss가 어떻게 변하는지를 그래프로 그린 것이 학습 곡선입니다.

    graph LR subgraph "좋은 학습" A["📉 train loss ↓<br/>📉 val loss ↓<br/>두 곡선이 함께 내려감"] end subgraph "과적합 Overfitting" B["📉 train loss ↓<br/>📈 val loss ↑<br/>검증 손실이 다시 올라감"] end subgraph "과소적합 Underfitting" C["📊 train loss 높음<br/>📊 val loss 높음<br/>둘 다 충분히 안 내려감"] end
    • 좋은 학습: 훈련 Loss와 검증 Loss가 함께 꾸준히 감소
    • 과적합(Overfitting): 훈련 Loss는 내려가는데 검증 Loss가 다시 올라감 → 훈련 데이터만 외워버림
    • 과소적합(Underfitting): 둘 다 높은 상태에서 안 내려감 → 모델이 너무 단순하거나 학습 부족

    개념 4: End-to-End 접근법의 장점과 한계¶

    🎨 비유로 시작

    End-to-End 학습은 마치 "통째로 외우는 공부법"과 비슷합니다. 영어 문법을 하나하나 배우는 대신, 영어 드라마를 수천 편 보면서 자연스럽게 익히는 거죠. 빠르고 효과적이지만, "왜 이 표현을 쓰는지" 설명하기 어렵다는 단점이 있습니다.

    📖 장점

    • 설계 비용 절감: 차선 검출, 경로 계획 등 복잡한 모듈을 따로 만들 필요 없음
    • 인간이 놓치는 특징 학습: 사람이 미처 생각하지 못한 도로의 미세한 패턴도 스스로 학습 가능
    • 빠른 프로토타이핑: 데이터만 충분하면 비교적 빠르게 동작하는 모델 제작 가능

    📖 한계

    • 블랙박스 문제: 왜 그런 조향각을 출력했는지 설명하기 어려움 → 사고 시 원인 분석 곤란
    • 대량의 데이터 필요: 다양한 도로, 날씨, 상황의 데이터가 없으면 일반화 성능 저하
    • 안전성 검증 어려움: 전통적 방식처럼 각 모듈을 따로 테스트할 수 없음
    • 극단적 상황 대처 부족: 학습 데이터에 없는 상황(갑작스런 장애물 등)에 취약

    생각해보기 💭

    실제 자율주행 회사들(Waymo, Tesla 등)은 End-to-End와 전통적 방식을 어떻게 조합하고 있을까요? 완전한 End-to-End만으로 충분할까요?

    🔨 따라하기¶

    앞 장(Chapter 11)에서 CARLA 시뮬레이터로 수집하고 전처리한 데이터가 있다는 전제로 진행합니다. 데이터가 없는 경우를 위한 더미 데이터 생성 코드도 함께 제공합니다.

    Step 1: 환경 준비 및 데이터 로드¶

    먼저 필요한 라이브러리를 설치하고 불러옵니다.

    # 필요한 라이브러리 설치 (Colab 기준)
# !pip install tensorflow matplotlib numpy

import numpy as np
import matplotlib.pyplot as plt
import tensorflow as tf

print(f"TensorFlow 버전: {tf.__version__}")

    이전 장에서 저장한 전처리 데이터를 불러옵니다. 데이터가 없다면 더미 데이터를 생성합니다.

    # === 데이터 로드 또는 더미 데이터 생성 ===

data_path = "carla_data_preprocessed.npz"

if os.path.exists(data_path):
    # 이전 장에서 저장한 데이터 로드
    data = np.load(data_path)
    images = data['images']        # (N, 66, 200, 3)
    steerings = data['steerings']  # (N,)
    print(f"저장된 데이터 로드 완료!")
else:
    # 더미 데이터 생성 (실습용)
    print("저장된 데이터가 없어 더미 데이터를 생성합니다.")
    np.random.seed(42)
    num_samples = 5000

    # 200x66x3 크기의 랜덤 이미지 생성
    images = np.random.randint(0, 256, (num_samples, 66, 200, 3)).astype(np.float32)

    # 조향각: -1.0 ~ 1.0 범위 (대부분 직진에 가까운 분포)
    steerings = np.random.normal(0, 0.3, num_samples).astype(np.float32)
    steerings = np.clip(steerings, -1.0, 1.0)  # 범위 제한

print(f"이미지 shape: {images.shape}")
print(f"조향각 shape: {steerings.shape}")
print(f"조향각 범위: [{steerings.min():.3f}, {steerings.max():.3f}]")

    Step 2: 데이터 탐색 및 분할¶

    모델에 투입하기 전에, 데이터가 어떤 모습인지 확인합니다.

    이제 핵심입니다! NVIDIA PilotNet 아키텍처를 Keras로 구현합니다.

    def build_pilotnet(input_shape=(66, 200, 3)):
    """
    NVIDIA PilotNet 아키텍처 구현

    구조:
    - 5개 합성곱 레이어 (특징 추출)
    - 3개 완전연결 레이어 (조향각 결정)
    - 출력: 조향각 1개 (회귀)
    """
    model = keras.Sequential([
        # --- 입력 ---
        layers.Input(shape=input_shape),

        # --- 합성곱 레이어 (특징 추출부) ---
        # Conv1: 24개 필터, 5x5, stride 2
        layers.Conv2D(24, (5, 5), strides=(2, 2), activation='elu'),

        # Conv2: 36개 필터, 5x5, stride 2
        layers.Conv2D(36, (5, 5), strides=(2, 2), activation='elu'),

        # Conv3: 48개 필터, 5x5, stride 2
        layers.Conv2D(48, (5, 5), strides=(2, 2), activation='elu'),

        # Conv4: 64개 필터, 3x3
        layers.Conv2D(64, (3, 3), activation='elu'),

        # Conv5: 64개 필터, 3x3
        layers.Conv2D(64, (3, 3), activation='elu'),

        # --- 1차원으로 변환 ---
        layers.Flatten(),

        # --- 완전연결 레이어 (판단부) ---
        layers.Dense(100, activation='elu'),
        layers.Dense(50, activation='elu'),
        layers.Dense(10, activation='elu'),

        # --- 출력: 조향각 1개 ---
        layers.Dense(1)  # 활성화 함수 없음 (회귀이므로)
    ])

    return model

# 모델 생성
model = build_pilotnet()

# 모델 구조 확인
model.summary()

    알아보기 📌

    ELU 활성화 함수를 사용하는 이유는? ReLU와 비슷하지만, 음수 입력에서도 약간의 출력을 허용하여 "죽은 뉴런(dead neuron)" 문제를 방지합니다. PilotNet 논문에서 ELU를 사용했기 때문에 원논문을 따릅니다.

    출력 레이어에 활성화 함수가 없는 이유는? 조향각은 -1.0 ~ +1.0의 연속적 숫자이므로, 출력값에 제한을 두지 않는 선형 출력을 사용합니다.

    metrics=['mae']  # 평균 절대 오차 (해석하기 쉬운 지표)
)

    # === 모델 학습 ===
history = model.fit(
    X_train, y_train,
    epochs=30,               # 전체 데이터를 30번 반복 학습
    batch_size=64,            # 한 번에 64개씩 처리
    validation_data=(X_val, y_val),  # 검증 데이터
    verbose=1                 # 학습 과정 출력
)

print("\n✅ 학습 완료!")

    알아보기 📌

    Epoch, Batch Size란? - Epoch: 전체 훈련 데이터를 한 바퀴 도는 것. 30 epoch = 30바퀴 반복 학습 - Batch Size: 한 번의 가중치 업데이트에 사용하는 데이터 수. 64개씩 묶어서 처리하면 메모리 효율적이고 학습이 안정적
